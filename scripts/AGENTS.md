# AGENTS.md — 管理与验收脚本

- 根 `package.json` 是命令入口；区分静态检查和依赖 dist 的运行检查，错误非零退出。
- 默认无真实付费调用，live 显式开启；日志脱敏，截图/题图/构建产物进入被忽略的 `.runtime/`。
- 生成器只读受审清单，不扫描开发规则或 notes；服务器配置、开发上下文和外部播放器不得装入 APK。
- 不隐式安装最新依赖或擅自操作设备/部署；子进程有超时、取消和清理，服务记录 PID/URL。
- 管理检查只读源文件，不自动改历史、放宽长度或更新冻结哈希；违规退出和边界输入必须有回归。
- 规则见 [维护流程](../docs/cookbook/change-management.md)，命令见 [开发流程](../docs/development.md)。
