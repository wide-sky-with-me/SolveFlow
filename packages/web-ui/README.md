# Web共用界面

`theme.css` 提供公网精简版已有的颜色、字体、基础控件和焦点；`icons` 提供同一套SVG；`rich-text` 提供禁用原始HTML及远程图片的Markdown/KaTeX；`select`提供同主题选择列表、键盘操作及表单验证；`dialog`共用原生HTML弹窗的焦点隔离、Esc、初始焦点和关闭后恢复。背景滚动锁定由主题维护，应用分别提供紧凑确认框或宽阅读布局。

公网单题版与中心考试平台通过公开入口消费。管理布局归应用自身；RN继续使用既有主题，不导入DOM组件。本包保留TSX，由消费方以自动JSX运行方式打包。

选择列表打开时滚动到当前项；Tab继续后续表单，Esc回到触发按钮，不将焦点留在已移除列表。
