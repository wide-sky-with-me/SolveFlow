# AGENTS.md — 解题与 Pi 适配

阅读 [Agent 子系统](../../docs/subsystems/agent.md)；版本以本包清单、锁文件和已安装类型为准。

## 循环与资源

- 只有 `src/pi/` 直接导入 Pi；使用锁定 SDK/Extension，不 Fork 上游、不用 Pi CLI 子进程充当服务。业务编排负责预算、独立验证、持久化与最多一次修正，不自建循环。
- 核实锁定 SDK 的图片、工具选择、事件、abort/dispose、ResourceLoader 语义；main 文档不能代替发布版回归。升级独立验证。
- 设备资源由受审清单生成；服务端 ResourceLoader 仅发现批准根。禁止发现开发 cwd/HOME/父目录、AGENTS/CLAUDE、notes、任意扩展或上传目录。
- 保留 Skill 描述→受限 read→正文/参考资料的按需加载，可组合学科。明确考试时仅预加载获准考试通则与参考；Skill 不是题库，不授予权限。
- Solver 使用受限 read 加已配置业务/MCP 工具；不能一刀切禁内置工具或全部放行。ls/find/grep 按依赖授权；bash/powershell/write/edit 默认关闭，只按批准且验收的隔离能力开放。
- 文件工具共用规范化路径/只读根/owner-run 校验，防穿越、符号链接、竞态逃逸。cwd 和提示词不是沙箱；不并存未受限同名工具。
- 每 run 固定工具名、来源、schema、权限快照，未知能力或权限扩大失败关闭；依赖不可用的 Skill 不得宣称完整可用。通用斜杠命令、模板、文件展开关闭。

## 工具与生命周期

- calculate 只接受受限 AST；不使用 eval、动态函数、属性访问、赋值或文件/网络能力。
- python_math 只接受获准结构化操作，不接受代码、shell、路径、任意方法或默认求值的 sympify/parse_expr。无网、无宿主访问、非 root、只读、CPU/内存/PID/时限与强杀验收完成前不注册；应用不挂 Docker socket。
- 搜索只走批准供应商，发送必要去标识查询；引用必须关联实际证据。
- MCP 由固定 client/Extension 桥接；stdio 程序及参数、HTTP 端点、凭据由管理员指定，不由模型 bash 或 npx 动态启动。
- MCP 按 server+tool 白名单、防重名、schema/结果验证、输出/超时/外发限制；readOnlyHint 不能代替副作用审查。无确认机制时不注册发送、写入、删除工具。
- 身份凭据隔离，能力撤销立即生效；搜索别名合计预算。断连降级和取消向下传播，共享连接引用计数回收，finally 释放订阅、会话与子任务。

## 解题与验证

- Solver/Verifier 共用内容政策；违规候选不得作为未验证答案发布。题干充分时尽力给结论，选项不全或非关键模糊作为明确警告；决定结论的关键条件缺失才澄清，不凭图形比例补条件。
- 单题按需校验、批量自动校验及服务端自动路径各按契约执行。Verifier 独立上下文、含原图且无工具；UNKNOWN、超时和无效结构不冒充 PASS。
- FAIL 最多一次修正；有效候选降级必须显式未验证。只展示教学步骤与安全阶段摘要，不输出内部思维链。
- 设备累计时间默认不限，阶段超时和模型/工具次数有界；保留服务总时间、格式修复、搜索和校验共用预算；失败、重试、Skill/MCP 调用均计数。用户备用组优先、无备用时可由已配置校验组最多接手一次，非政策澄清可重判，替换答案仍校验；禁止无界重试或模型自行选择服务。
- 诊断不得记录题图、题干、聊天、密钥、原始响应或 thinking；供应商异常映射安全错误。
- 修改模型适配、prompt 或学生 Skill 必须做行为回归；真实评测单独 opt-in，不以假结果或另一 LLM 的单独评分宣称准确率。
