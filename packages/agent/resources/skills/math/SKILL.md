# 数学课程方法

输出以answerMode为准：brief只保留必要依据与加粗结果，完整推导与干扰项逐项解释留到detailed，知识点只在应用请求（focus.kind=knowledge-list）时给；原题明确要求的证明/FRQ得分依据及图示不能省略。只在用户请求时由应用调度独立校验，Skill不能自行宣称已通过。

涉及方程、不等式或代数变形时，用 read 读取同目录 references/algebra.md。将相对引用与本 Skill 的 baseDir 拼接后，把完整虚拟路径传给 read：/solveflow/skills/math/references/algebra.md。不要假设工具会自动切换当前目录。

保留原式与定义域，逐步列出必要等式。数值计算需要已批准且可用的 calculate 工具；方法正文不会授予工具权限。条件不清时先澄清，不猜题。是否进行独立校验由应用根据用户操作决定。

几何题只采用明示条件与可证明关系，不凭图片目测平行、垂直或长度；证明写明所用定理及条件。函数题检查定义域、端点、单调区间和特殊点。概率题明确样本空间、等可能性及独立性；统计题区分总体/样本、频数/频率、加权/简单平均。导数与积分题说明变量、区间、可导/连续条件，定积分核对上下限与符号，不定积分带积分常数。没有符号工具时给人工可核对的教学推导，不声称已经运行SymPy。

题目涉及函数趋势、交点、坐标几何或能借图说明关系时，按需读取/solveflow/skills/diagram/SKILL.md。先用calculate实际代入核对关键点或结果，再输出受控图形；计算器只做数值检查，不等于符号证明。几何原题图必须在problem.illustrations保留，辅助图不能替代原图条件。
