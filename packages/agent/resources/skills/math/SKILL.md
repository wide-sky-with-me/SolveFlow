# 数学课程方法

输出以answerMode和系统题型规则为准：选择题用selectedOptions表达结论，answer只留决定性理由；非选择题遵守结果格式。brief不输出额外推导或知识点，detailed与按需请求按系统分层；原题要求的证明、FRQ依据和图示必须保留。独立校验由应用调度（批量自动，单题按需），Skill不能自行声称通过。

方程、不等式或代数变形先检查定义域、除数零值、变形等价性及回代；本次已加载的考试方法足以覆盖时无需重复读取。仅在需要补充代数检查方法时，用 read 读取 /solveflow/skills/math/references/algebra.md；将相对引用与本 Skill 的 baseDir 拼接成完整虚拟路径，不假设工具会切换目录，也不重复读取已加载正文。

保留原式与定义域，逐步列出必要等式。数值计算需要已批准且可用的 calculate 工具；方法正文不会授予工具权限。仅影响所求的关键条件不清才澄清，不猜题；题干充分而选项不全时先给数值或表达式结论并说明选项待对应。是否进行独立校验由应用根据用户操作决定。

几何题只采用明示条件与可证明关系，不凭图片目测平行、垂直或长度；证明写明所用定理及条件。函数题检查定义域、端点、单调区间和特殊点。概率题明确样本空间、等可能性及独立性；统计题区分总体/样本、频数/频率、加权/简单平均。导数与积分题说明变量、区间、可导/连续条件，定积分核对上下限与符号，不定积分带积分常数。没有符号工具时给人工可核对的教学推导，不声称已经运行SymPy。
配对计数先核对配对集合是否覆盖原项、端点是否重复、固定点/自配对项如何处理，用总项数守恒交叉检查。关键整数或小数的零位数、位数和符号从原图逐字符核对，不能靠视觉印象或复述候选的计数；具体反例先验证前提确实成立，再检验结论。表格按题内例子确认每格对应的行列对象和转移方向，累计量取差，往返总量不当成单程。

需要新增辅助图时，按需读取/solveflow/skills/diagram/SKILL.md；涉及关键点或结果的数值运算才用calculate核对，定性读原图不强制计算或新增绘图。计算器只做数值检查，不等于符号证明。几何原题图必须在problem.illustrations保留，辅助图不能替代原图条件。
