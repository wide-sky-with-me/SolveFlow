# 物理课程解题

输出以answerMode为准：brief只保留必要依据与加粗结果，完整推导与干扰项逐项解释留到detailed，知识点只在应用请求（focus.kind=knowledge-list）时给；原题明确要求的证明/FRQ得分依据及图示不能省略。只在用户请求时由应用调度独立校验，Skill不能自行宣称已通过。

先从原图提取研究对象、初末状态、已知量、方向约定、单位及所求。输入subject只是提示，不依赖用户手动选择学科；模糊数字、接线节点或未说明的关键条件先澄清。

本Skill面向物理大类，不限于下列示例或某个年级。先依据题目层次选择模型，遇到更高阶课程问题也按明示条件和可检查推导处理；不能仅因没有对应参考文件拒答。概念、比较、证明、计算、图像与实验题均适用，不要求每题都有计算或配图。

- 力学：运动学、受力与平衡、功和能、动量、圆周运动与引力；先划分对象及过程，再选择守恒或动力学方法，检查外力/外功及系统边界。
- 热学与热力学：温度、内能、热量、物态变化、气体状态及过程；区分状态量与过程量，注明功热正负约定、系统及近似条件。
- 电磁学：静电场、电势、直流/交流电路、磁场与电磁感应；区分场量和电路量，读清节点与方向，公式只用于其成立条件。
- 振动、波与光学：周期、频率、传播、干涉/衍射、反射/折射、成像；区分质点运动和波传播，几何光学与波动光学按题设选择。
- 近代物理基础：课程中的光电效应、原子/核、量子或相对论基本关系；说明经典模型的局限和题目采用的假设，不把近似结论扩展为无条件定律。
- 实验与测量：仪器读数、有效数字、误差来源、图像拟合、控制变量和结论范围；不虚构测量值，不把系统误差与随机波动混为一谈。

- 先建模再代数：指出采用哪条定律及条件，例如恒加速度、理想电源、忽略空气阻力。题目没有授权的近似不能悄悄加入；不默认所有运动都匀加速、所有电阻都恒定。
- 用统一单位建立方程，区分标量与矢量、位移与路程、速度与速率、合力与单个力。重力加速度优先用题设值，需要近似时明确说明采用值。
- 有数值时使用calculate核对关键中间量和最终量，先完成单位换算再提交纯数字表达式；方向、量纲、正负号和适用条件仍需教学推导，计算器不验证这些关系。不为同一结果机械重复调用。
- 根据题型按需读取 [模型与检查表](references/models.md)，完整虚拟路径为 `/solveflow/skills/physics/references/models.md`。
- 图像题读清轴变量、单位与刻度：斜率/面积的意义取决于坐标轴。有助于表达运动曲线、能量关系或光线路径时按需读取 `/solveflow/skills/diagram/SKILL.md`。当前图形没有箭头/电路元件等专用语义，不能把未标方向的线段宣称为完整受力图，不能凭空补接线。
