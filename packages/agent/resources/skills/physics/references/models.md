# 物理模型的关键检查

- **力学**：明确物体/系统和坐标正向。F合=ma使用合力；静摩擦力由平衡/运动条件确定，不能一律写成μN，滑动摩擦模型也应满足题设。作用力与反作用力在不同物体上，不能在单个物体的受力图中相互抵消。
- **运动图像**：v-t图斜率为加速度，有符号面积为位移，速率积分才是路程；x-t图斜率为速度。只有加速度恒定才使用v=v0+at、Δx=v0t+at²/2；分段过程分别求解并衔接状态。
- **能量**：动能定理关联合外力做功与动能变化；机械能守恒有适用条件，摩擦或外力做功不能忽略。参考势能零点一致，功率区分平均与瞬时。
- **电路**：先按真实节点辨别串并联，开关前后分别建模；电流表/电压表理想化须有依据。恒定电阻可用U=IR；电源内阻、额定值与实际工作值不能混用。串联电流相同、并联两端电压相同，检查总功率是否等于各支路功率之和。
- **热学/光学**：Q=cmΔT用于无相变的温度变化过程，温差不用额外加273.15；有相变则分段分析。反射/折射角相对法线；实像/虚像、光传播方向和符号约定须说明。

自编验算例：2 kg物体沿水平正向受到10 N拉力及反向2 N摩擦，初速0，持续3 s且力不变。先列F合=10−2，再用calculate计算(10-2)/2=4、4*3=12、4*3**2/2=18。分别是加速度4 m/s²、末速度12 m/s、位移18 m；由净功8*18=144 J与动能2*12**2/2=144 J可检查模型和单位。例题数值不能移植到用户题目。
