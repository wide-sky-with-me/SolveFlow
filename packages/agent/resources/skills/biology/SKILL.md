# 生物课程解题

输出以answerMode和系统题型规则为准：选择题用selectedOptions表达结论，answer只留决定性理由；非选择题遵守结果格式。brief不输出额外推导或知识点，detailed与按需请求按系统分层；原题要求的证明、FRQ依据和图示必须保留。独立校验由应用调度（批量自动，单题按需），Skill不能自行声称通过。

先识别研究层次、对象、环境/实验条件与所求；准确复述显隐性约定、亲本基因型、图例、坐标轴和实验组。模式图结构不能凭位置猜名称，题干或关键标注不清先澄清。

概念与图表选择题先明确每个陈述问的对象、范围和限定词，再分别判断真假，最后按完整选项文本对应标签；“可能”不能当成“必然”，“直接机制”不能扩大为所有相关过程。brief只保留决定答案的可检查依据，不输出冗长逐项推导。
区分单个细胞内部修复与组织层面的细胞替换；相关过程不一定满足题目指定层次。血管/膜运输模式图逐一定位标签、连接的起点和终点、箭头尖端，再确定名称和方向，不能凭上下位置或常识改写静脉/动脉等原选项。遗传题保留所有题设允许的亲代条件，区分体细胞与生殖细胞的新变异；may/could只需合法可能性，always/must须排除反例。
单个细胞体积增加、细胞内成分修复、组织生长/损伤修复和旧细胞替换分别判断，不能将教材概括的“生长与修复”不加层次地套给所有陈述。机制必须确实作用于该陈述对象，不从过程的常见用途推出每个近似词语都成立。

- 膜运输先判断物质、跨膜方向和梯度。区分维持跨膜浓度差的机制与膜外分布的成因；不因图中有梯度就同时选择所有运输过程。主动运输可逆梯度维持差异，扩散趋于减小对应梯度；渗透须确认讨论的是水及其跨膜条件。
- 图表先读轴、单位、图例和同一比例尺。风筝图横向区间表示分布范围，纵向宽度按题设表示个体数量；相同横向范围不等于相同丰度。区分物种丰富度、个体数与密度，不把示意面积或屏幕宽度当未经题设支持的数值。
- 在题目指定坐标处按图例读取风筝图的宽度，不能用整段覆盖范围代替该点读数；零宽度不能仅因区间经过此处就算作有个体，须遵守题设的出现/检测约定。宽度方向、数量或相对丰度含义由本图图例确定，不把一种布局套给所有图。无唯一最大值或单位不明时保留这种不确定性，不自行加入排序规则。
- 种群曲线先确认纵轴是某时刻的数量、累计数量还是变化速率；数量平台只说明净变化接近零，不能直接推出没有繁殖或死亡。纵轴带千、百分比等倍率时先换单位；图外时段不外推。
- DNA组成先确认单链或双链及百分比的分母；题给一条链而询问完整双链时计入互补链。不能把单链某碱基比例直接当整个分子的比例。

读不清决定答案的图线宽度、坐标或标注时说明具体缺失，请求保留图例和尺度的局部补图；不以放大后的猜测代替原图证据。

本方法面向生物大类，不限于遗传概率或初高中章节。概念辨析、结构识图、机制解释、材料分析、数量关系和实验设计分别选择方法；高阶课程题同样先明确模型、证据与限制，不把缺少某篇参考文件当成不能解答。

- 细胞与分子：生物大分子、细胞结构、膜运输、酶与信号；按结构—功能—条件解释，区分不同细胞/分子层次和因果链中的直接、间接作用。
- 代谢与能量：光合作用、呼吸及相关代谢过程；核对物质来源、反应位置、能量转化和限制因素，不能只用单个指标替代全过程。
- 遗传、发育与进化：遗传信息表达与传递、变异、分离/组合、自然选择及群体变化；假设必须来自题设，区分个体变化与群体频率、相关与遗传因果。
- 植物/动物生理与稳态：营养、运输、神经/体液调节、免疫、生殖与环境响应；区分反馈、调节目标和实际观察，不把课程模型当个人医疗诊断。
- 生态与多样性：种群、群落、生态系统、相互作用、物质循环、能量流动及保护；读清空间/时间尺度，不混淆数量、密度、丰富度等指标。
- 实验、数据与技术原理：对照、变量、重复、样本、图表、证据链与方法局限；课程技术可解释原理，危险操作和个人健康问题仍受系统边界约束。

- 遗传题先判断题设是否允许孟德尔分离/自由组合，区分基因型、表型、显性及是否携带；不能默认未知亲本是杂合子。概率的相加/相乘须分别满足互斥/独立或明确条件概率条件。
- 实验题辨明自变量、因变量、控制变量与对照，区分重复与新增处理；从实际结果说明支持什么，不把“可能机制”写成已证明的唯一原因。
- 代谢题区分物质来源、反应位置与能量变化；生态题区分个体/种群/群落/生态系统，物质循环不能写成能量循环。数据量不足时给范围或澄清，不补造实验数据。
- 遗传概率、倍率或图表数量计算用calculate核对，定性概念题不为凑工具调用计算。按需读取 [遗传与实验判断](references/genetics-and-experiments.md)，虚拟路径 `/solveflow/skills/biology/references/genetics-and-experiments.md`。

通过problem.illustrations保留原题显微图、装置图及结构图，不能用无关示意替代证据。可用数量随时间变化、剂量与响应等课程数据帮助解释时，按需读取 `/solveflow/skills/diagram/SKILL.md`；现有坐标图不是显微图/细胞结构绘制工具，不能捏造观测图像或把连线插值说成测得数据。

knowledgeDetails选本题直接考查的概念，解释定义、成立条件、本题应用和常见误判；定向追问结合本题的小例子回答，不串到其他题。教学答案交独立Verifier，不能以记忆结论或历史PASS代替检查。

只做课程解题，不据题图提供个人诊断/用药建议；危险生物操作、病原体培养/增强等请求服从固定CONTENT_POLICY，普通生物原理和安全教育不因关键词而一概拒答。

图表表达：区分实际观测点、连线示意与理论模型；样本量、误差线、显著性不能凭空添加。遗传样本空间适合用配子组合表说明，群体变化有题给数值时再绘制坐标图，不强行为每道概念题配曲线。
