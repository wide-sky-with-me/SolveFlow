# 遗传概率与实验推断

- 完全显性且无其他机制的单基因Aa×Aa，子代基因型AA:Aa:aa=1:2:1，表型才是3:1。比例是模型概率，不保证小样本实际个数严格相等。
- 条件概率须重新限定样本空间：上述模型中已知子代表现显性，杂合概率是(1/2)/(3/4)=2/3，不是1/2。
- 多基因分别计算再相乘前，要确认独立分配等条件；连锁、致死、性别相关遗传或外显率改变时不能直接套9:3:3:1。
- 对照实验尽量只改变所研究因素，其余条件一致并有合适重复；观察性数据的相关不等于因果，缺失对照不能靠结论措辞补齐。
- 图表先读对象、单位、基准组、样本量和误差线含义。相对增长率的分母是原值，区分百分比与百分点；图外的范围不能无条件外推。
- 光合/呼吸等课程图像须区分净量和总量、测量条件与组织对象；根据题设确定是否可用“总光合=净光合+呼吸”的模型，不能把任何坐标读数直接当总量。

自编验算例：完全显性，Aa×Aa，无致死、无选择差异。问隐性表型概率与显性子代中杂合概率。calculate核对0.5*0.5=0.25、0.5/0.75=2/3的数值近似；教学结论保留精确分数1/4和2/3，说明后者以显性子代为条件。工具小数不替代分离规律或条件概率推导。
