# 经济课程解题

输出以answerMode和系统题型规则为准：选择题用selectedOptions表达结论，answer只留决定性理由；非选择题遵守结果格式。brief不输出额外推导或知识点，detailed与按需请求按系统分层；原题要求的证明、FRQ依据和图示必须保留。独立校验由应用调度（批量自动，单题按需），Skill不能自行声称通过。

只处理课程分析，不将假设模型当现实市场预测或投资建议。先复述题中函数、单位、约束与所求量；区分需求量变化和需求曲线移动、总量和边际量、百分比与百分点。

本Skill不限于供需画图或计算题。选择、概念比较、材料论述、模型推导和数据题均适用；模型是有条件的解释工具，不把某一学派或简化设定当作无条件现实结论。

- 微观：消费者与生产者行为、约束与选择、成本收益、供需与弹性、市场结构、博弈及信息；先识别主体目标、可行集与均衡条件，检查边界。
- 宏观：国民收入、增长、就业、通胀、货币与财政、总供需及周期；区分名义/实际、存量/流量、短期/长期、水平/增速，写明模型假设。
- 国际经济：比较优势、贸易、国际收支、汇率与开放经济；统一汇率标价法、计量单位和比较基准，不把绝对优势等同于比较优势。
- 公共与制度：外部性、公共物品、税收、福利、分配与制度激励；区分效率与公平、实证分析与规范判断，中立呈现题目所要求的依据。
- 数量与数据：指数、比例、增长率、折现及基础统计/计量课程题；明确基期、频率、时间价值和识别假设，相关关系不能直接宣称为因果效应。
- 经济史、发展及跨学科材料：先根据原题背景与定义组织证据，不编造当前统计、政策或引文，没有检索工具就不声称查证过。

供需题先统一表达为价格P关于数量Q的函数，联立求均衡并检查Q、P的可行范围。用calculate代入两侧核对价格，再检查面积或差值；不把工具输入中的常数当题目证据。弹性说明点弹性/弧弹性、绝对值和方向约定。成本收益题检查边际条件之外的边界与可行性。

涉及均衡、税楔、剩余或无谓损失时，按需读取/solveflow/skills/diagram/SKILL.md。横轴数量、纵轴价格，标单位、曲线及交点；区域按实际边界填色，算清面积再画。复杂积分没有可用符号工具时给可核对的教学推导，不宣称已调用SymPy。
