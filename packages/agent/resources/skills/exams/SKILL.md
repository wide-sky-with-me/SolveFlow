# SAT / ACT / AP 专项方法

只在原题、标题或用户补充明确考试时采用其专属规则；普通英文课程题不能自动认定为某种考试。看得到的原题指令、版本和科目优先；缺少影响答案的材料、选项或限定条件才澄清，不追问无关年份。保持problem.subject为数学、英语等学科，不写SAT/ACT/AP。

来源已明确时，作答前必须读取本目录一个对应参考：SAT → references/sat.md；ACT → references/act.md；AP → references/ap.md。参考方法足够时直接求解；仅遇到尚未覆盖的方法才按需组合math、physics、chemistry、biology、economics或general，不能因学科名自动多读一套。已知本题考试时，本正文和对应参考在同一轮read请求中读取，不逐轮探索已知路径。相对路径按当前SKILL的目录解析，使用实际read支持的完整路径。

## 共用核对

- 保留英文关键语句、否定词NOT/EXCEPT/LEAST、选项字母及文本、图表标题/单位与小问标号，不能翻译后丢失语法考点。解释默认中文；要填写的英文句子或作答语言遵守原题要求。
- 选择题逐项核对条件，selectedOptions直接填写所选原始标签数组，例如["C"]；answer只写最多1–2句决定性理由，不写答案字母标题。前端分别渲染标签与解释，不从文本猜选项。problem.options完整逐项保存所有选项，题干不重复选项。保留F/G/H/J等原始标签，不按位置重编号；未看清选项就不要猜字母。详细排除过程按需展开。
- 填答题区分所求变量/组合/单位，给精确值与需要输入的格式；有多解时按本题要求选一个或列全，不把“任意一个”误写成全部。
- FRQ按(a)(b)(c)原编号回答，所有小问属于同一道题，不拆成questions。identify只需准确结论；justify/explain/show work必须给能支持结论的必要依据，哪怕answerMode=brief也不能省掉；完整教学推导才放按需步骤。
- 简洁不等于漏答：保留本题要求的列式、因果/文本证据、图示或单位；不额外添加第二种方法、重复验算或可选背景。核心结论加粗。题目明确要求论述/证明时，提供完成该任务所需的最短完整论证，不以一条结论代替。
- 未提供本题官方rubric时只说明必要作答要素，不宣称满分、不虚构逐点分值、年级总分或SAT/ACT/AP总分换算。给出考试名称不代表能访问题库、Bluebook、官方评分系统或联网。
- 学习验算仍可用已批准calculate；无计算器小节的公开解法须可手算，不能把工具输出当作考场允许的方法。不得执行代码或改变现有内容安全规则；中立历史/政府课程允许。

来源为截至2026-09-17核对的官方静态参考；参考链接不是本题答案证据，不能据此伪造citationIds或声称实时检索。

工具按实际必要性使用：阅读理解、语法、写作目标等没有数值运算的题，不调用calculate；禁止为了走流程计算1+1、计数字母或复核选项编号。简单读图比较无需额外拟合或重复验算；需要数值工具时只验算影响结论的表达式。
