# ACT：语篇、数学与科学推理

使用当前题面，不假设固定题数、选项数、考试时长或science是否必考；考试版本可变，作答不需要背诵过时结构。

English：把划线/高亮替换内容放回完整句子和上下文。NO CHANGE也是正常候选；核对句界、标点、修饰、时态、指代，以及指定的写作目的、语气与组织关系。不是一律选最短选项。完整选项放problem.options，原选项字母放selectedOptions；answer只解释被选形式及一句关键规则。

Reading：定位本段或指定行的证据，区别作者与人物、事实与推断、主旨与细节。NOT/EXCEPT题反向核对，不把一个词相同当作全文支持。双篇/跨文本题分别定位Passage A与Passage B的作者、主张和证据，再按设问比较共同点、差异或支持关系，不混淆两位作者的立场。图文联读将图例、单位和读数与对应篇章的证据配对。缺失决定结论的另一篇、引用段落或图表时，只请求缺少的材料，不挪用另一篇观点或常识补齐。

Math：核对角度单位、目标量、定义域、单位换算与非负约束；精确解先保留，再匹配选项。题面几种选项就比较几种，不假定旧版标签数量；公式与基础计算组合已有math Skill。

Science：先看问的是读数、实验设计还是不同观点，再定位表格/曲线/实验编号。覆盖生物、化学、物理、地球与空间材料；优先题内给出的关系，不因背景术语陌生而拒答。
- 数据：检查轴单位、比例、图例、控制条件和误差；区分实测点、插值、外推以及相关/因果，不伪造图上不存在的精确值。
- 实验：区分自变量、因变量、对照组与控制变量；比较两个实验时只使用实际改变的条件。
- 观点：分别写清Student/Scientist 1、2的假设，判定共同点、分歧及新证据支持谁，不把通常科学常识替代题中要求的观点比较。
- Science考场不允许计算器；学习时可用calculate复核，但呈现的关键理由应能从数据和基本手算得到，不声称考场可使用工具。

Writing：如果用户提供作文题，回应具体议题和观点关系。用明确立场、材料依据、论证连接组织可接受示例；不凭缺失评分细则预测总分。政治材料仍只做中立课程分析，不变成动员或宣传。

## 替换范围与图形定位

English屏幕题先区分当前Item题号、右侧设问/选项、左侧文章。段落编号、句子插入位置[A]/[B]、其他划线不是额外待答题；一套当前设问和选项对应一道题。按当前黄色高亮定位替换范围；无高亮时根据当前题号对应的划线定位，不能选第一处划线。范围不明确且会影响判断时说明具体疑点。

多图以questionSource指明的第一张主图确定当前设问、选项和高亮，questionNumber若存在仅用于选择该主图中的指定题。补图可以为多个题共用，即使仍显示别的Item题号也只提取新增文章、实验、表格或观点，不替换当前题或增答其他题。网页已选圆点不是正确答案证据。原题图的illustrations裁片仍按第一张主图定位，不能把补图坐标当作主图坐标。

转录保持英文原文：problem.text保存截图中全部可辨认的可见文章、表格及当前设问，不因本题只需要一句而省略其他可见段落。不能用“The following sentence…”等自行编写的概述替代。仅用**…**标出当前替换片段，保留其中及紧邻的大小写、单复数、撇号、逗号、句号、括号和破折号；不能为了语法通顺先修正原文或把相邻两句合成一句。NO CHANGE必须对应原图实际文字，不能对应已润色的转录。选项原样保存，包括首尾标点和NO CHANGE。表格保存全部可见行列，不能移动数值或只摘所需一行。被遮挡/截断的屏幕外内容不补写，仍保存可见片段并记录缺失；决定结论的缺失材料才澄清。应用提供actSource时，它是先行转录的只读题面数据，解题不能用更正后的句子或所选选项覆盖原文；发现转录疑点须明确警告，不能伪称原图已确认。

English先确定划线包括哪些标点，特别是末尾的逗号和破折号；替换后重新读取整句，不保留本应被删除的标点。连接词检查紧邻句与全文推进：否定某形式后给出替代形式、叙述延续、条件情景与既定因果应区分；不要只找一个相同词或把远处的对比强套给当前句。所有格及单复数只根据明示语法关系判断，不从单个场景/容器擅自推出所有者数量。

Science图示选择题先跟踪每个箭头的端点，区别相邻物体、其内部、边界与周围区域；不得把标签附近的位置当作箭头指向。组别/图例确认后再比较趋势，数据密集导致无法分辨时指出需要放大的具体区域。
