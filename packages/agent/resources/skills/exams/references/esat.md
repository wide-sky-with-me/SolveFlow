# ESAT：数理应用与无计算器解题

适用于明确标为ESAT的练习题；优先本题模块、指令和可见条件。2026-10-02核对UAT-UK的2026/27规范：五个模块为Mathematics 1、Mathematics 2、Biology、Chemistry、Physics；每模块27道选择题、40分钟，单独计时，剩余时间不转移。所有考生考Maths 1，多数课程再要求两个模块，具体组合取决于课程，不能说所有人必须考五科。所有模块假定Maths 1知识。不可使用计算器或词典，答错不倒扣；分别报告模块成绩，不将练习正确率换算成官方1–9分。

## 解题方法

先从题面确认所求量和限制，再选择最短的可靠推导。选择题保留所有可见原始选项标签与文本；完全无标签时按系统规则使用有说明的应用索引，局部标签或选项不全但题干可独立求解时，给出结论并提示人工匹配；只有影响推理的关键条件缺失才澄清。只在结果和完整选项文本对应后填写selectedOptions，不凭近似外观选字母。只有缺失信息影响答案才澄清，不为解一道题要求用户补全报考模块。

- Mathematics 1：比例、百分比、代数、几何、数据与概率题先统一单位和分母；连续百分比变化不能直接相加，逆向百分比须恢复原基数。面积/体积缩放不能沿用长度倍率；均值考虑权重，概率考虑是否放回及独立性。保留分数、根式或π，必要时用上下界排除选项，避免过早四舍五入。
- Mathematics 2：函数与图像、数列、三角、指数对数及微积分按本题所需使用；先检查定义域和区间，再讨论根、极值或积分。平方、约分、除以变量都要检查丢根/增根及零值；驻点不必是极值，闭区间最值还须比较端点。不要把数值搜索当证明。
- Physics：明确系统、方向与假设，先列量之间的关系，再代数求解；检查量纲、SI前缀、符号和数量级。区分图线斜率、面积与纵坐标，位移与路程；读清节点再判断串并联，开关前后分别分析。箭头方向不能用文字猜测。
- Chemistry：反应计量先配平、再用物质的量比例并检查限制反应物；区分粒子数、质量和浓度，核对电荷、单位和题给反应条件。原子/离子的质子数、中子数、电子数分别判断，电离不改变核内粒子；速率变化不等于最终产量变化。不因熟悉某反应便补入题目没有的条件。
- Biology：根据机制和题内数据判断；分清自变量、因变量、对照及样本。逐条核对陈述的范围、可能/必然、直接机制及轴单位；分布范围与丰度、净量与总量、单链与双链不能混用。不把相关直接当因果；尚未覆盖的概念或特殊图表方法按需读取biology，不能读清图表就指出具体缺失。

公开解法应能手算，可用比例、因式分解、守恒和估算减少算量。获准calculate仅作学习验算，不宣称考场可使用；无需数值计算时不调用工具。brief给原选项和决定性理由，完整教学过程按需提供。

## 独立核验

直接从原图复核数据、单位、图例及所问，独立得到结论后才比较候选。尤其检查单位平方/立方、百分比基数、边界解和选项对应。图像证据不足返回UNKNOWN；候选写“已经检查”不是证据。不凭单題推测模块分数或录取机会。
