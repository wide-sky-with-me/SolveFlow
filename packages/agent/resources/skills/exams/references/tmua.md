# TMUA：数学应用、逻辑与证明

适用于明确标为TMUA的练习题。2026-10-02核对UAT-UK的2026/27规范：Paper 1为数学知识应用，Paper 2为数学推理；各20道选择题、75分钟，总150分钟。两卷题目等权，答错不倒扣；不允许计算器，不提供公式册。知识范围主要对应Higher GCSE与AS纯数学；Paper 2还要求分析逻辑和证明。最终只有一个总成绩，不能按练习正确率自造官方1–9分换算。

## Paper 1与共用数学检查

围绕原题变量、定义域、参数和区间求解；注意“解的个数”与“解的值”、恒成立与存在一个解的差别。优先精确代数、因式分解、函数性质、对称性和必要的分类讨论；原题没有给出的单调性、非零性、正负号不能默认。保留根式/分数到比较选项时；所有候选根代回原条件。图像用于支持判断，不能用看似相交代替证明。

微积分注意净面积与几何面积；三角方程保留指定区间内全部分支；取对数、约分、平方和不等式两边乘除都必须保留合法条件。公开推导可手算，calculate只作受限学习验算，不能把数值枚举当作全称结论。
配对技巧须把端点、总项数和自配对项逐一核定，不默认所有项都成不同的二元组。涉及数字位数的反例逐字符读原数，先确认它符合题给前提；计算无误不能弥补反例对象读错或位数数错。

## Paper 2逻辑检查

- A if B：B推出A；A only if B：A推出B；A iff B必须验证两个方向。A推出B说明A对B充分、B对A必要。逆命题通常不等价，逆否命题等价；不能肯定后件或否定前件。
- “or”通常为包含或，除非题目另有限定。保留all/some/exists/none的范围；否定“所有对象都满足”是“至少一个对象不满足”，不是“所有对象都不满足”。嵌套量词的先后不能交换。
- 先区分命题真假与给定证明是否有效。找到证明里第一个不成立的推理，并说明缺少条件、循环论证或非法运算；正确结论也可能来自错误证明。
- 一个满足前提却不满足结论的反例足以否定全称命题；多个成功样例不足以证明全称命题。分类讨论需覆盖全部情况；反证必须产生真正矛盾。只在需要时用符号辅助解释，不把正式真值表当成必须的答题形式。

自编说明例（非官方题）：n是4的倍数能推出n是偶数，反向不成立，n=2是反例；“每个人至少读过一本书”不意味着“有一本书每个人都读过”。例子用于阐明方法，不作为用户题目的现成答案。

## 输出与独立核验

完整保留原选项，按系统规则保留可见原标签；完全无标签时仅使用有说明且对应原文顺序的应用索引，局部标签或选项不全但题干可独立求解时，给出结论并提示人工匹配；只有影响推理的关键条件缺失才澄清。selectedOptions与完整选项文本对应，answer给决定性依据。即使brief也保留必要的反例、条件或证明漏洞，不能只写“逻辑错误”。校验者重新读原图的量词、否定、if/only if、条件与选项，再独立判断；无法确定范围则UNKNOWN，不能认同候选的逻辑翻译。普通数学题不能仅因含证明就猜为TMUA。
