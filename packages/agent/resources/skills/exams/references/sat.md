# SAT：题内证据与规范填答

## 数学

覆盖代数、非线性关系、数据与概率、几何/三角。先检查问的是x还是x+常数、长度还是面积、百分数基数、一次解还是解的个数。数值/选项需代回原条件检查；不在精简答案中再展开第二种验算。

学生填答SPR可能有多个有效值但只需输入一个，按题意给一个合法值并说明对应条件。小数/分数首先尊重题图指令。数字SAT官方格式可用整数、分数或小数；正值最多5字符，负值最多6字符且负号计入。不要输入等号、单位、百分号、货币符号或带分数；可写成假分数。精确分数放得下时优先，避免过早四舍五入。例如精确2/3可输入2/3，不能粗略输入0.67。小数超长按界面给出的长度及舍入/截断规则处理，不能把SAT规则套给AP。

选择题selectedOptions填写原始标签数组，如["C"]，answer只给最短决定性依据；所选数值/表达式保留在problem.options对应选项中，标签交由前端单独渲染。散点图拟合线预测题区分趋势线与散点，不把散点值当预测值。只需按读图精度在指定横坐标读取趋势线并比较选项；除非题目要求求方程，否则不反复估计端点、截距和回归系数。误差可能改变选项时才澄清。

图上比例或默认定义域只采用明确考试说明或可证明条件；普通裁切题图不能凭外形测量精确数值。calculate只能数值验算，没有符号求解器或Desmos工具时不能声称调用。

## Reading and Writing

- 信息/证据：先定位材料明确支持的结论。图表题核对具体组别、单位、趋势及比较基准，文本证据不足时不能用课外常识补出结论。
- 词义与结构：在完整句子语境中代入选项，区别词典常用义、作者态度与本段功能；双文本分别建观点，不混淆作者。
- 表达目标：转折/因果/递进须对应句间关系；笔记整合先读写作目标，只使用与目标相关的笔记，不要求把所有信息塞入一句。
- 标准英语：判断主从句边界、标点、主谓一致、时态与修饰语位置，再比较选项；保留原句和标点，不只凭“读着顺”。

简洁答案字段示例：selectedOptions=["B"]，answer="材料中的关键对比表明这里需要转折。"。解释不必重复整段英文；需要完整上下文才可判断而图中缺失时，明确指出缺失哪一部分。

## 句界与证据核对

标点题先识别全部谓语和各分句的主从关系，独立分句不能仅用逗号拼接。however/though等连接成分可能归属前一分句，不机械套“分号＋转折副词＋逗号”；结合实际转折方向确定位置。冒号后的整组对比也可以解释前句，不能只看空格紧邻的连词。区分独立直接问句与嵌入式间接问句，后面出现“查明/想知道”不自动把前句变成宾语从句。

代词义选项时保留否定和限制词，核查代入后是否与后半句矛盾。证据题比较每项能否区分竞争解释；共同特征不一定能支持其中一个来源。排除额外假设，以题内支持程度作答。
