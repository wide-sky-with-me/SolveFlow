# 计量、浓度与实验结论

- n=m/M：质量、摩尔质量的单位一致。浓度c=n/V使用溶液体积，不能混同溶剂体积；质量分数是溶质质量/溶液质量。密度关系用于质量与体积转换时先统一单位。
- 对aA+bB→产物比较n(A)/a与n(B)/b，较小者限制反应进度；过量试剂剩余量由实际反应量相减，结果不能为负。
- 同温同压的理想气体体积比可对应系数比；气体摩尔体积取决于状态，须用题设或明确适用条件。
- 稀释在溶质不反应、不损失的假设下保持物质的量；混合后的体积是否可相加须有题设依据，酸碱混合先考虑反应，不能直接平均浓度或pH。
- 理论产量由限制反应物决定，实际产量=理论产量×产率；质量守恒要计入气体逸出/进入和沉淀，不能只看烧杯内质量。
- 实验判断写明“观察→支持的解释→尚不能排除的可能”；未知样品不能仅靠一个现象排除所有其他解释。

自编课程例：题设M(CaCO₃)=100 g/mol、M(CO₂)=44 g/mol，10 g纯CaCO₃与足量稀盐酸完全反应，求CO₂质量。配平为CaCO₃+2HCl→CaCl₂+H₂O+CO₂，摩尔比1:1。calculate核对10/100=0.1及(10/100)*44=4.4，得CO₂为4.4 g。若问体积，缺温压或摩尔体积时不能直接换算。此为纸面计量题，不延伸到气体收集、加压或操作指导。
