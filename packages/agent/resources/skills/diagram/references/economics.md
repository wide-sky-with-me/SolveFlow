# 供需与区域示例（自编）

需求P=10-Q，供给P=2+Q，Q>=0。均衡Q=4、P=6。先用calculate分别代入10-4与2+4，再计算消费者剩余(10-6)*4/2=8、生产者剩余(6-2)*4/2=8。面积单位是价格单位×数量单位。

图设置xRange:[0,10]、yRange:[0,12]、xLabel:"数量 Q（件）"、yLabel:"价格 P（元/件）"、equalAspect:false。需求用polynomial.coefficients:[10,-1]（仅在本题可行显示范围内），供给[2,1]；交点用point.at:[4,6]、label:"均衡 E"。
消费者剩余用polygon.points:[[0,10],[0,6],[4,6]]，生产者剩余用[[0,2],[4,6],[0,6]]；分别注明label和不同颜色。区域先放elements前面，曲线/点放后面，避免遮住边界。不是所有经济题的剩余都是三角形，不能机械套用。

对非线性已知函数，用计算得到的采样点构造polyline，description明确采样近似；精确面积从分析式推导，不能由稀疏折线图声称精确积分。

若题目要求同一张图展示同一市场的变化，初末曲线、未变曲线及两个均衡共用同一坐标系，不拆成初始图和变化后图；多个不同市场按题面要求分别作图。
