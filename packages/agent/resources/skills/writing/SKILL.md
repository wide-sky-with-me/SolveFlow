# 写作与修订

考试 Skill 负责限字、任务与课程要求；本 Skill 负责成文方法。以当前题目和用户指令确定语言、读者、目的、材料与范围，不猜评分标准。brief 仍须给完整的所求正文。

## 成文

1. 核对原题全部指令与已提供材料；阅读/综合写作缺少必需原文时先澄清。先确定能由材料支持的主张，不能编造引文、研究、人物言论或数据。
2. 每段围绕一个作用展开：提出主张、给出证据、解释证据怎样支持主张、处理反论点；按题型调整，不套固定五段模板。文学分析紧扣文本的措辞与手法，不能用情节复述代替分析。
3. `problem.response.type=essay`，`writing.mode=composition`；`answer` 是唯一完整正文，自然段用空行分隔。可选 `writing.title` 单独存标题，正文不重复标题。按要求的语言成文，不能插入中文教学提示、加粗“结果”、自报词数或评分。
4. 限字由考试/题面决定；应用按空白分词展示参考词数，不是官方计数器。接近上限时留余量。不要为满足字数添加重复论点。

## 点评与修改

- 只要求点评时，用 `writing.mode=feedback`、`response.type=short-answer`，`answer` 写具体反馈。指出问题所在、原因与可操作的修改，不冒充官方评分。段落评论可放 `writing.feedback`，paragraph 引用被评原稿的自然段；总体评论省略 paragraph。
- 要求修改时，用 `writing.mode=revision`、`response.type=essay`，`answer` 给完整修改稿；保留用户意思与已有可信证据。仅明确要求说明改动时附 `writing.feedback`，此时 paragraph 引用修改稿的自然段，评论不混入正文词数。
- 当前 `focus.answer` 是正在追问的完整答案；若它是点评，`focus.draft` 才是对应题目最近的完整原稿。逐段修订优先使用这些完整字段。缺少原稿时请求补充，不拿历史节选假装全文。
- 提纲、论点讨论、词句解释仍是 short-answer；没有完整成文就不标 composition/revision。跨题不能借用另一篇作文。

## 交付前核对

核对题目覆盖、证据来源、论证连贯、反驳公平、语言和字数。点评不能说文章有不存在的段落或引用；修订不能悄悄改变论点。工具只按实际能力使用，无数值运算不调用 calculate。独立校验由应用触发，写作流畅或格式正确都不是评分保证。
