# AGENTS.md — 客户端核心

阅读 [本地存储](../../docs/subsystems/storage.md)；API/SSE 兼容代码另遵循 [服务路径](../../docs/subsystems/legacy-server.md)。

新调用方按[架构中的公共入口职责](../../docs/architecture.md#代码职责)选择子入口，根入口只保留兼容；不跨包导入私有源码。学习与展示入口不得引入本地仓库或服务通信实现。

任务输入与缓存校验从 `src/local-run-request.ts` 读起，运行和保存从 `src/local-engine.ts` 读起；重构前核对 [生命周期](../../docs/subsystems/local-run-lifecycle.md)。请求准备保持无存储/模型副作用，异步等待的锁边界写清楚。

- 只依赖项目契约，不泄漏 Pi SDK 事件/JSONL。平台存储和模型执行经显式接口注入。
- 准备与结果写入串行化，模型执行按既有额度并行；同题追问与三类辅助请求遵循共享契约，不退化成全局互相阻塞。
- 结果保存失败保留有界内存结果并阻止新任务；重试只写存储，不重复付费。批量等待队列停止，用户明确继续后才派发。
- 取消和删除优先于迟到结果；删除成功后才清理待保存内存。删除前停止相应任务，失败不得让结果复活或消失。
- 存储损坏与 I/O 故障分别处理；坏记录保留并报告，仍计入题数上限。摘要可重建，原图和答案不能默默替换。
- 原图与元数据分离，更新答案不重写原图；事务更新摘要。读路径兼容已支持版本，破坏性变更提供迁移。
- 备份先完整验证再写入；普通导入跳过同题，选中坏题恢复才允许事务替换。图片、ID、归属、批次序号、诊断、头尾和容量均校验。
- 历史列表和切题不得全量读取图片；缓存、分卷、恢复缓冲与队列有界，取消释放资源。
- 网络/SSE 保持 `runId+seq` 去重、过期快照恢复、幂等提交及安全错误；断线不代表取消。
- 覆盖存储失败、部分写入、迟到取消、重启、重复导入、截断、并发与原始字节保留，测试不得只镜像实现。
