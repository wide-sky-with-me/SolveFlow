# 默认由设备持有数据和模型连接

日期：2026-10-03。状态：implemented。回溯整理 2026-09-15 用户授权及后续实现。

## 背景

用户要求完整迁移本地应用。原始选择及当时限制保留在 [ADR 0013](../../../../docs/adr/0013-local-device-agent.md)；其中早期协议、后台与备份描述已被后续实现替代。

## 决定

[设备 runtime](../../../../apps/mobile/src/runtime.ts) 连接本地仓库与引擎，模型连接由设备设置提供；Pi 适配仍集中在 `packages/agent/src/pi/`。Android 与 Web 共享业务，凭据和存储按平台处理。旧服务路径与数据独立保留。

## 放弃的方案

默认依赖 Hono 后端的 RN 路径被用户的本地迁移要求取代。未采用自写模型循环或 Fork Pi；实际移动兼容通过构建适配和静态受审资源完成。旧服务历史没有自动迁到设备，避免改变其数据归属和部署状态。

## 后果与限制

设备负责本地数据和备份；Web 受供应商 CORS 限制。模型并非离线运行，设备所有者不具备服务端多租户安全承诺。后续当前语义只在 [运行说明](../../../../docs/subsystems/device-runtime.md) 维护，不回写本笔记的历史依据。
