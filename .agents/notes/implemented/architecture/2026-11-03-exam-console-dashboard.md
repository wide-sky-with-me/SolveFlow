# 中心考试统计口径与控制台图表

日期：2026-11-03。状态：implemented。范围：管理端只读聚合、传统控制台及大屏；不改变模型授权或评分政策。

## 背景

已有看板只累计上限500条管理列表，统计与跟踪以completed_once为已答依据，重拍后旧答案失效仍被计入；新增回归实际得到1而非0。用户授权小范围真实模型验收，并要求简洁控制台和大屏。已有[答案展示决策](2026-11-03-exam-answer-presentation.md)规定按当前材料判断有效结果，统计须对齐。

## 决定

新增[契约](../../../../packages/contracts/src/managed-exam.ts)和[聚合事务](../../../../packages/db/src/exam-dashboard.ts)：SQL先按受信管理/负责范围聚合，不受管理列表上限影响。卡片、图表及前8条学生摘要在同一只读一致快照生成，避免不同轮询周期对不上；[跟踪查询](../../../../packages/db/src/exam-catalog.ts)也排除替代版本答案。已开始使用冻结题位，未开始用模板计分母；统计不生成精确分数或正确率。

[界面](../../../../apps/exam-web/src/browser/dashboard.tsx)复用主题及图标，用原生SVG绘制简单发布柱图与状态环图、原生进度条显示模块；原因图可进入原有问题队列。统计页增加发布明细，大屏复用相同数据。仅在用户管理显示新建用户入口；看板不重复堆管理操作。

状态环按红色问题、活动任务、有效答案、未拍及待解答互斥划分；卡片已有答案仍可包含核验异常，因此环图使用已完成区分。发布图按真实展示/人工记录计数，重答再次发布不伪装新增题或正确率。失败保留最后成功数据与更新时间并显式报错，恢复只重新读取，不调用模型。

## 放弃的方案

- 前端累计500条管理列表当系统总数：大样本会漏算；卡片和图表改用SQL聚合。
- 卡片/图表取新接口，学生摘要另取旧轮询：某题处理完成时会短暂显示不同结论，统一到一个快照。
- 为三种简单图增加完整图表依赖：现有React/SVG足够，避免额外体积和主题适配；交互复杂后可另行比较成熟库。
- 趋势线插入演示数据或预测：会误导监控，仅保留真实桶及零值。
- 大屏继续沿用普通页面留白/行高：截图显示下部被截，针对1920×1080压缩布局，保留移动端滚动。

## 后果与限制

无新增依赖或迁移。聚合范围不受500列表影响，但场次选择最多200、摘要和模块各8组，完整管理列表现有分页限制仍在。图表每五秒同步，不是逐帧实时；大屏示例一屏不保证任意窗口/超长数据都不滚动。真实模型使用独立合成题及隔离库，本机预览不因验证永久启用收费模型。

列表及场次选择上限后由[分页决策](2026-11-04-managed-list-pagination.md)补充；本决策的统计快照及摘要范围仍有效。

## 验证

[隔离回归](../../../../apps/exam-web/src/server/managed.integration.test.ts)覆盖权限、当前答案、模块分母、趋势及桶、筛选、同步失败恢复、明暗移动布局、大屏/全屏控制；[验收](../../../../docs/postmortem/2026-11-03-exam-console-live.md)记录实际成绩、14次真实请求和未验范围。初次脚本打包/迁移定位失败发生于外发前，不能计为供应商失败。
