# 公网精简拍题入口与密钥边界

日期：2026-10-31。状态：implemented。范围：独立`apps/photo-web`，不改变Android/iOS及既有Mac Web入口。

## 背景

用户要求另建分支部署手机拍照网页，仅保留考试选择、单题解答和历史，以访问密钥拦截；设置、批量及导出不公开。原本回环环境桥接不具备公网登录边界，不能仅隐藏原设置页后直接暴露。

## 决定

独立React入口复用客户端仓库/引擎，Pi仍仅由Agent包执行，但改在专用Node服务运行。浏览器不接收模型配置或API密钥；上传契约只允许一张JPEG、考试及运行标识，身份由服务端访问会话决定，模型/工具/预算不能由HTTP调用者选择。服务端执行图片解码、限制与去元数据，保留ACT的两张重叠阅读辅助图，原图始终为第一依据。

访问密钥在服务端仅保存SHA256摘要，高熵随机原文另行交付。会话Cookie为HttpOnly/SameSite=Strict，公网强制HTTPS；签名含本次启动随机量，重启需重新登录。登出撤销当前会话并取消其请求。限制失败登录、全局/身份并发及每日提交数；派发前原子保存运行ID，持久化失败不收费派发，同日重复请求不重放。单次请求另有取消和6分钟总时限，Agent内部次数约束保留。

历史按访问身份分库保存于当前浏览器，使用既有版本/事务和刷新恢复，不创建云端题库或跨设备同步。刷新中断不自动重答；保存失败先补存，不重复调用模型。双页编辑通过浏览器锁互斥。

## 放弃的方案

- 在完整工作区隐藏菜单：仍会耦合原生/批量流程，且隐藏UI不能作为服务端授权，未选。
- GitHub Pages单独托管：只有静态托管，无法安全托管模型凭据或服务端鉴权，未选。
- 浏览器直连模型：会向持有前端代码的人交付真实模型密钥，未选。
- 新开免费云函数账号：需要平台登录和地区/域名条件；先使用现有上海服务器，避免新增账号及托管费用。没有因此宣称任何免费服务在所有国内网络均稳定。

## 后果与限制

与既有设备链路隔离；公网版只有简答，标明未校验，不把备用接手当独立核验。共享访问密钥可供多人使用，但不是独立云端用户账户。每日提交与重启登录语义需在部署说明交代；图片不在本服务磁盘持久化。
