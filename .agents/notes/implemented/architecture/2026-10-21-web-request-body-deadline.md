# 本地Web请求正文独立截止

日期：2026-10-21。状态：implemented。范围：本地Web模型桥接的正文读取、配置互斥和模型并发名额。

## 背景

[固定代理](../../../../scripts/web-model-proxy.mjs)先占配置锁或模型名额，再等待正文。读取没有独立截止；设置正文不结束时阻塞派发，模型正文则沿最长阶段超时。Node服务级请求超时依赖启动入口，不能作为代理自身的释放保证。复现和实际成绩见[检查记录](../../../../docs/postmortem/2026-10-21-ui-backend-review.md)。

## 决定

正文从开始读取起最多10秒，沿既有字节上限收集，监听结束、错误、断连；所有路径清理读取计时器与监听。超时返回408，响应发送完成后关闭未完成正文的连接。原配置不动，上游未派发；配置锁和模型名额仍由原有finally释放，不引入重试。

正文完成后的模型响应沿既有阶段、背压、SSE/JSON字节限制与取消机制；不缩短已派发模型的推理时间。保留[设置编辑](2026-10-10-web-model-settings-editor.md)与[本地桥接](2026-10-08-local-web-environment.md)的授权及凭据边界，仅补充读取生命周期。

## 放弃的方案

仅依赖server.requestTimeout会随嵌入入口不同而改变；用300秒模型期限等待半截配置会过久阻塞新任务。超时后直接销毁socket无法给浏览器明确HTTP状态，改为发出408后关闭连接。

## 后果与限制

[远程上传决定](2026-10-22-remote-web-upload-budget.md)已局部替代模型正文与外层接收期限；本篇配置正文10秒及释放原则继续有效。

极慢本地上传会被拒绝，用户可明确重试；不会自动重放付费请求。正在持久化的完整配置沿原原子写入策略，本次不取消已开始的保存。HTTP断连测试不代表真实模型或公网多人隔离通过。

[设置回归](../../../../tests/unit/web-model-settings.test.ts)验证半截配置超时和断连、原配置/令牌不变及名额恢复；[代理回归](../../../../tests/unit/web-model-proxy.test.ts)验证契约上限个未完成请求释放、零上游派发及随后正常请求。实际命令、首次失败和复测见检查记录。
