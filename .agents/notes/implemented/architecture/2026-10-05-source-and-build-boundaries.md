# 源码职责、公共入口和构建边界

日期：2026-10-05。状态：implemented。范围：移动工作区、客户端导出、源码检查与构建命令。

## 背景

[设备运行决策](2026-10-03-device-owned-runtime.md)已经分离默认设备路径与保留服务。结构审查发现移动入口集中恢复、照片、任务操作及页面；客户端根导出混合本地和远程能力；旧 `build:server` 实际准备移动资源并构建全部非移动工作区。源码检查未拦截移动端服务/Node 导入，新增回归初次 17 失败、9 通过。

## 决定

- [应用入口](../../../../apps/mobile/src/app.tsx)只负责启动；[状态 hook](../../../../apps/mobile/src/workspace/use-workspace-state.ts)保留订阅、恢复及绘制就绪时序，操作和页面位于同一工作区目录。状态继续由工作区持有，页面隐藏而不卸载，不把锁或模型调用移入展示组件。
- [客户端兼容入口](../../../../packages/client/src/index.ts)保留原导出，增加按职责划分的公共子入口；API 仅复用纯学习上下文。错误类型共用同一实现，避免入口切换改变类型身份；业务不迁入契约包。
- [检查器](../../../../scripts/check-boundaries.mjs)按包职责拒绝不允许的工作区依赖、Node 和跨包私有文件导入，涵盖导出、动态字面量、类型导入和 CommonJS。开发配置及测试可使用 Node，Pi 导入范围不例外；打包检查继续核对移动 Agent 传递依赖。
- [根命令](../../../../package.json)区分共享、API 依赖、完整非移动工作区与设备导出。[原生构建](../../../../scripts/native-build.mjs)复用共享构建，避免另存一套依赖编译顺序。

## 放弃的方案

没有新增状态框架或按页面各建一个运行时，否则会改变共享任务和页面保留语义。没有删除客户端根导出或拆成更多 workspace 包，避免扩大兼容面与依赖迁移。没有只更名旧构建命令，默认设备开发需实际脱离数据库/API 编译。

## 后果与限制

公共接口、存储格式和模型次数不变，增加少量显式入口与工作区组装代码。源码检查不是沙箱或完整依赖图分析；测试例外不授予产品代码权限。构建入口的迁移要求见[开发流程](../../../../docs/development.md#构建范围)，不回写历史验收。

## 验证

边界回归修复后 26 项通过，包含在全量离线 927 项中；浏览器功能 70 项和完整性能组 20 项通过。共享构建实际选择 contracts/client/agent，API 构建选择 API 及其依赖，类型、JS/Hermes 导出和管理检查退出 0。完整命令、交互回归和未验证项见[结构优化验收](../../../../docs/postmortem/2026-10-05-structure-optimization.md)。
