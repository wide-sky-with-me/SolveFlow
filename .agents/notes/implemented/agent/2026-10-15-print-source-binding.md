# 整理图片来源绑定与局部重整

日期：2026-10-15。状态：implemented。范围：Web 图示整理、Pi 图片消息、参考选项索引；不变更持久契约和题目库。

## 背景

真实27题参考PDF已可下载，但第19题裁片含网页标题栏，显式重整又出现重复图示；结构/归属接受不代表视觉正确。相似滚动拍屏之前仅由一段 sourceOrder 数组与后续图片数组对应。逐框人工修正或修正一题时重跑整批，都会增加成本。

## 决定

- 用已安装 Pi 0.85.1 的结构化 user 消息，在每张图片紧邻位置写其序号、受信 source.id 和未旋转整图坐标参照；首段输入和所有来源 ID 不变，完整校验及三次总截止继续有效。
- 参考版允许沿用与原图文字/图形可靠匹配的已有应用选项标签，但须披露其不是印刷字母；不推定未知图的归属，不补造缺项。提示区分重复拍摄与不同必要图，重复拍摄只提取最完整的一份。
- 图片整理可显式重整当前来源记录；同图多题时重整其整个题组，保持共享来源和缓存键一致，其它记录复用。按钮按单题/题组显示，确认后才收费；取消、保存及原题保护沿用既有路径。
- 重整和恢复后只回收已无任何布局引用的派生裁片、编辑来源和调整，保留原始来源与在用图示。编辑选择按键保留，裁片退役则回到对应题组原图。历史材料可留作原始记录，但加入当前试卷前先校验当前图源白名单，避免先破坏内存布局后陷入不可保存状态。显式校验模型精修见[补充决策](2026-10-15-print-layout-refinement.md)。

## 放弃的方案

仅加结构重试不能识别合法但错误的框；全部套严格完整性门槛会损害参考版披露原有文本缺失的设计。当前未采用这两种做法，也未删除重复候选图、猜测坐标或放宽单页可读下限。

## 后果与限制

来源标记和提示只减少输入混淆，不构成视觉核验。最终裁片尚无自动内容复核门槛，须继续核对图形、边界与选项归属。已有缓存不被此提示调整自动重放，用户可局部显式重整。保留[精简生成视图](2026-10-15-print-layout-generation-view.md)、[持久整理](../storage/2026-10-14-persistent-paper-preparation.md)和[试卷单页](../storage/2026-10-14-exam-style-pdf-export.md)的其余约束。
