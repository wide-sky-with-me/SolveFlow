# 当前题组图示精修

日期：2026-10-15。状态：implemented。范围：显式当前题组图示精修与核对意见；真实路径持续验收中，不是答案验证或任意模型路由。

## 背景

[来源绑定](2026-10-15-print-source-binding.md)和结构重试保护归属，但合法矩形仍可能截断坐标轴或错配相似选项。真实重叠拍屏中，普通提取模型开启低档思考耗尽既有额度而没有正文；配置校验模型无意见重整减少了重复，却仍有错配。经逐图验证输入顺序一致后，明确的核对意见改善了当前裁片。

## 决定

保留普通整理关闭思考。新增用户确认收费的当前题组精修：只使用已配置校验模型、对应凭据、原输出额度和思考配置，仍为无工具独立请求及三次总截止。可选核对意见以共享严格 schema 限定为两千字符，仅追加到本题识别上下文，不改变题目、来源、答案或权限。

意见与模型角色不进入原图输入缓存键；保存的是原有版本的完整布局，因此再次导出和刷新复用，不重新收费。未配置校验模型不显示精修入口；同来源多题仍一起处理，其它记录不重放。

## 放弃的方案

未继续扩大普通模型思考额度，因真实试验已经耗尽额度且没有正文。未把仅结构接受当视觉通过，未引入自动任意选模型、无界重试或跨记录精修。独立自动裁片核验尚未实施。

## 后果与限制

用户仍须核对最终图形、完整标注和选项归属；核对意见不是可信的新题源，也不获得工具权限。思考配置只用于显式精修，不展示内部思维。模型配置、题库及原答案均不改动；失败和取消遵循既有保存规则。
