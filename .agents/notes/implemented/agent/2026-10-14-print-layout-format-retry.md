# 整理响应的有界格式修正

日期：2026-10-14。状态：implemented。范围：显式题目整理。

后续局部替代：[可见退避决策](2026-10-15-print-layout-resilience.md)将显式整理扩为三次，并允许归属不匹配及短暂传输失败重提取；本文其它约束保持，以下保留当时选择。

## 背景

[本机复盘](../../../../docs/postmortem/2026-10-14-print-layout-format-retry.md)实际收到完整 stop 响应，但模型将 sources、warnings、confidence 放在根对象，并使用图框角色枚举之外的值。HTTP 完成不等于内容校验通过。用户明确允许监控真实请求并尝试重试。

## 决定

[整理适配](../../../../packages/agent/src/pi/batch-print-layout.ts)强化根对象与逐题字段层级、图框角色约束。调用方显式开启时，JSON/结构错误最多进行一次新提取，并将有界、脱敏的校验路径加入格式反馈；新上下文只含原有输入与原图，不重放失败模型正文或思考。默认库调用仍为单次，[设备入口](../../../../apps/mobile/src/runtime.ts)仅在用户明确整理时开启。

两次请求共用原 controller 和截止时间，沿用原输出额度、关闭思考与无工具约束，SDK maxRetries 仍为零。有效结构引用陌生题目或图源、截断、输出超限、异常结束、取消与传输失败不重试。导出、刷新、重连和重试保存均不增加请求；持久化 schema 与归属校验不放宽。

本决策仅替代[预算决策](2026-10-14-print-layout-model-budget.md)中的显式整理“绝不追加请求”范围，其思考隔离、输出额度、截断拒收和其它规则保持有效。

## 放弃的方案

仅盲重试缺少结构反馈；无界重试增加费用并延长任务，均未采用。直接将根字段下移也未采用：同一实际响应还有非法角色，单次搬移并未通过契约，自动猜测图框归属会掩盖错误。始终保留完整严格校验，不用重试宣称识别准确。

## 后果与限制

每条记录最多产生两次模型费用，取消不重放；错误再次出现仍终止，已经保存的整理结果保持不变。诊断仅含状态、次数、耗时、字节数和白名单字段路径，浏览器控制台不保存响应原文。

## 验证

[重试测试](../../../../packages/agent/src/pi/batch-print-layout-retry.test.ts)覆盖成功修正、二次失败终止、归属/截断/超限/工具结束不重试、取消、共享截止和脱敏；既有预算与规范化回归保留。实际命令、真实调用次数、发布范围和未验证项归上述复盘。
