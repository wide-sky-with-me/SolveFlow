# 设备解题时间与 Web 流式传输预算

日期：2026-10-08。状态：implemented。范围：共享运行预算、设备阶段窗口、Android 后台期限与本地 Web 代理。

## 背景

用户授权适当延长时间，并检查最近批次第三题。只读诊断显示最新运行主模型两次流中断，备用模型在约38秒完成解答；随后校验两次HTTP 200，在约16秒与14秒中断。代理日志对应两次 response_limit：SSE超过1MiB即被截断。最新结果保留答案、未验证；不是模型名不可用或此次校验超时。上一轮第三题备用阶段45秒超时是另一失败，见[验收](../../../../docs/postmortem/2026-10-08-storage-maintenance-and-native-sync.md)。

## 决定

[公共契约](../../../../packages/contracts/src/agent.ts)统一180秒总期限，[运行预算](../../../../packages/agent/src/policy/run-budget.ts)使重试、修正及备用共享计时和派发额度。[设备适配](../../../../packages/agent/src/pi/mobile.ts)主/备用解题各最多60秒；普通核验45秒、图示/化学60秒、长文/分小问和独立选择90秒，均受剩余预算约束。无备用时预留45秒，首次窗口135秒；已有15秒流增量借用与一次20秒格式修复不增加总期限。

[原生插件](../../../../apps/mobile/plugins/with-solve-background.cjs)从共享常量生成 Kotlin 期限，供服务、阶段计时及 Headless JS 使用；唤醒锁与 Headless 仅增加5秒资源清理余量，不授予新模型请求。iOS使用相同Agent逻辑，仍没有Android前台服务。

[Web代理](../../../../scripts/web-model-proxy.mjs)给SSE设置8MiB传输上限，非流式JSON仍1MiB；总传输时间同步180秒。保留6并发、请求体限制、背压、取消和仅元数据日志；不累积或记录模型原文。

## 放弃的方案

仅延长超时不能解决字节上限截断；无限响应或无限重试破坏资源边界。全局提高JSON上限没有此次SSE证据支持。仅修改JS计时会仍被Android旧的120秒服务、阶段上限及125秒Headless提前中断，因此从共享契约生成原生常量。

## 后果与限制

慢请求可占用更长时间和传输容量；次数与付费门槛不增加，失败仍可能未验证。8MiB是有界工程取值，未证明覆盖所有网关响应。旧任务不自动重跑，旧包仍保留旧期限。保留服务的单次供应商/工具限制独立存在，不宣称其每次调用都可用满180秒。

本笔记局部替代[恢复窗口](2026-10-07-exam-reliability-recovery.md)、[重试窗口](2026-10-08-verifier-transport-degradation.md)及[本地桥接](../architecture/2026-10-08-local-web-environment.md)中的旧时间与SSE字节限制，其余规则继续有效。

## 验证

预算、备用、延迟候选、独立选择和取消回归覆盖新期限；代理验证2MiB流正常转发、超过8MiB拒绝并取消上游，JSON旧上限仍有拒绝回归。实际原生构建和浏览器结果归验收；本轮不发送真实题图、不宣称准确率提高。
