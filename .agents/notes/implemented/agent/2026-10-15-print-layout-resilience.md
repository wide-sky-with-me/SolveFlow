# 整理的三次尝试与可见退避

日期：2026-10-15。状态：implemented。范围：用户显式导出整理；不改变解题、答案修正或持久化协议。

## 背景

用户在部分题目已整理后再次遇到无效内容，要求失败后继续尝试。旧适配只对 JSON/结构追加一次，归属和连接失败立即终止，且 UI 不显示尝试次数。证据与验收见[复盘](../../../../docs/postmortem/2026-10-15-print-layout-resilience.md)。

## 决定

[运行入口](../../../../apps/mobile/src/runtime.ts)显式启用每条最多三次尝试；[适配](../../../../packages/agent/src/pi/batch-print-layout.ts)对 JSON、结构、归属不匹配和短暂连接/限流失败进行有界重提取。前两次失败后分别等待1秒、2秒，等待接受取消，三次共用原 controller 和总截止。SDK 重试仍为零，沿用模型、输出额度与关闭思考；新上下文不带失败正文或思考。

归属错误仅允许重新从原输入提取，不修改严格解析或接受陌生 key/source。三次失败仍终止并公开次数及脱敏原因；取消、已耗尽总时限、截断、超限、工具结束、凭据/余额/请求参数错误不重放。库默认仍为单次；原格式修正开关默认两次，新增行为须显式选择。

[整理编排](../../../../apps/mobile/src/local/prepare-paper-batch.web.ts)传递逐条次数/退避进度，成功记录按原流程提交缓存；再次点击只处理待整理记录。导出、刷新和保存重试不调用模型。

局部替代[原格式决策](2026-10-14-print-layout-format-retry.md)中的次数上限及归属/传输终止范围；其余限制保持。此处是导出提取重试，不是放宽 Solver/Verifier 的答案修正次数。

## 放弃的方案

不限次数重试会持续产生费用；从头重跑批次浪费已成功请求，均未采用。为通过校验替换图源或下调标准可能混题；保留严格归属并重新提取。沿用“只在控制台记录”不能解释当前是否已重试，因此在原进度区域展示，不新建模态框或副本设置。

## 后果与限制

最多三次模型费用，短暂故障也可能持续至上限；没有承诺整批或识别准确。退避仅避免立即重复，仍可能遇到服务限流。缓存由浏览器管理，清理会失去复用依据；存储失败仅重试保存。

## 验证

[韧性回归](../../../../packages/agent/src/pi/batch-print-layout-resilience.test.ts)覆盖第三次恢复、归属仍严格、网络/限流、永久失败、取消与共享截止；[浏览器回归](../../../../tests/mobile-e2e/paper-preparation.spec.ts)覆盖可见等待、次数终止及部分成功后的刷新续做。实际命令、失败与复测均归复盘，不用合成结果宣称真实整批完成。
