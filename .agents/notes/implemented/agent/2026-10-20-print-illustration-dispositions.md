# 旧图示标注的显式处置与去冗余原图

日期：2026-10-20。状态：implemented。范围：整理试卷的共享提案契约和模型生成指令，不改变题库、原始图片及既有成品缓存。

## 背景

用户重申“非必要不需要原图”。历史 `problem.illustrations` 可能把文字或数值表标成图；此前只要有旧标注而新结果无裁片，就恢复旧题并强制保留整图。模型完整转录的表格因此仍阻断下载。上一轮提示词要求所有已标注数值表留图，违背本要求，现已替代；[图源绑定](2026-10-15-print-source-binding.md)的来源紧邻、完整来源选择与归属约束继续有效。

## 决定

在[共享契约](../../../../packages/contracts/src/batch-print-layout.ts)新增可选、最多三项的 `illustrationDispositions`，按本题旧图示 ID 对账。完整文字或数值表声明须引用实际排入题干的内容；表格须保留完整列结构、分隔行及数据行。真实表格可以原样留空表头，不能为通过校验补造列名，表内仍须有非空内容。必要图形引用当前来源中的真实裁片，无法确认则显式保留来源。未知/重复 ID、失效引用和不在题干的转录不获豁免；提供处置后，任何未覆盖旧图示仍回退，不以任意一张裁片掩盖另一张遗漏。

[生成指令](../../../../packages/agent/src/pi/batch-print-layout.ts)明确非必要不保留原图，纯文字/完整数值表不重复附照片，几何、曲线、电路、结构式和图形选项不以文字描述替代。选项完整性、可信图源、置信度、疑点和取消/重试预算不变。

## 放弃的方案

强制表格留图与产品要求相反；直接删除遗漏校验会丢必要图形；按名称、旧标注、置信度或一句说明整体去图缺乏逐图关联。只有提示词也无法解除共享解析器的错误回退。

## 后果与限制

新字段属于共享提案，保留至移动端二次解析，通过路径稳定；回退改变题干/裁片时去掉已失效处置。新读取器接受无字段的旧 v1 提案并沿旧保护；旧版本读取器不保证接受新字段。已有 prepared 成品不重验提案，不清空缓存、不自动重放付费请求；仅显式局部重整覆盖当前题组。

结构检查能证明 ID 对账、引用存在和转录已排入题干，不能证明模型的视觉分类或全表逐格语义正确。真实原图与成品仍须核对，Schema 通过不等于视觉验收。

## 验证

[契约回归](../../../../packages/contracts/src/batch-print-transcribed-illustrations.test.ts)覆盖无冗余图、真实空白表头、混合保图、缺图保护、坏引用、旧提案及二次解析；[Agent 测试](../../../../packages/agent/src/pi/batch-print-layout.test.ts)检查实际请求与无声明回退。全部 1957 测试、类型检查和 Web 构建通过；真实局部重整、两次下载及缓存复用见[验收报告](../../../../docs/postmortem/2026-10-20-pdf-transcribed-tables.md)，不代表严格模式或部署完成。
