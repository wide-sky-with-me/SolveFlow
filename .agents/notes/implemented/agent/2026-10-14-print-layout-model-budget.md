# 整理任务独立的思考与输出预算

日期：2026-10-14。状态：implemented。范围：设备端试卷图文整理的思考与输出预算。

后续局部替代：[格式修正决策](2026-10-14-print-layout-format-retry.md)允许显式整理中的 JSON/结构错误最多追加一次请求；本页的思考隔离、输出额度、截断拒收和其它约束仍有效。以下保留原选择及当时证据。

## 背景

[现场复盘](../../../../docs/postmortem/2026-10-14-print-layout-truncation.md)确认：配置输出上限16384，整理隐藏压到8192，真实响应 length。移除压限后仍耗尽16384且正文为空；仅关闭整理请求的思考后正常 stop、1134 tokens，无思考块。数据只用于内存回放，诊断不留模型原始文本。

## 决定

[整理适配](../../../../packages/agent/src/pi/batch-print-layout.ts)克隆 solver profile，只对本次提取关闭思考，沿用既有协议，未显式指定协议时走现有类型协议默认值。保留已校验的配置输出上限，共享设备阶段时限，单次请求、无工具或自动重试、64KiB正文限制、取消优先。用户解题设置不修改；达到输出上限仍报告 truncated，不拼接截断 JSON。

[模型读路径](../../../../packages/contracts/src/batch-print-layout.ts)把空可选题号视作未填写；无标签选项图仅在其余来源结构、边界和唯一性均有效时保留整张对应图。保留图产生已有核对警告，未猜选项归属。存储 schema、严格解析器和题目/图源身份校验不放宽。

## 放弃的方案

仅增加 token 上限已实测仍失败。此前暂未采用关闭思考以保留默认行为，真实失败与用户同意的对照验证后改为仅整理任务关闭。永久修改解题配置或改路由会影响原任务，未采用。补造缺失题号/选项标签、把无标签图冒充题干图、自动重试追加费用，均未采用。

## 后果与限制

保留原图可能仍需用户确认图示归属；严格试卷继续阻止待核对项输出。供应商关闭思考字段兼容性沿用已选协议，本次实测的类型协议被当前模型接受；其它协议靠合成映射回归，不宣称全供应商验证。没有准确率或整批成功保证。此前设备输出预算和缓存版本保持不变。

## 验证

[预算测试](../../../../packages/agent/src/pi/batch-print-layout.test.ts)、[规范化测试](../../../../packages/agent/src/pi/batch-print-layout-normalization.test.ts)覆盖三种 token 字段、三种关闭思考协议、超过一分钟成功、截止/取消、截断拒收、原图保留与畸形/陌生来源拒收。普通解题思考回归不变。真实第四次响应在独立进程内存离线回放通过，无额外外部调用；实际成绩和发布状态归上述复盘。
