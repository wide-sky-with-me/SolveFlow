# 新题工作台的指针拖动草稿

日期：2026-10-27。状态：implemented。范围：Web相册新增题图；仅本地更新。

## 背景

[工作台草稿](2026-10-27-batch-import-workbench.md)已有点击插入与最终编号，多题逐张调整仍需重复点击。拖动预览会移动源格子及目标记录，若捕获绑在格子上或反复按目标记录重新定位，会丢失手势或落到相邻位置。

## 决定

[Web适配](../../../../apps/mobile/src/components/batch-import-drag-surface.web.tsx)统一使用Pointer Events，稳定根节点捕获指针。超过小幅移动阈值才启动拖动，普通点击继续定位。按当前可见格子的位置，在移除移动组的基础序列中解析落点，避免预览移动的记录把光标锁在前一格。

[投影](../../../../apps/mobile/src/batch-import-drag.ts)验证完整成员和目标，生成新图顺序与稳定已有ID锚点，不改变已有题目的相对顺序或存储接口。预览不保存，松手才提交内存草稿；整组按当前确认顺序移动。关闭、确认和排序在有效拖动期间互斥。

Esc、触控取消、失焦、隐藏、成员变化和卸载均释放捕获、监听及滚动帧；拖出网格松手放弃本次调整。消费拖动产生的点击，但下一次主动按下清除旧抑制，避免触屏后首个按钮点击失效。Esc同时消费对应keyup，防止撤销拖动时关闭整个弹窗。

## 放弃的方案

HTML原生拖放在触屏浏览器缺少统一手势；使用现有Pointer Events不新增依赖。格子自身捕获会受重排影响，因此使用稳定根节点。直接跟随预览中已有记录ID命中，在长网格鼠标跨格测试中落点偏移一格，改用可见格子位置投影。

## 后果与限制

Web支持鼠标和触屏；原生适配保留点击定位，本次未实现原生拖动。移动网格有界，不读取题图，自动滚动帧仅在拖动期间存活。保留上移、下移和点击路径以便键盘操作。确认导入后的保存、取消与解题生命周期仍按原工作台规则运行。

实际命令、失败及复测结果见[验收](../../../../docs/postmortem/2026-10-27-batch-import-drag.md)。纯投影与已有编号测试共15项通过；浏览器使用独立源和合成数据，触屏仿真不代表原生真机结果。无真实模型调用、远程部署或用户数据迁移。
