# PDF 入队持久化期间取消的所有权

日期：2026-10-17。状态：implemented。范围：导出队列准入与 Web 取消反馈，不改磁盘格式或容量上限。

## 背景

[前轮分段准入](2026-10-16-pdf-admission-yield.md)已处理入队前取消，但首次 queued 写入由队列持有锁，前台尚未拿到任务 ID，取消意图没有传入队列。原队列即使调用者已取消仍会接受并启动 runner；前台随后按 ID 取消只是较晚的补救。[当次证据](../../../../docs/postmortem/2026-10-17-pdf-admission-cancellation.md)保留失败回归与复测。

## 决定

[LocalExportTasks.enqueue](../../../../packages/client/src/local-export-tasks.ts)增加可选准入 signal：调用前、进入 I/O 锁后、首次写入完成后及 pump 前复核。首次写入期间取消不提前结束存储 Promise；写入完成后先补 cancelled，终止准入并抛原取消原因，不登记待执行 runner。queued 发布的同步订阅或微任务取消在 pump 前按 ID 收尾。

首次写入失败且已取消时，只保留有界 cancelled 元数据及 create 标记；中断其它排队任务期间才收到的取消也覆盖本次 interrupted 意图。补写取消失败沿既有 pending 保存恢复，重试只落盘，不恢复 runner。已接受任务仍使用原任务 ID 取消；准入 signal 不是接受后的自动生命周期绑定。

[Web 适配](../../../../apps/mobile/src/local/web-export-tasks.ts)把调用者 signal 传入队列，维持提交锁、捕获快照及字节预留，直到底层写入和取消收尾兑现，再由原 catch 释放。[界面补验](../../../../docs/postmortem/2026-10-17-pdf-cancel-ui-recovery.md)后，前后台提交均复用可取消操作，准入时显示收尾反馈并禁用重复取消；结束后才恢复按钮。后台接受后关闭或切页仍执行，不把卸载控制器绑定到独立 runner。

此决定局部替代前轮留下的入队写入交接边界，独立任务让出、完整校验、同段计数/克隆和初始化共享等待继续有效。

## 放弃的方案

只在前台拿到 ID 后补取消保留了队列提前启动的窗口。以 Promise.race 提前退回界面却让底层写入继续，会模糊锁与捕获快照所有权，提前释放容量后还持有旧输入；本次不采用。取消后正常返回提前终态可能绕开调用者既有错误释放路径，因此终止准入统一抛原取消原因。

不强行取消或让出底层事务锁，也不把可选 signal 隐式扩展为所有后台任务的全生命周期；前台原有任务订阅继续负责接受后的取消。

## 后果与限制

取消后首次写入仍须等待结束；界面提供收尾反馈而不是承诺即时终止 I/O。Web 存储继续沿原有打开/事务超时，不新增无限重试。写入成功后可留下 cancelled 历史，补写故障可能保留待保存取消状态，刷新仍依既有中断恢复规则。实际共享存储或跨进程冲突未扩展，磁盘版本无需迁移。

本次不宣称绘制长任务、总耗时、低内存设备或跨浏览器已优化。取消的第三方同步工作仍只能在任务边界后检查。

## 验证

[核心队列回归](../../../../packages/client/src/local-export-tasks.test.ts)覆盖首次写入前后挂起、已取消/锁等待、初写/补写失败、迟到取消、queued 发布取消、仅准入信号语义和取消后新建成功。[适配回归](../../../../apps/mobile/src/local/web-export-admission.test.ts)核对信号透传、提交锁、容量与订阅释放。[浏览器回归](../../../../tests/mobile-e2e/background-exports.spec.ts)在前后台入口延迟真实事务完成通知并注入取消补写故障，验证按钮、无 running/绘制/下载、保存重试及明确重新导出。实际成绩与执行边界分别见原证据及后续界面补验。
