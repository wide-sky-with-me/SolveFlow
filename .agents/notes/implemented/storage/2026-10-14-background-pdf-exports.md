# 本地后台 PDF 导出与已保存内容

日期：2026-10-14。状态：implemented。范围：Web 批次 PDF/ZIP。

## 背景

普通导出在整理缓存缺失时重新调用模型，完整保存答案的批次也被无效整理输出阻断。旧下载动作归属弹窗；关闭弹窗后没有独立任务、记录或可再次下载的成品。整理错误和解题错误共用文案，误导用户判断保存答案丢失。

## 决定

“已保存内容”不调用模型，复用题目、解答、原图和裁图；图框按对应保存解答的主图定位。缓存仅是优化，关联校验或恢复失败仍回退保存内容。缺少必要裁片时保留原图及疑点，不伪称严格试卷。其默认版式地位由[持久整理决策](2026-10-14-persistent-paper-preparation.md)局部替代，保底出口及本决策其它行为继续有效。

“严格试卷版”须显式选择，沿用[原试卷决策](2026-10-14-exam-style-pdf-export.md)完整题干、选项、必要图示校验；缓存缺失可调用模型，失败不降级为全屏截图。本决定局部替代[按需缓存决策](2026-10-13-print-layout-cache.md)的普通导出自动识别范围，其缓存与显式整理机制继续有效。

任务属于 Runtime 而非弹窗。单生成槽位和有界排队，接受时固定副本计划、题目快照与图示。前台下载同样生成记录，后台提交后关闭弹窗或切页继续运行。新建独立 `solveflow-exports` IndexedDB v1，records、files、sizes 原子删记录与成品；文件提交成功后才写 succeeded 并通知。

2026-10-15 性能补充：全队列数组快照会随每次进度替换，导致新打开的弹窗跟随后台逐页渲染。弹窗改选自己已接受任务的待保存冻结行，其余状态返回稳定 null；未持有任务时不遍历队列。自己的前台进度仍走既有工作订阅。未采用节流或另加缓存，避免延迟反馈及重复维护同步状态；队列、契约与持久化不变。

2026-10-17 派发补充：running 持久化并发布后的取消仍先收尾，再决定是否调用 runner；原因与限制见[执行发布门禁](2026-10-17-pdf-dispatch-cancellation.md)。本段不改变已经开始的 runner 的协作取消及其它后台生命周期。

浏览器关闭或刷新后未完成记录恢复为 interrupted，不恢复 runner、不重放模型。任务超时、取消优先于迟到产物；失败保存只重试持久化，不重跑生成。待保存产物仅保留一份有界内存。2026-10-15 补充：前台弹窗只按本次已接受的任务 ID 恢复成品保存，不按当前设置重新提交，也不猜测其它批次的待保存任务；恢复时用保存重试取代生成按钮。读取已保存成品的前后仍检查取消，避免读取期间取消却迟到下载；已落盘的成功终态不回退。应用内通知始终可用；用户点击开启系统通知，页面不可见时发送，权限或浏览器能力不影响生成。

2026-10-24 保存恢复补充：保存失败仍可明确下载内存中的原成品，保持待保存状态；只局部替代必须先入库才能下载的入口，见[成品恢复决策](2026-10-24-generated-export-recovery.md)。

## 放弃的方案

继续“下载前必须调用模型”会将推理可靠性和费用耦合普通导出。服务端导出会上传浏览器题库并改变部署与数据归属，未采用。未采用 Service Worker 渲染：DOM、字体与 Canvas 依赖活动文档。保存失败后按当前设置重新生成会重复绘制并改变原成品，按最近任务寻找恢复对象可能跨批次误绑定，均不采用。

## 后果与限制

浏览器退出后的继续执行未实现。成功仅指成品保存在导出库，不代表操作系统保存成功。原图像素可能含手写作答，保存模式的纯题目不承诺去除；严格模式或手工裁图保持原有要求。

历史备份不包含这些派生文件，清理浏览器数据会删除成品；不承诺跨设备同步。容量、条数、排队和期限见[当前文档](../../../../docs/subsystems/batch-pdf.md)。本地应用独占运行机制继续生效，不扩展服务器题库或模型权限。
