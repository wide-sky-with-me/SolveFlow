# 试卷式批次 PDF 导出

日期：2026-10-14。状态：implemented。范围：Web 题目投影、单题页面、副本设置和文件命名。

## 背景

用户明确要求仅题目时提取文字、选项及必要图示，一题一页；带作答时在同一弹窗逐份指定最终错题数并一次下载 ZIP。近期脚本 PDF 可参考白底、题号横线、公式及并排裁图，但含保存作答、封面和部分续页；旧纯题产物也出现一页多题。EXamTwin 的抽题结构将题目 Markdown 与作答产物分离，未发现其严格单页模板。

本决策局部替代[原多份导出](2026-10-13-batch-pdf-variants-and-image-layout.md)中的完整回答门禁、嵌套设置与连续分页，以及[按需缓存](2026-10-13-print-layout-cache.md)中正式输出可静默保留整张照片的路径。快照一致性、图源归属、标红/参照规划、取消、原始数据保留和按需缓存仍有效，历史成绩不改写。

## 决定

- 在共享契约增加无作答字段的题目投影；缺少已保存转录时传空参考给抽取，不伪造完整回答。作答规划保留完整回答要求。
- 主弹窗直接设置份数与每份最终错题数，正确数派生；取消关闭仅丢弃导出状态。原标红已包含在请求错题总数内。Web 使用既有 React DOM portal 提供唯一弹窗语义与即时键盘处理，避开原生弹层重复 dialog 及入场动画的 Escape 注册滞后。
- 派生页面仅使用完整题目与必要裁片，原图留在核对预览和原始阅读记录，待核内容阻止正式试卷式输出。
- 每题独占 A4 页面，无封面占页；先调整图尺寸，再等比适配文字，保持可读下限，溢出报题号。打印与下载克隆共用量测。
- PDF 与 ZIP 共用批次前缀、语义后缀及字节限制，单份作答也保留份序。缓存解析版本独立更新，不迁移或覆盖题目库。

## 放弃的方案

在连续流上只加强制换页会让长题继续跨页；直接固定高度隐藏溢出会丢题。两者都未采用。过度缩字会损害阅读，因此超长题显式报告而不是承诺任意内容都能单页。未配置模型时输出整张拍屏虽然易完成，但违背干净试卷目标，改为手动确认文字/裁图或待整理。

复用 EXamTwin 外部解析服务会扩大设备运行边界，本次只借鉴分离和来源核对原则，不新增服务、依赖或另一套前端。

## 后果与限制

下载继续使用现有栅格绘制，浏览器保留可选文字打印。尚未执行新版本真实模型重新抽取；近期已审核裁图与已存转录用于版式对照，不代表识别准确率。
