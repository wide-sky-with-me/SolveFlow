# 自足备份分卷与单题原子恢复

日期：2026-10-03。状态：implemented。回溯整理 0.1.70 存储修复。

## 背景

全库备份的内存压力和损坏记录需要独立处理；Web 的同步写入异常曾出现 Promise 已拒绝但先前请求仍提交。实际故障记录见 [生产修复](../../../../docs/RELIABILITY_REVIEW_2026_10_03.md)。

## 决定

[导出器](../../../../packages/client/src/local-history-export.ts) 按完整题目规划自足分卷，每卷可单独恢复；[仓库](../../../../packages/client/src/local-repository.ts) 先验证完整备份，再事务替换明确选中的坏题。Web 同步异常显式 abort；健康记录和诊断不覆盖。大小与格式当前说明归 [存储文档](../../../../docs/subsystems/storage.md)。

## 放弃的方案

把所有题图先合成一个大文件会提高内存压力；普通合并跳过已有 ID，无法用来修复该 ID 的坏图。仅拒绝 Promise 的回滚假设被浏览器故障注入否定，不能替代 IndexedDB abort。

## 后果与限制

坏记录保留证据并继续占额度。恢复仅限备份版本，无法识别有效 JSON 中的内容错误。Web 分卷 Blob 仍消耗内存；逐题合并导入遇到强杀可能留下已完成部分，重导入补齐，不能声称全库跨进程原子性。

## 验证

[备份回归](../../../../packages/client/src/local-history-import.test.ts) 和上述报告包含乱序/重复分卷、健康保护、同步事务失败。小阈值测试不等于手机大库压力验收；本次未新增真机测试。
