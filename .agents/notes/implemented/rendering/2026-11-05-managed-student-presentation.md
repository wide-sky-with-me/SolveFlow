# 学生拍题精简界面与统一展示状态

日期：2026-11-05。状态：implemented。范围：中心考试学生/教师题目呈现、图片操作及共享公式规范化；不改变模型或存储结果。

## 背景

用户确认手机截图中的调整：移除常驻统计和单题跳过按钮，总览收进弹窗，翻题/停止并列，答案只显示所选题；公式不应露出TeX命令，上传中的题不能画成未拍，原图应优先占空间并可重置。

本记录局部替代[手动逐题](../architecture/2026-11-05-student-manual-navigation.md)的常驻可折叠答案表及[原图渐进加载](2026-11-04-progressive-image-viewer.md)的大工具栏；其固定题位、手动导航、授权缓存和渐进替换规则继续有效。

## 决定

- [学生页](../../../../apps/exam-web/src/browser/student.tsx)保留拍照、当前答案和上下题，处理中居中显示停止作答；相册/补图另行居中。总览用原生Dialog，返回当前入口，不重排题位或自动取消其他题。单题跳过API保留兼容，界面不提供该按钮；下一题只导航，不伪造跳过或完成。
- [状态映射](../../../../apps/exam-web/src/browser/slot-state.ts)以活动run和当前presentation为准，历史completedOnce/skipped不能覆盖排队/核验。学生答案格与教师导航复用状态，红色问题标记独立保留。移除学生常驻统计不隐藏必要提醒，管理端统计保留。
- [原图页](../../../../apps/exam-web/src/browser/image-viewer.tsx)用角落的重置/全屏图标代替大工具栏；手势、滚轮及键盘缩放保留，重置明确同时恢复大小与滚动位置。原图升级仅显示小加载图标，错误仍可重试；缓存/权限和原图替换不改。
- [数学规范化](../../../../packages/contracts/src/math-text.ts)从客户端纯函数提升为公共格式辅助入口。[原客户端文件](../../../../packages/client/src/math-delimiters.ts)仅重导出，默认行为兼容。中心[文本适配](../../../../apps/exam-web/src/browser/rich-text.tsx)先规范化再交现有安全Markdown/KaTeX渲染，题干/选项/答案一致；仅中心额外识别带TeX运算符的简单算式，代码、金额、已有公式不二次包裹。数据库原文不修改。

## 放弃的方案

仅按曾经完成/跳过着色会复现已上传却像未拍。新增另一份模型状态或持久化展示字段会造成更多同步来源，因此只投影现有契约。为中心单独复制完整版的公式处理会分叉金额/代码规则，因此保留原公共客户端入口并共享纯函数；web-ui仍不依赖客户端、Node或模型，不放宽源码边界。自动猜补损坏公式可能改答案，因此仅规范化明确结构，错误交安全回退。

## 后果与限制

无迁移、新第三方依赖或模型调用。移除缩放按钮后可用手势、滚轮和键盘，重置/全屏仍为44px控件。代码块保持原文，缺失内容或无定界符的复杂公式不承诺自动修复。移动视口/WebKit不代替iPhone真机。
