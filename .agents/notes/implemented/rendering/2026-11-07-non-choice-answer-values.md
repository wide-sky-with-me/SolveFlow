# 填空答案的只读摘要与高亮

日期：2026-11-07。状态：implemented。范围：中心考试快照的短答案投影及学生预览。

## 背景

模型数值题已有responseValue，但快照未带出，学生总览截取了解释开头，答题页也没有对应字母标牌的数值高亮。需要兼容旧数据、人工修改与严格旧客户端，同时保留原始记录。

## 决定

[快照](../../../../packages/db/src/exam-attempts.ts)在一致读取事务内，用一次有界查询读取当前presentation所指run的短值，并核对材料版本。人工和模拟展示排除原AI值；默认不增加字段，由[契约](../../../../packages/contracts/src/managed-exam.ts)定义的能力头显式申请。无迁移，不回填或改写历史答案。

[摘要辅助](../../../../apps/exam-web/src/browser/answer-value.ts)优先投影值，旧记录仅采用明确结果行或全文本身已为短值的情况；多个不同结论不猜取。学生[答案卡](../../../../apps/exam-web/src/browser/student-answer.tsx)和[总览](../../../../apps/exam-web/src/browser/section-answers.tsx)共用它，核验配色与当前题蓝色仍按原状态。普通短值用纯文本，只有明确数学片段交给既有安全渲染，导航格不创建嵌套链接。

## 放弃的方案

给每格单独请求题目详情会形成多余请求，而且详情中的原始结果可能早于人工展示。按解释末尾数字或最后一个公式猜答案会误取中间量。重写已有answer字段会破坏历史并混合解释与填写值。因此只读投影已有结构化字段，无法确认时保留全文入口。

## 后果与限制

新客户端需要同版服务端才能收到结构化值；旧客户端字段保持不变。旧记录缺字段且没有明确短结论时，总览显示查看答案，不承诺恢复其真正数值。人工答案只按当前人工正文提取，不继承旧模型字段。无新增模型请求、权限或持久化副本；最多增加一次当前考试短值查询。
