# 学生及管理界面与部署验收提案

日期：2026-11-02。状态：proposed。范围：共用设计语言、页面结构、容器交付与验收。

## 背景

用户要求延续现有风格，而不是拼接一套通用管理后台。[当前CSS](../../../../apps/photo-web/src/browser/styles.css)、[SVG图标](../../../../apps/photo-web/src/browser/icons.tsx)及[完整端主题](../../../../apps/mobile/src/theme/palette.ts)已逐项核对；[交互原型](2026-11-02-exam-prototype.html)仅合成数据，无真实相机/模型/数据库。

## 决定

### 共用视觉及组件

[抽取的tokens](2026-11-02-exam-tokens.json)保留浅灰底`#f5f7fb`、白卡、主文字`#172338`、蓝色`#2867dd`，以及现有暗色语义。系统中文字体、正文15px、标题20–24px，按钮最小44px，圆角12–20px，细边框/轻阴影；SVG按现有24视口、1.8描边补充。

实现时抽取 `packages/web-ui` 的主题、按钮、输入、Popover/Listbox、Dialog/Drawer、卡片、状态、题号及上传卡片；学生和管理端共同消费，RN主题只对齐语义不直接导入DOM组件。照片不滤色；遵循减少动效和键盘焦点。弹窗只放对象与主操作，裁剪/旋转按小编辑入口打开，删除在缩略图角上，避免常驻说明小字。

### 页面

学生端：登录→待开始/可进入场次→当前模块。题号导航显示已完成和当前题，未来题禁拍；历史题可回看和补图。答案返回并提交后，拍照目标推进下一题，刚完成题答案仍固定可见。模块全部完成后才解锁下一模块。失败、澄清、断网、截止及上传未保存各有真实状态；提示可关闭或自动过期，未保存风险不自动隐藏。

管理端包含：

| 页面 | 主要内容 |
| --- | --- |
| 看板 | 当前场次、在线连接数、题位完成数、活动任务、待处理问题 |
| 实时跟踪 | 分配给自己的学生卡片，模块/当前题、最近活动、连接和解题状态；展开看题图与版本 |
| 用户管理 | 创建/停用/重置凭据、学生与支持人员角色、负责范围 |
| 考试安排 | 模板版本、模块题数、时间与学生分配、发布/撤回、展示策略 |
| 统计 | 已提交/已出答案/已核验分别计数，失败、补图、模型耗时和额度；模拟展示单列 |
| 角色权限 | 角色、操作权限、范围授权及审计；支持人员不能自行扩权 |

题目详情抽屉统一提供原图/补图缩略图、识别正文、原始解答、展示结果、核验和版本记录。原始解答及策略信息仅授权管理端可见；学生收到的模拟结果仍须明确模拟状态，不继承原始答案的核验标记。

### 容器与运行

Compose发布单元为`gateway`、`api`、`worker`、`events`、`postgres`、`redis`、一次性`migrate`；同一应用镜像按角色启动，镜像按版本及digest锁定。生产COS外置，不沿用停止维护的社区MinIO。PG/Redis仅内网，公网只开HTTPS入口，秘密只读挂载，不进入镜像或日志。

部署入口拟为`./deploy.sh --env private.env --release <version>`，不是当前已存在命令。步骤：检查端口/凭据/桶→拉取校验镜像→备份→带锁迁移→健康检查→启动worker/事件→切换路由→双端冒烟；失败保留旧版并回滚路由。已有443由公网简易版占用，首轮用独立staging域名/入口，切换前核对其他服务，不能直接抢占。

迁移采用expand/contract，旧客户端先兼容读取，回滚不执行drop；不可逆迁移须前置恢复演练。数据卷、证书和私有配置独立保存。备份目标PG WAL＋每日全备及COS对象版本，异机保管；目标RPO≤5分钟、RTO≤1小时，均需恢复实测后才能承诺。

单机不是高可用。约12用户的初始容量以受限图像处理、API/worker分开、PG池和模型并发受控为前提；2核4GiB旧服务器须先测同机其他负载，不能保证容量。Redis建议初始128MiB缓存上限并留进程余量，淘汰只影响可重建缓存；永久状态不得存入其中。

## 放弃的方案

- 直接引入另一套管理主题：图标、表单、弹窗和暗色状态不一致。
- 只跑通`docker compose up`即称生产完成：未证明身份、迁移、数据恢复及弱网。

## 后果与限制

本轮交付为提案、DDL草案和原型；没有生产Compose或业务实现，不宣称一键部署已完成。客服对话、录屏、题库及跨端历史迁移不列首轮范围。
