# PDF 已复制源布局暂停

日期：2026-10-18。状态：proposed。范围：Web 隐藏源布局；仅隔离实验，未接入产品。

## 背景

[隐藏根](../../../../apps/mobile/src/local/batch-export-root.web.tsx)的固定离屏源在整份绘制期间仍参与主文档布局。[下载器](../../../../apps/mobile/src/local/download-batch-pdfs.web.ts)已将其深拷贝进独立打印 frame；绘图库的字体度量却仍使用主文档。此前[外壳 layout 隔离](../../../../docs/postmortem/2026-10-17-pdf-layout-containment.md)没有减小工作计数，本次考察源节点退出布局，而非数值缓存或更换字体度量 Document。

## 决定

仅在首个页面已完成 JPEG 字节读取并进入 PDF 后，且源 Document 的 fonts.status 为 loaded 时，暂时移除受本次根持有的 fixed 容器。保留 React 根、控制器和节点；下一份提交前重接，最终仍由原 finally 卸载。不能提前调用 dispose，因为它会中止下载器持有的根信号。

候选不改变首屏 await 顺序、scale、JPEG 质量、布局适配、原图、缓存、模型调用及绘制生命周期检查。打印 frame 与 React 源是兄弟节点，移除源容器不应移除 frame 的祖先。未就绪字体分支保留原路径，不等待新的字体周期。

实验用 WeakMap 将已复制 frame 内容绑定到原元素；恢复另由容器身份领取，未使用“最新任务”全局槽。样式/aria 标志只是隔离实验的附加筛选，正式实现必须由根交付精确的逐次所有权句柄，不能把外观标志当所有权依据。

## 放弃的方案

本批次阶段诊断只有两条块公式，字体就绪重测开销较小；没有删除重测、推算最终几何或引入跨页字体缓存。跨题测量批处理也未实施，自动表格的内在宽度相互依赖，收益证据不足以支持新增协议。

## 后果与限制

保留隔离候选，不因两个整批计时样本的中位数改善就接入。首段输入长等待仍在；公开回调、取消优先级及多份代次契约尚未成为产品测试。

## 验证

实际私有路由、可见 JPEG/绘制流、RGBA、可信取消和多份检查见[当次证据](../../../../docs/postmortem/2026-10-18-pdf-source-suspend.md)。候选去掉包装后与原两个 Metro 工厂的语法树一致，未新增 await；它不是源码实现或正式构建验收。

接入前补根重接、释放后取消/字体和尺寸回调、逐份身份、重接失败、卸载异常与晚回调反例；另覆盖阅读、纯题、字体未加载及更多份数。保真通过不代表生产流畅，断开节点也不代表物理内存已回收。
