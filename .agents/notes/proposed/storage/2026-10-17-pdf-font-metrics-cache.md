# PDF 单副本字体度量缓存候选

日期：2026-10-17。状态：proposed。范围：Web PDF 单副本字体度量性能。

## 背景

[导出实现](../../../../apps/mobile/src/local/download-batch-pdfs.web.ts)每页新建 html2canvas 渲染器。1.4.1 的 FontMetrics 只有实例内缓存，测量发生于模块全局 document，不是[打印框架](../../../../apps/mobile/src/local/print-batch.web.ts)已等待字体的 iframe。度量反复触发几何读取，是可独立考察的热点；实测、字体替换反例及修正集中保存在[验证报告](../../../../docs/postmortem/2026-10-17-pdf-font-metrics.md)。

## 决定

产品保留原库度量路径。完整快照及减少字体源读取的后续候选都缺少接入所需的整批正收益；暂缓缓存接入和更复杂失效模型，保留候选与失败证据。后续单项离屏布局隔离同样未形成接入收益，见[布局实验](../../../../docs/postmortem/2026-10-17-pdf-layout-containment.md)。不以单批图像相同或一次提速作为接入依据，不将隔离浏览器原型拦截复制到产品。

最窄共享范围是同一任务的单个副本、同一实际测量 Document、稳定的字体与探针样式代次。保留原始字体族和浮点字号；有界映射仅保存 baseline/middle 数值，不共享保留 Document 的 FontMetrics 实例。缓存命中返回独立数值对象，未知状态走原始度量。

归属必须在原调用或 renderer 创建时固定。结束后关闭代次并令迟到查写失效；新任务使用不同映射对象。单副本结束或切换也隔离数值。此约束独立于[客户端 runner 串行](../../../../packages/client/src/local-export-tasks.ts)，因为 bounded 提前结束等待不等于库原生工作已停止。

字体 `status=loaded`、`fonts.ready` 或仅按字体族/字号建键都不充分。已加载 FontFace 可被另一已加载对象替换；须考虑弱身份、描述符与状态失效。真实 CSSOM 与媒体反例另证明规则数量、DOM 通知或 CSS 文本单独都不足。未知状态和容量上限之外回落原始测量，不扩张无限缓存。

若进入接入阶段，要求精确版本、可复现的可读 runtime/types 修改、未启用时默认行为等价，以及当前 Web 真正分发入口的证明。不能只补 `dist/lib`、只增加类型，或以另一份构建的成绩代替现有入口验收。

## 放弃的方案

- 跨任务或跨副本的永久全局缓存：扩大字体/样式失效面；取消 A 后旧渲染可能继续，清空再复用同一 Map 会允许迟到回填。
- 在迟到 getMetrics 中读取全局当前任务：可能把 A 的工作绑定给 B。实验在 iframe、context、实例链路固定归属，而不是临时切换共享原型闭包。
- 只检查字体已就绪：真实浏览器已复现同样 loaded 状态下的旧值复用，故已修正实验而未移除断言。
- 仅补丁私有 lib 文件或降低截图分辨率：前者没有命中公开分发入口的证明，后者不是本次保真提速方向。
- 每次 parseMetrics miss 都完整序列化 CSSOM：同批扫描成本已超过对照的原字体度量成本，抵消初始收益；不因同样带扫描的对照更慢就采纳。改进失效成本仍须保持正确性，不退回只监听 DOM。
- 整个 getMetrics 外层新增扫描：实验实际只包装 parseMetrics，外层会扩大调用次数及成本，也不是直接迁移原候选。

这些取舍不替代已采用的[异步 JPEG 编码](../../implemented/storage/2026-10-16-pdf-async-jpeg.md)或[并发挂载](../../implemented/storage/2026-10-16-pdf-concurrent-mount.md)，也未新增让步点或更换首帧绘制顺序。

## 后果与限制

减少内嵌字体源读取仍保留普通样式完整检测，真实源替换与整批画质均通过，但样式检测成本依然超过原度量节省，暂不接入。规范要求的字体对象替换、同步未就绪回落及独立成本见[源代次报告](../../../../docs/postmortem/2026-10-17-pdf-font-source-epochs.md)。选择器剪枝没有实施，单凭不匹配 body 不足以排除间接布局影响。

若将来重启候选，仍需承担字体/样式状态读取、容量回落、生命周期与依赖维护成本；不同布局、特殊 fallback、字体失败、伪类/容器查询及 A/B 真实迟到交错尚未形成完整门禁。字体缓存不自动解决输入捕获、解析长任务、独立原生取消或资源静默。

## 验证

字体/所有权数据见[度量报告](../../../../docs/postmortem/2026-10-17-pdf-font-metrics.md)，CSSOM、媒体红绿及完整扫描取舍见[样式报告](../../../../docs/postmortem/2026-10-17-pdf-font-styles.md)。隔离实验不等于产品回归或生产流畅性达标，产品源码与构建尚未接入该候选。
