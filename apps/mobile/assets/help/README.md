# 使用说明配图

2026-10-21从当前网页版截取，全部使用合成练习与隔离本地记录，不含真实题图、个人信息、模型配置或凭据。仅用于网页版的图文使用说明。

- `pdf-options.png`：导出内容、版式、错题标记及份数设置。
- `wrong-question.png`：带错题标记的预览页眉。
- `export-menu.png`：“我的”菜单中的导出记录入口。
- `start-question.png`、`crop-question.png`：开始拍题、选择图片与确认裁切。
- `batch-order.png`：批量导入前排序、上移、下移及确认入口。
- `question-materials.png`：同题补图保存后的材料与重新解答入口。
- `history-search.png`：单题/批量切换及关键词搜索。
- `backup-records.png`：导出本地记录的完整备份入口。

更新界面后应重新核对按钮名称和位置；替换图片时同步核对[PDF配图](../../src/components/pdf-usage-guide.web.tsx)与[操作配图](../../src/components/usage-guide-screens.web.tsx)中的宽高比。截图与零模型调用证据保存在忽略目录 `.runtime/usage-guide-2026-10-21/`、`.runtime/usage-guide-more-2026-10-21/`。
