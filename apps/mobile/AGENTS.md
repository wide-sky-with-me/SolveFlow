# AGENTS.md — 通用客户端

阅读 [设备运行](../../docs/subsystems/device-runtime.md) 和 [图文与切题](../../docs/subsystems/rendering.md)。

- 维护 RN/Expo 通用客户端，平台差异放 `.native` / `.web`；不新增另一套前端。
- 核心从 `@solveflow/client` / `@solveflow/agent/mobile` 调用，不直接导入 Pi、服务端配置、数据库或 Node 专用包。
- Android 密钥用 SecureStore，Web 密钥仅内存；设置切换与活动任务互斥。新题保存考试快照，改默认值不覆盖历史。
- 单题/批量模式在相机内选择，连拍默认同批；历史保持单题、批量、搜索的扁平入口，说明集中到使用说明。
- 前端不得随意新增说明性小字；优先用准确的标题、标签和按钮表达操作。删除重复说明和宣传文案，非必要流程解释集中到使用说明或折叠项，不占题目主体空间。仅在影响当前操作或判断时显示必要提示，保留错误、识图疑点、任务反馈和数据丢失等实际风险提示。
- 相机拒绝后保留相册入口；关闭和迟到授权回调释放设备资源。题图规范化、裁切、EXIF 清理与大小限制不能绕过。
- 图片长按走系统分享；取消分享不作为发送成功。Pearson 等外部展示工具不得成为 App 实体或打包资源。
- DOM 禁止 raw HTML，限制链接协议，KaTeX `trust=false`；禁止任意远程题图。Service Worker 不缓存 API、SSE、私有图片或会话。
- 公共组件使用主题、按钮和动效约定；保留深色模式、系统字体、减少动态效果、键盘与短横屏可访问性。
- 切题保留旧页直至目标读取、布局和文档绘制就绪；页缓存有界，保留草稿与阅读位置。Android 原生合成确认不能用 JS 定时器冒充。
- Android 前台服务支持后台解题；系统杀进程后只恢复状态，不重放任务。不得向手机真实数据库注入损坏或清库。
- 备份/恢复不包含设置与密钥；坏题覆盖必须有明确的应用内确认，失败保留原数据。
- UI 变更验证实际交互；动画问题结合逐帧画面与系统帧指标，不用浏览器移动视口替代真机结论。见 [打包验收](../../docs/cookbook/android-release.md)。
