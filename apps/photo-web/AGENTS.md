# AGENTS.md — 公网精简拍题

- 独立浏览器入口，只保留考试选择、单张照片解答及当前浏览器历史；不引入设置、导出或批量界面。
- `src/browser` 不依赖 Agent、Node 或服务端模块。真实模型凭据只在 `src/server`，请求不能指定模型、URL、工具或运行预算。
- 服务端校验访问密钥、同源请求、图片和额度；未登录不得派发模型。Cookie使用HttpOnly，公网必须HTTPS；日志不含密钥、照片、模型正文或内部思考。
- 历史按访问身份分库，本地事务和取消复用客户端引擎；刷新不重答。共享访问密钥不是多用户云端数据账户。
- 部署只操作本项目新建服务与目录；不覆盖现有Mac服务。详细部署与恢复步骤归所属文档。
