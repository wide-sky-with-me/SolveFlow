# SolveFlow 公网手机拍题

独立精简入口：访问密钥登录、考试选择、单张拍照/相册、简洁答案和当前浏览器历史。没有模型设置、批量或导出页面。单题沿用简答模式，结果标明未校验。

浏览器复用客户端引擎与本地历史；服务端执行固定模型流程，访问Cookie、图片校验、并发/每日额度和重复提交保护均在后端。已接收任务支持刷新和断线后恢复结果，不自动付费重答；临时结果不是跨设备云历史。模型密钥不进入浏览器，开发资源不进入学生提示。

停止先保存本地取消，离线时暂留同步状态；恢复后只补取消，确认后提示消失，不恢复已取消答案。拍下一题仍受服务端并发和额度约束。

进度直接接收运行事件，照片读取按运行ID/序号合并；迟到读取不能将新重答或终态退回排队中，未保存的内存结果仍保留。

联网或回前台时放弃挂起的旧状态查询，按原轮询间隔读取同一任务；不重传照片，不增加答题派发。

界面沿用完整版的蓝灰主题、纸张插画和紧凑按钮。默认选择“未指定”考试；考试选择使用带选中标记的浮层，支持方向键、Home/End、Enter、Esc及点击外部关闭；解题时锁定选择，历史保留题目原有考试快照，缺少考试字段时显示“未指定”。主题跟随系统，兼容320宽及短横屏。答案尚未保存时禁用退出，先重试保存。

重新解答等待中、失败或停止时，保留已有的有效答案并标为“上次答案”；本轮失败单独显示，不把旧答案冒充新结果。原图入口独立保留，首次解题失败或缺少识别结果时仍能查看。缺少题目信息时显示本轮补充要求。删除确认与中心平台共用弹窗：先聚焦“保留”，Esc关闭，删除完成后回到历史页签，连续确认不重复删除。公网错误提示只提供学生可执行的操作，不要求检查隐藏的模型设置。

- 构建：根目录`pnpm build:photo-web`。
- 检查：`pnpm --filter @solveflow/photo-web typecheck`、`pnpm test:photo-web`；后者需要先构建并有Chrome，只用合成题/假模型。设置`SOLVEFLOW_PHOTO_TEST_ENGINE=webkit`可改用已安装的Playwright WebKit。
- 打包：`pnpm package:photo-web`；从当前锁定依赖离线收集Sharp运行库和Node，不打包配置、历史或真实图片。
- 运行：`SOLVEFLOW_PHOTO_CONFIG`指向0600的服务端配置，`pnpm start:photo-web`。

部署、签名证书续期、访问密钥交付及回滚见[操作指南](../../docs/cookbook/public-photo-web.md)；边界原因见[决策](../../.agents/notes/implemented/architecture/2026-10-31-public-photo-web.md)。
