# AGENTS.md — 中心考试平台

- 学生端和管理端共用 `packages/web-ui`；浏览器只依赖共享契约和 UI，不导入数据库、Agent 或私有配置。
- 各功能文案保持精简，导航已表达的页面标题不在正文重复；筛选保留无障碍名称，说明文字只保留操作需要的内容。
- 当前语义归 [中心考试平台](../../docs/subsystems/managed-exams.md)，运行步骤归 [操作指南](../../docs/cookbook/managed-exams.md)。不要将提案中的待实现能力写成已完成。
- 身份从持久Cookie会话读取；每次题位、文件、事件订阅检查归属。学生请求不能指定owner、模型、工具或预算。
- 写入走HTTP事务，WS只通知；拍摄、重拍和补图固定题位ID。断线不取消已接收任务，重启不能重放已派发付费请求。
- 原始解答与练习展示分开保存；模拟结果不继承原始核验或解释。目标分数映射没有来源时不生成精确承诺。
- 只用隔离数据库、合成图和假模型回归。真实模型、私有对象桶和部署分别验收；不借用既有公网服务。
