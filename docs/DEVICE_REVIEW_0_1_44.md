## 后台问题与对照

最初“回到桌面后服务仍在”不能证明解题继续运行。第三张批量题解题约 6.0 秒，但校验仅留下请求开始；返回前台后才收尾，任务耗时约 108.6 秒。再次单独校验时，系统在进入桌面约 8 秒后，对 SolveFlow 进程报告厂商扩展的 `isFrozen=true`、`allowFreeze=true`，即使标准进程状态仍是前台服务、`mHasForegroundServices=true`。标准 Android 缓存冻结字段另为 false，不能混为同一个标记。

系统“应用信息 → 电量 → 后台耗电管理”的原设置为“智能控制后台耗电”。此次将 **SolveFlow 单个应用** 改为“允许后台耗电”，未修改全局省电策略。相同模型、相同题图重新解答后，在桌面后台完成：

| 项目 | 诊断结果 |
| --- | --- |
| 解题首次内容 / 输出结束 | 2.2 / 6.5 秒 |
| 校验首次内容 / 输出结束 | 10.4 / 14.5 秒 |
| 整个任务 | 21.1 秒，正确答案 C（44），独立校验通过 |
| 原生服务 | 切到桌面后约 25.5 秒采样时已释放，返回前台之前确认 |

解除该应用的后台限制后，活动任务期间不再出现上述厂商冻结标记。此次故障与手机后台策略有关；这一次对照不能代表所有 Android 厂商、息屏或省电状态。允许后台耗电可能增加活动任务期间的耗电，任务结束后的服务释放已实测。
