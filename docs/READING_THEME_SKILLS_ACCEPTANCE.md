# 0.1.15 阅读、主题与学科方法改进

日期：2026-09-17。继承 0.1.14 的后台服务与诊断，见[后台验收](BACKGROUND_SOLVE_ACCEPTANCE.md)。

## 本轮行为

- 默认跟随系统外观，通过 React Native `useColorScheme` 订阅系统变化；“我的 → 外观”可选择跟随系统、亮色或暗色。选择保存到已有本地存储独立 `appearance` 键，版本1，不改动模型设置或题目记录。主题切换不重建工作区、不取消或重提模型任务。
- RN 使用订阅主题的基础视图映射原有设计色板，不修改动画值、布局或照片像素。正文 DOM、历史 DOM 和公式预览通过显式 theme 属性同步，公式、辅助图、弹窗、输入框和状态栏随之切换。系统暗色启动资源一并配置；iOS 未构建验收。
- 澄清问题、用户追问和更正内容统一使用现有安全 Markdown/KaTeX；图题、图注与图例同样渲染公式。保留源码输入能力，不把 `$...$` 当普通展示文字。仍禁原始 HTML、外部图片和危险链接，KaTeX trust=false。
- 图形在答案区直接可见，也在详细步骤区复用显示；仍只有一份题目图数据，每道题的图仅出现在该题内。自动缩紧图形横向留白，保留等比例几何关系，窄屏可放大/横向滚动。步骤默认折叠不变。
- 绘图 Skill 说明定义域、范围、轴单位、关键点、解析多项式、采样近似和不同学科图表的边界；不为重复展示复制 figure 数据或扩大3图预算。
- general 按读题、材料、论述、图表、实验和表达题型组织，补充语文、英语、历史、地理、中立社会科学及信息技术方法。math/physics/chemistry/biology/economics 按各学科主要分支扩展，参考文件只是可选补充，不再暗示只能处理少数例题。
- 能力白名单、只读资源、calculate、Pi 循环、独立 Verifier 与固定内容安全边界保持不变；不声明能生成目前不支持的地图、器官图、分子结构或运行任意程序。
