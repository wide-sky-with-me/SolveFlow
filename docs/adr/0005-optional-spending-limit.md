# ADR 0005：累计费用限制默认关闭

2026-09-14，用户明确要求取消当前费用额度限制，默认无限测试额度。此要求取代M0阶段默认30元上限与强制供应商硬额度确认；它不表示更改供应商账户套餐或免除真实计费。

`SOLVEFLOW_LIVE_BUDGET_RMB`缺省、空值或`unlimited`均表示无限累计费用，内部使用null表示，避免Infinity在JSON中被隐式转换。正数表示可选的本地累计RMB上限，不再限定30元；数值须在整数micro-RMB可安全表示范围内。用户当前.env与.env.example均改为unlimited。实际模型、供应商、endpoint与密钥仍来自服务端配置，不回退或改用其他型号。

无限模式下，API准入和真实Solver/Verifier父侧授权不再读取或追加费用账本，也不要求初始化标记，因此旧余额、锁、账本丢失等都不会成为费用准入障碍。原账本完整保留，不清空、不把历史支出记为0。预检明确输出budgetMode=unlimited，而非虚构余额。renew命令在无限模式拒绝执行；无需继续重置额度。

`SOLVEFLOW_LLM_HARD_QUOTA_*`及旧DMX别名仅保留解析兼容，不再参与准入。保留显式LIVE_CALLS、模型与凭据配置验证、固定路由身份和每run最多10次模型外发授权。原有Solver/Verifier轮数、工具限额、取消及120秒总时限继续有效，它们属于运行边界，与累计费用无关。模型报价元数据仍保留，有限模式继续用原保守预占；无限模式不声称计算实际账单。

费用控制不需要在所有生产部署强制启用：共享模型账户可能需要服务商侧配额或按租户计费，但本地开发账本不能替代这些能力。本次保留可选有限预算以兼容既有记录和有需要的部署，默认路径没有该门槛。有限模式会继续考虑账本已有历史，切回有限模式不自动新建窗口。

复现测试覆盖无限模式下经过编译application入口、真实Pi/原图/独立Verifier与本地合成提供商完成解题，且Spy确认不读取/打开账本；另验证无限费用下不放开错误路由、取消和请求次数边界，以及有限预算与旧记录回归。实际验证数量见PI_COMPATIBILITY.md最新记录。

实际验收：497项离线/23项隔离DB与存储集成通过；lint/typecheck/build:server通过。服务在原3100/3101端口重启，网页和API均HTTP200，solvingAvailable=true，m1:preflight报告unlimited。没有进行本轮付费解题；未修改前端，未重跑Next构建和浏览器E2E。此前发现的多题请求与工具失败处理仍是独立待处理项，不因取消费用限制而宣称修复。
