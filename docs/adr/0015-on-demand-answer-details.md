# ADR 0015：本地简洁答案、按需步骤与手动校验

日期：2026-09-17。状态：用户已明确授权。

## 决定

Android 与 RN Web 默认生成简洁答案：必要的关键算式或依据与结果，核心结果使用 Markdown 加粗。首轮不生成完整步骤和知识点长篇解释。题干仍完整复述，图示在解题必要时保留；原有按题分组与图片证据不变。

用户展开“详细步骤”时，为所选题目与解答版本创建独立 explanation run，保留原答案可见，支持取消、失败重试与本地缓存。成功后重复展开、切页和重启不重复请求。步骤需要重新核对原答案，不能把旧答案当真值。

本地校验默认关闭，只在答案旁提供“校验”按钮，不增加设置项。点击后创建 verification run，独立 Verifier 无工具，读取原图、适用的更正条件及所选候选答案。只检查一次，不自动重做答案；发现问题明确显示，用户可以重新解答。详细步骤可单独校验，避免把简洁答案的校验结果套用到新生成的步骤。

初次输出不设置 verified，通过可选 verificationStatus=not_requested 区分“尚未请求校验”和“校验失败”。只有有效 PASS 才能设置 verified。校验期间保留原答案，状态只更新按钮。明确的内容违规校验结果仍替换为固定拒绝；Solver/Verifier 始终共用原有内容政策。

## 契约与兼容

- 输入新增 answerMode=brief|detailed、verificationMode=automatic|manual；本地引擎显式选择 manual。
- verificationTarget 仅由引擎从本地已保存、同题合法来源解析，不接受模型自行选择任意记录。
- run context 新增 explanation 与 verification，关联 sourceRunId 及可选题号。两种操作不成为同题追问的新答案版本。
- 简洁输出 schema 限制空步骤及无详细知识点；多题允许空 stepIds。旧持久化结果继续使用原契约解析。
- 旧服务端路径未指定模式时仍按既有自动校验及最多一次修正执行。此次没有迁移旧服务数据。

仍采用原 Pi Agent 循环、受审 Skill 与权限工具。120 秒期限、单题一个活动任务、幂等及取消后的终态保护不变。没有自动模型切换或密钥打包。

## 展示与验收

历史解答移到“查看原图”旁，弹出版本选择，仅挂载所选解答；减小顶部页签空档。Android 答案 DOM 按文章内容测高，关闭视口驱动的 matchContents，屏蔽分数像素反馈并固定 WebView 文本缩放，仍支持系统字体大小、详细步骤展开和窄屏公式滚动。

验证必须分别覆盖无自动校验、手动 PASS/FAIL、原答案持续可见、步骤缓存与重试、旧记录恢复、实际 APK DOM 高度反馈及真机抖动。真实模型单题耗时仅作本次观察，不能当作普遍性能承诺。实际记录见 [验收](../ON_DEMAND_ANSWER_ACCEPTANCE.md)。

2026-09-18补充（以最新用户要求为准）：选择题模型直接输出problem.options和selectedOptions，answer只承载简短解释。前端按字段显示“答案：原选项标签”、逐行选项与下方解释；删除选择题文本正则提取，不做旧格式兼容。标签必须属于本题选项，多题/追问/按需步骤保留各题标签。耗时分析及实际验收见[选择题验收](../SAT_CHOICE_ACCEPTANCE.md)。
