# ADR 0022 — ESAT、TMUA、TARA 考试增强

- 日期：2026-10-02
- 状态：已接受
- 授权：用户指定 https://esat-tmua.ac.uk/prepare/ ，要求解析三门考试特点，并按已有考试类型实现增强。

## 范围与实现

2026-10-03 用户进一步明确：Pearson 官方交互播放器只在外部浏览器中展示样卷，供手机使用 SolveFlow 拍照测试；它不是应用组件，不引入播放器、网页嵌入、平台账号或试卷接口，也不进入安装包。三门考试增强仅包含以下受审方法与既有解题链路。

扩展 `ExamTypeSchema` 为 general/sat/act/ap/esat/tmua/tara。首次配置和设置提供新选项及简短能力说明；沿用现有题目/批次考试快照，不增加模块选择必填项。模块/卷别从明确题面或用户补充确定，只有影响答案的条件缺失才澄清。历史无 exam 的记录仍按 general，改默认值不改旧题。

新增三份受审参考 `resources/skills/exams/references/{esat,tmua,tara}.md`，更新考试 Skill、学生 SYSTEM、VERIFIER、原生资源生成清单和服务端 Skill 白名单。设备在 Solver 与 Verifier 首轮提供考试通则及所选一份参考；其他学科 Skill 继续按需读取。只增加参考文件，不增加工具权限、网络抓取、模型路由或另一套 Agent 循环。

- ESAT：无计算器的数理应用；模块辨认、单位/量纲、科学图表、精确计算与原选项对应。
- TMUA：数学应用及逻辑证明；if/only if、必要充分、量词与否定、反例、证明错误及定义域。
- TARA：按论证分析、数值/空间问题与写作区分方法；作文默认只答选定一题，最多750词，完成题目论证要求。UAT-UK不为作文评分，不虚构分数。词数是模型指令和核验要求，本次没有新增确定性的官方词数计算器。

共用输出继续使用原 `problem.options`、`selectedOptions`、answer/按需步骤；完整写作不得因brief变成摘要。单题手动校验、批量自动校验等既有规则不变。

## 依据与兼容

采用2026-10-02读取的UAT-UK官方概述和2026年10月/2027年1月适用规范；具体资料、差异分析和实际验收见 [增强记录](../UAT_UK_EXAMS.md)。不复制整份规范或官方题库，不把旧入学考试整套成绩换算视为新考试规则。

这是枚举的兼容扩展，无数据库表变更。新客户端继续读取旧考试；新枚举题目或设置不保证旧版客户端可读，不能降级后宣称兼容。备份沿用现有结构，exam值保留。

## 验收边界

覆盖契约、受审资源读取、首轮请求、独立Verifier无工具与原图、单题/批次快照、旧题追问、导出和桌面/窄屏设置流程。离线模拟仅证明工程链路，不证明三门考试答题准确率。当前未授权新的真实模型接收端点，不进行付费外发测试。
