# ADR 0019：历史手势、统一题目页与返回路径

- 日期：2026-09-21
- 状态：已接受；用户要求修复左滑、批量详情与返回行为。

## 决定

历史列表由自身视口处理纵向滚动，移除外层原生 ScrollView 对同次触摸的竞争。横移达到6px且至少为纵移的0.85倍时锁定横向，20px拖动或12px快速轻扫展开操作；明确纵向后交给列表滚动，保留菜单按钮和键盘入口。翻页重建滚动容器，避免上一页的触摸惯性继续推动新页。仍每页最多20题。

单题与批量在“当前题目”中显示，共用 QuestionReader、QuestionPager、QuestionThread。批量详情不再是独立全屏 Modal，不提供额外返回按钮；原图、设置、相机等既有模态交互仍先自行处理返回。

本地页面历史最多保留32项，仅存页面、题目ID与批次信息，不复制图片、答案或模型状态。从历史/收藏打开后，返回对应来源；历史的分类、搜索、页码、滚动位置继续保留。Web 使用浏览器历史支持前进/后退；Android 系统返回先回上一个页面，到根页面后第一次提示“再按一次返回退出”，2秒内再次返回才退出。页面导航、触摸或应用前后台切换清除退出计时。

不改变持久化契约、Pi 循环、模型配置、付费请求、后台队列与数据删除语义，不增加依赖。页面历史仅存于当前应用进程；重启沿用既有题目恢复入口。

2026-09-22 审阅修复：删除后按实际剩余记录清除前进、后退及“当前题目”缓存中的失效题目/批次引用，保留浏览器条目 key；仅删除批次内一张时保留批次并清除该选中 ID。返回空白首页时同步清除旧题显示。搜索词变化从第一页展示，单纯离开再回到历史仍保留页码。批次相册选择等待期间禁止重复打开；若期间离开该批次页面，迟到图片释放，不保存或启动解题。

会话内解答以持久化追加顺序为准；单题和批量的事件更新均按 ID 原位替换，首次出现才追加。禁止按设备墙钟 `createdAt` 重排解答，也不能把旧解答的迟到事件移到数组末尾：设备自动校时回拨或同毫秒事件会破坏原题→追问的顺序，导致旧答案覆盖追问进度、取消入口或重新解答失败提示。历史题目列表仍按保存日期展示。

## 验证

导航状态单测覆盖单题/批量来源、浏览器前进后退、容量边界、退出计时及清除。手势回归先复现短斜向滑动旧阈值失败；浏览器覆盖实际触摸、长列表滚动与惯性期间翻页、单题/收藏/批量返回。构建和真机结果见[历史管理](../LOCAL_HISTORY_MANAGEMENT.md)。
