# ADR 0006：明确指定的多题解答与题内图示

日期：2026-09-14。用户要求按题分割，逐步展开解答，图放在所属题内；据此将原单题范围扩展为同图明确指定最多4题，仍不做整卷批改。

已保存记录显示：4题的12个步骤平铺，各步骤标题重复题号，唯一图示在全部步骤末尾。仅改提示词无法给前端可靠的归属。

采用v1向后兼容的可选questions元数据：number、该题answer、按顺序的stepIds、figureIds。原steps/figures保持全局唯一ID，避免两份步骤正文漂移及Verifier/revision引用失效。运行时校验题号唯一、2–4题、每个步骤及图恰好归属一次，继续保持总16步/3图与原有调用、输出及时间上限。新多题必须按提示填写questions，单题沿用原结构；不引入额外依赖。

页面每题一个区域，顺序为题号、教学步骤、题内图示、结论。步骤编号题内重启、标题公式用现有Markdown/KaTeX。教学步骤讲已知与方法、关键推导和结论，不展示模型内部思维链或流出未验证正文。Verifier对照原图核对全部指定题目、选项及图示归属，任一题错误不标整组通过。

历史数据保持不变；仅当答案、全部步骤和全部图示都有一致明确题号时生成兼容分组视图，歧义时原样展示，不能编造图示归属。不重新求解或重新认证历史答案。数据库无需迁移；升级API/worker并同步构建Web，旧页面需刷新以读取新增字段。

代价：引用元数据略增输出长度，仍受32KiB及环境配置token上限限制；复杂四题可能触及现有任务预算。当前无每题单独校验状态，也未实现原图按题自动裁切；统一原图预览保留，多题提示不在各题重复嵌入整页照片。

验收结果见docs/MULTI_QUESTION_ACCEPTANCE.md。
