# ADR 0004：显式授权新的预算窗口

2026-09-10，用户表示“我重置了额度，你再试一个复杂点的题目试试”。沿用此前30元限额，授权新一轮30元测试预算。此明确授权允许追加新窗口，不改变旧账单、不退款；更换模型、额度不足、重启服务本身都不构成续额授权。

固定账本新增version 1/type=renew记录，包含唯一授权标识、上一窗口预占总额与新窗口限额；重放校验总额、重复ID与固定配置限额。旧reserve/settle记录兼容，全部保留，attempt ID跨窗口仍唯一；settle不释放额度。每个窗口仍最多30元，供应商硬额度前提保留。旧程序不识别新记录时失败关闭，服务需同步更新。

管理员在没有活动调用时执行 `node scripts/renew-budget.mjs --confirm-new-budget <唯一授权ID>`，此前先build:server并确认.env门控和供应商额度。命令不接收任意账本路径、不重建丢失文件，不自动生成授权ID，因此重复执行同一授权失败；不得因低余额自动调用。学生HTTP、worker、模型无续额入口。

本次记录ID为user-reset-20260910-complex-1，原窗口7条预占合计27.499072元完整保留。新窗口30元。预占是保守调用许可，不等于供应商实际扣费。
