# ADR 0020：考试评测后的答案完整性与工具收束

日期：2026-09-28。状态：用户授权实施；真实对照结果见 [修复验收](../EXAM_FIXES_2026_09_28.md)。

## 依据

[原评测](../EXAM_PHOTO_EVAL_2026_09_28.md)完成 918 道模拟照片主测及 88 道清晰图对照。用户要求根据发现的问题修正。主要工程问题为 brief 答案字段过短、校验接近总期限时丢失已生成答案、重复工具调用耗尽轮数；英语句界和图示边界也有模型误判。

## 决定

- 普通选择/填空仍要求短答；题目明确要求的作文、证明、多小问属于答案正文。顶层与分题 answer 上限统一为 8000 字符，brief 的教学 steps / knowledgePoints 仍为空。字段结构与版本不变，属于向后兼容的上限放宽；旧版客户端不保证能读新版长答案。设备最终 JSON 总量仍受 64 KiB 限制，流量限制不变。历史上下文仍按现有摘要上限截取，持久化原答案不截断。
- 设备 verifier 阶段取 `min(20秒, 总剩余时间−1秒)`，为退出和落盘留余量。超时仅按现有语义发布未校验候选；真实总超时、取消、权限失败仍为终止条件，不伪造 PASS。不是为 Solver 新增可用时间。
- 使用锁定 Pi 0.85.1 的 `prepareNextTurnWithContext` / `beforeToolCall`，不重写循环。相同工具参数累计三次、连续两次工具错误、任一工具类别达到现有上限、工具轮后剩余不足 25 秒时，下一轮不再提供工具，要求依据已有证据完成或明确澄清。若仍请求工具，阻断执行并以 TOOL_LIMIT 结束；已有的一次格式修复仍可无工具执行。该状态按 phase 隔离，不阻止独立校验或合法修正。
- 增加受审 SAT/ACT/AP 方法提示：先解析完整句界及替换范围，区分证据与常识推断，核对图例与箭头端点，完整完成原题要求。Verifier 单独从原图判断，不把候选转录当已核实事实。未注入测试题号、选项答案或评分真值。
- 维持用户模型、思考设置、120 秒总预算、16 个 Solver 请求、工具与校验次数上限、无自动 fallback。服务 HTTP 400 尚无根因证据，不据此改供应商参数或自动重试。

## 验证与限制

先补复现测试并观察失败，再修实现；覆盖长答案与旧记录兼容、无工具收束后的独立校验/格式修复、重复工具阻断、晚启动校验超时，以及原有取消/硬期限不变量。另用原模型原参数原图复测所有错答/技术失败、长答/图表诊断及原本正确的题；新结果独立保存，不能覆盖原整卷成绩。

提示词改进不能保证模型不再误判，同模型校验仍可能共同犯错。此次是电脑端生产解题核心与模拟照片验证，不等于真实手机相机、后台生命周期或未见新卷准确率验收。
