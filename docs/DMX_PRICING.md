# 历史：DMXAPI 临时型号报价核实

核实日期：2026-09-10。本页记录首次M0探针所用 `deepseek-v4.1-flash-expires-on-0910` 的历史报价；它已不是本机当前配置。用户更换后的引用及M1网页实测见 [M1真实验收](M1_LIVE_ACCEPTANCE.md)。

## 来源与口径

- [DMXAPI 模型价格页](https://www.dmxapi.cn/rmb)的实际页面脚本调用[公开人民币报价接口](https://www.dmxapi.cn/api/dmxapi/rmb/pricing/public)。本次以无凭据 GET 读取对应型号条目，没有调用模型。
- 此条目 `billingMode` 为 `tiered_expr`。普通输入 1.5 元/百万 tokens，输出 4.5 元/百万 tokens，缓存读取 0.05 元/百万 tokens；周一至周五北京时间 09:00–12:00、14:00–18:00 翻倍。两个时段互不重叠，最高倍率为 2。
- 本机两个角色的配置均采用高峰上界：普通输入 **3 元/百万 tokens**、输出 **9 元/百万 tokens**。缓存读取按更贵的普通输入预占。探针不会执行远端表达式或按低于这两个受审上界的配置预占。
- `modelPrices` 中的基础价格零值是该表达式计费条目的占位字段，不能当作免费。公开报价不是当前账户/令牌分组的实际账单；特殊分组或价格变化须重新核对。
- [计费文档](https://doc.dmxapi.cn/jijia.html)说明 cn 站人民币计费，并按供应商返回的 token 用量计费；[DeepSeek 思考参数文档](https://doc.dmxapi.cn/thinking-deepseek.html)说明思考 token 按输出计费。没有套用 DeepSeek 直连或美元价格。

## 额度与预占

用户本次指定累计额度 30 元；已填写本机预算与额度金额，但金额本身不证明后台开关状态。[令牌文档](https://doc.dmxapi.cn/lingpai.html)确认可设置 CNY 额度及“无限配额”。用户随后明确确认当前专用令牌已设置30元且关闭无限配额，因此已启用配置确认门控。确认来自用户，不能把公开文档当作账户设置的独立证据，也未证明任意并发/延迟扣费场景绝不透支。

当前公开参数给出上下文 1,000,000、最大输出 384,000 tokens。初次探针对每次请求按完整输入/输出容量预占：`1,000,000 × 3 / 1,000,000 + 384,000 × 9 / 1,000,000 = 6.456 元`。实际请求发送 `max_tokens=4096`，但此临时型号的实际限制语义尚未验证，预占不依赖它降低费用。较高的用户报价会提高预占。

正常离线样本为两次 Solver（含 read 后续轮）加一次 Verifier，按上述价格真实运行会预占 19.368 元。这不是实际扣费；未知账单保持预占且不退款，30 元账本最多容纳四次该上界请求。不得清空账本以便重跑；后续若改用更紧的经过验证的 token 上界，必须保留历史累计记录。
