## 验收边界

- 代码审阅阶段未连接手机，浏览器和 APK 资源验证不代替真机验收。随后追加的覆盖安装、相册、返回、缩放和桌面后台结果单独记录于上述真机回归；连续拍摄、息屏和稳定三并发仍待验证。
- 取消保证以 `cancelRun()` 成功返回为提交边界。最终写入中收到取消会纠正保存；进程在纠正落盘前被杀或存储本身失败，仍不能保证取消落盘。跨崩溃的更强保证需要持久化取消日志或底层事务设计，本轮未扩展架构。
- 本次未改服务端数据库/对象存储，不启动外部数据库、对象存储或运行相应集成测试；不将离线测试标为真实模型准确率或性能评测。
