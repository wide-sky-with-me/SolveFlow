# 考试安排工具栏换行与提醒焦点

2026-11-18，在隔离 PostgreSQL、Chrome 和 Playwright WebKit 中验证中心考试管理页面。

## 复现

场次详情的工具栏使用两列网格摆放搜索、刷新和新建三个控件。2560 像素宽度下，新建按钮仍比刷新按钮低 57 像素。教师提醒的容器使用 `:focus-within`，点击内部按钮会给整块提醒加外框。两个浏览器均复现了这两处问题。

## 验收

- [场次与成员](../subsystems/managed-exam-events.md)的界面测试遍历 320、390、640、641、760、761 和 2560 像素。390 像素及以上的受测宽度中，搜索、刷新、新建同排；320 像素保留完整搜索框，刷新与新建一起换行。
- 在桌面验收新建用户、选择考试模板、新建场次与搜索同排，在 640 像素验收添加学生与搜索同排。场次详情继续完成新建、编辑、配置学生和删除的完整操作。
- 点击[教师待处理提醒](../subsystems/managed-exam-attention.md)可展开列表，鼠标操作不会出现整卡焦点框。用 Tab 进入题目、Shift+Tab 返回标题时，焦点跟随当前按钮。管理端集成套件 28 项通过，使用合成账号与考试数据。
