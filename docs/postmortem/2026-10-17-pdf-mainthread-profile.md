# PDF 主线程采样与独立输入

日期：2026-10-17。

范围：既有 `127.0.0.1:3100` Web 构建、Chrome 154、CPU 4 倍降速，同一已整理的真实 27 题缓存。模型调用为零，源记录与冻结对照保留。重复执行不算新增独立题目。

结论：长任务包含 CSS 解析、样式构造和字体度量。独立时刻的可信取消及随后 27 页恢复通过，但输入仍有排队；生产流畅性未完成。本轮未修改产品绘制代码，未接入字体预取或新缓存。

## 变更与处理

- 私有诊断器沿用有界关闭及原生 JPEG 包装，另采 CPU profile；首尾命名 JS 标记约束采样与浏览器时钟的偏移，不假定两者同原点。主包、公共块、html2canvas、jsPDF 的 VM 源码与 HTTP、磁盘字节分别一致。
- 另开不带 CPU profiler 的输入实验：取得真实取消按钮坐标后，由驱动独立定时；按下与抬起连续发送，不等待按下完成才发抬起。保留完整可信事件三元组，未使用 JPEG 通知门禁。CDP 可信事件不等于硬件输入。
- 字体预取暂缓：它搬移而不减少实例内测量，旧首屏及分数流原点反例仍需处理，且当前任务不只含字体。新的私有候选只复用单 Context 内已审核的 16 个 CSS descriptor 身份，不改字体、布局或异步顺序。

## 验证结果

### 诊断与取消

带 profiler 的三次恢复各 27 页，另有六次门禁取消作为上下文；这是诊断而非无扰动性能比较。初版函数内计时未包住进出边界，停用于精细任务归因；正式归因采用调用者前后计时包络的重采。该次最长重叠任务 651ms，字体 `parseMetrics` 含子栈权重约 180.4ms，CSS 构造叶节点约 139.2ms，另有分词、文本边界等。权重是采样区间估计，不是精确独占 CPU/原生耗时。未复现先前 1122ms，亦未追认其原因或宣称提速。

修正版要求外层包络标记，观测偏移区间半宽约 0.379ms，不当总误差保证。首次分析错误假定增量非负，遇到 -1µs 增量退出 1；改为累计有符号增量、保留时间戳/节点配对稳定排序，样本完整保留，六项排序/边界用例通过。依据 [协议](https://chromedevtools.github.io/devtools-protocol/tot/Profiler/#type-Profile)及 [DevTools 的累计与排序实现](https://raw.githubusercontent.com/ChromeDevTools/devtools-frontend/main/front_end/models/cpu_profile/CPUProfileDataModel.ts)。未补写缺失栈。

独立定时输入依次为按钮坐标获取后 80/900/4000ms。按下时间戳到捕获为 11.6/247.7/38.0ms；到 click 捕获为 23.7/254.8/46.0ms。驱动定时迟到约 0.23–0.38ms，仅属驱动时钟，未混入浏览器延迟。

click 捕获到首次 abort 为 3.2/0.1/0.7ms，到取消事务提交为 306.4/195.3/188.0ms。到驱动观察下载可用的上界为 825.2/446.5/438.9ms，包含协议及断言等待，不是精确重绘时间。三次均无成品入库或下载，随后真实恢复 27 页；该恢复最长重叠任务 568ms，最大相邻 RAF 间隔 583.2ms，不当作 FPS。

合计四份 PDF、108 页分别完成 A4、单页 JPEG 与冻结对照字节相等、实际下载/入库哈希一致校验；其中 81 页来自 CPU 诊断，27 页来自独立输入实验。原生接口保持真实调用。注册帧已断开，URL 自然回收，各组三个关闭回执成功；不据此宣称原生工作排空或系统级无泄漏。人工查看恢复后的桌面画面，成功提示与下载入口可读。

旧核验器因只接受原目录前缀退出 1，定时实验当时尚未启动；新核验器明确校验两种用例计划、事件顺序及原有成品门槛，复测退出 0。失败日志保留。

### 私有标量原型

`css-scalar-memo-r42.mjs` 使用弱 Context 键、固定 16 身份、每 Context 总计最多 1024 条；仅真正字符串且长度不超过 256，值仅有限数值或字符串。资源、颜色、word-break、对象/数组结果旁路；不规范化 raw，不跨页复用。校验 type/parse 的数据字段，变化或访问器走原解析；IDENT 非规范标识符旁路，保留 initialValue 回退依赖。未冻结描述符或增加等待。

Node 对真实公共 parse 执行 1056 次矩阵对照及八组边界检查，含负零、非有限值、对象转换/原异常、零值命中、身份/Context 隔离、256/257 边界、总上限与满额旧命中、描述符修改、资源调用、完整 CSS 声明读取顺序。原颜色 `constructor()` 返回 Context 的合成反例已实际验证且旁路，未扩大颜色缓存。测试退出 0；这不是浏览器、字体、布局或提速验收，也未验证任意内部 helper 热替换。
