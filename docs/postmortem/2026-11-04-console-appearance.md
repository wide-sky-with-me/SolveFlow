# 控制台导航、主题与动态图表改进

日期：2026-11-04。范围：`feat/public-photo-web`本机工作区，中心考试平台、共用主题/图标及隔离回归；真实模型调用0。未提交、推送或部署远程。

## 变更与处理

参考[shadcn/ui侧栏](https://ui.shadcn.com/docs/components/radix/sidebar)与[Tabler开源控制台](https://preview.tabler.io/)，自行沿用既有React/SVG和蓝灰主题实现，没有复制模板代码或新增依赖。

Logo移至完整宽度顶栏左侧，右侧提供浅色/深色/跟随系统主题。桌面侧栏支持图标折叠和浏览器记忆；窄屏使用原生导航抽屉。主题文件在CSS前执行，保持原script-src限制，不用内联脚本放宽CSP。共用主题的系统深色规则同时适配显式浅色，避免仅改背景导致控件仍是深色。

发布图增加面积折线/柱图切换、悬停和方向键读数；状态环、覆盖仪表、问题条图、模块进度与学生表按功能安排。入场、线条绘制和数据变化有短动效，减少动态偏好下禁用。全部读数仍来自原一致快照；空趋势保留零值，不添加装饰数据。

手工合并用户提供的`change.patch`：正文不重复导航标题，筛选隐藏可见标签但保留无障碍名称，首页/统计/大屏增加手动刷新。手动、自动共享进行中请求，切换筛选或离开会取消旧查询；迟到finally不清掉新请求。没有修改统计口径、角色或模型执行。

截图发现深色提醒过亮、窄屏表格逐字换行，已改用共用语义色及表格内部滚动。额外故障注入复现：偏好写入被拒绝后，进入大屏会重置主题；补充本页内存偏好，跨标签存储更新仍能使其失效。
