# 中心考试列表分页与选择框验收

日期：2026-11-04。

范围：`feat/public-photo-web`的中心平台列表、筛选、选择框和学生考试入口。只使用随机隔离PostgreSQL 17、合成图片/记录和假任务，不发起模型请求。

## 变更与边界

原用户/分配/跟踪最多500、场次200、模板100；前端整体渲染和轮询，超过上限无法继续查看，分配考试和问题筛选的下拉框也被截断。

新界面使用分页信封及服务端计数，按页搜索、筛选、跳转和切换容量；原数组接口留兼容。查询在同一只读快照中应用身份范围，总数不由当前页累计。普通列表用有ID次序的偏移分页，原问题队列保留游标。分配数量、在线数及学生可进入考试/全局问题提示独立查询，避免再次被当前页截断。当前说明归[列表语义](../subsystems/managed-exam-lists.md)。

管理端只轮询当前页面；翻页/筛选取消旧请求，同页读取去重，保存后强制重读。选择框可检索页外选中项，权限与用途过滤仍生效；老师跨页多选提交完整选中ID，不把当前页当所有已选老师。初次默认选择与失效选择分开，失效后不换成别人。

## 发现与修复

- 新夹具首轮缺少`one`导入，退出1；补齐导入后，620学生/625场次/125模板的后端专项通过。
- 问题队列新增搜索最初改变默认解析对象，旧契约断言失败；搜索改为可选，保留原默认输出，11项契约回归通过。
- Chrome按回车翻页后，加载禁用触发失焦，又将页码夹回1；保留回车提交，失焦仅恢复显示，Chrome/WebKit专项通过。
- 原回归发现普通下拉框的listbox区域被改成全部内容高度；普通菜单恢复原DOM，搜索菜单保留独立滚动区域。新增状态过滤使旧测试同时匹配隐藏option和可见状态，测试改为定位实际考试卡片的状态，保留原行为断言。

所有命令在仓库根执行，Node 24.19.0，浏览器目录`.runtime/playwright`；隔离数据库使用已有`postgres:17.9-alpine3.23`，测试容器结束即删除。临时专项脚本只增加Vitest的名称过滤，沿用原180秒期限、断言与容器清理；完整入口仍为`pnpm test:exam-web --image=postgres:17.9-alpine3.23`。

- `pnpm build:exam-web`、`pnpm --filter @solveflow/photo-web build`、`pnpm exec tsc --noEmit`退出0。`pnpm lint`退出0，代码边界及文档检查通过。
- 分页专项5/5通过，58项跳过，24.52秒，退出0；包括真实服务上的Chrome/WebKit操作、末页收缩和旧搜索响应隔离。
- 首轮原功能回归56/58通过，2项失败按上述菜单/定位修复；日志`.runtime/pagination/existing-first.log`保留。
- `PLAYWRIGHT_BROWSERS_PATH=.runtime/playwright node scripts/test-managed-exams.mjs --image=postgres:17.9-alpine3.23`全量62/63通过，131.15秒，退出1；剩余开考测试仍有一处隐藏option定位冲突。修正为考试卡片状态后，临时同脚本以`-t "a future exam auto-enters"`定向复测1/1通过、62跳过，13.99秒，退出0。63个不同场景均有通过证据，不把多轮重复数相加。
