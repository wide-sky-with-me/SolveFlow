# PDF 字体缓存的样式失效与扫描成本验证

日期：2026-10-17。范围：本机 Web PDF 私有字体缓存，不是产品接入或生产流畅性完成声明。

## 结论

前次[字体度量候选](2026-10-17-pdf-font-metrics.md)仅处理字体状态，仍会在样式变化后复用旧值。本次保留真实浏览器反例，加入有界样式状态；初版快照又漏掉样式表 media 的实际匹配状态，继续复现并修正。字体、样式和生命周期门禁保持原强度，没有更改截图质量或首渲染让步顺序。

完整 CSSOM 文本扫描本身成本过高，暂不作为产品方案。只与同样带扫描的对照比较会夸大方案价值，必须同时考虑额外门禁成本；本轮不将私有包装或扫描器复制到产品。

## 真实样式反例

夹具在既有 `http://127.0.0.1:3100` 来源运行，使用精确安装的 html2canvas ESM 原度量方法和本地 KaTeX 字体；只暴露构造器，不改原方法体。两次测量的族名、32 px 字号、body 继承字段及单个 loaded 字体相同，每次新建实例，避免原实例 `_data` 混入验证。

| 插入通用 span 样式 | 旧值复用 | 通过 | 通过 |
| CSSOM 同条规则原地修改 | 旧值复用 | 通过 | 通过 |

CSSOM 反例的规则数量仍为一，head MutationObserver 记录为零；因此只看规则数量或 DOM 变更通知不足。已读反例中 baseline/middle 应从 30/19 变为 59/19，旧缓存仍返回 30/19。各例结果、源码与字体哈希保存在独立目录，失败没有覆盖。

## 候选及边界

V3 读取普通、构造及导入样式表的规则文本、禁用状态、嵌套媒体匹配、根/body/直属子节点属性和视口状态；同时保留字体弱身份、描述符、就绪检查及副本隔离。超出 128 表、8192 规则、嵌套深度 8、原始状态文字 1,048,576 UTF-16 码元、每节点 64 属性或 body 128 直属子节点时走原度量；字体集合另限 256、序列化字体状态 131,072 码元，数值缓存仍限 256 项。这些是状态接纳上限，不是峰值分配字节保证。

V3.1 增加样式表及导入媒体匹配；关闭或断开的任务跳过样式快照，迟到回调仍走其自身原度量，不重新保留已清空的状态。合成测试 30 项通过，包括 CSSOM、媒体变化、容量、未知/异常回落、返回值隔离及关闭后的迟到调用。这不是实际原生取消/资源静默证明，也不是应用单元测试。

这些快照不等于任意 CSS/布局的完整模型。容器查询、伪类/后代状态、特殊回退和真实 A/B 迟到交错仍需独立门禁；不以当前反例通过承诺通用缓存正确性。

## 整批与成本

V3 已完成同一真实 27 页批次的三次恢复导出和六次取消。独立校验以先前原版逐页图像为参照，核对输入、当前产品源码、实际入口指纹、包装次数、关闭状态、存储/下载、JPEG 与可用的 RGBA；退出码 0。没有业务模型或页面异常，结束后无 iframe，底层原生静默仍未观测。

| V3 运行 | 恢复导出 | 样式快照累计 | 原度量累计 | 度量调用/命中 | 最长任务 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 画质与剖析 | 27.2441 s | 4274.8 ms | 376.7 ms | 158 / 137 | 1107 ms |
| 无剖析包装对照 | 25.9804 s | 4077.3 ms | 2609.4 ms | 158 / 0 | 938 ms |
| 无剖析缓存 | 23.1083 s | 4031.5 ms | 399.8 ms | 158 / 137 | 855 ms |

均为 CPU 四倍降速。两臂只有一次无剖析计时；一批 158 次 parseMetrics 调用触发的快照累计约四秒，超过对照中全部原字体度量成本。与前轮无此扫描的计时差异只是跨轮提示，不推断长期收益百分比或真机表现。不能因扫描对照更慢就宣称产品加速。

媒体修正版完整画质导出 27.0261 s，158 次调用命中 137 次，样式快照累计 4329.5 ms，最长任务 1190 ms；取消至收尾为 92.6/288.9 ms。它单独与原版完成 JPEG/RGBA、当前运行时、关闭后状态释放及实际执行源码独立校验，退出码 0；没有用初版代替修正版成绩。本轮合计四次完整恢复、八次取消，108 页 JPEG 和新增 54 页 RGBA 对照一致，仍是同批重复验证。

样式独立校验首次将原包字节哈希与 Python 读取后归一化换行的文本哈希混比，退出码 1；定位为 88 处 CRLF，字体字节相同。保留失败日志，补原字节/换行转换断言及实际暴露构造器模块的完整文本核对，重试退出 0。七类红绿、原 loaded 字体替换及冻结 runtime 均通过，未削弱画质或清理门禁。

后续[字体源代次复测](2026-10-17-pdf-font-source-epochs.md)减少源读取后仍未形成足够整批收益，未接入产品。

## 可维护接入复核

静态子审查确认公开 UMD/ESM、入口白名单、内部 iframe renderer、声明与 source map 都需纳入版本补丁。但其把实验包装误读为整个 getMetrics，错误建议每次 getter 都扫描；主会话已据 AST 生成器及真实字体夹具纠正私有报告。

实际实验包装的是 parseMetrics，仅原 `_data` miss 进入外部状态检查。将来迁移优先维持此调用频率，不新加全 getter 快照、不更换测量 document、不共享实例，也不把单实例动态失效说成新能力。该接入尚未实施，source map 维护代价及默认分支等价仍待验证。
