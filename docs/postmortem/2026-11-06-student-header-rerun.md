# 学生顶栏精简与原图重答验收

日期：2026-11-06。

范围：`feat/public-photo-web`本地工作区，承接[已发布版本](2026-11-05-student-teacher-ui-deployment.md)继续修改。使用随机隔离PostgreSQL 17.11、合成题图、假模型、Chrome和Linux WebKit。

结论：移除学生模块省略菜单及顶栏考试名称，记录入口移至头像菜单，考试状态居中且保留结束确认，Logo可回首页；已拍题新增原材料重答。六组最终166项、契约单元16项通过。本地阶段未提交、推送或部署，后续腾讯云更新见[发布](2026-11-06-student-controls-deployment.md)。

## 变更与原因

- 原考试记录/结束按钮占正文一行，考试名称在Logo旁重复。改为[账户菜单](../../apps/exam-web/src/browser/account-menu.tsx)进入记录/退出登录，[状态入口](../../apps/exam-web/src/browser/student-header.tsx)居中展示，名称及结束操作按需查看；学生继续隐藏计时，教师/服务端计时不变。Logo返回首页后不在当前页面自动重入唯一考试。
- 移除学生模块菜单，保留模块页签、总览和上下题；旧跳过API及历史状态兼容。记录仍使用已有搜索、筛选、分页和继续查看。
- “重新解答”复用本题revision和原图/补图，追加普通学生任务，不重拍、不改题号或自动切题。已有答案保留到新结果发布；重复点击、显式失败重试、材料/人工版本竞争均有保护，不重放原始结果。
- [独立学生入口](../../apps/exam-web/src/server/service.ts)与[事务](../../packages/db/src/exam-reviews.ts)核对本人、活动任务和时间窗口，不开放教师延后处理权限；请求ID单独幂等，原始AI与人工历史保留，无迁移或新依赖。

当前行为归[逐题流程](../subsystems/managed-student-flow.md)，权限/并发原因归[决策](../../.agents/notes/implemented/architecture/2026-11-06-student-rerun.md)。
