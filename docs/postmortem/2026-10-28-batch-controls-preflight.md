# 批次取消、状态计数与导出预检验收

日期：2026-10-28。范围：本地批量队列、派生摘要、Web导出。Linux、Node 24.19.0、pnpm 11.7.0，测试使用隔离存储、合成图片和假模型。

## 变更与处理

停止本批不再先等待其他批补图，补取消尚在启动的请求；停止代次防止未接受的旧准备迟到入队。任务总览分别显示已出答案、校验中、已停止、待补充及失败；派生摘要升级并从元数据重建。导出前汇总缺题干、选项疑点等，可跳转到对应题目；快速版缺题干先阻止导出，疑点仍可保留原图。缓存尺寸与可用容量在提交、派发前读取，保留最终事务保护。

当前语义见[批量任务](../subsystems/batch-tasks.md)、[导出任务](../subsystems/export-tasks.md)，原因见[决策](../../.agents/notes/implemented/architecture/2026-10-28-batch-stop-and-export-preflight.md)。私有日志、源码基线和截图位于`.runtime/batch-controls-preflight-2026-10-28/`。

## 验证结果

修复前停止边界2例和摘要1例失败，保留`stop-before.log`、`summary-before.log`。首次预检回归暴露等待函数只能返回void及夹具固定Promise步数，修正为泛型值返回和等待显式任务门；原取消、复制隔离、资源及错误断言保持。缓存故障夹具继续与队列共享同一存储对象，没有移除失败注入。

浏览器扩展回归另复现桌面端待保存通知遮挡“我的”页导出记录入口；主菜单改用“待保存”标记，记录弹窗仍显示错误和恢复入口，不删除待保存结果。

- `pnpm exec vitest run`定向11个队列/历史/摘要/预检/准入文件，首轮202通过、1例失败；失败是夹具用普通Error代替正式ExportTaskFailure造成安全脱敏断言不符。恢复真实错误类后准入文件92例通过，保留原安全错误及取消断言。加上单独摘要迁移1例、契约及成品任务125例，本轮329个不同单元场景最终全部通过；重复复测不累计。
- 旧版本摘要重建测试验证仅读元数据，不读原图或补图，原图、记录及其他键保持原字节。新摘要可区分停止和失败，候选等待核验仍计已出答案。
- `pnpm build:shared`、根`pnpm exec tsc --noEmit`、移动`pnpm --filter @solveflow/mobile typecheck`及Web独立导出退出0。类型检查曾发现等待函数返回void和测试错误缺traceId，分别修复泛型结果与合法安全错误；未使用断言或忽略指令绕过。
- 专用回环URL为`http://127.0.0.1:45238`。使用`pnpm exec playwright test --config playwright.functional.config.ts`定向总览、导出预检、后台导出、PDF和异步补图。首轮32例30通过、2例失败，复现桌面待保存通知遮挡菜单；修复后最终版本相关18例全部通过。加上当前批次、历史、任务总览、导出记录的题号跳转回归，合计40个不同浏览器场景最终通过，含新预检、缺题干逐题定位、缓存满/清理恢复、答案已出但校验中、停止、原有错题标记和补图导出。
