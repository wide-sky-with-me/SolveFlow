## 观察边界

仍只修改五处冻结 AST 位置。绘图记录通过真实 CanvasRenderingContext2D 的 WeakMap 绑定到对应 render 调用，仅观察每个源文档首序号，原生 Promise、this、参数、返回值和异常透传。没有新增字体等待、布局测量、重绘或早期图源哈希。

每个 IMG 对象首用时保留 currentSrc 或 src，后续只复用弱身份；本次恢复首页八次绘制恰为八个不同对象。仅保留有界原始值和字符串：最多 128 条绘图、64 个图源、单源 4MiB/合计 32MiB；不以 DOM/IMG 强引用留存图源。原始像素仍有独立有界读回。

所有窗口完成、原生通知与 URL 自然空闲后，才传出图源、计算真实文件及负载哈希、取得实际 VM。观察器读属性及像素有开销，本轮不作吞吐或生产内存验收。v1 未采样；实际样本使用补强原始值限制的 v2，旧证据保留。

## 核验与复现

私有目录 `.runtime/pdf-production-2026-10-16/` 的 `draw-r46-interactive-{observe,yield}-v2` 保存 PDF、原始 RGBA、图源文件、实际 VM、驱动和关闭回执。`r46-draw-pair-v2.json` 保存输入签名及逐像素比较，`r46-phase-pair-v2.json` 保存字体与逐页 JPEG 比较；不公开题图或编码内容。

独立核验沿用哈希锁定的旧核验器定义，保留五处 UTF16 字节重放、源快照、可信输入、唯一终态、原生 JPEG/字节链、PDF/IDB、自然回收及关闭门禁，另验新增数组不可改写前缀和图源真实文件。反例的证据合同与成品保真分开。

```sh
node .runtime/pdf-production-2026-10-16/check-draw-r46.mjs
python .runtime/pdf-production-2026-10-16/check-draw-verifier-r46.py
python .runtime/pdf-production-2026-10-16/verify-integrity-r42.py
```

包装契约 17 组、两个真实样本证据合同与 19 个篡改反例通过；两份独占核验报告及最终产品完整性复核均退出 0，反例仍为未接受。未重建产品、未新增模型请求。
