# AI 阅读路径与客户端可读性整理

日期：2026-10-03。

范围：AI 开发指南、本地任务生命周期说明及客户端内部重构，不改变产品行为。

结论：客户端 117 项回归、类型和文档检查通过；未执行浏览器、真机或真实模型验收。

## 变更与处理

- [AI 接手指南](../cookbook/ai-development.md) 将常见任务关联到实现和失败测试，说明当前事实、生成文件、学生资源隔离、定向搜索和简短交接。根规则与文档导航指向它，无需把全部历史加载进上下文。
- [生命周期](../subsystems/local-run-lifecycle.md) 解释 session/run/source/题号、锁内准备、锁外执行、取消补写、保存重试和删除顺序；字段与上限仍由契约拥有。
- [请求准备模块](../../packages/client/src/local-run-request.ts) 从引擎抽出无存储/模型副作用的校验与输入组装；公共引擎接口、校验顺序和失败代码保持。具体选择见 [决策](../../.agents/notes/implemented/architecture/2026-10-03-local-request-preparation.md)。
- 引擎统一活动任务快照的读取，展开多语句行和大对象，并补充锁边界说明；关键取消与落盘闭包保留在一起。导出器给分卷头尾预留量命名，区分已知损坏与 I/O 故障，说明规划后仍要检查实际字节。

## 验证结果

- 整理前，5 个引擎/批量/历史/导出规格共 62 项通过。首次运行误收录本轮临时测试副本并报缺模块；将副本改为 `.snapshot` 后复跑同命令通过，没有修改发现规则或删除断言。
- `pnpm exec vitest run packages/client/src --maxWorkers=2`：15 个文件、117 项通过。含新增 3 项缺失来源的按需请求用例，确认拒绝前未写 queued、未占槽、未调用模型。该范围大于基线，不能当作新增 55 个测试。
- `pnpm typecheck`：共享服务包构建、根 TypeScript 与移动端类型检查通过；此前单独客户端构建也通过。
- `pnpm lint`、`pnpm docs:check`、`git diff --check` 均通过：42 份当前文档、7 篇决策、8 处源码锚点、108 份冻结档案。管理检查器本身未修改，不将上轮 14 项管理测试当作本轮成绩。
- 引擎中超过 200 字符的单行由 16 行减为 0，导出器由 2 行减为 0；这只是阅读形式指标，行为是否保持仍以回归为依据。

未做真实付费、浏览器交互、手机或新 APK 验收，也未执行全量 Expo 导出：本轮修改共享客户端内部组织，使用客户端业务回归与全项目类型/包构建验证。取消与原生存储的系统行为仍以既有真机边界为准，不以本轮重构宣称新增保证。
