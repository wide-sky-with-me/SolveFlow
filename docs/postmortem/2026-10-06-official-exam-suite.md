## 测试方法与版本证据

Node 24.19.0，Android 0.1.76 / code 77 的共享 Agent 构建；固定 OpenAI Completions、provider-default thinking、16,384 输出 token，同配置独立核验、简洁答案。主机最多同时 6 题，应用批量默认并发仍为 3。生产总预算 120 秒、工具限制、格式修复及纠错保持原设置；首次解题可能因核验预留而早于 120 秒超时，见[问题分析](2026-10-06-official-exam-suite-analysis.md)。没有在中途改模型、资源或预算。

在线题图从正常公开练习页面采集，官方解释随后独立获取；按软件原始选择提交，严格对照回顾页的完整题目 ID、题号、选项和正误。PDF 原页渲染，附加跨页及共用材料；Guide 裁切排除解答。真值不进入模型输入，开发规则和本机路径不注入学生提示。20 道早期 TMUA 第一卷仅规范化旧分类标签，输入消息、考试背景及原记录均未改。

校验 3,385 个唯一运行 ID、90 个来源、158 份 PDF 哈希和完整真值；70 个构建/依赖文件保持冻结。全部输入尺寸、数量、字节、EXIF及哈希预检，207 道共用材料引用和 125 道划叉题另查；5 处抽取文字异常人工看图。在线 444 张实际输入清晰度筛查发现一张模糊写作图；筛查不是逐字人工验题。

按卷内出现次数计分，失败和澄清保留；生产内部工具续轮、一次格式修复及纠错算同次运行，已完成题不重放。两次进程中断累计涉及 12 道正在运行题，原始开始记录及未知终态保留；依据用户“继续”指令单列 `interruption-resumed` 补测，汇总取首个可观察完整结果，CSV 标明原始状态和变体，因此全范围合计不是纯首发成绩。选择题按官方完整选项集合；填答按官方允许值、单位等价及绝对容差 `1e-9`。两处明确最终答案的人工语义评分更正绑定原图、候选及官方键哈希，原输出未改。

工作区有既有未提交改动，Git HEAD 不是完整版本标识。70 文件快照 SHA-256：`3a7172ccd95eeda617a15f186485ec21ef050c8776d996bf833d5e603a77b1ab`；题目清单 SHA-256：`e4ed707ab5ebb2592b93f83c8ac7b1bbba039863336b8171f7d05032e49f24b6`。私有图、键、模型原文及脱敏请求留在忽略目录 `.runtime/official-online-2026-10-06/`。
