# 中心考试自由导航与界面复查

日期：2026-11-03。分支`feat/public-photo-web`工作区增量，未提交、未部署。本轮按用户新要求撤销未拍题/前序模块的导航限制，保留[核验处理](2026-11-03-exam-reviews.md)其余约束。

## 改动

- 固定题位直接跳转、跳过本题/整模块、返回补拍；题号和任务ID不重排，切走不取消任务。
- 跳过、未拍、已有答案分别统计；全跳过不误计完成，也不清红色待处理问题。
- 工作游标与最后查看题位分开保存，老师能看当前位置、分项统计和近期操作记录；WS失败由轮询兜底。
- 全量题号收进快捷导航弹窗，拍照入口保留在主页面；模块操作折叠到菜单。选择框共用主题、图标和键盘行为，缩略图删除统一角标，去掉重复小字和正常连接提示。

## 验证环境

Node24.19.0、pnpm11.7.0、`postgres:17.9-alpine3.23`；随机隔离数据库、临时HTTP和Chrome，合成图片及假模型。手机视口390×844，老师端1440×1000；浏览器测试主动拦截WS，再由老师确认验证HTTP轮询同步。没有真实题图外发或付费调用。

## 失败与处理

首轮23项通过、1项浏览器失败：断言在异步导航响应前读取数据库。第二轮同样23/1，另一处在弹窗跳转结束前检查拍照按钮。补上等待实际导航完成，保留目标题位/按钮断言后24项通过。补充查看位置与工作游标分离后，浏览器再次23/1：提交后因表单重绘提前读取旧空题状态，误清等待任务。改为匹配本次run ID和材料版本后自动前进恢复。最终24项通过，不累计重复轮次为新样本。

## 限制

当前跟踪的是学生主动上报的题位和中心答题数据；离线后位置停留在最近记录。没有新增提前交卷或强制模块计时。真实模型、私有桶、完整容器/恢复验收及远程部署沿已有待办，不能用假模型或Chrome视口代替。
