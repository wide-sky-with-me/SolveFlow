# 中心考试提示样式与密度优化

日期：2026-11-04。

范围：`feat/public-photo-web`工作区的中心考试学生页、教师详情及共用提示组件；合成题、假模型和本机预览。没有付费请求、权限调整或远程部署。

## 变更与处理

原红色提醒直接展开全部题号，手机仅两题就占约150像素；错误、普通提示和已解决提醒的图标、间距各自实现。

新增[共用提示](../../packages/web-ui/src/feedback.tsx)，统一信息、成功、警告和错误的图标、色调、边框及间距。错误保留alert语义，普通反馈使用status；沿用描边图标、蓝灰主题、44像素触控目标及系统深色模式，没有新增依赖。

[题目提醒](../../apps/exam-web/src/browser/components.tsx)使用原生details/summary，红色待处理和绿色已解决默认折叠为摘要，列表内滚动。红色摘要持续存在，收起不清问题或标记已读；展开后仍可定位题目、查看最新答案。同步更新保留展开状态。学生、教师详情及其他考试提醒使用同一结构，当前语义归[问题总览](../subsystems/managed-exam-attention.md)。

初次构建发现测试中的DOM类型未缩窄，修正后类型检查和构建退出0。首次隔离回归未启动：本机没有默认17.11镜像，改用已有`postgres:17.9-alpine3.23`，没有下载新镜像。

第一次完整回归52通过、2失败：折叠摘要仍有86像素，旧CSS的14像素上下内边距未清除。保留原72像素上限，清除重复规则；两项定向复测通过，退出0。新增覆盖键盘展开/收起、实时更新、61项滚动、长错误文本和明暗对比度；原教师处理、失败重试、通知已读和定位断言保留。
