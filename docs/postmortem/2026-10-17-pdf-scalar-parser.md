# PDF 标量解析缓存实浏览器对照

日期：2026-10-17。

范围：本机 `3100` 当前构建、Chrome 154.0.8037.97、html2canvas 1.4.1，四倍 CPU 降速；同一已保存的 27 题、单份作答 PDF。每次使用新浏览器上下文和复制缓存，直接生成首份，不以前置取消预热。没有新增识别或整理模型请求。

结论：两种私有标量缓存均通过冷首份保真，但未证实整批收益，暂缓产品接入。七份 PDF 共 189 页逐页嵌入 JPEG 原字节与冻结基线一致；这是同一题集的重复验证，不是七组题源。产品代码、依赖及发布产物未变，整体生产流畅性仍待优化。前置热点证据见[主线程与输入](2026-10-17-pdf-mainthread-profile.md)。

## 变更与处理

仅在隔离浏览器替换动态库响应，保存实际执行的 VM 源码和哈希；原路径仍执行服务器原字节。每种补丁的关闭态和开启态使用完全相同的响应字节，仅私有开关不同。

候选按真实描述符身份限制到 16 个标量属性，使用 Context 弱键、每 Context 合计 1024 对、原字符串最长 256 字符；保留描述符变化旁路。对象、数组、颜色和资源不缓存，不增加让步或改变字体度量。缓存函数沿用已通过离线对照的版本。

通用包装先包裹公共解析器；未见收益后，再把调用缩到获准的 16 个构造器属性点，原公共解析器初始化表达式和其它调用保留，继续验证保真、真实工作量与耗时。

两个包装生成器曾在浏览器启动前严格退出 1：一个误按函数声明定位实际函数表达式；另一个误限独立变量语句，实际为压缩后的 `for` 初始化声明。分别改用语法树定位、支持同一变量声明列表内插入后，语法检查和真实导出重测通过；原失败日志保留。

## 验证结果

全部不带 CPU profiler；各原生运行及独立核验退出 0。耗时为可信下载点击捕获至该任务成功事务提交，不包含后续自然 URL 等待；长任务列为与该区间相交的完整任务时长。它们不是 CPU 归因或实体低端机成绩。

| 执行顺序 | 路径 | 耗时 ms | 最长任务 ms |
| --- | --- | ---: | ---: |
| 1 | 原路径 | 19544.5 | 578 |
| 2 | 通用包装开启 | 19463.3 | 714 |
| 3 | 原路径 | 18767.2 | 667 |
| 4 | 通用包装关闭 | 18207.0 | 569 |
| 5 | 定点包装开启 | 20350.5 | 679 |
| 6 | 定点包装关闭 | 17782.6 | 606 |
| 7 | 原路径 | 18814.8 | 770 |

通用包装开关两态公共入口均为 244426 次；开启时跳过 56571 次原解析执行，剩余 187855 次。定点两态入口均为 57440 次；开启时同样命中 56571 次，剩余 869 次在这些点执行原解析器。两个分母覆盖范围不同，后者高命中率并非额外削减工作，更不等于 CPU 或整批提速。缓存开启均未优于各自关闭态，本样本尚无接入收益证据；样本量也不足以作普遍因果判断。

开启态每份累计创建 27 个 Context 状态、存入 869 对，单 Context 观察最大 43 对；这是累计计数，不是活对象数量。各份均通过 A4、27 张不同页面 JPEG、下载/IDB 文件哈希一致、源数据与整理缓存不变、自然 URL 延迟回收、仍可观察的编码画布归零/绘制 iframe 断开及三条关闭回执核验；这些不证明无泄漏或所有原生工作已排空。

独立核验器保留可信输入、同任务事务和精确场景计划，并核对保存的库/主包 VM 字节、缓存源文件及观察窗口结束后取源的顺序。另以真实阳性对照和 12 个反例核验身份、时间、源快照、缓存限额及计数门槛，退出 0。该冷首份场景没有取消用例。

实际执行命令摘要（目录和核验报告均独占创建）：

```sh
P=.runtime/pdf-production-2026-10-16
python "$P/inspect-scalar-r43.py" --name scalar-r43-cold-on-v1 --mode on --scenario cold --cpu 4 --cycles 1
python "$P/inspect-scalar-sites-r43.py" --name scalar-r43-sites-cold-on-v1 --mode on --scenario cold --cpu 4 --cycles 1
python "$P/verify-scalar-r43.py" scalar-r43-cold-on-v1
python "$P/summarize-scalar-r43.py"
```

工作产物在上述私有目录；`r43-summary.json` 汇总七份独立报告，`r43-verifier-check.json` 保存反例结果，`r43-source-final.json` 复核当前 VM/HTTP/dist 与冻结对照字节。Node 为 24.21.0，仓库声明 24.19.0 的引擎警告仍存在。没有改检查上限或基线。
