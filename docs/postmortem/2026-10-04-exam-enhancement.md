# 考试作答与同题材料增强验收

日期：2026-10-04。

范围：当前未提交工作区，默认设备链路、共享契约、保留服务路径的长文兼容。浏览器为桌面与 390 像素窄屏；真实模型由主机执行生产设备 Agent，使用此前授权的官方题源合成拍照样本，非手机拍摄。

结论：补齐结构化作答、完整源答案上下文、同题补图和证据快照。离线检查与浏览器交互通过；真实模型小样本中 AP 校验出现超时，原始失败保留，不能据此宣称全部题型可稳定投入生产。

## 变更与处理

- [作答契约](../../packages/contracts/src/response-format.ts) 区分七种形态；单选、SAT 填答、TARA 词数、声明小问完整性和作图输出执行结构检查。SAT 字符限制核对 [College Board 数字考试说明附录 D](https://satsuite.collegeboard.org/media/pdf/assessment-framework-for-digital-sat-suite.pdf)。格式通过不代表数值、论证或评分点正确。
- [学习上下文](../../packages/client/src/learning-history.ts) 保留指定源答案全文与小问，其他题号不混入；输入、协议和消息展示同步支持 8000 字符。浏览器初测发现旧消息展示仍限 2000 字符，导致白屏，已修复并保留回归。
- [同题材料](../../apps/mobile/src/components/question-materials.tsx) 允许先保存主图，再追加最多七张补图，总图像不超过 8 MiB。保存不发起模型调用；图片独立持久化、事务追加、备份恢复和删除一起处理。辅助核验使用源 run 的材料快照。
- 多图请求考虑 base64 膨胀，避免允许保存却不能发送；服务网格图编号随补图数量偏移。服务长文封包单独有界扩大，MCP 默认大小、结构和权限不变。
- 旧答案校验前拒绝不合法考试格式，不付费请求“通过”。自动解题为校验预留时间；长文校验可使用更多剩余时间，仍受 120 秒总期限约束，见 [运行语义](../subsystems/agent.md) 与 [决策](../../.agents/notes/implemented/agent/2026-10-04-exam-response-and-materials.md)。

### 真实模型样例

沿用已授权路线 `qwen3.8-flash`、Chat Completions、既有考试参考；真值仅用于事后对照，不传给模型。初轮 4 个样本共 10 次 HTTP 模型请求，均 HTTP 200，没有自动改换型号。金额未从供应商账单核对，不以请求数推断费用。

| 样本 | 初轮结果 | 耗时 |
| --- | --- | --- |
| ESAT 备考 ENGAA 2023 第 6 题 | 单选 B，与保存的官方答案一致，独立校验 PASS | 18.7 秒 |
| TMUA 2021 Paper 1 第 5 题 | 单选 F，与保存的官方答案一致，独立校验 PASS | 26.2 秒 |
| TARA guide 写作样例 | 英文正文按空白分词 222 词，类型/上限字段正确，模型校验 PASS；未作人工评分 | 53.1 秒 |
| AP Statistics 2024 第 2 题 | 四小问 `(a)`、`(b)`、`(c)(i)`、`(c)(ii)` 齐全；校验超时，保留未通过状态 | 100.7 秒 |

AP 初轮解题约 60.7 秒，校验到 40 秒上限时仍有总预算。提高长文校验可用上限后定向重测一次，共两次 HTTP 请求，此次 Solver 用时 88.6 秒，实际留给校验约 30 秒，119.0 秒仍校验超时；四小问保留为未通过状态，说明调整时间分配尚不足以解决该模型的复杂题延迟。本轮合计 12 次 HTTP 请求，4 个唯一题目，AP 重测不计作新样本，原始失败不覆盖。

## 未验证项与剩余风险

未打包/安装新 APK，未测真机相机补图、原生低内存和长文 WebView 性能，也未执行 PostgreSQL 全链路集成。多图传输和持久化用离线夹具验证，真实模型本轮仍使用历史单张样本，不能证明多页阅读准确率。

题型字段仍由模型识别；旧记录和兼容输出可缺少字段，不能保证漏读小问被代码发现。AP 各学科评分量表、图形细节、材料引用准确性和校验误放行仍需专项题集。TARA 词数只是本地参考，不代表官方计数或作文质量评分。

补图不能单独删除或覆盖；内嵌裁框仍只支持主图。新备份不保证旧客户端可读，不能降级覆盖安装。当前结论不替换历史准确率，也不改变 [发布状态](../project-status.md) 的试用定位。
