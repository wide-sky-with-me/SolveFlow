## 命令、失败与证据

- `pnpm mobile:doctor` 在允许本机构建子进程后确认 SDK/JDK 就绪；受限环境首次报告 Java 不可用不代表未安装 JDK。

- 四轮 `scripts/test-android-pager.mjs` 均退出 0，使用明确设备、Windows ADB、上述次数和方向。录屏解码帧数与时间戳数量相等；FFmpeg 的原始时间基警告日志保留。

- `pnpm lint`（含文档检查）与 `git diff --check` 退出 0；版本、验收报告、发布状态及构建排障指南已同步。
