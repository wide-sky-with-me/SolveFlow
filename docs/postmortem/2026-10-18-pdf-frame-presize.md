# PDF 资源表达式与建帧预尺寸复测

日期：2026-10-18。

范围：Web 答案纸面、单份、固定缓存的 27 题；以资源期限修复后的实际构建为基准。分开执行资源同步表达式诊断、原始像素门禁和无回读交叉计时。不改变现有服务、产品源码、图片、scale、JPEG 质量或模型调用；候选保持私包隔离。前置证据见[来源交接报告](2026-10-18-pdf-source-handoff-yield.md)。

结论：保真、取消与受控建帧契约通过，但预尺寸候选未显示输入或吞吐收益，不接入产品。当前样本也未支持字体 getter 重活的推断；继续定位建帧及浏览器样式/布局阶段，不把等待误作 CPU。整体生产流畅度未验收。

## 资源表达式诊断

本机 Chromium、CPU 4×，单独执行两次可信取消及一次完整导出，27 页 JPEG 与绘制流通过。实际 VM 与私包哈希匹配，缓存、无成品取消、已观测资源门禁保持原断言；未采集 RGBA 或 CPU profile，不作性能对比。

探针只包围同步表达式：分别记录 document.fonts、fonts.ready、document.images、逐张 decode 启动和 Promise.all 调用。聚合调用的参数先完整求值，再记录调用至返回；另记整个资源参数表达式。保持原 Promise、receiver、既有 then 链和逐次建帧句柄，无新增 await 或反应链；反向去除标记后原工厂语法树一致。嵌套跨度不相加，晚到记录归属原调用。

1100 ms 取消及成功任务的完整资源表达式分别为 1.6、2.0 ms；29 张图片的 decode 同步启动合计各 0.7 ms；fonts.ready 含 document.fonts 的同步跨度至多 0.6 ms。其 Promise 真正待定时间不在这些值中。700 ms 取消的按下排队 133.9 ms，按下事件在样式聚合调用前到达，没有与这些资源表达式重叠；本次未复现上轮等待位置，不据此否定其他样本的资源阶段长等待。同步壁钟也不是 CPU 采样；当前证据未支持字体 getter 是根因。

## 单变量候选

原屏幕样式含 10mm padding，正文 max-width 为 178mm；源码在资源成功与取消检查后才写最终 width/maxWidth=178mm、padding=0。本次只将原三项赋值移至 details 展开后、首次资源 await 前；公式及单题适配、最终取消检查仍在原位置，不加来源让步、等待或检查。恢复移动表达式后，原工厂语法树一致，其他模块字节未变。选择与代价见[提案](../../.agents/notes/proposed/storage/2026-10-18-pdf-frame-presize.md)。

候选在资源失败前也会写所拥有的屏外正文，并让资源计时器在尺寸写入后安装；不是等价重排。未采用的替代位置为样式 fulfilled 回调内：它较晚且会新增取消后迟到回调中的尺寸写入。相同最终样式不证明相同首屏像素、字体观察或最小字号分支。

## 保真、契约与交叉结果

原始像素对照、候选各新导出 27 页；之后 ABBA、BAAB 顺序各臂四组，每组四次可信取消与一次新导出。A/C 延时为 80、700、1800、4200 ms，B/D 为 250、1100、2600、4800 ms，从控制器取得取消按钮后启动，不代表精准阶段锁定。总计主实验 270 页 JPEG/绘制流通过，其中 54 页严格 RGBA 一致；32 次可信取消通过。另加前述独立诊断为本轮 297 页、34 次可信取消，无模型调用。

实际私包抽出的建帧函数在受控 DOM、样式、字体、图片与计时器下通过 20 个案例：每臂覆盖正常资源门禁/显式清理、预先取消、样式/字体等待中取消、资源超时及迟到样式、字体 getter 抛错、解码同步抛错/异步失败、样式失败，以及资源等待续体前取消。验证终态无有效 frame、计时器/监听清理、原元素未改、失败不适配、取消/超时后无新增尺寸写入，无未处理拒绝；候选失败前已有尺寸写入是预期时序差异。DOM 与适配调用受控，不替代真实冷字体、布局或完整产品 owner/期限契约。
