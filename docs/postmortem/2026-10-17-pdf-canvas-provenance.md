# PDF 画布归属与长任务诊断

日期：2026-10-17。

范围：沿用[窗口复核候选](2026-10-17-pdf-lifecycle-window.md)的隔离 Web 产物，追踪原生画布创建栈、弱对象身份、绘制及编码调用，并采集主线程轨迹。没有修改产品源码、SDK、锁文件或已服务产物；没有新的采用判断或速度结论，整体生产目标继续开放。

## 判读更正

前轮所称“未编码画布”的 `encoded=false` 只是旧探针未观察到该对象通过 JPEG `toBlob`，不排除 `toDataURL`、其他编码或绘制，也不是所有权标记。旧探针只用 WeakRef 保存画布；资源快照和编码标记查找会逐项 deref，使成功读取的目标至少保活至当前 JavaScript 作业结束。存活采样既不证明长期强持有，也不证明原生位图已经回收。

本轮在诊断运行时登记画布时保存数值 provenanceId，通过同一对象的 WeakMap 查找关联创建栈，避免靠尺寸、序号或时间猜归属。仅增加弱引用和标量元数据，不保留目标的跨任务强引用；保留所有原生调用和原有输入、事务、保真、清理断言。诊断标签显式排除延迟比较。

独立解析浏览器实际执行的 SDK，空 SVG 能力测试对应 `wB`，UTF-16 区间 `[135477,135707)`；其创建栈首个 SDK 位置为第 19 行第 134337 列，后续经过 SUPPORT_SVG_DRAWING、isRenderable 和 Cache.addImage。唯一的默认 300×150 画布 id0 正在此函数内创建，实际 drawImage 调用一次，PNG toDataURL 正常返回一次，JPEG toBlob 为零。能力 getter 只缓存布尔值，未显式缓存画布；这是本次复现的对象级归属，不是对旧轮无创建栈对象的追溯。

另有 30 个作业输出画布，按已进入 JPEG 编码输出的共同构造函数识别，并反查当前下载器没有传入借用 canvas。全部历史观察与最终观察均满足“输出仍存活则宽高严格为零”，包括未进入 JPEG 编码的取消输出；未知创建函数为零。新增谓词反例分别检出 encoded=false/true 的非零作业输出，并允许已归属的功能探测对象；没有放宽原有断言，更没有清零任意借用或未知画布。

## 长任务边界

轨迹和创建栈均有观察开销，以下只用于定位，既不是新的生产延迟成绩，也不与前轮计时拼接。按同线程 user-timing 标记对齐 performance.now；原生列为任务内区间并集，并非互斥 CPU 分解。

| 窗口最大 RunTask | 原生样式/布局/GC 并集（毫秒） | 已知边界 |
| --- | --- | --- |
| 首次取消 587.867 毫秒 | 0 / 0 / 21.593 | 不与输出画布创建到 JPEG 调用跨度重叠；消息入口本身不足以证明全部工作归因 |
| 再次取消 527.053 毫秒 | 79.533 / 330.053 / 88.079 | 包含样式、布局和回收，仍未进入输出跨度；各列不可简单相加 |
| 成功导出 359.106 毫秒 | 116.189 / 22.986 / 6.424 | 与输出跨度重叠 317.600 毫秒；只缩小解析节点预算不覆盖这一整段 |

成功窗口的最大单次布局涉及一个 800×1100 文档的 6189 个布局对象，另一次主文档布局共有 7325 个对象；后续另有仅更新 527 个元素的文档样式事件。帧身份与规模已保存于 `r55-layout-details.json`，未逐一映射 iframe 所有者，不把这些事件混为单一解析阶段。FontMetrics、排版、绘制及异步续体的确切占比仍需窄范围 JavaScript 采样或额外阶段跨度，当前没有根因闭环。

[下载器](../../apps/mobile/src/local/download-batch-pdfs.web.ts)已经通过 ignoreElements 跳过非目标兄弟题页内容、保留外壳几何；本轮没有重复提出这个既有优化。后续先区分首份准备、绘制/字体度量与解析任务，再选独立改动，继续保留首页同步、scale2/JPEG0.94、取消优先、超时与原生清理边界。
