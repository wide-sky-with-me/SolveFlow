# 2026-11-04 看板刷新、计时与表格对齐

范围：`feat/public-photo-web`中心考试平台。用户反馈自动同步时画面跳动、已作答学生显示“未进入”、学生表头/行内容未对齐，以及手机顶部冗长、教师提醒不够醒目。

## 原因与修复

看板与分页列表原先共用自动/手动忙态，五秒轮询会改变按钮文字、转动图标或禁用按钮，影响布局和焦点。现由同一读取hook管理：自动请求保留画面和控件，只显式手动刷新显示转动；按钮文字/宽度固定。手动碰到在途后台请求时共享原请求，不额外派发。查询取消、强制保存后读取、权限及失败提示保留。

看板学生摘要漏传timing，被旧数据兼容默认值填成未进入；实时跟踪本来正确。现在复用学生快照/实时跟踪的服务器计时投影，覆盖未开始、进行和结束。在线只代表有效会话近期活动；已登录但未点开始的学生仍可正确显示“在线、未进入”。

学生表采用固定列比例；前两列左对齐，数值、状态、用时和操作列居中。紧凑用时仅显示时间或“未进入”，不重复表头文字。窄屏保留表格内部横向滚动。

学生考试名称和计时通过现有React portal进入共享顶栏；退出考试或切换身份时随页面卸载，不复制计时器或新增写入。考试记录、结束考试左右排列，总览缩成四项统计条，保留红色问题及结束确认。教师端新增右下红色提醒，通过既有授权队列静默读取最多3题，点击直达题位；弹窗打开时让开，问题解决后消失，读取失败不伪装清零。初次完整回归发现多题列表常驻展开会遮住全屏大屏学生按钮，原40秒断言超时；现默认保留红色摘要，多题按需展开，单题直接进入，未放宽原回归。

后续反馈补充：教师的题目导航和操作记录改为独立弹窗，双端共用题目正文/选项与原图缩略图；学生答案详情补回原图/补图入口。新增原图查看器支持有界缩放、拖动、滚轮、双击和双指，读取source而非thumbnail；不修改图片、材料版本或答题请求。人工草稿存在时禁用切题，查看图片及操作记录保留草稿。

当前规则见[刷新](../subsystems/managed-exam-lists.md)、[看板](../subsystems/managed-exam-dashboard.md)和[考试计时](../subsystems/managed-exam-timing.md)。没有新依赖、协议或迁移，不改变答题/核验、账号及已有记录。
