# 连拍缓冲与多份快速PDF本地提速

日期：2026-10-25。

范围：用户选择[流程审查](2026-10-25-batch-workflow-speed-review.md)中的多份PDF资源复用及连续拍摄缓冲。Linux、Chrome、隔离存储、合成题图及虚拟相机；模型仅夹具，无付费请求。不部署远程Mac。

结论：快速下载改用ASCII文字、局部Unicode行图及共享编码资源；连拍可在待存照片处理期间继续拍摄，最多3张。50题含图10份的相同合成夹具从25.548秒降为7.953秒；不是实题或手机速度承诺。

## 变更与处理

旧快路径每份重新测量、加载题图、编码整页JPEG；相机等待归一化及保存后才允许下一拍。新增[PDF资源](../../apps/mobile/src/local/direct-pdf-resources.web.ts)和[拍摄缓冲](../../apps/mobile/src/batch-capture-buffer.ts)，长题续页、错题计划、黄色高亮、书签和最终原子保存保留。缓存上限与所有权原因见[PDF决定](../../.agents/notes/implemented/storage/2026-10-25-direct-pdf-resource-reuse.md)、[连拍决定](../../.agents/notes/implemented/storage/2026-10-25-continuous-capture-buffer.md)。

已保存计数只在持久化成功后递增；顺序保存/入队，完成拍摄等待排空。写失败保留待存照片供明确重试/放弃，不重复归一化或入队。Web待存期间注册关闭/刷新确认。相册导入及模型并发不变。

### 复现与回归

旧构建新增回归分别因PDF无原生英文文字、首张归一化未完快门禁用而失败（退出1）。首轮新构建发现中文作答标题使后续英文解释整块栅格化，改为按段落选择路径；另修正测试将历史摘要重复算为题图，以及故障注入误伤已完成答案写入的问题，未放宽产品断言。

- `pnpm exec vitest run` 定向7文件：78项通过，退出0。覆盖捕获上限、乱序归一化、顺序保存、失败重试、不重复入队、退出、资源释放，以及导入和PDF内容/容量/草稿。
- `pnpm exec playwright test` 指定 `batch-pdf-variants.spec.ts`、`batch-solving.spec.ts`、`materials-multi.spec.ts`，筛选快速PDF、连拍和补图快路径，桌面/移动视口共26项通过（13个场景各执行两种视口），退出0。包含10份不同错题数、纯题、备注、取消迟到编码、90段长文、补图/更正补图，以及相机写失败后明确重试和完成拍摄排空。
- PyMuPDF对实际下载文件逐一解析，验证长文90段全部存在、英文解释可选取、纯题不含解释、10份独立内容和书签/链接页码有效。长文5页，答案PDF3页，纯题2页，补图/更正补图各3页；中文、希腊字母、重音字符、特殊引号及emoji渲染图人工核对。
- 最终Web构建后，`usage-guide.spec.ts` 两种视口2项通过，退出0；新增待存及失败恢复说明。`pnpm exec tsc --noEmit`、移动端 `typecheck`、`build:web`、`pnpm lint` 和 `git diff --check` 均退出0。初次状态页超限11个文档单位，精简原措辞后复查通过，未调整上限。精确命令及日志索引在私有 `verification.json`。

### 同夹具性能对照

50题，每题3段英文、4项选项、每份不同作答、答案表及高亮；含图组使用50张2000×1500合成JPEG。独立浏览器页面，预热1题后顺序运行；两版同一夹具，无应用UI、模型或最终存储耗时。单次墙钟观测，不作统计分位数。

| 内容/份数 | 旧耗时 → 新耗时 | 成品MiB旧 → 新 | 图片加载旧 → 新 |
| --- | --- | --- | --- |
| 纯文字1份 | 0.684 → 0.402秒 | 11.44 → 0.38 | 0 → 0 |
| 纯文字10份 | 7.239 → 3.862秒 | 114.42 → 3.83 | 0 → 0 |
| 含图1份 | 2.434 → 1.908秒 | 28.64 → 17.10 | 100 → 50 |
| 含图10份 | 25.548 → 7.953秒 | 286.38 → 171.02 | 550 → 50 |

含图10份耗时下降68.9%；Canvas编码次数510→135，现在计数包含局部字形PNG和题图JPEG，不能把它解释为页面数。纯文字1份编码次数22→69但资源更小；并非编码次数越少就一定更快。图片加载计时可能重叠，不用其相加作耗时归因。

## 未验证项与剩余风险

没有Android/iOS新包或真机连拍验收，移动视口不代表手机处理速度。缓存超限会重做部分处理；大图ZIP及最终浏览器持久化仍占时间，未更改下载/保存策略。连拍待存照片在内存，强杀/强制刷新可能丢失；浏览器确认不是持久保存。真实题图、新模型准确率、Mac部署及其他浏览器未验证。
