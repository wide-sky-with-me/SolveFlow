# 2026-11-04 原图缩放与全屏修复

范围：`feat/public-photo-web`中心考试平台，学生和教师共用的原图查看器。用户反馈缩放像在放大背景，图片反而显小，且没有全屏入口。

## 原因与变更

[查看器](../../apps/exam-web/src/browser/image-viewer.tsx)原先只将缩放比例乘到滚动区域，图片本身仍使用适应窗口后的宽高。百分比变化、滚动和拖动均能触发，但照片尺寸没有变化。旧回归只检查百分比、滚动位置和手势，没有校验图片实际几何尺寸，这是漏检原因。

现将同一比例应用到照片宽高并保持纵横比，滚动区域继续承载放大后的图片。新增工具栏“全屏查看”，沿用原生dialog覆盖网页视口；进入/退出时重新适应窗口，全屏内可继续缩放。Esc先退全屏，关闭按钮直接关图，保留原详情与焦点。加载、缓存、失败重试和题位身份不变，不发起答题请求。

当前行为归[答案展示](../subsystems/managed-exam-answers.md)。没有新增依赖、协议或数据库迁移。
