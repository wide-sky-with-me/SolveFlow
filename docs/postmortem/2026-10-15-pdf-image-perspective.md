# PDF 四角校正与实图连续导出验收

日期：2026-10-15。

范围：本机原有 3100 Web、Chrome 154.0.8037.97、Node 24.21.0、pnpm 11.7.0。使用隔离 QA 存储副本中的同一批 27 道真实存量题；浏览器回归另用合成数据，不合并计算真实样本。

结论：显式四角编辑、有限图外留白、失败后重试和刷新复用通过定向回归；最终实图校样连续下载十份，每份 27 页 A4。此结论仅覆盖本机 Web，不等同正式生产发布或全平台验收。

## 变更与处理

仅旋转仍保留拍屏剪切；模型裁片边缘还约束了完整图示的矩形选区。新增原裁片坐标的四角编辑，允许有界白边，沿用已有锐化、容量、取消和保存边界。运行语义归[题图处理](../subsystems/print-images.md)，兼容与替代选择归[四角决策](../../.agents/notes/implemented/storage/2026-10-15-explicit-print-perspective.md)。

初版输出尺寸向下取整使对角线限幅得到 2047 而非 2048，已改为有界四舍五入并补回归。随后用实图发现硬限图内会压缩标签余量，增加图外白边；精确坐标保留输入文本，补逐键输入负号、小数点以及越界显示约束。

首份实图校样的单摆标签仍贴边，结构脚本通过后未直接视为视觉验收。扩大左侧、底部余量；最终又逐张处理八个选项图，保留频率曲线的原有斜率和台阶、零点、20／40 与时间单位，去除所选区域外的拍屏边条和单选圈。限定坐标轴区域的离线测量只辅助本次取点，未加入运行时自动识图能力。

## 验证结果

- `pnpm --filter @solveflow/contracts build`、`pnpm exec tsc --noEmit` 与 `pnpm --filter @solveflow/mobile build:web` 均退出 0。Node 与项目声明的 24.19.0 有精确版本差异警告，未改工具版本或锁文件。
- 定向 Vitest 涉及四角契约、派生结构、纯像素采样及批量参数保留，39 项通过，退出 0。覆盖凸性／交叉／越界、恒等与投影采样、白边、不修改源数组、尺寸上限及前置／中途取消。
- `playwright.functional.config.ts` 下的后台导出和图示整理场景共 106 项通过，退出 0；包括桌面与移动视口、短横屏、拖动／方向键、逐键负数输入、非法范围阻断、加工失败保留旧结果及存储失败只补保存。此处移动视口不是原生真机。
- 实图通过应用界面完成十张图的显式校正，只有这十个派生像素键变化；全部 29 个在用未加工裁片的 URI 哈希不变，其余派生像素不变。刷新后四角参数与像素复用一致，打开和连续导出后缓存快照未再变化。
- 最终连续下载十份同一批次 PDF，每份 6,596,592 字节；逐份检查共 270 页均为 A4。十条新任务均成功，下载与保存文件的大小／SHA-256 多重集合一致，无残留打印 iframe、页面异常或模型路由请求。未把重复导出算成新题样本。

人工查看最终第 19、23 页及桌面编辑器截图：选项图的参照轴已摆正，单摆的高度、质量和位置标签留有余量；识别疑点、应用选项标签声明与作答区域仍在。原始 27 条记录快照 SHA-256 前后同为 `baaa5796f47c31b39c7e5733ae7b57bec9f66b8d9eaa7a839343e239647190cf`；派生快照由 `afa2176493d635e41f00909319b1e473b536603a05bb7bae66892d5d97384f44` 变为 `7ac13f482c7fc278d52942fbed7616fa09e742d06dd4d3d73d726b43970fdcf1`。哈希对象为所选记录及派生条目，访问时间元数据不计入派生哈希。

私有证据保留在 `.runtime/pdf-production-2026-10-15/`：`perspective-r15-v1/` 保存贴边校样，最终结果为 `perspective-r15-v2/result.json`、`continuous-01.pdf` 至 `continuous-10.pdf`、`page-19.png`、`page-23.png` 和 `editor-desktop.png`；重放脚本为 `accept-perspective-r15.py`，取点测量为 `measure-option-axes-r15.py`。浏览器回归输出位于 `e2e-perspective-r15-final-v2/`。原图、题目正文、配置和文件不进入 Git。

## 未验证项与剩余风险

人工四角只是纸面近似，不恢复缺失图文或证明物理比例；深阴影、细小文字、弯曲纸面仍需核对。源题原有未完整选项和不确定标签未伪造补齐。单像素等退化输入的扩边尚未做完整端到端覆盖。

未执行实体打印、原生设备、新 APK／iOS 打包、其他浏览器、低内存整机或无限时长压力验证；已有[连续导出观测](2026-10-15-pdf-render-subscription-load.md)也不证明无泄漏。本次未新增付费调用、提交、推送、部署或替换原服务。
