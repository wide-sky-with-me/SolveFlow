# 中心考试功能与界面复查

日期：2026-11-05。范围：`feat/public-photo-web`当前中心考试平台，包含学生考试/临时拍题、教师处理和管理控制台。只评估、未改业务实现或部署；没有调用付费模型、访问正式考试或清理用户数据，不代替设备端或完整安全审计。

## 已确认问题

### P2：提交已成功但回执丢失后，编辑草稿无法自恢复

[学生保存](../../apps/exam-web/src/browser/student.tsx)保留原requestId供相同内容重试，但失败后的草稿仍允许删图。隔离复现：补图两张，服务端接受并返回202时模拟回执断开；在保留的草稿删除一张后重试，沿用相同requestId，服务端返回409“同一请求标识不能用于不同内容”。

[服务端幂等校验](../../packages/db/src/exam-attempts.ts)拒绝变更内容是正确保护，不能直接放宽。缺口在前端：不确定提交结果时应先读取当前题位/提交结果，再决定关闭已提交草稿或建立新的操作。目前需要用户取消并重新处理；本轮没有发现重复模型调用。复现记录为状态202→409、图片数2→1。

同一技术错误同时出现在正文及草稿弹窗，DOM测得两份；文案直接暴露请求标识概念。建议只在当前操作位置显示明确的恢复动作，不把后台幂等术语交给学生判断。

### P2：手机时间偏差会禁用可进入的考试

[考试列表](../../apps/exam-web/src/browser/student-workspace.tsx)用浏览器Date.now判断开始/截止并禁用按钮。两场考试均由真实隔离API返回available，正常时间按钮可用；仅把浏览器时间调快一天后，两者显示“已结束”且按钮禁用。Chrome/WebKit均复现。

服务端时间与进入权限仍正确；此问题针对多场可选或手动列表，不能据此说唯一场次自动入场也全部失效。建议API返回服务端计算的入场状态或时间锚点，展示和权限采用同一依据。

### P2：撤回考试后，开始弹窗仍保留旧安排

同一[学生工作区](../../apps/exam-web/src/browser/student-workspace.tsx)把readyExam保存为独立快照，轮询没有在考试失效时清理它。不限时考试的开始弹窗已打开后撤回分配，等待下一次实际轮询，API的available已空，弹窗仍存在并保留“开始考试”。Chrome/WebKit均复现。

后端仍会拒绝失效安排，不是绕过撤权；但学生面对已经撤回的考试仍被要求开始。应按稳定ID持续核对当前可进入列表，关闭失效弹窗并给简洁状态提示。

### P2界面：自由拍题与正式考试的图片操作不一致

[自由拍题](../../apps/exam-web/src/browser/practice.tsx)仍用普通Dialog加img；正式学生/教师题图使用[ImageViewer](../../apps/exam-web/src/browser/image-viewer.tsx)。Chrome/WebKit均完成合成图和假答案后打开原图，找不到正式考试具有的“放大图片”控件；自由拍题没有相同的缩放、拖动和全屏入口。建议复用图片查看组件，保留临时图片的本地Blob来源和生命周期。

### P3界面：没有整页溢出，但内部表格和手机信息顺序仍不理想

[学生进度表](../../apps/exam-web/src/browser/dashboard.tsx)在[样式](../../apps/exam-web/src/browser/console.css)中最小宽780px。1440视口的首页表格容器实测760px、滚动内容784px，“查看”右侧超出容器约23px；需横向滚动才能完整看到操作。320视口容器273px，操作列远在首屏外。已有横向滚动与整行点击，因此不是数据丢失，但操作发现性弱。建议桌面调整列宽/布局，窄屏保留关键列并固定操作入口或使用卡片。

390×844下学生进度起点约1853px，320×844约1822px；老师需要先经过多个图表才能到学生。建议手机端前置待处理与学生进度，折叠空趋势图；桌面继续保留完整看板。

## 既有功能缺口及待查风险

- [错题设置](../../apps/exam-web/src/browser/allocation-fields.tsx)仍仅支持每模块错题数，不能指定具体题号；替代单选只是换选项，不保证实际必错，目标分数换算未接通。删除学生提示没有实现这些能力，边界归[答案展示](../subsystems/managed-exam-answers.md#错题模拟)。
- 角色权限页目前是固定四类角色说明，不能新建角色或编辑权限；这属于当前能力范围，不能当作已有动态权限管理。
- [请求](../../apps/exam-web/src/browser/api.ts)统一50秒超时，教师初次[同步](../../apps/exam-web/src/browser/use-attempt.ts)期间主要显示等待文字。前轮公网WebKit一次超时的根因仍未确认；本轮隔离巡查不能消除此风险，应单独检查慢读超时、重试入口及服务观测。
- 域名部分网络备案阻断与HTTP临时入口仍归[访问验收](2026-11-05-http-ip-trial.md)，本轮未重测公网或真机。

## 复现与截图

使用随机PostgreSQL17.11-alpine3.23容器、合成图、假模型及Chrome/WebKit。诊断脚本及快照在忽略目录`.runtime/review-20261105/`：`run.mjs`初轮，`followup.mjs`与`final-diagnostics.mjs`定向诊断；命令追加`--image=postgres:17.11-alpine3.23`。脚本生成临时审查测试文件，结束移除文件及本轮容器；原业务回归按名称筛选跳过，不能把这些诊断失败说成原回归整体退化。

有效失败证据：时钟/撤回四项断言，修正夹具后图片控件两项断言，补图恢复一项202期望得到409的断言；分别对应以上四类问题，双浏览器不累计为新缺陷。初轮自由拍题假响应不符合共享schema，修正后才计入控件缺失；首轮巡查直接从大屏点击被覆盖侧栏，改走已有“返回控制台”，不把这个脚本步骤误判为导航缺陷。补图诊断先因两份错误触发严格定位失败，改在草稿弹窗定位，保留重复计数及最终409断言。

最终截图巡查覆盖1440/390/320宽、明暗主题与八个管理页面，共48张；无整页横向溢出、JS错误0。使用实际主题事件及保存偏好，逐页记录实际主题，避免组件重新挂载把手动CSS设定还原。人工抽查首页、手机列表、场次、角色页、大屏、失败草稿及自由图片弹窗；不代表逐像素或所有弹窗均已审阅。仅新建报告的检查使用`pnpm docs:check`，不重复构建或沿用旧129项成绩。
