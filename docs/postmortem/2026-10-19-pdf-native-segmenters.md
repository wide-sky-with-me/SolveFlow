# PDF 原生分词器单次绘制复用候选

日期：2026-10-19。

范围：Chrome 154.0.8037.97、html2canvas 1.4.1、本机同一份27页真实照片批次缓存；模型与外部网络请求均拦截。沿用[前轮真实计量边界](2026-10-19-pdf-real-admission-accounting.md)。

结论：固定环境的分词与整批保真通过，交叉时延方向混合；原生构造环境变动有已复现的不等价反例。候选保留隔离，不接入产品源码、补丁、锁文件或现有页面；生产流畅仍待验收。

## 变更与处理

- 当前页排除与旁页空壳已在现有实现，未当作新优化。字体度量缓存的既有失效反例仍有效。
- 隔离候选显式开启后，每个 html2canvas Context 分别复用 word/grapheme；dispose/finally 清空并封闭缓存。覆盖文本范围、回退字素及带字距绘制调用点，无新增 await。
- 从校验后的上游包重建对照，UMD/ESM/min三入口逐字节匹配已安装包。两臂共用主包中的启用标记、相同包装/压缩流程及其余资源；这是完整构建基础上的隔离替换，不是新 Expo 构建。
- 静态基线服务未携带 CSP 响应头；回放路由明确注入项目 Web 服务源码中的同一策略，并记录来源哈希及原始缺失状态，未替换原服务。
- 首次交互对照在旧驱动“取消必有新记录”断言失败。现有准入前取消契约允许零记录。保留失败，后继驱动分别要求：零记录时整个账本不变且零提交；已入队时新增真实 cancelled 记录、无成品并保留旧记录。成功分支仍要求一个真实 succeeded 记录和完整文件；不伪造取消任务。

## 验证结果

证据根目录为 `.runtime/pdf-production-2026-10-16/`，只保存本轮产物，不覆盖历史验收。

- `inspect-native-segmenters-r89.py --cpu 4`：12组合成多语料，24组输出、54组交错迭代比较一致。每块2400次调用；word新建/复用中位164.15/54.00 ms，grapheme为121.45/56.00 ms。包含分词、数组处理和校验，不是构造器独占成本，更不是 PDF 提速。
- `check-segmenter-context-r89.py`：实际候选 UMD 的启用、不同 Context、关闭/缺省、封闭及初始缺 Segmenter/Intl 路径一致；启用上下文各构造2个，关闭路径逐调用构造。独立计数桥归一化源码换行，其哈希不是原始产物字节哈希；未用于整批时延，手动封闭不证明实际回调清理。
- 两臂各一次27页原始像素捕获，54页可见 JPEG/绘制流与54组 RGBA 均匹配规范样本；原题/排版摘要和资源释放核验通过。捕获运行不计时延。
- 后继驱动以 control-a/reuse-a/reuse-b/control-b 串行交叉，每臂两个新上下文、各两轮，完成8次整批恢复和16次可信指针取消。每臂5次准入前、3次已入队取消；零记录与真实记录、账本、成品及资源分别通过。连同原始像素运行，共270页 JPEG/绘制流核验、54组 RGBA；仍是一份27页样本重复回放。
- 4倍CPU降速，实际点击捕获到成品 URL 创建的中位为21002.70/18621.55 ms（对照/候选）；四个配对变化为+3.95%、+0.75%、-21.34%、-26.85%。方向混合，不把合并中位下降11.34%归因为稳定收益；最大成功长任务429/446 ms。取消 pointerdown 的 Event Timing 最大排队224.7/20.8 ms，各8条，但阶段/调度有差异，不称为页面INP或优化因果证据。仅比较同主上下文时钟窗口，非下载完成，未使用捕获或CPU采样成绩。
- 只读审查后，`check-segmenter-mutation-r89.py` 在独立 Chrome UMD 桥复现：预热后删除/替换构造器时，旧实现抛错而候选复用旧对象；固定identity包装器切换locale时，候选word/grapheme钉住不同locale。后者使用受控包装器且文本输出仍同，未证明原生默认locale真实热变或画面错误。反例核验通过不等于候选等价通过。

## 未验证项与剩余风险
