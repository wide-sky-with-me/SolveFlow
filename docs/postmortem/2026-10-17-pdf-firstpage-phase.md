# PDF 首屏让步差异定位

日期：2026-10-17。范围：当前 Web 构建、同一已备妥批次 27 页 A4、一份、一题答错；Chrome 154.0.8037.97、CPU ×4。每臂独占运行，先按 80/900/4000ms 独立计时发送可信鼠标取消，再恢复导出。不是无前置取消的冷首份。

## 结论

复现了[绘制让步实验](2026-10-17-pdf-cooperative-yield.md)的首页差异，并将编码前差异定位到图示区域的 32 个像素。两臂每份 158 组实际字体 baseline/middle 逐项相等，旧字体缓存反例不足以归因于本次度量变化。图像绘制参数、解码位图及画布后端尚未核对，最终根因仍未知。

实验版首页未过保真门禁，不接入产品。产品源码、dist、依赖、基线及质量门槛均保持原样；本轮只增加私有诊断与公开证据。此前[克隆排除](2026-10-17-pdf-mathml-clone.md)和[分段解析](2026-10-17-pdf-cooperative-parser.md)均不重新包装为已采用优化。

## 单变量与真实身份

两臂使用同一私有库字节、源快照和观察器。observe 不增加让步；yield 只在每个源打印文档第一次整页 render 入口增加一次宏任务，解析和 CanvasRenderer 构造已完成。恢复时检查捕获的 frame 链及源节点，已移除则停止；未更换测量文档、启用缓存、等待新字体或改动编码 Promise。

实际公共入口、同步根克隆、根解析、原始字体度量及绘制入口共五个固定 AST 位置插桩；原解析与度量返回值透传。字体测量弱身份是主文档，区别于打印和克隆文档；打印与克隆文档的 fonts.ready 等待不代表测量文档就绪。此处仅记录原度量结果，不调用额外 fonts.check/load 或扫描 CSSOM。

首序号画布在原生 JPEG 编码前读取真实 RGBA；窗口结束、原生通知与 URL 自然空闲后才传出像素并取回实际 VM。读回有诊断开销，本轮不作吞吐基准。
