# 中心考试图片渐进加载验收

日期：2026-11-04。范围：`feat/public-photo-web`工作区的图片查看链路；未提交代码，未改Mac主分支应用。

## 原因与修改

同一生产题图的只读样本：原图3,876,928字节，公网下载11.53/11.85秒，服务器回环含鉴权、数据库及私有对象读取仅0.103/0.084秒。已有清晰预览543,153字节，公网1.15秒；缩略图7,602字节，0.315秒。慢点主要在这次公网传输，不据此推定腾讯云带宽套餐。

改为先读清晰预览、需要细节时读原图；切换保持几何位置，失败保留预览。登录会话内有界复用，缓存命中先HEAD重新鉴权；退出释放。原图质量、模型输入和已有数据不变。当前语义及缓存限制见[答案展示](../subsystems/managed-exam-answers.md#题目与原图)，取舍见[决策](../../.agents/notes/implemented/rendering/2026-11-04-progressive-image-viewer.md)。

- 修复前HEAD回归失败：响应无有效Content-Length；修复后1项通过，覆盖三种视图、跨学生隔离、老师撤权和不读取对象存储。
- 缓存单元9项通过：去重、释放取消、并发/容量/原图数量限制、格式与流式大小校验、过期身份、撤权、迟到响应、超时。命令`pnpm exec vitest run --project unit apps/exam-web/src/browser/image-cache.test.ts --maxWorkers=2`，退出0。
- 学生/老师各在Chrome与WebKit执行像素级缩放、全屏、拖动、双击、手机宽度、Chrome双指和原图失败重试，共4项通过；新增两种浏览器会话复用、旧图迟到、HEAD拒绝、会话切换和320像素无溢出，共2项通过。截图人工检查浅/深主题。
- `node scripts/test-managed-exams.mjs --image=postgres:17.11-alpine3.23`退出0，共127个独立用例：事务44、控制台36、边界16、临时拍题5、计时18、分配8。随机独立PostgreSQL、合成图、假模型；本轮无付费调用。

`pnpm --filter @solveflow/exam-web build`、定向类型检查、`pnpm lint`均退出0；手机工具栏调整后六项图片浏览器交互复测退出0。初始失败与复测日志、截图在忽略目录`.runtime`和本机临时目录。

腾讯云已更新为Docker `20261104-progressive-images`，镜像`sha256:7668dcafcd401013eb0602ed1a609824f926baca6cac8659d6b0dfc1ed6404a2`。基于前版离线COPY构建，保留依赖与迁移7，备份后替换应用；账号、场次、题图、答案、模型配置、后端容器及其他应用保持不变。回执记录数据库备份190,724字节、对象备份7,652,707字节，本轮发布未发起付费请求。

可达公网路径上，两种浏览器各测同一现存题图一次，业务写入均为0：

| 浏览器 | 清晰预览可见 | 按需原图完成 | 关闭重开原图 |

| Chrome | 1.435秒 | 5.873秒 | 0.156秒 |
| WebKit | 0.965秒 | 7.910秒 | 0.133秒 |

远程Mac直连仍被腾讯云备案拦截，不能把本机可达认定为全网发布可用；实际证据和账号/手册交付见[访问排查](2026-11-04-apple-access-and-guide.md)。
