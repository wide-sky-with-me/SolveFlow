# 教师AI答题与手动选项验收

日期：2026-11-03。分支`feat/public-photo-web`工作区增量；未提交、未推送、未部署远程。行为归[答案展示](../subsystems/managed-exam-answers.md)，原因归[教师操作决策](../../.agents/notes/implemented/architecture/2026-11-03-teacher-question-actions.md)。

## 问题与修改

原先只有存在开放问题的题才显示教师操作，已核验题不能由老师重新答题。现在负责老师可处理全部已拍题：AI答题使用当前原图/补图及既有worker，手动作答展示完整选项。单选/多选按真实标签生成答案；无选项或选项不完整时自由填写。未拍题不显示操作。

新增人工记录版本令牌，防止两位老师在相同材料/run上互相覆盖；null令牌沿用旧幂等摘要。再次编辑带入学生当前人工答案，草稿冻结版本。已有人工答案不能核验旧AI候选，须重新AI答题；新任务显示实际状态，同时保留上次人工答案供查看，成功AI发布后采用新答案并保留人工历史。

手动表单打开后自动定位并聚焦，不要求老师在长题后寻找；答案或处理意见为空时不能提交。选项卡复用系统主题和原生表单语义，没有新增依赖、迁移或常驻说明小字。

## 失败保留

修改前新增两项事务回归均失败：健康题被开放问题门槛拒绝。修正后两项通过。首次扩充浏览器/选项场景有两项测试失败：精确label定位包含了textarea文本值，改用可访问textbox角色；不完整选择题夹具错误地提供了有效选择答案，改为真实契约允许的澄清结果，未放宽schema。其余断言保留。

验证还补充了明确选项不完整时的自由填写路径，避免被部分选项卡锁住。最后为自动定位和空表单禁用新增断言，定向4项复测通过。
