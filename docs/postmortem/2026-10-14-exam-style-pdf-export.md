## 变更与处理

先看近期数学、物理 PDF 的渲染页面和 EXamTwin 的题目/作答分离逻辑，再调整现有设备链路，不接入外部抽取服务。版式保留白底、题号横线、原选项顺序、公式、必要裁图和页脚，去除封面及作答解释。原始阅读记录仍走独立打印路径。当前语义只在[批次 PDF](../subsystems/batch-pdf.md)维护，取舍见[决策](../../.agents/notes/implemented/storage/2026-10-14-exam-style-pdf-export.md)。

首次浏览器复测暴露两项实际问题：原生弹层套 Web 弹窗产生重复 dialog；入场动画完成前 Escape 未生效。局部改为既有 React DOM portal 后复测通过，未改动公共原生弹层。新增无答案场景的第一轮失败另属测试脚本：页面执行环境引用外部辅助函数导致事务等待；修正为自包含守卫。一次复测与构建并行导致移动视口重载失败，停止并行改写测试产物后通过，最终整套检查按构建后测试顺序执行。

增加横纵双向量测及可读字号下限，超限报题号而非隐藏裁切。整理警告也阻止正式文件；手动使用同题裁片保留其它必要图示，不静默丢掉选项图。

## 未验证项与剩余风险

真实版式回放复用已保存转录和已审核裁图，证明页面、计数与下载结构，不证明新模型能从原图准确提取全部题目。缺完整答案的抽题端到端使用合成响应验证；真实付费识别未启动。图片/题干仍需在预览中核对。

本轮不代表新APK/iOS原生交付、移动浏览器真机下载、Firefox/Safari、公开部署或模型准确率验收。栅格下载与浏览器可选文字打印仍有各自格式限制，超长题保留显式错误与原始阅读入口，不无限压缩字号。
