# 教师题目导航与当前答案展示验收

日期：2026-11-05。

范围：`feat/public-photo-web`本地未提交改动，在[学生展示细化](2026-11-05-student-presentation.md)之后调整教师详情。使用隔离PostgreSQL 17.11、合成题/图片、假模型及Chrome/Linux WebKit。

结论：教师题目导航默认内嵌展开，计时居中置于标题栏；选择题省去重复文本框，改选项仅为草稿，点击“保存并通知学生”才发布。学生保持所选题答案直接可见、详情按需展开。本轮149项通过，无提交、推送或部署。

## 变更与处理

- 教师详情原来需另开题目导航弹窗。改为工具栏下按模块展开，选题后不关闭；可手动收起，后台同步不重置展开状态。98题导航在自身区域滚动，人工草稿期间仍禁止切题，操作记录继续独立弹窗。
- 计时由详情正文移至标题栏中央；结束考试入口和实际计时语义不变。窄屏计时分两行，长姓名截断，不挤压关闭按钮。
- 完整选择题直接选择选项，不重复显示“确认答案”文本域。保留处理意见和显式保存；取消不写入。简答、未识别或选项不全仍保留答案输入。原有材料、run、人工记录并发令牌和提交幂等不变。
- 金额被误识别为公式及裸TeX修复沿用前轮共享规范化，本轮补充教师金额长题干的无溢出检查。学生答案继续读取所选题presentation，不借用最近完成题；老师处理另一题不会改变学生查看位置。

当前语义归[答案与人工确认](../subsystems/managed-exam-answers.md)及[学生逐题流程](../subsystems/managed-student-flow.md)，入口为[教师详情](../../apps/exam-web/src/browser/monitor.tsx)。

## 验证结果

证据在忽略目录`.runtime/teacher-layout-20261105/`，截图为合成内容。

- 新增Chrome/WebKit用例首次2项失败，复现导航未默认内嵌（`red.log`）；实现后定向2项通过（`targeted.log`）。人工截图发现状态文字换行挤压，新增单行高度及格子无横向溢出断言后两浏览器均失败（`navigation-label-red.log`）。调整为题号/状态分行、状态不折行，最终两项通过于下述交互组。
- `pnpm --filter @solveflow/exam-web build`退出0（`build-final.log`），含TypeScript检查与浏览器/服务端构建。
- `node scripts/test-managed-exams.mjs --image=postgres:17.11-alpine3.23 --suite=core`退出0，基础44/44、88.36秒及交互71/71、159.66秒（`core.log`）。保留原断言，旧测试仅按新导航和保存文案调整操作路径。验证真实HTTP事务的教师单选/多选保存、学生答案同步、未识别题自由输入、原图、通知、当前题及迟到详情隔离。

- 新教师用例使用完整98题、四模块，检查默认展开、单层弹窗、收起状态保留、草稿禁用导航、选项编辑/取消不发送写请求；在320/390/768/1440像素及双主题检查标题计时中心误差不超过2像素、金额保留、文字无溢出。人工复核桌面深色、320浅色及学生直接答案截图，`screens/`保留16张教师图。
- 文档初检发现操作指南及状态页超出长度限制，精简文字后重查，不调整门槛。最终源码边界、文档及差异空白检查见`lint-final.log`和`diff-check.log`。
