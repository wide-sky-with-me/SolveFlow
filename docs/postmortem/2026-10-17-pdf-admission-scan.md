# PDF 准入重复扫描修正

范围：本机 Web、Chrome 154、既有27题真实批次。只修改[输入计数](../../apps/mobile/src/local/export-input-bytes.ts)及[回归](../../apps/mobile/src/local/export-input-bytes.test.ts)，不改渲染库、像素参数、快照校验、容量、冻结时点或队列生命周期。业务模型调用0。

结论：调用内有界 ASCII 证明复用已进入当前 Web 构建，未替换渲染库响应或方法。独立核验54页实际 PDF JPEG、27页 RGBA 与原基线一致，四次取消后恢复导出通过；真实输入微测支持局部收益，不代表整体导出提速或生产流畅验收完成。

## 定位与处理

复查[协作解析实验](2026-10-17-pdf-cooperative-parser.md)的实际执行源码和同窗 CPU profile。用开始/结束前后时钟界限枚举重叠端点，不挑有利偏移；有效相对区间宽109.074ms。最长320ms任务位于测量后446.7ms，早于首次解析约2910.4–2912.1ms；计数覆盖采样119.08–119.15ms。另有258/246/296ms启动段包含完整快照校验或投影，并非都属绘图，不据此删除重复校验。

计数仍用 JSON.stringify 的遍历、转换和异常；只在本次调用缓存至多64个已满足原 ASCII/无转义条件的长字符串。相同值免重复扫描，但每次出现仍计全额字节；超出缓存照原路径处理，调用结束即释放，不缓存全局校验结果。原因和代价见[原决策补充](../../.agents/notes/implemented/storage/2026-10-16-export-input-byte-accounting.md)。

## 实际验证

真实输入在隔离上下文的计数入口截获后明确终止准入：未建任务、未启动渲染、原记录和整理缓存哈希未变。111个长字符串值共70种；完整原生 JSON UTF-8 为23,131,056字节。基线、单值复用与有界集合复用全部计数相等。相同输入轮换执行顺序，CPU×4时基线117.5/119.2/122.5ms，集合73.8/70.7/73.0ms；单值125.2–146.5ms，未采用。先前CPU×1已运行各路径，故这组不是冷输入或独立用户样本，更不是点击延迟或整批吞吐。

Node 合成微测覆盖重复、独立、混合及超缓存输入。首轮未隔离 GC 的独立串出现回退；保留原结果，后续新建输入、显式 GC、轮换顺序后仍只将结果视为微测，不宣称任意输入零退化。去注释后的 TypeScript 编译文本核对确认实际采用的候选与产品函数相同。

回归先红后绿：原实现两项失败，重复扫描6次而非2次、超缓存140次而非76次；保留退出码1。修正后定向111项通过，扩展12文件197项通过。覆盖原生 JSON 等价、Unicode/转义/孤立代理项、标准转换与异常、重复引用、跨调用重验、缓存边界和原容量判断；同时复查准入取消、冻结重验、存储故障、生成、画布/编码与任务收尾。

`pnpm --filter @solveflow/mobile typecheck`、`pnpm build:web` 退出码0。重建前保留旧产物，现有3100服务刷新读取新入口；未另起应用服务。Node实际24.21.0与声明24.19.0不同的既有警告保留。

原生浏览器两次完整运行：各在CPU×1/×4取消后导出27页；四项取消保持终态、无文件，下载与入库字节/哈希相等，题库/缓存不变，无残留打印 frame、零页面错误。独立重开 PDF 核对54个 JPEG，并比较首轮27页原始 RGBA 哈希，全匹配旧基线；当前8份源文件、实际产物和第二轮 CDP 执行源码指纹一致，新主入口含有界集合、无新增 await。计时轮完整窗口21.38s、最长任务644ms；含像素采集的质量轮单列，不作吞吐对比。
