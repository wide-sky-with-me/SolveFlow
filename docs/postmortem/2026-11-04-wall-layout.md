# 数据大屏分区与边界验收

日期：2026-11-04。

范围：`feat/public-photo-web`工作区的中心考试管理大屏，Linux上的Chrome、Playwright WebKit与隔离PostgreSQL 17；只使用合成数据与假模型。此前顶栏/侧栏及主题验收见[前轮报告](2026-11-04-console-appearance.md)。

## 变更与参考

原大屏沿用普通看板的等权卡片，覆盖率不突出，学生表格需要横向滚动。浏览并实际查看[DataV官方演示](https://github.com/DataV-Team/DataV)和[GoView工作台截图](https://github.com/dromara/go-view)后，采用中央主图、左右监控和下方趋势的分区方式，保留共用蓝灰主题、图标、筛选与全屏操作。两项目仓库均标注MIT；仅参考布局，未复制代码、图片或引入其框架/依赖。

[大屏组件](../../apps/exam-web/src/browser/wall.tsx)突出真实答案覆盖率；状态环图、原因条图、模块进度和近一小时发布趋势继续使用同一快照。学生摘要改为紧凑列表，可直接打开原详情。首次截图发现8行摘要需要滚动，已压紧行距，长姓名和模块名保留完整悬停文本。零题数为0%，隐藏零长度圆弧；无任务不显示活动呼吸点。小屏转为两栏/单列，不通过整体缩放压小所有文字。当前行为归[控制台说明](../subsystems/managed-exam-dashboard.md)。

## 验证结果

- `pnpm --filter @solveflow/exam-web build`：首次提取图表后因可空数据检查退出2；补充快照就绪条件后通过，最终构建退出0，产物已更新本机静态预览。
- 定向隔离回归：2项通过、54项跳过，7.80秒；覆盖Chrome/WebKit的8条长姓名、8个长模块、1920×1080完整摘要、320/390/768/1440像素、空数据、学生/问题跳转、图表读数与减少动效。命令为原隔离运行器加`-t 'console wall:'`，临时运行器与日志保存在`.runtime/wall-redesign/`。
- `PLAYWRIGHT_BROWSERS_PATH=.runtime/playwright node scripts/test-managed-exams.mjs --image=postgres:17.9-alpine3.23`：退出0，56/56通过，137.02秒；包含原有全屏打开学生详情、退出恢复、刷新及权限/任务回归。
- 最后仅扩大手机操作按钮的点击区域，并增加至少44×44像素断言，定向双引擎2/2再次通过，7.76秒，退出0；不重复累计为58个场景。
- `pnpm exec tsc --noEmit`、`pnpm lint`及`git diff --check`均退出0。状态页新增索引首次超出文档上限24单位，精简新增文字后复查；未调整门槛。未修改共用主题或公网拍题入口。

截图入口为`.runtime/wall-redesign/index.html`；两引擎分别保存实际数据、合成多学生、浅深主题、空数据及5个窄屏状态，每引擎11张。1920×1080与1440×1000外层无需滚动，更小窗口允许纵向滚动；检查未出现横向溢出或页面异常。环形入场动画在两个时点读取实际进度，两引擎均读取到环形进度在180毫秒内增长；系统减少动效时禁用，不把静态截图视作动效验证。

## 未验证项与剩余风险

模型调用为0次；未部署远程Mac或公网，未提交代码。浏览器移动视口不等于iPhone/Android真机、电视或投影仪验收；长列表仍允许面板滚动，无法保证任意内容/分辨率均一屏显示。原有工作区改动和本机考试数据保留。
