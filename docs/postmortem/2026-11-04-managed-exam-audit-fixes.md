# 中心考试巡查六项修复验收

日期：2026-11-04。

范围：`feat/public-photo-web`的管理/教师写入、身份切换、图片回收、问题队列和进度环。原始缺陷归[巡查](2026-11-04-managed-exam-audit.md)，本报告不改写原失败结论。

## 修改与边界

1. 管理与教师写入在事务内锁住操作者，复查状态/角色。撤权先提交则拒绝旧快照；合法写入先取得锁时，撤权等其提交。覆盖创建用户/模板/场次/分配、更新用户、教师AI/人工处理；不以接口按钮隐藏代替权限。
2. 首次会话、登录和退出共用身份代次/取消机制；其他页面换身份或登录失效立即结束加载，旧响应及finally不能恢复旧用户或覆盖新忙状态。取消不回滚服务器已提交的操作。
3. 回收在LIMIT之前筛掉保留家族和活动任务，锁内继续复查引用，保留原图片期限和删除重试规则。
4. 游标末页变空时回到第一页重新读取，不在仍有前页问题时显示全局空态。
5. 看板卡片、原因、模块入口携带当前场次；问题队列提供场次筛选，SQL先做权限和场次过滤再计数/分页，其他场次不混入。
6. 进度环数字与说明移出SVG，用HTML覆盖层保持可读字号；手机说明12px，环的绘制和主题保留。

无数据库迁移、新依赖、模型调用、提交或远程部署。取舍和锁序归[决策](../../.agents/notes/implemented/architecture/2026-11-04-managed-exam-audit-fixes.md)，当前语义分别归[平台](../subsystems/managed-exams.md)、[问题队列](../subsystems/managed-exam-attention.md)和[看板](../subsystems/managed-exam-dashboard.md)。
