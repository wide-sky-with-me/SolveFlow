# 中心考试六项审查缺陷修复

日期：2026-11-03。分支`feat/public-photo-web`工作区增量，未提交、未部署远程。当前语义归[中心考试平台](../subsystems/managed-exams.md)，取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-03-exam-review-hardening.md)。

## 修正范围

| 原问题 | 修正后的行为 |
| --- | --- |
| 过期未完成考试持续占用活动唯一约束 | 新入场在学生锁内收尾旧记录；有效期内仍互斥，旧题/提醒/宽限任务保留，老师可继续处理 |
| 保存一次失败将已生成答案改为SOLVE_FAILED | 同一结果有界重试保存，不重新答题；取消/新版本/租约优先 |
| 重置密码期间旧密码请求建立有效新会话 | 会话INSERT校验读取密码时的auth_version，失配返回401且不发Cookie |
| 网关后所有人共享20次/分钟限流桶 | 仅可信代理转发链提取客户端IP，保留原有限流，拒绝伪造/畸形转发头 |
| 答题中刷新后，后台已到第2题但页面仍停第1题 | 从服务端当前活动run恢复等待，结果返回自动前进；手动跳题不被旧结果打断 |
| HTTP同步中到达的WS通知被丢弃 | 合并为读取结束后的立即补查，保持串行和取消释放 |

## 首次失败与复测

修复前新增六项回归均失败，原24项通过：旧考试返回409；密码重置后旧登录及会话仍200；第21个转发IP被429；一次保存故障导致failed且无结果；刷新后拍摄第2题按钮未出现；通知序号30而快照停29。

文档检查曾因运行语义正文超过长度上限失败，精简重复表述后按原门槛复查。分离生成/保存、关闭过期活动记录并保持老师收尾、绑定密码版本、可信代理解析、恢复活动等待及合并通知后，首轮33项集成全部通过；补充互斥竞争、真正模型失败及刷新后手动跳走等断言后35项通过。日志在忽略目录`.runtime/exam-review-fixes/`，不累计重复轮次为新场景。

## 限制

保存保护只持有内存结果并最多4次写入；持续数据库故障或进程崩溃仍不能保证保留未提交答案，不自动重新收费。代理配置需按实际网关网段确认；本轮未替换远程服务或证明真实Caddy/COS/模型联调。未改变数据库迁移或用户既有题图；完整容器、真实模型、手机相机与生产恢复验收仍待单列。
