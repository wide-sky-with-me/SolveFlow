# Web本地环境模型配置验收

日期：2026-10-08。

范围：当前Web导出、本地回环Node服务和隔离Chromium桌面/移动视口；模型数据均为假服务。实际根`.env`仅修改新增Web启用与备用配置，不改既有凭据。

结论：Web可从本地`.env`加载解题、校验与备用模型，真实密钥留在Node；启动不调用模型。手工模式与本地历史继续可用。真实供应商模型兼容性、付费调用与准确率未验证。

## 变更与处理

`pnpm start`读取根环境文件，开启`WEB_ENV_ENABLED=true`时提供非秘密设置与临时角色令牌，客户端经同源固定角色代理转发。请求不能指定上游地址、模型或超配输出；不同地址/供应商不能继承共用密钥。代理限制来源、并发、字节和时间，取消下传，错误脱敏。

环境模型在界面只读，考试偏好独立保存，不覆盖原手工设置或把令牌落盘。改文件后重启服务并刷新；普通静态托管、Expo开发和原生维持手工配置。桥接暂不可用时提示且保留历史访问。当前语义见[设备运行](../subsystems/device-runtime.md#模型与考试)，取舍见[决策](../../.agents/notes/implemented/architecture/2026-10-08-local-web-environment.md)。

## 未验证项与剩余风险

没有真实模型请求或正确率结论；当前供应商是否支持备用型号仍需用户实际验证。浏览器测试中的移动视口不是原生手机，本轮没有APK或iOS构建。

环境代理只用于本地回环单用户试用，不是公网身份、配额或生产网关。新服务重启会使旧令牌失效，需要刷新，不自动重放付费请求。网页与本机用户可调用已固定的模型，需信任本地访问环境。
