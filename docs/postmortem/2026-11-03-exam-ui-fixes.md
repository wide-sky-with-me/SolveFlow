# 中心考试答案与界面五项修复

日期：2026-11-03。分支`feat/public-photo-web`工作区增量，未提交、未部署远程。当前行为见[答案展示](../subsystems/managed-exam-answers.md)，取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-03-exam-answer-presentation.md)。本轮不扩展评分或练习模拟规则。

## 改动

1. 单选/多选答案由所选原选项同步生成，选择题文本框只读；服务端拒绝矛盾文字，拒绝时不清问题或保存人工记录。简答/作文保留自由填写。学生详情显示人工标记与所选项。
2. 后台题失败仍积累红色问题；通用错误仅显示在正在查看该题的页面，不把上一题失败显示为新题失败。
3. 服务端快照提供latestAnswerSlotId，按当前材料版本有效答案的发布时间选择，模型/人工记录在考试锁内使用实际发布时间；重拍替代旧版后排除其展示。刷新不再按最大题号回退。
4. 未开考时不提前标记自动进入；唯一有效场次开考后自动入场，主动返回列表不重开，入场失败不循环请求。身份改变后忽略旧入场响应。
5. 文本域使用共享蓝色焦点环，保持明暗主题与普通输入框一致。

无新增依赖或数据库迁移，不改已部署迁移、已有原始解答和人工记录；快照字段缺失兼容null，选择题旧接口仍接受仅标签的答案。

## 失败与复测

修复前原35项通过，新增两项数据回归失败：矛盾答案未被拒绝、快照没有实际最近题位。修复后首轮38/39：新增脚本在textarea已有内容后用精确label定位失败，改用浏览器实际textbox可访问名称。第二轮仍38/39：新增轮询断言用了默认1秒，早于已有2秒通知窗口；改为等待准确的红色问题数，使用既有同步窗口，未修改业务条件。最终39项通过，不把重复轮次累计为新场景。

## 限制

历史矛盾人工记录不自动重写；需单独核对。旧记录的事务开始时间无法还原为实际发布时间；历史相同时间按题序稳定排序。新前端对缺少最近字段的旧服务不冒充最大题号为最近。真实模型质量、私有桶、生产部署及真机交互未在本轮验收。
