# PDF MathML 克隆排除实验

日期：2026-10-17。范围：当前 Web 构建、同一已备妥批次的 27 页 A4；一份、一题答错。Chrome 154.0.8037.97、CPU ×4，独占浏览器采样，无 CPU profiler/Debugger；实际执行脚本仅在全部窗口结束并自然空闲后取回。

## 结论

确认存在冗余克隆，但未证明排除它能改善整批或最坏主线程任务。密集观察版本通过保真后，又去掉克隆、解析与布局插桩重测，仍未取得收益；本轮不接入正式路径。产品源码、dist、依赖、共享公式输出与基线均保持原样。此前[纯值缓存实验](2026-10-17-pdf-scalar-parser.md)亦未接入，此处补充独立克隆路径证据。

共 7 份 PDF、189 次逐页 JPEG 字节比对通过，重复的是同一组 27 页，不是 189 种题。密集版本另有 6 次独立计时取消及两次随后恢复；低开销版本仅测冷首份，不继承取消验收。生产流畅性目标继续开放。

## 路径与观察

[共享公式渲染](../../apps/mobile/src/dom/math-render.ts)仍输出 `htmlAndMathml`。[PDF 绘制](../../apps/mobile/src/local/download-batch-pdfs.web.ts)的分页文本行框跳过 MathML，但不代表原库忽略整棵树。实际源节点为 absolute、1px × 1px、overflow hidden、`clip:auto`、`clip-path:inset(50%)`；MathMLElement 支持 `.style`，后代确实深克隆。

以下只取无前置取消的冷首份，含 `.katex-mathml` HTML 外壳，计数不是活内存：

| 作用域 | off | on |
| --- | ---: | ---: |
| 源外壳 / 子树元素 | 91 / 997 | 91 / 997 |
| 实际克隆元素 / 文本节点 | 997 / 478 | 0 / 0 |
| 实际解析元素容器 / 文本容器 | 189 / 3 | 0 / 0 |
| 全文档克隆节点 | 7564 | 6089 |
| 全部解析元素容器 | 3590 | 3401 |

原解析器未按 MathML 命名空间统一过滤；90 个 math 根因显示值被阻断，另一个根及少量后代实际可见，确有 3 个文本容器。因此既不把全部 997 个元素当作解析工作，也不从浏览器空裁剪推断原画布必然零像素。以实际成品验收；冷两态源 inventory 与克隆根尺寸、scroll 尺寸逐项相同。

候选仅在既有 `ignoreElements` 返回假后，条件排除临时绘制克隆中的 MathML 外壳：严格匹配上述样式及可见 `.katex-html` 兄弟。主页面、源打印 frame 与无障碍结构不变，不改分页、字号、画质、字体等待或原生 Blob/字节 Promise。密集版记录真实克隆及解析入口；低开销版只包装公共导出，保留四个整数，不插入克隆/解析代码，不包装 onclone。

## 原生验证

“冷首份”指新上下文内没有前置取消或 PDF 预热；“恢复”指本上下文先按 80/900/4000ms 独立计时发送可信鼠标输入，再成功导出。三态中 original 是真实 HTTP 原库；每个版本的 off/on 字节相同，仅私有开关不同。

下表为下载 click 捕获至成功事务提交 / 窗口内重叠完整任务最大值，单位 ms；不是驱动命令返回时间。

| 密集 on | 冷首份 | 20988.5 | 582 |

密集版取消输入时间戳至 click 捕获为 12.5/643.0/147.9ms（on）、14.6/268.2/57.0ms（off）；捕获至首次 abort 为 0.1–0.9ms，至取消提交为 154.7–223.2ms。状态取消有效不等于输入流畅。恢复累计统计可含旧任务迟到工作，不用于纯工作量对照。

独立核验覆盖 A4/27 个不同页 JPEG、原字节、PDF/IDB 精确 hash、源快照、可信 pointer 三联、同任务唯一终态、实际 VM 与单次库请求、自然 URL 延迟回收、原生通知及 iframe/canvas 释放、三项关闭回执；业务模型调用和外连均为零。包装契约合成检查为 13/15 组，真实正例与篡改核验回归为 18/13 项；合成检查不是浏览器成绩。
