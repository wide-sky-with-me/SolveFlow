# 多题分页、绘图与跨学科验收

2026-09-17，最终版本 0.1.20（Android versionCode 21）。范围是当前照片内的题目持续对话；同图最多4题及显式选题要求不变，历史列表仍按照片记录。

## 交互与设计依据

- 当前题目改为每页一题，顶部固定题号、上一题/下一题按钮和页数；点击题号直接跳转。按照用户明确要求，手指左滑上一题、右滑下一题；到边界停止，不循环。
- 每题独立纵向阅读，切页收起键盘；访问过的页面保留组件、输入草稿、指定知识点/步骤、展开状态和滚动容器。追问及重新解答仍使用原有题目上下文，不触发新模型请求来切页。重新打开记录默认首道已识别题；先前未分题的澄清/失败保留在独立“补充”入口，不计入题目总数，不参与左右翻题。
- 初始只挂载当前题，后续按访问挂载；开屏仅等待可见答案就绪。隐藏页从键盘和无障碍树中移除。尊重系统减少动态效果设置，过渡区域裁切，避免横向溢出。
- 0.1.20进一步将题号轴改为44px高圆角轨道、36px选中块，保留触控热区；题号、页数和线条箭头居中对齐，移除题号下方圆点，选中项自动滚到可见位置。知识点折叠行采用名称与右箭头同行、浅分隔线，展开时箭头转向及标题变色，适配亮暗主题和键盘焦点。
- DOM手势限定在当前解答区域，放大图示、横向公式、链接、按钮、输入和长按选字不用于翻题。Android仅在顶部导航区补充方向识别，解答区由DOM处理，防止原生父容器抢走图表拖动，WebView内部经受限回调传递方向，只接受±1；重复事件节流。
- 参考 [WAI 轮播模式](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/) 的单页阅读、独立选择控件和非手势入口；不自动翻页。产品明确指定的手势方向优先于通常的轮播方向。

## 绘图与 Skill

- 原来把坐标范围机械五等分；现在使用1/2/5乘10的幂选刻度，常见小范围显示整数或0.5。支持较小/大数量级，不强行把所有数据取整，保留原数学定义域。算法思路参考 [D3 ticks](https://d3js.org/d3-array/ticks)，没有新增依赖。
- 区域底层、曲线中层、关键点及标签顶层。标签独立于绘图区裁切，有底色、边界限制、候选位置避让和必要引线；长标签用短编号，完整内容留图例。思路参考 [Matplotlib zorder](https://matplotlib.org/stable/gallery/misc/zorder_demo.html) 和 [annotation](https://matplotlib.org/stable/api/text_api.html)。拥挤图仍受有限面积约束，不能承诺任意24个长标注都能舒适呈现。
- 调整视图比例和字体，提高手机上的图示占比；答案与详细步骤仍复用同一图。旧记录图例已有坐标时避免再拼接一遍。
- diagram明确短标签、数据范围、分段/曲线定义域、图表目的和避免虚构数据；通用、物理、化学、生物Skill补充步骤表达与学科图表检查。calculate说明精确支持的操作符、函数、角度单位和表达式例子，不新增执行权限。
- 真实数学验收暴露`questions`结构错误：单题被输出为空/单元素多题分组。SYSTEM和唯一一次格式修复明确“单题省略questions，小问不拆题”。不通过丢字段、增加修复轮次或降低Schema门槛接受错误候选。
