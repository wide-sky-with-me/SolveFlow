# 设备运行

[runtime.ts](../../apps/mobile/src/runtime.ts) 打开独占本地应用锁、平台文档库、仓库、引擎和批量队列。启动时将已落盘答案保留为未验证并附中断警告，没有候选的中断任务恢复失败；不自动调用模型。平台注入配置、图像处理和执行器。

## 模型与考试

### 凭据和环境模式

模型服务为用户设置的 HTTPS 地址，协议显式选择 Chat Completions 或 Responses；不按供应商猜协议。模型设置与输入输出由 [设备契约](../../packages/contracts/src/local.ts) 校验。Android/iOS 使用 SecureStore 保存密钥，普通Web仅保留内存密钥；原生不读取服务端`.env`。

`pnpm start` 可通过根`.env`中的`WEB_ENV_ENABLED=true`启用[本地Web桥接](../../scripts/web-env.mjs)。解题/校验沿用`SOLVEFLOW_SOLVER/VERIFIER_*`与共同`SOLVEFLOW_LLM_*`，显式`WEB_ENV_<ROLE>_*`优先；备用仅在配置模型时启用。设置可编辑模型，保存到Node侧独立配置文件，重启后覆盖.env初值；同服务留空保留密钥，跨地址/供应商须新密钥。浏览器只接收参数与临时令牌，[固定代理](../../scripts/web-model-proxy.mjs)转发请求；密钥不返回浏览器、不进入题目库。持久化与恢复见Web指南。

环境模式优先于手工配置，模型派发使用内存角色令牌。仅本地代理明确标记尚未调用上游的401才合并续取配置（5秒有界）；三组参数不变时替换令牌并补发一次，供应商401不重放。取消的等待者停止补发，不影响其他等待者。服务重启后参数变化则要求刷新；启动或刷新不调用模型、不重放失败请求。未启用桥接、静态托管或Expo入口走手工配置，桥接失败仍可查看历史。

桥接只支持回环同源，拒绝外来Origin/Host、未配置模型和超配输出。配置及草稿测试须角色令牌，保存与上游请求互斥；断开取消，不作公网多人方案。原因见[本地桥接](../../.agents/notes/implemented/architecture/2026-10-08-local-web-environment.md)。配置、更新与故障操作见[Web指南](../cookbook/local-web.md)，阶段、响应大小与日志边界见[模型传输](model-transport.md)。

### 模型组与并发

设置分为解题、可选独立校验、可选备用解题三组。备用默认关闭；[初始配置](../../apps/mobile/src/components/settings.tsx)使用GPT-6 Sol官方地址、Responses、低思考与非流式，须填写密钥或调整兼容服务，不覆盖已保存配置。独立校验手工填写，环境模式优先采用已保存配置。旧设置可不含备用字段。执行器固定三组配置与密钥快照，保存切换与活动任务互斥；三组密钥一并清除，持久化失败回滚新槽。接手条件、一次上限与重新核验见 [Agent](agent.md#预算和验证)，不支持模型自行选择供应商。响应方式可在各组高级参数中选择，.env使用`WEB_ENV_<ROLE>_STREAMING=true/false`；默认行为见[传输方式](model-transport.md#流式与非流式)。

设置中的“批量答题与校验并发”分别控制两组执行名额，默认及范围见[契约](../../packages/contracts/src/local.ts)。活动任务结束或明确停止后才能保存，保存成功后应用于后续批次；保存期间拒绝新派发。Android/iOS随本地设置保存；Web环境模式也可调整，考试与并发用独立偏好一次写入，不存环境模型和令牌。旧设置缺少并发时使用默认值，旧Web考试键继续可读；损坏偏好保留并提示，不偷偷覆盖。

本地Web环境支持[整组模型配置预设](model-presets.md)，可载入、另存和启用；凭据与平台边界见该页。

### 考试快照

顶部快捷保存默认考试，活动任务期间锁定；不改模型或密钥。题目与批次保存考试快照，历史沿原快照执行；更正考试文本仅作本题上下文。类型共用 [exam.ts](../../packages/contracts/src/exam.ts)。

## 任务

宽屏Web使用紧凑顶部导航显示默认考试与整体计时；题目页不重复显示介绍标题、说明与考试卡片。批次和正文同宽居中，窄屏沿用导航。

### 答题与学习

单题先给简洁答案；步骤、知识点列表和校验按需生成并缓存，辅助请求按契约并发。批量其他题目尚在执行时可生成已完成题目的学习内容；源题自身仍在校验/修正时需等待结果稳定。旧记录只有知识点名称时可补生成讲解。批量连拍归入同批，照片先保存，再由有界队列解题及独立核验。拍摄序号和原题号分开。

### 批量图片顺序

批量相册支持一次多选，先进入[顺序预览](../../apps/mobile/src/components/batch-import.tsx)，默认文件名自然排序（1、2、10），可按时间从旧到新、手动上下移动或移除图片。Web 时间来自文件修改时间，原生只识别文件名日期；不保证等于拍摄时间，未知时间排在已知之后。确认前不落盘或调用模型；确认后按预览顺序追加批次位置，并依次入队，求解与校验各按保存的并发设置独立派发；完成先后不改变位置。

一次选择不超过剩余批次容量和100MB；规范化与单图限制继续生效。保存成功才移出预览；失败保留供重试，不重复加入。保存成功但入队失败单独提示，可从批次手动继续。停止导入不停止已加入题目。“取消导入”释放剩余预览；“完成拍摄”保留已保存批次，“放弃本批”确认后只删除本批。相机和批次菜单均可再次调整图片，事务及取消见[生命周期](local-run-lifecycle.md#取消保存和删除)。离开期间的迟到选择不保存或派发。文件名和时间不写入历史。

[LocalEngine](../../packages/client/src/local-engine.ts) 管理执行、取消、结果写入与保存重试；[LocalBatchQueue](../../packages/client/src/local-batch.ts) 管理派发。终态写入失败会阻止新任务并提示保持应用打开；重试保存不调用模型，队列恢复需用户明确操作。

### 补图与更正

同题跨页可先保存题图，再在“同题材料 / 补图”拍摄或从相册添加，经裁剪确认后保存，不自动付费。更正题干时可添加或删除本次用图，至少保留一张，取消不保存；新解答及其核验使用所选图片，旧版本保留。单独补图后可选择重新解答，同图多题明确选择目标。材料只扩展同题证据，不把独立题目合成整卷批改；上限及快照见[存储](storage.md)和[生命周期](local-run-lifecycle.md)。

### 状态与整体计时

题目序号和速选列表显示四态：绿为通过校验，橘为已有答案但等待/未通过校验，红为失败或仍待关键补充，灰为尚无答案。答题与校验互不占同一执行槽；答案先展示，独立校验可继续在后台完成。容量与恢复见生命周期。

工作区顶部提供唯一的整体手动秒表，跨题目、批次及页面累计；开始、停止、续计与重置不调用模型，不随解题阶段自动启停。刷新恢复，手动开始未停止时按墙钟继续；清空题目历史不归零，下一次测试由用户重置。计时不属于题目备份，旧逐题数据保留但不合并。原因见[整体计时决策](../../.agents/notes/implemented/architecture/2026-10-09-overall-study-timer.md)。

并发修改先看[任务生命周期](local-run-lifecycle.md)，核对准备、执行、取消与删除时序。

### 平台生命周期

Android 前台服务提供后台任务与原生计时支持；系统杀进程不能保留未落盘的内存结果。iOS 没有该前台服务，任务需保持应用前台；Web 需保持页面存活；手工模式刷新后密钥重填，环境模式续取临时令牌。设备本地记录可离线查看，解题仍需联网。

字段见契约；恢复见[存储](storage.md)，验证见[Agent](agent.md)。
