# 批量图片导入

批量相册一次多选，先打开[导入确认弹窗](../../apps/mobile/src/components/batch-import.tsx)。默认按文件名自然排序（1、2、10），可按时间从旧到新、手动上下移动或移除。Web取文件修改时间，原生只识别文件名日期；不保证等于拍摄时间，未知时间排最后。

为已有题目追加共享图片并自动重答，使用[批量补图](batch-materials.md)；它不新增批次题图。
连续相机拍摄的待存缓冲与失败恢复见[批量连续拍摄](batch-capture.md)。

## 处理与保存

确认前不保存题图或调用模型。确认后[预处理缓冲](../../apps/mobile/src/batch-photo-preparation.ts)只处理当前及下一张，沿用平台归一化、EXIF清理及大小检查；[保存入口](../../apps/mobile/src/components/batch-capture.tsx)仍按预览顺序逐张保存并入队。解题与校验按各自并发派发，完成先后不改变批次位置。容量上限见[契约](../../packages/contracts/src/local.ts)。

[已有批次](../../apps/mobile/src/components/batch-workspace.tsx)打开相册时读取一次缓存位置，保存成功才递增；引擎保留序号唯一性和容量终检。导入期间不逐图切换底层题目，预览结束后统一刷新摘要并选择最后加入的题目。

首次相册导入与已有批次新增共用[图片工作台](image-workbenches.md)，首次只调整新图顺序，不显示已有位置的追加操作。已有批次从相册选一张或多张均打开新增工作台，默认末尾追加，可逐张或整组指定插入点；连续拍摄默认追加，批次菜单不提供位置预设。编号、拖动及保存规则见[批次顺序](batch-order.md)。

编号网格仅用摘要，不读取已有原图或补图。图片编辑保留位置草稿，取消导入释放全部输入和预览。已处理JPEG保存时复用，输入由预览持有至保存或预处理结束。

缩略图读取与释放统一见[预览与资源](image-workbenches.md#预览与资源)，不改变保存或模型输入。

确认后按最终位置使用同一双图预处理缓冲。停止或失败后重新读取一次已保存摘要，剩余输入保留各自目标，重试不会再加入已成功项。

Web拖动期间只投影草稿；确认、关闭及排序等操作暂时禁用，松手确定位置后恢复。稳定根节点持有指针捕获，预览重排不丢失手势。自动滚动只在有效拖动期间运行；松手、取消、失焦或卸载均停止帧循环并释放监听和捕获。拖动不触发保存或解题，仍须点击“导入并解题”。位置行为见[批次顺序](batch-order.md)。

## 进度、停止与失败

导入进行时收起排序和定位工作台，显示剩余/已加入数量和停止按钮。停止只影响后续保存；已接受的当前保存可以完成，已入队题目继续解答。未保存输入仍保留在预览，可调整或明确继续，重试不会重复加入已保存项。

离开导入界面后，当前已接受保存可完成，守卫阻止迟到入队；重新打开仍能看到保存结果。新一次导入不自动重放模型请求。

原图由预览持有，归一化图在保存实际索取时交接所有权。未索取、停止或失败后的预取图统一释放；等所有原生解码结束后再删除其原图。预处理失败按输入顺序报告，不抢先打断前一张保存。取舍见[决定](../../.agents/notes/implemented/storage/2026-10-23-batch-import-preparation.md)，平台批量读取见[存储](storage.md#数据与事务)。
