# Web导出任务与成品保存

本页维护[批次PDF](batch-pdf.md)的任务生命周期、成品存储及保存恢复；题目整理与版式仍归批次文档。

## 导出前检查

[预检](../../apps/mobile/src/local/export-preflight.ts)汇总全部缺题干、选项不完整、识别疑点及缺作答，问题项可打开对应题目。快速原文缺已解析题干时先阻止提交，可补答或改版式；选项与识别疑点只提醒，仍保留原图导出，不新增识别调用。原始记录不要求已解析题干，纯题检查不读取作答。

弹窗“导出检查”与导出记录显示缓存已用/可用空间，并提供重新检查和记录管理。提交及队列派发前读取有界尺寸索引，已知缓存满或浏览器配额耗尽时不准备图片、不生成PDF；浏览器不支持容量估计时不当作零。准确成品大小须生成后才能确认，不能保证预检后空间不变；事务写入仍是最终容量保护，不自动删除旧文件，也不放宽上限。打印到系统PDF不占成品缓存，仍可使用。

## 执行与恢复

[预检/复核](../../.agents/notes/implemented/storage/2026-10-19-pdf-preflight-validation.md)与[私有投影](../../.agents/notes/implemented/storage/2026-10-19-pdf-captured-projection.md)逐记录可取消；核对完转页面准备，再逐页生成。通用投影/单记录同步，计量/原生捕获同段。入队/派发前取消不生成；接受后关窗/切页续行。单槽、至多三项排队，整批保存；弹窗只随自身待存。

“我的”菜单的“导出记录”或通知入口支持搜索筛选、查看/取消、下载及确认删除；关窗清除删除确认。普通通知8秒收起，新通知重计时，存储故障提示保持。在“我的”主菜单以导出记录入口的“待保存”标记替代悬浮通知，避免遮挡操作；打开记录后保留错误详情。补存/下载不拦取消，同任务去重；失败滚动聚焦。成品在独立 `solveflow-exports` IndexedDB，不随历史NDJSON导出或同步；上限见[任务契约](../../packages/contracts/src/export-task.ts)及[存储适配](../../apps/mobile/src/local/export-task-store.web.ts)，浏览器清理可删除。

入库才成功通知，非系统保存。系统通知手动开启，仅页面不可见时发，不含题目。保存失败保留有界成品；前台同窗补存并下载原任务，不采用新设置，可取消。记录页重试只保存，同一终态不重计完成时间；失败/中断重新导出须确认内容。文件与记录原子删除。

成品位于访问者当前浏览器，与部署主机无关。累计512 MiB；文件写入120秒、元数据10秒。容量、配额、超时等错误分别提示，不自动删旧文件。保存失败可“下载已生成文件”，不重绘/调用模型，仍等待保存；明确删旧成品后可补存。刷新/关闭丢失未入库成品，见[成品恢复决策](../../.agents/notes/implemented/storage/2026-10-24-generated-export-recovery.md)。

关闭/刷新后未完成任务标为中断，不自动续做或重放模型。PDF不作题库备份，使用[NDJSON](storage.md)。取舍见[试卷决策](../../.agents/notes/implemented/storage/2026-10-14-exam-style-pdf-export.md)、[后台导出决策](../../.agents/notes/implemented/storage/2026-10-14-background-pdf-exports.md)和[持久整理决策](../../.agents/notes/implemented/storage/2026-10-14-persistent-paper-preparation.md)。
