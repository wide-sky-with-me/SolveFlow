# 中心考试答案展示与人工确认

本页维护答案字段、最近答案和界面提示；身份、红色问题及核验解除条件归[中心考试平台](managed-exams.md)。

## 人工答案

老师可处理负责学生的全部已拍题，包括已核验通过的题；未拍题没有作答入口。“AI 答题”基于该题当前原图/补图重新解答并核验，“手动作答”由老师确认答案和意见。活动任务期间不重复发起AI任务，人工确认仍可终止本题活动任务。

完整识别的单选/多选题展示带原文的选项卡片。老师改变选择时，[共享格式化函数](../../packages/contracts/src/managed-exam.ts)同步生成“标签. 选项内容”，多选逐行展示；超过答案长度上限时只展示标签。选择题答案框只读；简答、作文、尚未识别或明确选项不完整的题保留自由填写，不虚构缺失选项。

[服务端](../../packages/db/src/exam-reviews.ts)先校验当前材料/run/人工记录、权限和选项，再检查答案文字：接受共享格式或仅包含所选标签的旧格式，拒绝选项C却填写B的矛盾。拒绝不保存人工记录、不解除问题、不取消当前任务。已保存的原始AI解答和人工记录不改写。

[老师表单](../../apps/exam-web/src/browser/monitor.tsx)从学生当前答案初始化，固定开始处理时的选项和版本。`expectedReviewId`防止两位老师在同一材料/run上互相覆盖；旧请求缺失该字段默认null，仅可处理尚无人工答案的版本。幂等重试沿用原回执，旧null令牌不改变既有摘要。学生补图或另一位老师确认后，旧草稿提交被拒绝。

[学生详情](../../apps/exam-web/src/browser/student.tsx)展示人工确认标记和所选选项。已有人工答案不能直接“重新核验”旧AI答案；应使用“AI 答题”生成新答案。AI处理期间保留原人工答案供查看，同时显示新任务状态；成功发布后采用新AI答案，失败保留旧答案并建立待处理问题。历史人工记录不删除。取舍见[教师操作决策](../../.agents/notes/implemented/architecture/2026-11-03-teacher-question-actions.md)。

## 题目与原图

两端共用[题目正文、选项和原图入口](../../apps/exam-web/src/browser/question-content.tsx)，保留当前答案的选项标记；人工选择表单打开时不重复展示一套选项。学生拍题区域及答案详情均可查看当前版本原图、补图；教师详情采用同样的缩略图和放大图标，不跳转新标签页。

[原图查看器](../../apps/exam-web/src/browser/image-viewer.tsx)先读取已有2048像素清晰预览；放大到120%、显示尺寸超出预览像素或点击“高清原图”时读取source图片，不改变上传原图或答题输入。原图下载期间继续显示和操作预览，替换时保持缩放、宽高比和拖动位置；原图失败保留预览及手动重试。预览失败只尝试一次原图兜底，不触发答题。

独立弹窗提供100%到400%的相对缩放、滚轮、双击、拖动和双指缩放；100%表示适应窗口，不表示原始像素一比一。窗口大小变化时重新适应，照片不滤色或改写。关闭回到原详情和查看入口；手机手势仍需真机验收。

缩放同时应用到图片和滚动区域，维持原始宽高比；可从工具栏进入覆盖网页视口的全屏查看。进入或退出全屏时重新适应窗口，全屏内继续支持缩放/拖动；Esc先退出全屏，再按一次关闭图片，关闭按钮直接返回原详情。手机工具栏自动适配宽度。

首次图片未解码时显示加载状态并暂时禁用缩放；已完成的图片同时检查complete和自然尺寸，避免错过加载事件。同一登录会话由[有界内存缓存](../../apps/exam-web/src/browser/image-cache.ts)复用Blob，不写浏览器持久存储。最多8项、2张原图、16MiB编码数据和4个并行下载；正在查看的图片不淘汰。关闭取消未完成下载，退出或切换登录释放全部URL和请求。每次缓存复用先发送受权HEAD；[服务端](../../apps/exam-web/src/server/images.ts)检查当前文件及分配权限，只读元数据，不下载对象。取舍与内存限制见[决策](../../.agents/notes/implemented/rendering/2026-11-04-progressive-image-viewer.md)。

教师的题目导航、操作记录各用独立弹窗，关闭后回到学生详情；导航选题只改变教师查看位置，不移动学生游标。人工草稿未取消或提交时禁用切题入口，避免静默丢失；操作记录和原图查看不清除草稿。

## 最近答案

快照新增可空`latestAnswerSlotId`；旧快照缺失时默认null，不用最大题号推测“最近”。[查询](../../packages/db/src/exam-attempts.ts)只考虑当前材料版本仍有效的人工记录或答案展示，按实际发布时间选择。

[模型结果发布](../../packages/db/src/exam-jobs.ts)和人工确认在考试锁内使用`clock_timestamp()`记录发布时间，避免长事务的开始时间误导顺序。沿用现有时间列，无新增迁移；历史记录仍按原有时间排序，时间相同时用题序稳定排序。

补图/重拍替代版本后，该题未发布的新结果不算最近答案；已有其他有效答案仍可显示。老师更新历史题、乱序答题及刷新后均读取同一服务端结果，不依赖前端内存顺序。

## 错题模拟

答案模式显示“正常答题 / 错题模拟”；正常答题直接采用实际解答，错题模拟按以下规则生成展示结果。协议值仍为`original`和`practice_simulation`，已有记录无需迁移。

错题模拟按每模块错题数生成分散题位，原始结果由数据库阻止覆盖。仅支持有效单选的替代选项，管理端保留模拟标记及未应用原因。学生端不显示场次或答案的模拟提示；替代答案不显示AI已核验或待核验徽标，不修改实际核验状态。正常AI答案及人工答案的状态照常展示。不继承正确解析/核验，不保证替代答案在实际题目中必错。AI按目标分数换算及参考表管理尚未接通。

## 页面与开考

后台任务失败会保留对应红色问题；只有正在查看该题时才出现该题的通用错误，不把第7题失败显示成第8题失败。持久问题仍能定位原题，跳走不清除。

[自动入场](../../apps/exam-web/src/browser/main.tsx)等待唯一有效场次，未到时间时不提前记为已进入；开考后按正常轮询入场。按场次记录已尝试进入，防止主动返回考试记录后马上重开，或失败时循环请求；失败仍可手动重试。身份切换后丢弃旧入场响应。普通输入和文本域共用[焦点样式](../../packages/web-ui/src/theme.css)，不增加说明小字。

操作步骤见[指南](../cookbook/managed-exams.md)，历史界面修正见[验收](../postmortem/2026-11-03-exam-ui-fixes.md)，全部已拍题的教师操作见[后续验收](../postmortem/2026-11-03-teacher-answer.md)。这些修正不改变已有、明确标识的错题模拟与原始结果保存规则。
