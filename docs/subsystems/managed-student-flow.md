# 学生逐题答题与答案导航

适用中心考试学生页，入口为[StudentAttempt](../../apps/exam-web/src/browser/student.tsx)。固定题位、跳过及跟踪事务归[中心考试](managed-exams.md)，时间和截止归[计时](managed-exam-timing.md)。

## 顶栏与考试记录

顶栏左侧Logo返回首页，账户头像菜单进入“考试记录”、[服务方案](managed-model-services.md)或退出登录；兼有管理角色时也可切回管理端。主动返回后不自动重入唯一考试，仍可从记录继续查看，不结束后台考试或答题。记录按“进行中 → 可进入 → 已结束”排序，再展示待开放、过期及撤回记录；排序在服务端分页前执行。顶部提供全部、进行中、可进入、已结束快捷标签，切换回到第一页并保留搜索。进行中按钮浅黄、可进入浅绿、已结束中性灰；已结束仍可查看记录。旧的“可进入”接口筛选继续包含进行中考试，新快捷标签使用独立互斥分类。

[考试状态](../../apps/exam-web/src/browser/student-header.tsx)居中放在顶栏，不常驻考试名称或计时。点击可看考试名称和进行/结束状态，并从中确认结束考试；到点或老师结束时关闭旧状态框，沿原结束提醒处理。主页面不重复显示返回记录、结束考试及模块省略菜单；模块页签、题号总览和上下题继续可用。

## 拍摄与下一题

选择题位后拍照，确认上传，等待解答及核验，当前题答案直接显示。学生自行把答案填写到实际考试界面，再点击“下一题”；SolveFlow不新增学生答案输入或提交记录。解答完成、老师更新、刷新或重连都不会自动切换正在查看的题。

“上一题/下一题”位于拍摄区底部，只移动本模块相邻题位；首题禁用上一题。处理中在两者之间显示“停止作答”，只取消本题任务。“从相册选择/补图”另行居中，不提供“跳过本题”按钮。仅节末且有后续模块时，下一题替换为“进入〔下模块名称〕”；最后一节末题禁用下一题。模块页签和总览仍可直达，失败题也可暂留。

切题写入原有导航事务；恢复页面优先使用`viewedSlotId`，无查看位置时才回退`nextSlotId`。后者继续作为后台推荐工作游标，模型完成推进它不会改变学生查看位置，也不会将未看的题报给老师。

## 重新解答

已拍题在相册/补图旁提供“重新解答”，使用当前原图和补图重新解答并核验，不新建题位或材料版本。处理中保留旧答案并显示任务状态，新结果出来后更新本题；不自动跳题。未拍题、活动任务或已结束考试不能发起。

[学生重答事务](../../packages/db/src/exam-reviews.ts)只接受本人当前材料/run/人工版本和显式请求ID；拒绝过期版本、越权、未开放/截止或撤回场次。普通学生任务不借用老师的处理期限。网络失败先同步，主动重试相同源版本沿用请求ID；刷新、重连和返回页面不自动重做。仍受原模型额度、并发和取消规则约束，取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-06-student-rerun.md)。

## 当前题与本节答案

[当前答案](../../apps/exam-web/src/browser/student-answer.tsx)直接读取所选题的展示记录，未出答案就显示本题状态。它不使用全场`latestAnswerSlotId`，跨模块和返回旧题不会残留最近完成题的答案。识别题干按需展开，原图/补图沿用放大查看器。

选择题突出显示字母与对应选项；填空题突出显示可直接填写的数值、分数或文字，总览同步显示短答案。取值、旧记录回退、公式及兼容规则归[答案预览](managed-answer-previews.md)。

题目详情请求可取消，并同时核对题位、材料版本、run和人工确认版本；切题或新版本到来立即隐藏旧详情，迟到响应不能混入当前答案。详情读取失败保留快照已有答案，提供只读重试，不触发模型调用。

[本节答案总览](../../apps/exam-web/src/browser/section-answers.tsx)收进右上“总览”弹窗，默认当前模块，可切模块查看并点选题位；关闭后回到入口。主页面不常驻全场统计卡和答案表。红色问题和老师解决通知仍按[提醒规则](managed-exam-attention.md)保留；只发文字的[老师消息](managed-exam-messages.md)独立展示，不解除问题。

[状态映射](../../apps/exam-web/src/browser/slot-state.ts)在学生总览与教师导航统一为五类：未答、正在回答、校验、通过、出错，附图例和文字，不只依靠颜色。排队/识别/解答/修正归正在回答；核验任务或已有答案待核验归校验，提示区分“校验中/待核验”；AI通过或人工确认归通过，仍分别标识来源；失败/需补图/中断或待处理问题归出错。停止、跳过或已拍但无答案归未答。当前任务和失败优先于旧答案，不以历史`completedOnce`误标完成。

当前查看题另用蓝色底与描边高亮，状态圆点和红色问题标记仍保留。答案选项标牌只有AI核验通过才用浅绿，其他展示答案用浅黄；人工确认继续注明“老师已确认”，不冒充AI核验。配色沿用共享明暗主题。老师已答统计仍按当前有效答案计算。

学生界面隐藏计时，老师端与服务端继续累计全场用时，跨模块不重置；到点仍刷新并弹出结束提示。
