# 本地存储与恢复

[LocalRepository](../../packages/client/src/local-repository.ts) 使用统一文档接口：Android/iOS [SQLite](../../apps/mobile/src/local/documents.native.ts)，Web [IndexedDB](../../apps/mobile/src/local/documents.web.ts)。设备库与服务端数据库独立。

## 数据与事务

磁盘v2将元数据、不可变原图和材料分开保存；公开记录及NDJSON备份仍为含图片的v1。材料以`material.<sessionId>.<id>`保存，元数据只含尺寸、字节数和ID，结果更新不重写图片。activeImageIds选定当前用图，新run的imageIds保存有序快照；旧materialIds保持可读，引用不存在的图片按损坏记录处理。

更正可添加或移除本次用图，已保存的历史图片不物理删除，旧解答仍可核验；新图片、选择和queued任务一起提交，失败不留下部分编辑。单独补图追加到当前选择；同题活动任务或全局待保存故障阻止修改，其他批量题不阻挡空闲题补图。缺少事务的适配器拒绝编辑。每次请求最多8张、8MiB；历史最多63张补图及32MiB图片，达到历史容量需新建题目。上限由[材料契约](../../packages/contracts/src/material.ts)拥有，备份保留当前选择和旧快照。

读路径兼容旧 v1/v2；新增材料和答案字段为可选扩展，新客户端能读旧备份，旧客户端不能保证读取新备份或覆盖新数据。新增诊断的可选隐藏推理字节数与接手原因仅在当前客户端读取；旧诊断保持兼容，不改历史版本含义。不支持降级覆盖安装，升级前保留备份。版本与其余上限由 [设备契约](../../packages/contracts/src/local.ts) 定义。

旧版固定的 `MODEL_UNAVAILABLE` 错误在记录及备份读取时转换为当前安全文案，原记录不因读取被重写；任意异常文本仍拒绝。兼容范围见[决策](../../.agents/notes/implemented/storage/2026-10-08-local-error-message-compatibility.md)。

摘要是可重建的派生数据，历史浏览读取摘要，不并发预读整库图片。收藏和批次名称独立保存，防止模型结果覆盖用户操作。题图、元数据和摘要的组合写入使用平台事务；Web 请求同步抛错也显式 abort，不能只拒绝 Promise。

损坏的 JSON/版本/结构及 Web 非字符串文档值与存储 I/O 故障分别处理：坏记录保留并报告，健康记录可用，坏记录仍占用题数额度。维护入口可确认重置损坏收藏/批次名称；原图、补充材料或记录损坏可从备份选中恢复整题。有效 JSON 中的内容错误不自动识别。

模型设置损坏时保留原值、以未配置状态开放历史与备份；用户保存有效设置后才替换原值。Web 最近会话的 localStorage 定位缓存不可用时显示提示，恢复后清除，不阻挡 IndexedDB 中的健康题目或手动解题；真实数据库读写故障继续报错。取舍见[恢复边界决策](../../.agents/notes/implemented/storage/2026-10-07-browser-recovery-boundaries.md)。

自动校验前保存的候选采用completed/pending内层结果及verifying外层任务状态；仍可取消，不是已完成校验。摘要新增可重建answerState，旧摘要按元数据重建，不读取全库题图。新可信度、选项完整性与诊断字段为可选扩展，严格旧客户端不支持降级覆盖。

整体秒表在`study-time.overall`单独保存v1累计毫秒和开始时刻，不依赖题目存在，删除历史不归零。旧逐题键`study-time.<sessionId>.<sessionId>:<题号或single>`保持可读，每会话最多40项，随所属题目删除；不合并到整体值。坏计时值保留并提示，只能由用户明确重置，均不纳入题目备份。诊断每run最多128项，包含白名单工具与排队元数据，不保存参数或模型正文。

## 失败结果

最终落盘失败的结果保留在引擎有界内存中，新增题目和新模型任务被阻止；已接受任务可以结束。等待中的批量照片保留，但队列停止派发。

保存重试只合并对应 run，不重复付费或自动继续队列。取消保持优先，删除成功后才清掉待保存结果。关闭进程会失去尚未落盘的结果；界面提示保持应用打开，不能把重试功能当跨进程持久化保证。

## 备份与恢复

[导出](../../packages/client/src/local-history-export.ts) 逐题规划，每卷最多 128 MiB，每行最多 64 MiB；每卷有完整头尾，可单独、乱序、重复恢复。规划保留 ID/字节数，写入时再次校验；无法读取的题目数量在确认导出前显示，原数据不删除。Web 每卷构造 Blob，文件上限不等于内存峰值。

[导入](../../packages/client/src/local-history-import.ts) 接受至多 768 MiB 的完整备份，校验版本、数量、归属、编号、批次位置，以及原图和各材料的 JPEG 结构。普通合并跳过已有题目，逐题事务写入；操作失败撤回本次新增键，进程被强杀可能保留已完成部分，重导入可补齐。

普通导入保留已有坏记录与无效记录键并计入容量；元数据损坏可隔离，但若同题派生摘要同时是 Web 非字符串值，当前冲突检查仍会中止导入。该组合边界由源码确认，尚未执行隔离故障复现，待修复；不能将已有回归解释为所有损坏组合均可导入。冲突检查读取有效题目元数据、独立诊断键，并保守预留坏题有效摘要中的批次位置；不读取整库图片。损坏元数据中无法识别的引用只能在后续单题修复时检查，现有文档键仍禁止覆盖。存储 I/O 失败直接停止导入。

单题修复只替换用户选中且无法读取的题目，先验证整个文件，再以一个事务写入题目/原图/补充材料/摘要/收藏；健康题目不能覆盖，已有诊断键保留。只能恢复到备份版本，未备份内容无法重建。

备份不包含模型设置、密钥及秒表旁路数据。中断任务保留已落盘候选为未验证并附警告，没有候选才转失败；不重放模型。源文件和平台适配是完整 API 的唯一清单，决策原因通过其 `Decision:` 锚点查找。

Android 先等待系统选中文件复制到私有缓存完成，再以只读句柄进行两遍读取；复制期间取消也等待复制结束后清理，避免读取半成品或留下迟到文件。设备故障注入与系统选择器验收按 [隔离存储流程](../cookbook/android-storage-acceptance.md) 执行。
