# 无考试安排的临时拍题

学生没有当前可进入的考试时，首页显示拍照和相册入口，考试类型默认未指定；未来场次和历史记录仍可查看。身份仍须登录，非学生角色不可调用。正式考试可进入时仍走固定题位、中心存储和老师跟踪。

[页面](../../apps/exam-web/src/browser/practice.tsx)只保留当前一题，图片使用可释放的Blob URL，答案仅在组件内存；不写浏览器历史库。刷新清空当前题，不恢复或自动重做。拍下一题替换当前显示；取消、身份变化和卸载使旧响应失效。

原图复用正式考试的[图片查看器](../../apps/exam-web/src/browser/image-viewer.tsx)，支持缩放、拖动与全屏查看。显式本地模式只接受本页Blob来源，不走远程图片缓存、不上传预览；关闭查看器不撤销图片，拍下一题或离开页面时由临时拍题组件释放URL。

[临时任务](../../apps/exam-web/src/server/practice.ts)复用图片规范化和模型编排，不调用图片存储，不建立题位、考试、答案或解题记录。请求标识绑定学生及输入摘要，相同请求不重复派发，不同学生不能读取结果。最多同时处理4题、每位学生1题；最多128份临时记录、每份结果512KiB，终态10分钟后按30秒周期清除，模型执行6分钟截止，上传读取最多45秒。服务重启清空任务，不自动重放。HTTP断开后当前页面只查询同一标识；取消先到也阻止随后派发。选择服务方案期间取消不再开始读取题图；取消的重复请求直接返回终态。进程关闭清空任务后，迟到的准备结果返回取消，不查询或重建已清理记录。

API进程须配置固定模型、启用真实调用并连接Redis；Redis不可用时停止新模型派发。每次外发前重新检查登录、学生角色和当前考试安排。单题最多24次请求；独立临时拍题日限额为`min(100,dailyCallsPerStudent)`，按UTC日计数。Redis仅保存用户日调用计数，不保存题图、题目或答案；这不是考试记录。当前只支持单API进程，不跨副本恢复。

图像格式、尺寸和相机边界沿[图片输入](image-input.md)，固定模型凭据不返回前端。正式考试仍按[中心平台语义](managed-exams.md)持久保存。
