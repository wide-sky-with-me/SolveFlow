# 批量补图与自动重答

批次操作中的“批量补图并重答”由[分配界面](../../apps/mobile/src/components/batch-materials.tsx)提供，不要求整个答题队列空闲。一次选择多张图片，在[工作台](../../apps/mobile/src/components/batch-material-workbench.tsx)选中补图后，通过编号网格绑定对应原题图；同图可给多题，一题可收多图。卡片显示绑定数量，移除补图同时清除其绑定，未分配图片须绑定或移除后提交。缩略卡片与按需编辑沿[共用交互](image-workbenches.md#共用交互)。

Web支持Tab定位、空格/Enter切换；双击题号或Alt+Enter查看原图，最终绑定保持不变。鼠标按住扫过题号可多选，从已选题号起拖则取消沿途选择；同次扫过不反复切换，靠近滚动区边缘自动滚动。Escape、失焦和指针取消还原本次扫选；触屏保留滚动与逐题选择，原生长按查看原图。分配摘要最多两行；选择立即更新草稿，最终“保存补图并自动重答”前不落盘。

“继续添加补图”追加到当前列表，保留已有绑定和编辑，并选中第一张新图。取消选择不清空草稿；多轮选择共用张数和原始字节上限。提交后可再次打开批量入口继续补图。

## 提交与保存

“保存补图并自动重答”明确同时提交补图和后续模型任务。成功提示按提交时确定的5秒截止时间收起，恢复前台时重新核对过期，右侧×可立即关闭。切换批次或离开页面清除，不以队列是否完成作为寿命。选择和分配仍是草稿，取消不写入、不停止旧任务。确认后仅更新接收者，其他题的等待、求解和核验继续；共享原有并发槽位，不新增无限并发。存在待保存结果或删除冲突时仍拒绝。加载清单只读取摘要，查看某张原图时才读其图片。

[批次契约](../../packages/contracts/src/local.ts)限制输入张数、接收者和展开后的新增图片字节总量；每题仍受已有图片数量、当前请求字节及历史容量约束。新图按导入顺序追加，保留当前主图及原有选择。图像规范化和EXIF清理沿用[批量导入](batch-import.md)，不绕过图片校验。

[仓库](../../packages/client/src/local-repository.ts)先只读校验归属、重复、图片、材料限额和事务支持；[引擎](../../packages/client/src/local-engine.ts)预检上下文与对话次数，并只保留目标题的更新权。预检失败不停止任何旧任务。预检通过后取消接收者的活动请求，等其保存收尾；原等待项暂不派发，其他题照常推进。再次验证最新状态后，全部接收者、材料及摘要共用一次事务保存；失败不保存前缀补图、不调用新的重答模型。

取消旧任务后若存储失败，已取消任务保持终态，不自动重放；原来尚未派发的等待项解除保留后继续。真正的结果保存故障仍按全局存储阻塞规则停止派发，不承诺损坏存储时其他任务可正常写入。

复用的是用户选择的图片内容，每个接收者拥有独立材料ID和私有存储键，防止跨题引用或单题编辑影响其他题；没有新增全局共享图片表。旧run的图片快照和答案不变，旧v1内联记录在本次事务中沿既有v2分离格式保存，备份保持兼容。[材料存储](storage.md)继续拥有单题限额及版本规则。

## 重答与取消

全部保存成功后，[批量队列](../../packages/client/src/local-batch.ts)替换接收者的旧等待项，按原题图顺序各建立一次新计划；重叠分配不重复重答。已有答案创建新版本，未答或失败题也会解答。目标旧请求迟到不能覆盖新结果；其他题不取消或重新排队。同图多题沿原小题对话依次重答，完成当前解题/核验后再继续；取消、失败、存储故障或停止不继续该图剩余计划。不单独分配图内某一道，补图中的其他题不扩充为新题。

首次请求未生成可引用答案时，补图重答保留最近原解题消息，包括明确题号与空消息；使用当前全部用图，不以通用重答文案覆盖原要求。失败、取消及被本次补图取消的首轮均适用。返回多题后的历史与导出沿用[重试投影](batch-tasks.md#等待与隔离)，不增加旧失败空题；取舍见[决定](../../.agents/notes/implemented/architecture/2026-10-29-supplement-scope-and-deletion-admission.md)。

停止或离开在事务开始前生效时不写入；已接受事务须等结束，期间停止可保留完整补图，但不派发新重答。已入队后关窗/切页可继续，用户可用“停止批量解题”停止。可在这轮重答期间继续打开工作台提交下一轮；重叠目标按提交顺序更新，最终使用已保存的全部当前材料。重启、重开分配和结果保存重试不自动重放模型。

题目页“重新解答”只锁定本题，其他题运行时仍可提交；已在队列或执行中的本题禁止重复提交。等待槽位时显示本题排队状态，运行时沿原进度显示；准入及并发见[本地任务](local-run-lifecycle.md)。原来的“同题材料 / 补图”保持手动重答。复用存储见[原决定](../../.agents/notes/implemented/storage/2026-10-24-batch-material-assignments.md)，异步准入见[新决定](../../.agents/notes/implemented/storage/2026-10-27-asynchronous-batch-materials.md)，运行生命周期见[本地任务](local-run-lifecycle.md)。
