# 中心考试问题总览与解决通知

本页维护学生全局状态、教师待处理队列及通知已读语义；身份、任务与同步链路归[中心考试平台](managed-exams.md)，人工答案字段归[答案展示](managed-exam-answers.md)。

## 持久问题

AI未通过、UNKNOWN、超时/无核验、澄清、解答失败、中断、取消及题型不符均建立问题。每个题位最多一个未解决问题，处理历史保留；刷新、切模块、继续下一题、补图或重试都不清除。红色题号可定位，未解决时没有关闭入口。考试列表和管理看板显示累计数。

学生待处理提醒使用红底白字警告栏，强调累计题数；当前考试的警告随滚动保持可见，其他考试警告保留独立入口。警告没有关闭操作，展开后选择题目；收起只隐藏列表，不清除问题。教师详情保留紧凑摘要。摘要支持键盘操作，数量变化播报，长列表局部滚动；普通信息与操作错误沿用共用提示，错误保留alert语义。

学生题目总览按整场考试显示当前材料的已有答案、处理中、待处理和未拍数。已有答案仍可能待处理，因此这些数不应相加当作总题数。需要补图时保留红色问题与当前题状态，不重复增加同义错误条；网络、上传及其他操作错误仍单独显示。未拍指尚未保存题图；在本机选图但上传/提交失败时，草稿错误仍在当前页面，不虚构已接受任务或服务端问题。

答题页的考试名称和持续计时集中在顶栏；考试记录与结束考试左右排列。题目总览使用紧凑统计条，手机不重复显示标题和总数，辅助技术仍可读取。缩小间距不弱化红色提醒，也不改变题位、拍摄和结束确认行为。

## 教师队列与处理

[待处理题接口](../../packages/db/src/exam-attention.ts)按当前管理场次/负责学生授权，不因兼具学生身份而取得其他学生权限。按场次、学生和问题类型筛选，默认30项、最多100项；以问题创建时间和ID分页，保留小数精度。已处理行在下次同步消失，带游标的当前页变空时回到第一页重新读取；全局0项才显示无问题。看板入口保留当前场次和原因，侧栏入口默认全部场次。列表五秒刷新，可直接打开对应题处理；逐题提交答案，不向多题套用同一答案。

[教师全局提醒](../../apps/exam-web/src/browser/teacher-attention.tsx)固定在右下角，沿用学生端红底白字和警告图标，每五秒静默读取同一权限范围内最多3道题及总数。默认收起列表，保留醒目提醒条；单个问题点击直达，多题时点击展开，选择具体题目打开对应学生、题位，“查看全部”进入未筛选队列。收起不清除问题，清零后提醒才消失；读取失败保留上次问题并显示错误。处理详情、管理弹窗或手机导航打开时暂时隐藏，关闭后继续显示；浏览器全屏时跟随全屏元素，不另建问题状态或触发答题请求。

管理页按提醒实际高度预留底部滚动空间，展开、换行与窄屏变化后重新测量，末行及分页可滚到提醒上方；操作中的下拉菜单位于提醒上层。管理弹窗临时隐藏提醒时保留空间，避免背景滚动位置跳变；无提醒时恢复普通页尾间距。列表内容较多时沿用内部滚动。

老师可重新核验已有AI答案，或针对原图/补图使用“AI 答题”、选择“手动作答”。这些操作对全部已拍题开放，不限红色队列；选项和版本规则归[答案展示](managed-exam-answers.md)。只接受负责老师、场次管理员或系统管理员。老师可在截止后主动收尾，单次任务最多7分钟；撤销分配、停用老师/学生和取消仍使任务失效，不开放学生过期提交。

解除条件是当前材料的有效AI PASS，或老师填写答案及处理意见后人工确认。人工确认另存记录，标记“老师已确认”，不计入AI核验数，不冒充verified；确认、取消该题活动run、游标推进和事件同事务提交。旧版本、过期租约或被替代任务的迟到结果不能清除新问题。

## 解决与已读

[0006迁移](../../packages/db/migrations/0006_exam_resolutions.sql)为已解决问题增加已读时间，沿用问题ID，不生成第二份处理记录。[考试快照](../../packages/db/src/exam-attempts.ts)返回当前版本尚未读的已解决通知；同题有新问题或已被重拍替代时排除旧通知。AI PASS和人工确认均可通知，历史已解决记录升级后默认为未读。

[学生页面](../../apps/exam-web/src/browser/student.tsx)收到未读解决通知时主动弹出“答案已更新”，汇总题目并区分老师处理与AI核验。拍照选择器、图片处理/上传、草稿或其他弹窗打开时延后提醒，返回前台后再展示；不自动跳题或丢弃草稿。多条新通知合并展示，刷新或重进考试仍提醒尚未查看的答案。

关闭或“稍后查看”只确认本次页面已提醒，不请求服务端已读，同一通知不会随轮询反复弹窗。“已解决”入口持续保留；点击题目先定位、读取最新详情并打开答案，再提交已读。读取失败保留通知以供重试；旧版本被替代或产生新问题时移除失效提醒。过期考试可在本地定位回看，不发起新的解题。

已读接口只允许该学生本人。写入持考试锁、指定问题ID，并检查当前材料和同题无新问题；重复已读不再产生事件，旧通知不能消除新问题。其他标签页通过同一事件/快照同步。持久红色提醒和解决通知独立，不以关闭通知替代问题解决。

老师修改原本没有问题的题，通过同一WS/HTTP快照更新学生详情和最近答案；不为通知伪造红色问题，也不生成“已解决”通知。已有红色问题被解决时仍使用上述持久通知。
