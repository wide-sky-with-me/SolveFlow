# Web 打印与 PDF 分页

本页维护[批次导出](batch-pdf.md)的页界语义；题图像素处理见[图片整理](print-images.md)。屏幕预览随内容展开，打印与PDF在独立帧中按A4实际尺寸排版。

## 试卷页面

默认先缩小图示并整体缩排，正文最低8pt；仍超限时自动将同一题续到下一页，不需要重新调用模型或手动删减材料。续页标原题号和续页序号，保留题干、选项、疑点与作答；逻辑题数、对错规划和文件名中的题量保持。

短段落、选项、图示及公式尽量整体移动；过长段落按完整行拆分。表格优先在行间续页，续表重复表头。页脚保持在正文之外，不按屏幕预览的滚动位置截取。单个不可拆分公式/图示过高、超宽内容或找不到安全页界时停止并提示，不裁切内容或继续缩小正文掩盖失败。
带图选项的并排布局在单页溢出时先转为单列再续页，保证DOM顺序与视觉顺序一致，防止截点包含旁边尚未放得下的长选项。短题保留原布局。快速原文使用独立的简单文本/原图分页，不进入本节的试卷测量与截图流程。

A4无封面，带图选项并排；纯图省略占位说明，保留字母与实质文字。题干保留显式换行，表格须含Markdown分隔行。分数字号完整，识别/整理疑点同框并分别解析，保留全文和公式。

试卷边生成边续页，总页数未确定时只显示当前页并注明“总页数统计中”，到最后一页才显示最终总页数；快速原文先算完本份页界，再显示确定页数。

## 帧与绘制

打印帧在接入内容前用固定doctype声明进入标准模式，与PDF截图克隆保持相同的表格行高及盒模型；题目仍通过DOM克隆接入，不将用户内容写成HTML。

[打印帧](../../apps/mobile/src/local/print-batch.web.ts)冻结来源正文，保留页壳。接入当前题并等待图片/字体就绪后，[续页器](../../apps/mobile/src/local/paginate-question-pages.web.ts)在克隆DOM中移动尾部；尚未接入的其它题不提前迁移。续页让出事件循环并检查取消，原题、答案及整理缓存不变。

[PDF适配](../../apps/mobile/src/local/download-batch-pdfs.web.ts)逐物理页绘制，新增页接入后更新清单；绘制克隆仍须匹配已测量尺寸。进度总页数会随后续长题增加，页数上限按最终物理页累计；阶段、文件体积与取消限制仍沿[导出说明](batch-pdf.md)。

“原始记录”沿阅读规则续页，跳过相邻块的纯空边距。[按记录绘制](../../apps/mobile/src/local/reading-pdf-scope.web.ts)保留记录壳高度，每页仅接入当前记录，首次克隆确定该记录页界，后续续页检查一致性；移除整张无图文或可见装饰的空白尾页，全部完成后写入页脚总数。实际页数仍受限；未知结构或越界图文保留整本路径。打印/下载共用字体及图像资源门禁，取消或失败释放帧与冻结正文；保存重试不重新渲染或调用模型。

此过程只自动排版，不能校验识别内容或答案正确性。取舍见[续页决定](../../.agents/notes/implemented/storage/2026-10-21-question-continuation-pages.md)。
