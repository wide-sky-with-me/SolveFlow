# 批次 PDF 导出

Web读取失败/取消可重试，不调用模型。忙时须显式取消；关闭/Esc不终止。整理/参照/预览可折叠，底栏固定。

Android/iOS快速原文入口及文件交接见[原生PDF](native-pdf.md)；本页其余版式和浏览器打印仍属Web路径。

## 题目与来源

“快速原文”支持带作答/纯题，格式与边界见[快速PDF](quick-pdf.md)。

“纯题目”无需已完成答案，不含作答、解析、校验提示及对错统计。未解答纯文字题可用整理题干，空占位或缺图仍阻断。“题目与作答”沿用题目图示并附本份作答，切换保留副本设置。“原始记录”含原图、保存回答及已有详情，可打印或后台导出，不属严格试卷。

打开仅读快照/缓存，不解码或调用模型；失败原位重读，保留草稿/参照/整理。默认复用题干/裁片；待核对题留原图/疑点，允许多份；缺题干/原图仍阻断，模型整理须显式操作。完整文字/数值表仅转录，必要图形留裁片；旧图示按[显式处置](../../.agents/notes/implemented/agent/2026-10-20-print-illustration-dispositions.md)对账，无声明沿旧遗漏保护。结构接受不等于视觉核对。

“严格试卷版”显式选择，缺缓存时Agent按主图/补图提取完整文字、数学、选项与图框。已有题干仅作参考，未解答记录可无参考。图源必须属于该记录，不使用答案生成图、远程图片或替代性视觉描述；历史材料版本仅供对应保存解答与原始记录使用。

核对入口直达首题，不调用模型。同源[重整题组](../../.agents/notes/implemented/agent/2026-10-15-print-source-binding.md)；普通整理关闭思考，[精修](../../.agents/notes/implemented/agent/2026-10-15-print-layout-refinement.md)仅用校验模型及配置额度/思考/意见，不动全局设置、题库、答案、缓存键。按[精简视图](../../.agents/notes/implemented/agent/2026-10-15-print-layout-generation-view.md)接受[完整契约](../../packages/contracts/src/batch-print-layout.ts)；[适配](../../packages/agent/src/pi/batch-print-layout.ts)对格式/归属及可重试传输错误最多三次、共用截止，取消优先，显示次数与脱敏原因，详见[重试决策](../../.agents/notes/implemented/agent/2026-10-15-print-layout-resilience.md)。未覆盖旧图示回退原图；参考版保留疑点并接受可靠裁框，暂无自动视觉复核。

图示从原图派生，先裁片后旋转，不按题中斜线扳直。导出前自动清晰化，可靠边界才旋转/裁框；已有几何保留，可显式重算本批图示。像素管线、保存失败和人工确认见[题图处理](print-images.md)。

整理/裁片/调整在独立 IndexedDB 版本化保存，键含原题、完整图源字节及处理版本；图文变化仅失效本记录，份数/规划/精修意见/文件名不失效。重整只清未引用裁片，保留来源与在用图。无年龄过期，[缓存适配](../../apps/mobile/src/local/batch-print-cache.web.ts)限容量/LRU；浏览器可清理，非备份。旧提案仅显式整理时本地转换；取消保留已存项，重开不重提。格式隔离，不迁移题库。

## 份数与作答

逐份设置错题数和可选备注，答对=题量−错题；同图按实际题界计数。备注限80字，减份后再增加保留；不改错题分配。预览切副本，提交固定快照/计划/图示/备注/导出时间；关闭丢弃未提交设置。

“标记错题”默认关闭；开启后按本份计划在错误题号旁显示“× 作答错误”并突出作答区，续页重复标记。不重新判题或附正确答案。文件名及记录区分版本；旧v1缺字段沿用原版，见[决定](../../.agents/notes/implemented/storage/2026-10-21-marked-answer-exports.md)。

整数草稿非法时提示并阻断导出，保留有效预览；Esc恢复并保留焦点，有效时关窗。上下键调整；减份再增保留草稿，隐藏非法项重现须修正。保存重试沿用成品。

计数按导出假定：原作答全部默认计对，原有校验/回答失败不预占错题数；没有保存答案的题保持空白，不补答、不改变verified。指定错题数才决定本份错误数，与历史状态独立；原始记录模式仍展示历史。

新增错误用当前完整打印选项；缺项或原选择未映射时保留原选并提示。打印/渲染终检变更选择，冲突报题号，不重规划。非选择题按填写内容或未作答计错；显式参照覆盖导出作答，不改历史。

错题按题号分层随机抽取，兼顾本地估计的题目复杂度、相邻题与多份重复。复杂度来自已保存题干/步骤，不是标定难度；无内容不猜等级。打开窗口固定种子，设置不变时预览/打印/下载一致，新开重新抽取；提交后固定计划。候选不足、错题过多或组合有限时可能相邻/重复，见[规划决定](../../.agents/notes/implemented/storage/2026-10-21-export-error-distribution.md)及[打印边界](../../.agents/notes/implemented/storage/2026-10-15-printable-variant-boundary.md)。

## 页面与文件

导出可按[自定义题图顺序](batch-order.md#可选导出顺序)重排，只影响本次快照；同图多题成组，副本作答和备注保持关联。

预览随内容展开；打印/PDF自动缩排，长题续页并保留题号及完整内容。字号、图示/公式/表格页界、实际页数及取消语义见[打印分页](print-pagination.md)。

有备注的作答PDF命名为`备注_YYYYMMDD-HHmmss.pdf`，取提交时本地时间，整批固定；ZIP内同名加序号。无备注沿用原命名：纯题为 `批次_题目_N题.pdf`；作答为 `批次_作答_第01份_N题_对C_错W.pdf`；多份为 `批次_作答_M份.zip`。非法字符规范化，长前缀缩短；见[备注决定](../../.agents/notes/implemented/storage/2026-10-22-export-copy-remarks.md)。纯题单份直接下载，多份作答全部生成后下载 ZIP；失败不下半批。

预取消不读种子/原图；逐份建帧，正文冻结、逐题接入；异步JPEG、页标识唯一，取消不计成品。快照验归属/顺序/终态/缺图/容量；数量门禁先于准备/模型/排队，续页验实页数，见[契约](../../packages/contracts/src/local.ts)。

帧资源20秒、下载资源30秒；每份10秒/实页（60秒至5分钟），建帧就绪起计时，续页不重置。超时注明份数/页码，见[时间预算](../../.agents/notes/implemented/storage/2026-10-21-pdf-copy-time-budget.md)。字体失败阻断、取消优先；交接前验活，异常逐项释放，未知错误脱敏。
各版式[容量估计](../../.agents/notes/implemented/storage/2026-10-15-pdf-capacity-estimate.md)不替代门禁；单份PDF/多份ZIP按[成品契约](../../packages/contracts/src/export-task.ts)分限，见[取舍](../../.agents/notes/implemented/storage/2026-10-22-multi-copy-pdf-capacity.md)。
