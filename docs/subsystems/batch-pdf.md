# 批次 PDF 导出

Web：批次操作/历史菜单同窗配置。初读失败或取消可原位重试，不排队或调用模型。失败聚焦、成功不跳转。忙时显式取消，关闭/Esc不终止；整理/参照/预览可折叠，底栏可见。

## 题目与来源

“纯题目”不投影作答，也不依赖已完成答案；不含答案、解析、校验提示及对错统计。未解答纯文字题可用整理题干，空占位或缺图仍阻断。“题目与作答”沿用题目图示并附本份作答，切换保留副本设置。“原始记录”含原图、保存回答及已有详情，可打印或后台导出，不属严格试卷。

打开读快照/缓存，不解码或调用模型；缓存读失败原位重读，保留份数草稿、参照与整理。默认试卷复用题干/选项/裁片，缺结果只提示待整理，首次显式整理。非必要不保留原图：完整文字/数值表仅打印转录，必要图形保留裁片；旧图示按[显式处置](../../.agents/notes/implemented/agent/2026-10-20-print-illustration-dispositions.md)逐项对账，无声明沿旧遗漏保护。结构接受非视觉核对。

“严格试卷版”须显式选择，缓存缺失时 Agent 根据当前主图和补图提取完整文字、数学、选项与必要图框。已有题干仅作待核对参考；未解答记录可没有题干参考。图源必须属于该记录，不使用答案生成图、远程图片或替代性视觉描述；历史材料版本仅供对应保存解答与原始记录使用。

未整理或图示/选项待核对可直达首题，不调用模型。同源[重整题组](../../.agents/notes/implemented/agent/2026-10-15-print-source-binding.md)；普通整理关闭思考，[精修](../../.agents/notes/implemented/agent/2026-10-15-print-layout-refinement.md)仅用校验模型及配置额度/思考/意见，不动全局设置、题库、答案、缓存键。按[精简视图](../../.agents/notes/implemented/agent/2026-10-15-print-layout-generation-view.md)接受[完整契约](../../packages/contracts/src/batch-print-layout.ts)；[适配](../../packages/agent/src/pi/batch-print-layout.ts)对格式/归属及可重试传输错误最多三次、共用截止，取消优先，显示次数与脱敏原因，详见[重试决策](../../.agents/notes/implemented/agent/2026-10-15-print-layout-resilience.md)。未覆盖旧图示回退原图；参考版保留疑点并接受可靠裁框，暂无自动视觉复核。

图示从原图派生，先裁片后旋转，不按题中斜线扳直。首次整理自动摆正；旧裁片通过“摆正本批图示”本地更新，保留已有旋转与再裁切。像素管线、保存失败和人工确认见[题图处理](print-images.md)。

整理/裁片/调整在独立 IndexedDB 版本化保存，键含原题、完整图源字节及处理版本；图文变化仅失效本记录，份数/规划/精修意见/文件名不失效。重整只清未引用裁片，保留来源与在用图。无年龄过期，[缓存适配](../../apps/mobile/src/local/batch-print-cache.web.ts)限容量/LRU；浏览器可清理，非备份。旧提案仅显式整理时本地转换；取消保留已存项，重开不重提。格式隔离，不迁移题库。

## 份数与作答

逐份设置最终错题数，答对=题量−错题；同图多题按实际题界计数。预览可切副本，后台提交固定快照、计划和图示；关闭丢弃未提交设置，不改历史。

数量用整数草稿；非法时提示并阻断作答导出，保留有效预览。非法值Esc恢复有效值并保留焦点；有效时Esc关窗。上下键调整；减份再增保留有界草稿，隐藏非法项重现须修正。保存重试沿用旧成品。

计数按业务假定：完整且没有对应红色校验失败的原作答计对，原标红默认计错；指定错题数包含原标红，不是额外增加量。未知或未校验结果不会因此变成 verified。指定错题数低于原标红数时，需要有效正确参照并实际改写导出作答。原作答不完整时仍可抽取纯题，但作答副本入口暂不可用。

新增错误用当前打印选项；缺项或原选择未映射时保留原选并提示。打印/渲染终检变更选择，冲突报题号，不重规划。非选择题按填写内容或未作答计错，减少错误须有效参照；与参照矛盾须改实际作答，不只改统计。数量/参照无效报原因；副本优先不同组合，不足允许重复。见[规划](../../packages/client/src/batch-print-variants.ts)与[打印边界](../../.agents/notes/implemented/storage/2026-10-15-printable-variant-boundary.md)。

## 页面与文件

单题A4无封面，带图选项并排；纯图省略通用占位说明，保留字母、图与实质文字。试卷题干保留显式换行，原文和普通阅读不变。表格须含 Markdown 分隔行。分数字号完整，疑点同框，按识别／整理来源独立解析，保留全文和公式。先调图示再按正文字号适配，超限报题号，不裁切或跨页；原始记录续页跳过相邻打印块的空边距，保留未知块与溢出图文。打印/下载共用[适配](../../apps/mobile/src/local/print-question-pages.web.ts)，绘制克隆复测。

命名共用批次前缀与字符/字节规则：纯题为 `批次_题目_N题.pdf`；作答为 `批次_作答_第01份_N题_对C_错W.pdf`，单份也保留份序；多份为 `批次_作答_M份.zip`。非法字符规范化，超长名称保留完整语义后缀。纯题单份直接下载，多份作答全部生成后下载 ZIP；失败不下半批。

预取消不读种子/原图；逐份挂载就绪建帧，根错即止。留页壳；正文源内冻结，逐题迁入帧等资源后绘制。异步JPEG、页标识唯一。正文位图，批次名打印、文字可选，保存/取消不计成品。快照验归属/顺序/终态/缺图/容量；数量门禁先于准备/模型/排队，续页验实页数，见[契约](../../packages/contracts/src/local.ts)。容量/期限保留原因。

帧资源每次20秒、下载资源30秒、每份建帧后60秒；失败字体阻断。取消优先、到期失败，交接/打印前验活。清理异常仍结算并逐项释放，保留原因；未知错误脱敏、迟到收尾。见[资源与清理交接](../../.agents/notes/implemented/storage/2026-10-19-pdf-cleanup-settlement.md)。
首份完成后更新容量参考，近上限提示取消减份；估算不替代门禁、不改画质/缓存，见[决定](../../.agents/notes/implemented/storage/2026-10-15-pdf-capacity-estimate.md)。

## 后台任务与记录

[预检/复核](../../.agents/notes/implemented/storage/2026-10-19-pdf-preflight-validation.md)与[私有投影](../../.agents/notes/implemented/storage/2026-10-19-pdf-captured-projection.md)逐记录可取消；核对完转页面准备，再逐页生成。通用投影/单记录同步，计量/原生捕获同段。入队/派发前取消不生成；接受后关窗/切页续行。单槽、至多三项排队，整批保存；弹窗只随自身待存。

“我的 → 导出记录”或通知入口支持搜索筛选、查看/取消、下载及确认删除。补存/下载不拦取消，同任务去重；失败滚动聚焦。成品在独立 `solveflow-exports` IndexedDB，不随历史 NDJSON 导出或同步设备；上限由[任务契约](../../packages/contracts/src/export-task.ts)和[存储适配](../../apps/mobile/src/local/export-task-store.web.ts)维护，浏览器清理可删除。

入库才成功通知，非系统保存。系统通知手动开启，仅页面不可见时发，不含题目。保存失败保留有界成品；前台同窗补存并下载原任务，不采用新设置，可取消。记录页重试只保存，同一终态不重计完成时间；失败/中断重新导出须确认内容。文件与记录原子删除。

关闭或刷新浏览器后未完成任务恢复为中断，不自动恢复生成或重放模型。PDF 不是可恢复题库备份，仍使用[存储](storage.md)规定的 NDJSON。取舍见[试卷决策](../../.agents/notes/implemented/storage/2026-10-14-exam-style-pdf-export.md)、[后台导出决策](../../.agents/notes/implemented/storage/2026-10-14-background-pdf-exports.md)和[持久整理决策](../../.agents/notes/implemented/storage/2026-10-14-persistent-paper-preparation.md)。
