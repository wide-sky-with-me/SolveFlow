# 批次 PDF 导出

仅 Web 提供入口：批次详情的“批次操作 → 导出本批 PDF”，或“历史题目 → 批量记录 → 批次菜单 → 导出 PDF”。两入口打开同一居中弹窗，关闭后停留原位置。表单复用项目按钮与明暗主题；导出内容采用分段选择，一份副本直接显示，多份及多图使用统一选择面板。图片整理和导出预览默认折叠，选择题目同步本题图片，底部操作固定可见。

原始阅读记录包含已保存题干、原图/补图、AI回答及已有详情；导出内容可选择“题目与作答”或“纯题目”：前者呈现题目和该份作答选项，后者只呈现题干、选项及必要图示，不包含作答、解析、对错统计或副本设置。两者复用同一Agent整理结果；切换不重做识别，也不丢失已设置的作答份数和对错数量。题目与作答、纯题目使用当前所选图片；编辑补图保留的旧版本只进入原始阅读记录，避免重复附图。源图、会话与独立校验状态不因导出改变。备份恢复仍使用[存储与恢复](storage.md)中的 NDJSON，PDF不能恢复历史。

## 题目与图片

打开弹窗只读取快照，不逐张解码、扶正图片或调用模型。首次预览、打印或下载作答副本时，默认由Agent提取必要题干、材料、选项和图示；文字题只导文字，有图题仅保留实际图示与关键标签，排除相机/网页边框、控件和无关背景。未配置模型或识别有疑点时明确保留完整原图及补图，用户可手动仅保留文字或指定裁片。选择原始阅读记录后才整理整张原图。

整理使用当前解题模型读取原图和每张补图，提出题干/选项转录、图片区域及纠偏角度，不重答题；高级区域中的AI识别按钮可显式重新识别。逐题单次、有取消和超时，无工具和自动重试；数量、字节与输出上限由[契约](../../packages/contracts/src/batch-print-layout.ts)和[适配](../../packages/agent/src/pi/batch-print-layout.ts)拥有。低置信、疑点或遗漏已有选项/图示保留原题及原图并说明；未知/遗漏图片或题目引用拒绝。超过单次来源数量的记录保留全部原图供手动整理。

图框相对未旋转原图；先裁出原像素及边距，再扶正，避免将原图坐标误用到旋转画布。提取图仍可微调或恢复未整理裁片。AI结果须在预览中核对，不修改存储答案或宣称识别准确率。

整理结果在独立的本机IndexedDB中有界缓存结构与必要裁片，刷新后可复用，命中不重做图像整理或模型调用。缓存键包含解析版本、题干和完整来源图片；题干、原图/补图变化只重整该记录，重命名和份数调整复用。最多128项/64MiB，超过容量或7日未用时逐出；缓存不是备份，清除浏览器存储会失效。取消保留已完成记录，后续显式操作只补缺失；刷新、关闭不自动重放请求。缓存失败告知用户，本次仍可导出。

## 份数与作答

“批量导出”弹窗可选择份数，逐份设置答对/答错数；两数之和固定为实际题数，同图多题分开计数。弹窗取消不应用草稿。预览可切换每份，原阅读记录仍可单独打印。

计数依用户业务规则：已完成且没有对应红色校验失败的原作答按对计，未知/未校验不被改成 verified。原红警告默认计错；减少错误前，需逐题给出有效参照答案。原作答不完整的批次只开放阅读记录，不能假装具备完整作答副本。

新增错误会实际更换合法选项；非选择题使用填写的错误作答，未填写时留空并计错。减少错误会实际改为参照答案。人工参照与输出对错发生矛盾时同样调整实际作答，不能只修改统计。选项缺失、没有合法备选、参照不明确或数量非法时拒绝规划。不同份优先使用不同错题组合；组合不足或全部正确时允许重复，不制造不存在的差异。

纯题目输出单份PDF，文件名为 `批次名称_总N_纯题目.pdf`，不使用作答对错规划。带作答文件名为 `批次名称_总N_对C_错W.pdf`；多份追加 `_01` 等序号避免同名，非法字符清理，超长名称保留完整统计后缀。

## 文件与失败

单份直接下载PDF，多份在本地生成全部文件后一次下载ZIP，失败不下载半批。PDF按A4排版、每页单独高清绘制，避免整本大画布；第一版下载PDF的正文为页图，不可选中文字，原浏览器打印入口保留可选中文字。打印对话框的保存/取消由浏览器控制，打开窗口或发起下载不等于确认文件已保存。

快照读取校验归属、顺序、成员变化与任务终态；缺图、损坏、容量超限或正在处理的任务中止。识别期间模型配置与新解题派发互斥；取消、超时或关闭后释放会话、打印frame、画布及下载资源。快照、份数、页数和文件容量以[契约](../../packages/contracts/src/local.ts)及[下载适配](../../apps/mobile/src/local/download-batch-pdfs.web.ts)为准。
