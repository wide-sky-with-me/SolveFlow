# 解题核心与资源

[设备适配](../../packages/agent/src/pi/mobile.ts)使用锁定 Pi Agent；[业务编排](../../packages/agent/src/orchestration/solve.ts) 管理解题、校验和有界修正。服务端通过受控加载器和工具桥接使用同一契约。

## 资源与工具

[资源生成器](../../scripts/prepare-mobile-agent.mjs) 只读取明确列出的学生 SYSTEM、VERIFIER、内容政策和受审 Skill 文件；[生成资源](../../packages/agent/src/pi/mobile-resources.ts) 属于构建产物。开发规则、notes、HOME/cwd、插件和外部播放器不在清单中。

考试Skill管理试卷要求，学科Skill管理方法（含写作），共享契约决定作答形态；不按考试×科目复制Skill。展示与局部检查见[阅读与绘制](rendering.md)。

模型用受限read加载方法/参考；明确考试时预加载考试通则与对应参考，其余仍按需。设备提供受限计算能力，不把服务端 MCP、搜索或隔离 Python 的设计当作手机已有能力。

Skill服从应用作答模式与校验时机。已加载方法覆盖的检查无需再读参考；定性图表无需额外计算/绘图，决定答案的数值仍需验算。

服务端工具须核验权限、身份、路径与输出；脚本/写入默认关闭，数学执行须隔离验收。见[Agent规则](../../packages/agent/AGENTS.md)。

## 预算和验证

调用额度与传输规则见[模型预算](model-transport.md#调用额度与阶段)，本节维护校验和一次接手的语义。

用户备用组优先接手主 Solver 的可恢复模型故障或自动 FAIL 的一次纠错；没有备用时可使用已配置校验组。非政策澄清允许较强模型重新判断一次，仍缺关键条件才追问。替换答案重新独立校验，接手占用既有一次修正机会，不循环路由。取消、身份/额度、有限总期限或次数耗尽不触发接手；步骤/知识列表不接手；单题主动校验判错且已启用备用时，客户端自动新增备用解答，保留原版与失败校验。原因见[本轮决定](../../.agents/notes/implemented/agent/2026-10-08-exam-flow-evidence-and-budgets.md)。

单题手动、批量自动校验；服务端由编排执行。Verifier 使用本次答案版本的主图/补图快照、已有答案和独立上下文，无工具；直接核对结论、关键条件、必要计算与选项对应，不要求从头完整解题或另给选项。判错后由备用重新解答，再校验新答案；未知不接手。历史 independentChoices 仍可读，返回时仍检查矛盾，但不再是新 PASS 必填条件。原因见[直接核对决策](../../.agents/notes/implemented/agent/2026-10-09-direct-answer-review.md)。

有效 PASS 才 verified；两条路径均查转录与逻辑/运算，多题和分小问还须逐项 coverage 完整对应原题号/标签，每项完成实质检查。缺项、重复、串题或未完成检查降 UNKNOWN，不自动付费补验。历史 v1 保持可读，重新核验采用当前门槛；旧客户端未必支持新字段，不降级覆盖安装。FAIL 最多修正一次。自动核验/纠错遇可恢复模型故障或核验次数耗尽时，保留有效候选与已有检查，标未验证并警告；取消、身份、有限总期限或求解次数耗尽终止任务。手动核验不使用该降级分支；超时、格式异常和疑点分别展示。覆盖门槛见[核验覆盖决定](../../.agents/notes/implemented/agent/2026-10-05-verification-coverage-and-time.md)。

题干充分而选项不全时给可检查的结论，optionsComplete=false、uncertainties明确警告且不猜selectedOptions；关键条件缺失才澄清。校验分别判断答案和evidenceStatus，证据不确定或选项对应不全降UNKNOWN。历史缺字段仍按原覆盖规则可读，不代表执行了新证据检查。

批量先保存并展示未验证候选，再进入独立核验队列；检查点、派发和恢复规则见[本地生命周期](local-run-lifecycle.md)。预算、阶段截止、格式收尾、传输重试及脱敏诊断统一见[模型传输](model-transport.md)，不在本页重复维护。

## 答题形态

[作答契约](../../packages/contracts/src/response-format.ts) 表达单选、多选、数值填答、简答、文章、分小问和作图。原题提供考试、模块与作答要求，填答值和解释分开，分小问保留原标签。格式校验拒绝声明小问缺答/重复、单选多标签、缺少图示的作图输出，以及不合法的 SAT 填答形式；TARA 文章检查 750 词上限。词数按空白分词，仅为本地参考，格式正确不代表内容正确。

旧记录可缺少新增题型字段。模型识别题型后由代码检查结构与考试规则，仍可能漏读/误分类。设备格式失败最多使用既有一次修复机会，旧答案手动校验前也检查考试格式，失败不调用模型、不标通过。

新Solver原题号兼容：安全非负整数转字符串，null/空白省略，再严格校验；不改答案、选项或身份，存储不使用此转换。见[题号与路径决策](../../.agents/notes/implemented/agent/2026-10-06-skill-paths-and-source-number.md)。无标签选项全部可读时才用注明的应用索引；原标签保留。

多页图片作为同题证据传给两个独立阶段；材料文字不能授予工具权限。原题裁框仍相对第一张主图，补图可整图查看，尚不支持从补图生成内嵌裁框。完整答案上下文的版本规则见 [生命周期](local-run-lifecycle.md)。

输出含答案、教学步骤、图示与安全摘要，不含内部思维链。违规候选不交付；契约检查证据/覆盖，不保证正确。
