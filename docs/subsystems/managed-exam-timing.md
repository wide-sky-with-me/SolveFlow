# 考试开放时间与作答计时

适用`apps/exam-web`中心考试平台；设备端批次计时独立维护。协议归[考试契约](../../packages/contracts/src/managed-exam.ts)，事务归[计时实现](../../packages/db/src/exam-timing.ts)。

## 入场与过期

限定时间场次保存开放、截止时刻。学生在窗口内实际进入才创建考试记录并写入`started_at`；仅登录、看到安排或老师查看不开始计时。唯一可进入的定时考试自动进入，多场可选。重复进入恢复同一考试，不重设开始时间。

不限时间场次的`closes_at`为NULL，不伪造遥远截止日期。首次进入显示开始提示，点击“开始考试”才入场；已经开始的考试直接恢复。不限时仅取消截止约束，仍受身份、分配、场次状态和单场互斥限制。

限定窗口已过、学生从未入场的安排显示“已过期”，登录后弹窗提醒，并支持过期筛选。该状态由已保存的时间窗口和无入场记录计算，不新建假考试或写入虚假用时；撤回的安排不算错过考试。

## 持续计时

数据库UTC时刻是计时依据；学生、老师快照共用`startedAt/endedAt/elapsedSeconds`。学生页隐藏计时，老师端用单调时钟补显示秒数并同步校准。切模块、切页、断线、关闭网页和设备休眠均不暂停，离开时间计入；未进入不累计。

`completed/finished_at`表示题目已有答案，不等于学生交卷。答完全部题仍计时；主动结束或定时到点后才固定用时，并释放下一场入场资格。模块参考时长不另行启动计时器。

考试卡片在已入场但未结束时显示“进行中”；“已结束”筛选只收录实际结束或已入场后到点的考试，不把全部答完或从未入场的过期安排混入。

## 结束与通知

学生从顶栏“考试状态”进入结束操作，有权限的老师沿详情入口结束，均先弹窗确认；取消不会写入。确认事务锁住考试，保存结束时刻、来源和操作者，停止该场未完成任务。重复结束返回同一记录，迟到答案不能重开考试或修改用时；不影响其他场次。老师只能操作被分配学生，管理员和场次管理员沿用已有范围。

定时到点由服务器自动结束，不等待学生在线或点击。events进程限量扫描；读取考试快照时也补做截止收尾。结束时刻取真实截止时间，服务器重启、扫描延迟和通知确认都不延长考试。学生收到“考试已结束”弹窗确认知晓；老师提前结束时有同样提醒。若手动确认框正打开，自动结束提示替换它，避免两个结束框叠加。

截止后不接新图，截止前已接受的答题保留原有最多5分钟收尾宽限；收尾只保存结果，不恢复学生拍题权限或计时。主动结束则取消未完成任务。已存原图、答案、红色问题和老师处理入口保留；老师后续处理不会改变结束时刻。

结束来源和时刻持久保存；结束提示的知晓标记只在该学生当前浏览器会话内有界保存。换浏览器再次查看历史可能再次提示，不表示考试重新结束。迁移及回退限制见[操作指南](../cookbook/managed-exams.md#计时升级与回退)。
