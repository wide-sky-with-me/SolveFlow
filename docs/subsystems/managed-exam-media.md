# 中心考试媒体读取与保存

适用考试平台后端图片链路；浏览器预览、缩放和会话缓存归[答案展示](managed-exam-answers.md#题目与原图)。文件始终私有，不接受任意远程URL，身份与归属仍按[平台](managed-exams.md)检查。

## 授权与读取

[图片权限](../../apps/exam-web/src/server/images.ts)使用与分配/WS相同的权限谓词，合并素材反向引用与负责范围检查。只有本人或有权访问已引用题图的老师/管理员可读取；未引用图片不会因为管理员身份自动开放。父图/变体与反向引用分别使用迁移12的索引。

[媒体HTTP](../../apps/exam-web/src/server/service.ts)每次GET/HEAD都重新检查当前会话、图片状态、分配权限并记录审计；HEAD只返回元数据，不下载对象。响应保留`private, no-store`，不返回公开对象地址。后端缓存不保存授权结论，命中字节也不能绕过撤权。

[进程内字节复用](../../apps/exam-web/src/server/media-reader.ts)只保存缩略图及模型预览，最多32项、32MiB，可用60秒，按最近使用淘汰；最多8个缓冲读取。相同对象合并下载，一个查看者取消不会影响其余查看者，全部离开则取消底层读取，迟到数据不得写回缓存；失败和长度不符不缓存。每个API实例分别持有，退出进程清空，不提供跨实例持久缓存。

原图及缓冲名额之外的请求走[存储流](../../apps/exam-web/src/server/storage.ts)，避免API先收齐原图再响应。流遵守背压、容量、已知长度、30秒读取超时和取消；异常终止传输，不把截断数据当作成功图片。只实现get的注入适配器仍可有限缓冲读取，不扩展并行名额。前端仍需下载完成后解码，后端流式不等于弱网原图立即显示。

## 上传与回收

上传保持既有解码、去EXIF及三份变体。三次对象保存并发启动，最多3个；等待全部完成后才统一ready，任何失败都先等其他保存收尾，再标记家族删除和上传拒绝，防止迟到PUT重建失败对象。幂等标识、题位归属、容量与次数限制不变，模型任务不因此重放。

未引用图24小时回收、题图30天保留；[回收](../../apps/exam-web/src/server/maintenance.ts)继续锁内复查引用并排除活动任务，删除失败有界重试。缓存不会延长数据库中的可读状态。策略、并发及升级取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-09-managed-backend-performance.md)。
