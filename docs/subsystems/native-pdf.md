# 原生批次 PDF

Android/iOS从批次操作、历史批次或任务总览打开“导出PDF”。当前提供快速原文的题目与作答、纯题目；多份分别设置错误数、备注及可选错题标记，单份生成PDF，多份生成ZIP。答案总表、黄色高亮、书签、长题续页及作答规划与[快速PDF](quick-pdf.md)、[批次规则](batch-pdf.md#份数与作答)共用，不重识别或调用模型。网页的整理、严格试卷及原始记录版式尚未接入此原生入口。

## 输入与执行

[弹窗](../../apps/mobile/src/components/batch-pdf-export.native.tsx)读取完整批次快照及当前补图，检查归属、终态与容量。缺已解析题干阻止提交，缺作答或识别疑点保留提示。份数、错误数和备注沿共享草稿校验；提交固定题图、顺序、作答计划与时间，后续编辑不改变已接受任务。

[任务管理](../../apps/mobile/src/local/native-export-tasks.ts)沿`LocalExportTasks`单槽有界队列，在工作区生命周期中持有任务。关闭弹窗、切换题目继续执行；取消卸载本轮渲染页，释放传输缓冲，迟到回调不能保存成品。应用终止后未完成记录标为中断，不自动续做；iOS/Android导出期间保持应用前台，不能将关闭弹窗等同于后台系统保活。

PDF通过随包内置的[本地DOM渲染页](../../apps/mobile/src/dom/native-pdf-document.tsx)复用生成器。仅传固定题目快照，不传模型设置、密钥或运行时对象；图片限定记录内JPEG。输入和文件按[契约](../../packages/contracts/src/local.ts)分块、逐次确认，并校验任务标识、顺序、容量、文件头和最终长度；不加载远程页面，不解释用户HTML。

## 成品与保存

[独立SQLite库](../../apps/mobile/src/local/export-task-store.native.ts)保存版本化任务及PDF/ZIP字节，不属于题目备份；容量与数量沿[导出任务契约](../../packages/contracts/src/export-task.ts)。写入容量在事务内计算，删除文件和记录同一事务，失败保留二者。生成成功后才能显示完成；保存失败保留有界成品，重试只补存、不重绘。用户可先保存或分享待存成品，再清理旧导出记录。

“我的→导出记录”支持搜索、取消、重试保存、重新导出及确认删除。普通通知8秒收起，保存故障继续保留。系统目录选择或分享由用户操作：[文件交接](../../apps/mobile/src/local/save-export.native.ts)逐块写出，取消删除不完整文件；分享弹窗关闭不宣称已发送。App内成品不因取消系统保存而删除，仍可再次保存。

系统分享使用任务独立的完整文件副本，写完后才交给接收方；Android分享选择器返回不代表接收方已读完，因此不立即删除副本。分享缓存另限512MiB、500条，后续分享时清理超过24小时的副本；近期缓存已满可改用“保存文件”，不删除App内成品。

Web成品继续保存在浏览器IndexedDB，和原生SQLite不互通；两端均不自动上传到Mac。移植和文件语义见[PDF验收](../postmortem/2026-10-30-native-pdf.md)，最新双平台模拟器范围见[设备验收](../postmortem/2026-10-30-android-emulator.md)。
