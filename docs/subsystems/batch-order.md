# 批次插入与导出顺序

题图顺序使用已有`batch.position`，题目、图片和解答仍由稳定session ID关联，原题Item号不因插入改变。保存时的批次顺序与本次导出顺序分别处理，不新增持久化版本。

## 新题插入

[批次操作](../../apps/mobile/src/components/batch-workspace.tsx)不再提供新增位置预设；继续拍摄和相册新增默认追加到末尾。已有批次从相册选图后打开[新增题图工作台](../../apps/mobile/src/components/batch-import-workbench.tsx)的居中弹窗，单张也显示位置选择。编号网格沿用题目快捷跳转样式，不显示图片：选择待加入的新图，再点已有编号，即插在它之前。大号数字显示调整后的编号，随插入、移动和移除即时更新；小字保留“新1”或发生变化的原编号，蓝色光标跟随当前新图。目标说明同时展示新图的新编号、目标题的新编号及原编号。可逐张选择、整组放到同一处，或点击“末尾”追加；未指定默认末尾。

工作台只维护本次草稿，已有题图的相对顺序不变。新图按预览中的最终位置保存；同一插入点内沿用文件名/时间或手动排序。每张图的目标绑定稳定已有ID，重新排序或移除其他待导入图不会丢失其位置。取消不保存、不调用模型。连续相机快存不增加逐张确认步骤。

Web支持鼠标或触屏直接拖动待加入编号条及网格中的新图；格子左右两侧分别表示插到该位置之前或之后，也能拖到“末尾”。新图之间可拖动换序；开启“整组拖动”会按当前新图顺序连续移动全部待加入图。拖动时预览编号，松手才确定草稿；长网格靠近上下边缘自动滚动。拖出网格松手、按Esc或触控取消均恢复拖动前的位置。点击定位与上下移动继续可用；原生端保留点击方式。

[编号投影](../../apps/mobile/src/batch-import-placement.ts)与保存语义一致：指定插入时预览连续编号；普通末尾追加保留历史已有间隔，新图从最大编号后开始。点击目标仍使用稳定ID，可见编号变化不会选错原题；不改模型原题Item号。

[插入契约](../../packages/contracts/src/local.ts)只提交原批次中已有题图的ID，空目标表示末尾。[仓库](../../packages/client/src/local-repository.ts)在一个事务内保存新图、顺延后续位置及更新摘要，成功后才允许入队。当前位置有空缺时按现有相对顺序恢复连续编号；重复位置、目标删除/归属变化、容量不足或无事务支持均拒绝，不静默追加到其他位置。

已有记录的分离原图/补图键、解答和模型请求快照不重写；旧内联记录保留其字节。普通结果保存采用仓库当前批次位置，后台迟到结果不能覆盖新顺序。模型任务按原ID继续，不因插入重答旧题。插入逐图提交，停止/失败只阻止后续加入，已保存题图仍保留；恢复规则沿用[批量导入](batch-import.md)。

显示顺序与派发顺序不同：新图保存后按入队先后等待，不抢占正在答题或校验的旧题，也不重排已等待题。图片、答案和补图分配始终按稳定ID关联；编号只改变显示位置。“调整批次图片”编辑已有顺序或删除题图则会先停止本批，成功后须手动继续待解题，见[生命周期](local-run-lifecycle.md#取消保存和删除)。

已有批次调整的缩略卡片、位置操作及取消草稿统一见[图片工作台](image-workbenches.md#操作与保存)；它只改顺序或删除题图，不覆盖已保存原图。

默认末尾追加继续使用原保存路径，未增加逐图全量元数据读取。指定插入需要验证批次并更新受影响位置，受现有题图数量上限约束。没有跨批次移动或已有题目归属变更。

## 可选导出顺序

[导出窗口](../../apps/mobile/src/components/batch-export-order.web.tsx)默认按批次顺序；展开“调整导出顺序（可选）”后，可选择题图并移动到指定导出位置，也可恢复默认。以题图为单位，同图多题保留为一组。

[纯投影](../../packages/client/src/batch-print-order.ts)只重排本次快照的位置与显示题号，不写仓库。题目与作答继续按稳定key关联：副本数量、备注、参照答案及已指定的错题不因移动改变，也不重新随机选错题。答案表、正文、页脚题号及书签使用重排后的导出顺序；主图及其补图保持归属。

副本初始错题分布依据批次顺序；手动重排保留这些题，因此新位置可能相邻，不保证重排后的分散程度。

顺序适用于快速原文、保存/整理版式、纯题目与原始记录，以及前台、打印和后台提交；后台接收时冻结快照，后续窗口调整不改已接受任务。重新打开导出窗口恢复批次顺序，不将可选设置保存为批次顺序。严格检查完整成员排列，拒绝重复、外来或遗漏ID。
