# 教师独立消息

教师可以对已拍题只发消息，无须选择或填写答案；与[人工确认和问题解决](managed-exam-attention.md)分开。从教师详情“发消息”标签进入右侧面板，不另开编辑弹窗；发送成功原位提示并清空正文，同题草稿切换归[界面约定](managed-interface.md)。契约归[managed-exam](../../packages/contracts/src/managed-exam.ts)，事务归[exam-messages](../../packages/db/src/exam-messages.ts)。

## 发送与接收

发送内容为1至2000字的纯文本，绑定学生、考试、题位及材料版本。只有系统管理员、所属场次管理员或该学生当前负责老师可发送；服务器重新核对账号与授权，不接受客户端指定学生归属。发送允许没有答案、解答失败、核验中或已结束的题位；消息不改变答案、人工确认、核验状态或红色问题。

消息落库后随学生工作区的定期同步显示，不因换设备、刷新或切换考试丢失。蓝色“老师消息”与红色待处理问题并存，不宣称该题已解决。点击先查看完整消息；“我已阅读”或“查看本题”才标为已读。关闭弹窗不标已读，读取失败保留消息；查看本题可定位对应考试与题号，不自动重答；定位请求失败后显示“重新定位消息题目”，由学生明确重试。

未读消息覆盖学生全部考试，不受当前列表搜索、分页或状态筛选影响。列表切换或读取失败时保留最近成功同步的消息，成功同步空列表才清除。接口在新客户端显式申请时附带消息；旧严格解析客户端不收到额外字段。

## 一致性与限制

请求携带材料版本及幂等标识；同一消息重复提交只保存一次，同键不同内容拒绝。发送失败后，原内容重试沿用同键；编辑正文后使用新键，避免被旧回执阻断。题图更新后新消息拒绝旧版本，未归档考试中，已成功发送的同内容重试仍返回原回执。归档后禁止新发送，已有未读消息仍可阅读。

每个学生最多100条未读，每场考试最多1000条消息，每位发送者每分钟最多20条；跨考试的收件人与发送者配额在事务内串行检查。超限明确报错，不丢旧消息或伪报成功。消息只支持文字，未提供群发、附件、已读回执面板或历史消息检索。

持久化由[迁移10](../../packages/db/migrations/0010_exam_teacher_messages.sql)新增独立表，发送不放宽原有人工确认的必填答案与处理意见。设计原因见[决策](../../.agents/notes/implemented/architecture/2026-11-07-teacher-messages.md)。
