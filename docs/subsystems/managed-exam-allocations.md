# 场次与学生分配

管理端在“考试安排 → 场次”的搜索栏右侧新建场次。同一表单选择模板、时间、学生、负责老师及答案模式，不再另设“分配学生”按钮。计时规则归[考试计时](managed-exam-timing.md)。

## 创建与调整

一次新建选择1至100名学生，每名学生可分配0至32位老师；初始所选老师应用于这批学生。学生和老师均使用主题一致的搜索多选下拉框，跨页保留选择，关闭后只显示摘要。分页、用途与账号范围见[列表](managed-exam-lists.md)。

场次与全部学生分配在同一事务创建，任一学生、老师或设置无效则整体回滚。相同请求键及内容重试返回原场次，不创建重复记录；改变内容须换键。旧的单独创建场次/分配接口保留兼容，新界面不使用两次写入拼接发布。

从场次行或分配记录进入“调整分配”，可搜索、分页查看学生，批量添加学生，或单独调整某位学生的多位负责老师。新增学生同样整体提交；已在本场次的学生不能重复添加。仅系统管理员或该场次管理员可管理，普通老师不能为自己增加授权。

未开考学生支持确认后移除；这是保留原记录的撤销，不删除账号或历史。恢复沿用原分配ID、答案模式、时间和老师。已开考学生不允许移除，仍可调整老师；需要中止时使用现有结束考试流程。已结束或取消场次不能新增、移除或更换老师。

## 权限与并发

更换老师只改变该学生在该场次的老师授权，不重建考试、题位、错题安排或任务，不重置计时。原老师不再拥有由这条分配授予的访问权，新增老师立即获得查看与介入权限；其独立管理员身份等其他合法权限仍有效。

调整携带分配版本；其他人先保存时拒绝旧版本，保留表单并提示同步。账号状态/角色在事务中锁定复查；老师介入在取得考试锁后重新检查授权，防止撤权前排队的旧请求在撤权后落库。锁顺序、幂等及取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-04-sitting-allocations.md)。

## 兼容与验证

沿用迁移7中的分配版本、老师授权和幂等记录，无新增迁移或依赖。新接口由[共享契约](../../packages/contracts/src/managed-exam.ts)约束，数据库事务见[实现](../../packages/db/src/exam-allocations.ts)。隔离事务、并发和两种浏览器证据见[验收](../postmortem/2026-11-04-exam-allocations.md)。
