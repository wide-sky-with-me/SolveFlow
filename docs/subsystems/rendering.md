# 题目阅读与绘制

React Native 提供导航、相机、分页和设置；本地 DOM 提供 Markdown、KaTeX、图示与公式预览。正文跟随设备字体，数学符号使用随包字体。渲染禁止 raw HTML、限制链接与内容大小，KaTeX `trust=false`。

## 答案与长文

[答案组件](../../apps/mobile/src/dom/answer-content.tsx) 按原标签展示各小问，将可直接填写的数值与解释分开；文章使用独立阅读区域显示自然段、标题、参考词数和声明上限；参考作文、写作点评和修改稿有不同标题，段落点评按需展开，点评不计入正文词数。旧答案没有这些字段时沿用原正文显示。用户消息展示和输入使用同一长文上限，公式预览仍保留较小的独立限制。

## 学科结构

[知识点组件](../../apps/mobile/src/dom/knowledge-panel.tsx)兼容模型把公式包在行内反引号中的输出：标题、解释、题中应用和易错点里的明确数学片段交给 KaTeX，普通代码及代码块保留原样。此兼容仅在展示时启用，不改保存的知识点名称或追问引用；其他正文沿用原有 Markdown 规则，公式语法错误仍提供可读回退，安全和资源限制不变。

[公式渲染入口](../../apps/mobile/src/dom/math-render.ts)在展示前移除不属于空白的 C0 与 DEL 控制字符，兼容旧结果中的不可见 ESC；换行和制表保留，原始结果不重写。语法、命令信任和宏展开限制继续由 KaTeX 执行，不把无效公式伪装成成功。行内公式留出分数上下的绘制空间，关闭纵向滚动以避免短分数出现滚动条箭头；长公式保留横向滚动。

[学科组件](../../apps/mobile/src/dom/subject-content.tsx) 将作文正文与点评分开，将已配平的化学反应式独立展示。KaTeX 使用现有包附带的 mhchem，支持上下标、电荷、反应和平衡箭头；安全和资源限制不变，语法错误保留可读回退。

[坐标图](../../apps/mobile/src/dom/answer-figure.tsx) 支持有标签的曲线、关键点、填色区域、虚线与方向箭头。图元可声明点在曲线上、交点及多边形面积关系；经济图要求两轴变量及单位。具体边界由 [图形契约](../../packages/contracts/src/figure.ts) 管理。

化学守恒与图内关系的提示只描述已执行的局部检查，不使用整题校验标记。它们不能验证原题识别、反应可行性、经济假设或证明；只有独立校验有效 PASS 才可标 verified。未声明这些结构的旧答案继续显示，不补造检查成绩。分层原因见 [决策](../../.agents/notes/implemented/agent/2026-10-04-subject-presentation.md)。

## 切题

[QuestionPager](../../apps/mobile/src/components/question-pager.tsx) 只挂载当前、邻页与过渡所需页面。目标数据、布局和文档可展示后切换，旧页在等待时保留；快速请求有界合并，失败提供回退，草稿/滚动状态独立保存。

[文档就绪](../../apps/mobile/src/components/document-paint.ts) 与 [Android 模块](../../apps/mobile/plugins/solve-background/SolveDocumentModule.kt) 联合处理浏览器绘制帧、原生布局和 WebView 合成确认。Android 题页保持稳定原生层级；短时预绘制仅限当前/请求目标，并限制数量、面积和时间，取消或卸载清理。Web 与 iOS 使用对应布局路径。

浏览器 requestAnimationFrame 不等价于 Android 合成完成；公式测量、页布局和可见像素是不同证据。切题变更需验证实际正文，而不只检查题号变化。

## 交互

“我的”页从历史摘要统计记录、解答、收藏、去重批次、状态、运行中数量及科目；随历史更新，不读取题图或调用模型。运行中标记独立于答题状态，校验数不是正确率。菜单标题和值统一行高，箭头独立绘制并在行内垂直居中。

统一主题/按钮/弹层处理深色、系统字体、短横屏、键盘和减少动态效果。单题历史的记录数量、清空入口和分页集中在列表下方，窄屏允许换行。“未校验”显示在答案标题旁，诊断放在题目卡；仅进行中的任务在解答下方显示进度及取消操作。原图可缩放、拖动和长按系统分享，分享取消与成功分别处理。Web 大图支持加减键缩放、方向键有界平移、0复位。批次操作弹层保留固定关闭栏、限制面板高度，操作列表独立滚动。

[弹窗容器](../../apps/mobile/src/components/motion-modal.tsx)在 iOS 的独立原生窗口内重新测量安全区域，避免固定返回栏进入状态栏；不复用根窗口的初始测量值。默认允许横竖屏，调用方显式指定方向时沿用其限制。Web/Android 沿用各自窗口布局。

工作区、导航、补图和设置页共用宽度约定；备份长文与普通弹窗有独立阅读上限。短横屏空状态缩小插画、左右布局，让拍照、相册及配置入口可见。导航与核验状态保留可读字号及主题对比度。

Web 宽度至少1100px、高度至少600px时启用[桌面样式](../../apps/mobile/src/workspace/desktop.web.css)：品牌与默认考试、批次和正文居中；拍题、统计卡横排，状态与菜单分栏，三组模型统一三列。缩窗恢复移动布局，保留草稿。样式仅由`startup.web.ts`导入，不改变原生安全区域与键盘避让。

设置、备份和维护使用 [PageHeader](../../apps/mobile/src/components/page-header.tsx)，标题、返回入口固定在滚动区外，运行中沿用退出限制。连接测试只校验当前角色的模型与密钥，就近显示进度与脱敏结果，并滚动到反馈。

iOS 设置页在键盘出现时缩小内容区域，长表单可在键盘上方滚动，返回栏继续固定；Web/Android 保持原有键盘布局。

[设置页](../../apps/mobile/src/components/settings.tsx)上方考试与并发卡等高，下方三组模型字段对齐；可选组开关在标题行，思考强度未开启时禁用。高级参数同步折叠，保留草稿；协议说明集中到配置说明。保存栏固定底部，保存校验完整配置。凭据归属见[设备运行](device-runtime.md)。

空状态只呈现标题、必要指引和入口，不额外展示提示卡片；题页不重复显示通用声明或“排版中”浮层。排序、核验流程和公式输入格式集中在使用说明，时间排序启用时提示来源差异。识图疑点、实际错误、校验结果与任务反馈就近展示。

裁切先保留题干、选项、坐标轴及图例，再按现有尺寸上限缩放和去除EXIF。已处理预览仅在内存标记，保存复用JPEG，避免再次压缩；标记不写入历史。未经处理图片仍须规范化并校验字节和尺寸。同题补图保存不触发请求；单题与批量共用更正窗口，可拍摄、添加和删除本次图片，至少保留一张。编辑取消不落盘，提交后新解答采用当前选择；历史答案主图按自己的快照展示，旧校验不受编辑影响。

[裁切界面](../../apps/mobile/src/components/photo-editor.tsx)为预览和拖动手柄保留空间；窄屏微调列表收缩并独立滚动，短横屏将微调放在侧面。预览继续保持原图比例，不以拉伸图片换取高度。

[Web 导航](../../apps/mobile/src/use-workspace-navigation.ts)用严格版本的浏览器页面快照恢复跨刷新前进/后退；返回时同步最近题目目标，可确认不存在的题目/批次引用清除；损坏记录或批次归属不明时保留目标与维护提示，读取故障仍显示错误。旧版仅数字的浏览器条目无法重建。原因与限制见[导航决策](../../.agents/notes/implemented/rendering/2026-10-07-browser-history-reload.md)。
