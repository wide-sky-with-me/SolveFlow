# 中心考试服务方案

适用`apps/exam-web`，与完整版客户端的[本地预设](model-presets.md)分别存储。这里只允许学生选择系统配置好的两套方案，不开放任意模型、接口、密钥或执行工具。

## 使用与权限

学生头像菜单“服务方案”打开主服务/备用服务弹窗，只显示名称、当前选择和可用状态。选择后点击“切换方案”，偏好绑定账号，刷新或更换设备后仍保留。正在处理的题继续使用原方案；切换、刷新、重连不会重新收费或自动重答。禁用的已选方案不偷偷回退，学生需主动选择其他方案。

仅系统管理员可进入“服务配置”。每套分别编辑解题、独立核验和可选自动备用，包括供应商、HTTPS地址、模型、协议、流式/非流式、上下文/输出容量及思考参数。两套编辑草稿各自保留；点击“保存配置”生效，旧版本冲突须重新读取。场次管理员和老师没有此权限，服务端逐请求检查身份，写事务复查角色/状态。

“备用服务”是学生手动选择的整套配置；“自动备用”是某套内原有的一次解题接手机制，两者不互相替代。教师AI答题/核验使用该学生提交新任务时的方案；人工确认不调用模型。

API Key仅允许写入，不通过管理员或学生接口回传。留空只在同角色、同供应商标识与相同规范化地址时保留；变更目标需填新密钥。“检查接口”只读取供应商模型目录，不提交提示词；目录列出模型不代表视觉、工具或完整解题已验证。

## 初始化与维护

先运行全部数据库迁移，再启动新API/worker；服务方案始于迁移8。私有配置保留`models`作为初始主方案，可用`secondaryModels`提供初始备用方案，两者沿`WebStoredModelsSchema`格式。增加`modelSettingsKey`：用安全随机数生成的32字节密钥，编码为64位十六进制，保存于0600私有配置；各API、worker和events必须一致。不要将密钥粘到源码、日志、文档或浏览器构建中。

首次启动按缺失方案初始化，之后以数据库版本为准，不用环境配置覆盖管理员保存值。未提供初始备用时显示不可用，管理员填写并启用即可。`liveCalls`仍由服务端控制，网页配置不能绕过它、调用额度或全局并发。

地址只允许已有受信服务及API易官方节点`https://api.apiyi.com`、`https://b.apiyi.com`；需要其他供应商时，由部署者在私有`allowedModelOrigins`加入精确HTTPS origin，再重启相关进程。浏览器不能扩展此名单。模型请求禁止跨域重定向，防止凭据随跳转外送。[API易兼容接口](https://docs.apiyi.com/api-capabilities/openai/compatible)使用`https://api.apiyi.com/v1`；本次Qwen模型名以认证目录中的`qwen3.8-max`为准，不沿用TokenPlus的名称前缀。

## 保存与任务绑定

迁移新增服务头、不可变配置版本和账号选择表；配置和凭据由[服务层](../../apps/exam-web/src/server/model-services.ts)用AES-256-GCM加密，绑定方案代码与版本，数据库不保存明文密钥。API返回的公开投影只有名称与可用状态。主密钥必须与PG备份一起受保护地备份；直接替换或丢失主密钥将无法读取旧配置，不能靠重新生成来恢复。

[入队事务](../../packages/db/src/exam-model-services.ts)在首次提交、补图/重拍、学生重新解答及教师AI操作时固定方案版本。模型请求不占数据库事务；管理员修改、禁用或学生切换只影响后来接受的任务，不改变已接收任务的密钥和模型。老任务没有绑定信息时沿原私有配置执行，不自动重放。

无考试临时拍题同样在接收时绑定方案，在进程内保存引用，不把题干、图片、结果写到上述配置表。原临时任务过期、取消和幂等规则不变。相关取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-06-managed-model-services.md)。

工作进程使用共用的[阶段与进展保护](model-transport.md)，并发名额准入后才启动首响应计时。阶段取消会中断等待名额；调用账本保存固定超时或HTTP错误码，成功置空，重复结算不能覆盖终态。脱敏调用日志含角色、模型、供应商主机名与耗时，不记录正文。
