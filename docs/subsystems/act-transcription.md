# ACT可见题面的独立转录

默认设备路径在用户选择ACT后，新解答与整题重新解答先转录、再解题；两次调用使用当前选定的Solver（主动备用重答则使用备用）。单次答题阶段多一次正常模型请求，沿现有模型、费用、次数和取消约束；没有新增OCR供应商或宿主工具。题内追问、详细步骤、知识点与主动校验不重新转录。保留服务路径尚未接入此两阶段流程。

## 原文与作答

[转录契约](../../packages/contracts/src/act-transcription.ts)分开保存按阅读顺序的全部可见文章/表格块、当前设问及原选项。当前高亮通过原文块、逐字文本和出现次数定位，应用检查它确实存在后才加标记，不让模型以更通顺的候选词替代。容量、题数、疑点和范围均由契约限制；无效结构使用既有一次格式修复，不截短原文凑容量。

[转录策略](../../packages/agent/resources/ACT_TRANSCRIBER.md)要求保留全部可辨认可见正文、选项首尾标点及表格各行列，排除相机和导航文字；屏幕外内容不补写。转录上下文不接收旧答案、候选、历史或旧识别正文；重新解答用可选结构化题号选择同图内的指定题，保留本轮用户说明、明确更正与转录核验疑点。第一张主图确定当前设问、选项及高亮，补图中的另一Item题号不能替换当前题；补图新增的文章、表格、观点仍须全部读取。缺少一张关键表格时仍保存其余可见内容，由解题阶段判断是否需要澄清。

[设备适配](../../packages/agent/src/pi/mobile.ts)在本轮内保留转录，[绑定投影](../../packages/agent/src/pi/act-source.ts)拥有最终题面文字、选项和范围；解题阶段的概述、润色或交换后的选项不能覆盖原文。解题新发现的疑点与合法原图裁片仍保留，并交给独立核验；裁片坐标只属于第一张主图，不支持补图坐标冒充原图。多题按指定题号对应独立问题，共享可见文章，不把其他划线拆为题目。输入与裁片边界见[隔离决策](../../.agents/notes/implemented/agent/2026-10-26-act-material-source-isolation.md)。

Web为斜拍小字额外生成两张[旋转、分区放大视图](../../apps/mobile/src/local/act-transcription-views.web.ts)，本轮缓存后只给转录和核验使用；不新增模型请求。原图始终第一张，补图顺序保留，辅助视图明确标为原图派生，不能据其裁边认定原图缺页。保留黄色范围，不做去色/锐化；辅助图受数量和总图片容量限制，不覆盖保存的原图。原生不生成这类普通辅助视图。

核验明确定位视觉疑点后，纠错及复验优先使用[局部复读](image-review.md)，可来自主图或任一已选补图；它替换普通辅助视图，仍保留完整原图与全部材料。原生也已有局部裁片实现，真机验收范围另见对应报告。

普通逻辑修正复用转录；独立核验指出TRANSCRIPTION错误时才在既有一次修正内重新转录。主解题失败后的备用接手可复用有效转录，转录本身失败则由既有接手路径处理。转录与解题共用原有答题阶段时间窗口、次数预算和一次格式修复，取消后不派发下一阶段。

## 核验与历史

ACT核验必须分别报告正文、设问、选项、当前范围及表格的实际检查结果；答案PASS或笼统的transcription声明不够。已确认差异判FAIL，未检查或不确定降UNKNOWN；仍须完成逻辑/运算及逐题覆盖等原门槛。检查不能凭候选没抄到某表格就认定原图没有该表格。

最终题面写入现有候选，新增可选的`transcriptionScope`仅说明采用了可见题面转录流程，不代表识别正确。核验分项也为可选字段，旧v1记录保持可读，新核验按当前门槛检查；旧客户端未保证支持新字段。没有自动迁移、补全或重放历史模型调用，旧题需手动重新解答才能应用新流程。

[快速PDF](quick-pdf.md)继续只读已保存题面，不在导出时补识别；故新流程对重新解答后保存的内容生效，不能恢复旧PDF里已经缺失的原文。模型仍可能误读细小标点或模糊字符，不宣称完整性或正确率保证。原因见[决策](../../.agents/notes/implemented/agent/2026-10-23-act-source-capture.md)。
