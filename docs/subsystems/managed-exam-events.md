# 场次、具体考试与成员

中心考试采用“场次 → 具体考试 → 学生分配”三层。[场次页面](../../apps/exam-web/src/browser/exam-events.tsx)负责列表与页面切换，[编辑表单](../../apps/exam-web/src/browser/exam-event-editors.tsx)负责两级保存草稿，[成员查询](../../apps/exam-web/src/browser/exam-event-members.tsx)负责人员分页；契约归[exam-events](../../packages/contracts/src/exam-events.ts)，事务归[exam-events](../../packages/db/src/exam-events.ts)。

## 三层职责

场次统一名称、考试类型和模板；类型由模板决定。场次不设置时间或单独维护人员名单。每个场次最多100个未删除的具体考试，分别设置名称、开放时间、截止时间及学生分配。学生看到具体考试名称；一个学生的多场考试仍受原有同时入场互斥约束。

具体考试一次选择1至100名学生、0至32位老师，初始老师和答案模式应用于这批学生，保存全部成功才发布；任一分配无效则整体回滚。后续可追加学生，再逐人调整多位老师与各模块错题数量，详见[分配规则](managed-exam-allocations.md)。错题模拟不承诺精确分数，展示限制归[答案展示](managed-exam-answers.md#错题模拟)。

场次参与人员按未删除的具体考试及未撤销的学生分配实时去重汇总；老师还须有未撤销的负责关系。不额外同步一份名单，新增、调整或撤销分配后自动反映。学生与老师名单均可搜索、分页。

## 修改与删除

两级名称均可修改，包括学生已经入场之后；具体考试名称同步到学生考试记录、考试快照和教师视图。改名不重建考试、改变计时或重新答题；表单未调整时间时保留原秒数与毫秒精度。

场次模板仅在所有下级考试都没有入场记录时可改，并同步到下级具体考试；所有已保存的错题配置必须与新模板兼容。具体考试的时间仅在没有入场记录时可改，并同步到学生分配。已有入场记录时保留结构与时间，仍可改名或更换负责老师。

删除须确认，采用归档保留题图、答案、计时与审计记录；存在进行中的考试或未收尾任务时拒绝删除。删除父场次同时归档下级具体考试，管理列表、实时跟踪、统计、筛选选项和待处理队列隐藏已删除记录；学生全局待处理计数不再包含归档考试，实际参加过的历史及问题记录仍可查看。无恢复归档入口。

## 权限、并发与升级

系统管理员可管理全部场次，场次管理员仅管理自己的；普通老师只拥有被分配学生的跟踪、答题及[消息](managed-exam-messages.md)权限。创建具体考试继承父场次模板与归属，不接受浏览器指定其他模板或管理员。

写入携带版本和请求标识；重复请求返回原回执，内容变化或版本落后则拒绝，保留表单供刷新后处理。结构变更与入场锁定同一分配记录，避免“检查未开考后恰好入场”的竞争。归档先锁已有作答，再锁分配，与老师介入及任务收尾串行；已归档考试不接受新的教师消息。边界取舍见[归档可见性决策](../../.agents/notes/implemented/architecture/2026-11-07-archived-exam-visibility.md)。

[迁移11](../../packages/db/migrations/0011_exam_events.sql)为每条旧考试创建同名父场次，不合并同名记录；旧分配和考试ID保持不变。旧写接口仍创建默认父场次，旧客户端字段不扩展。部署步骤归[升级指南](../cookbook/managed-exams.md#计时升级与回退)，取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-07-exam-event-hierarchy.md)。
