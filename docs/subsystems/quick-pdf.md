# 已解析内容快速PDF

“快速原文（最快）”连续排版已解析题干、选项及作答，可选纯题目；跳过模型、整理缓存、自动图片加工和网页逐页截图。备注、错题计划/标记、ZIP及取消/保存沿[批次PDF](batch-pdf.md)流程，取舍见[快速导出决定](../../.agents/notes/implemented/storage/2026-10-22-direct-parsed-pdf.md)。

## 内容与资源

题干、选项及原回答不重识别，公式及Markdown保留原文写法。缺已解析题干会指明题号，用户可改选其他版式；同源原图保留一次，不能用未声明图示推断无图。纯题投影不读取作答，图片自身包含的手写答案仍会存在。预览及浏览器打印同样显示原文。导出只读原记录，使用任务快照固定的错题计划。

带作答时开头生成一个总表，按批次题号每5题一组显示数字答案数组。数字对应本题原选项顺序：通常A/B/C/D为1/2/3/4，FGHJ或其他标签同样按实际顺序编号，不按字母表硬换算。选项不全或标签无法对应时显示待核对；简答/作文跳到正文，数值填答直接列值。总表数字以黄色底显示，正文仍保留黄色作答字母；纯题目不生成答案表或答案高亮。

答案表与正文共用本份固定作答计划，启用错题标记时两处同时标识。每个数字具有独立跳转区域，避免五列链接互相覆盖。题目正文及书签保留可见原题号，重复原题号以批次顺序区分。

下载PDF包含“答案表”（仅带作答）及各题书签，按实际分页结果指向题目所在页；答案表中的条目还可直接跳到题目位置。长题可续页，书签不假定一题一页。预览和浏览器打印保留可点击答案表；浏览器自带的打印PDF是否生成书签由浏览器决定，应用下载的PDF统一生成书签。

## 多份复用与保存

每段可打印ASCII用PDF标准字体文字，其他字符用浏览器字体绘制局部透明行图，保留中文、特殊标点和数学字符。英文文字可选取；中文行图不可选取。题图作为独立资源嵌入，尺寸适合的JPEG直接使用，否则按显示尺寸处理，保留比例和原图内容，不做旋转、锐化或识别。

同次任务的副本共享换行、编码题图与字形行缓存；分别限制2、32、8MiB，各最多2048项，超限逐出，解码像素及时释放。不同作答可能改变页界，每份仍独立分页，书签及链接按各自实际页码定位。任务结束或取消释放缓存；取舍见[资源复用决定](../../.agents/notes/implemented/storage/2026-10-25-direct-pdf-resource-reuse.md)。

长文本按行续页，图片缩放到可用页面。页数和容量沿[批次PDF](batch-pdf.md)上限，单份按实际页数计时，取消释放图片、画布和ZIP资源，迟到结果不得保存或下载。最终成品沿原队列原子保存，不交付半批；保存重试不重新生成。大图、很多份或浏览器存储较慢时仍会耗时。
