# 考试平台界面与动效

中心考试客户端、教师端和管理端沿用共用蓝色强调、系统字体、细线图标与明暗主题；界面收尾样式归[design.css](../../apps/exam-web/src/browser/design.css)，页面布局继续由各功能样式维护。看板结构及图表口径归[控制台](managed-exam-dashboard.md)，逐题规则归[学生流程](managed-student-flow.md)。

## 视觉一致性

[共用反馈色](../../packages/web-ui/src/feedback.css)唯一维护信息、成功、等待、错误四套语义颜色。状态标签、答案高亮、总览和提示消费同一调色板，包含显式明暗与跟随系统；颜色仍配合状态文字，不改变核验或人工确认语义。浅绿只用于AI已核验的答案，人工答案标识沿[摘要规则](managed-answer-previews.md)。

卡片保持安静边框与轻阴影，弹窗及菜单使用更高层级的阴影。关闭、新建沿同一SVG图标系统，保持44像素主要交互目标与键盘焦点。次要按钮提供悬停和按下反馈；触屏不依赖悬停才能发现操作。

四个以内的手机模块标签等分，较长名称最多两行，完整名称保留为文本和标题，避免省略末尾的一／二；更多模块继续横向滚动。考试管理页采用分段选项卡。普通表单底部操作区在弹窗内部保持可见，滚动留出焦点空间；保存失败显示在弹窗顶部独立提醒区，避免被操作区覆盖；教师题内编辑和图片画布保持各自布局。

## 动效边界

[管理页面容器](../../apps/exam-web/src/browser/admin.tsx)只按主动切换的页面身份创建入场效果；自动同步保留同一节点，不按更新时间或请求序号重挂载。学生当前答案按题位切换轻淡入，同题结果更新只改变内容与状态色。看板原有曲线、进度和环形图继续按实际数据更新，不用动画制造数量或完成率。

弹窗约200毫秒、菜单约150毫秒入场，使用透明度和小幅位移；图片查看器只淡入，避免改变缩放坐标。退出、取消和焦点恢复立即执行，不等待动画事件或定时器。首页统计沿同一页面更新，不另开固定视口覆盖层。

遵循系统`prefers-reduced-motion`时禁用非必要动画和过渡，保留清晰的文字状态；持久提醒静止呈现，只在展开时旋转箭头；不闪烁、不自动消失。实现参考[W3C C39](https://www.w3.org/WAI/WCAG22/Techniques/css/C39.html)与[Chrome动效指南](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/motion)，不引入动画框架或业务等待逻辑。

浏览器动效、焦点、对比度、手机布局与真实页面回归见[界面验收](../postmortem/2026-11-08-managed-ui-polish.md)。WebKit视口检查不替代iPhone真机与触屏键盘验收。
