# 跨批次任务与进度总览

[本地批量队列](../../packages/client/src/local-batch.ts)由运行时持有，切换、新建批次不会销毁已有等待或执行任务。所有批次共用答题与校验并发，不为每个批次另开模型池；按照已入队顺序派发。同图补图重答计划仍依次执行，见[批量补图](batch-materials.md)。

## 等待与隔离

每批题图数量、跨批次等待队列容量、已接受的解题与核验输入上限分别由[设备契约](../../packages/contracts/src/local.ts)定义。等待队列只持有题图ID、批次身份与请求描述，派发时才由引擎读取图片。达到已接受输入上限时，剩余题目保持等待，不因校验积压报启动失败。等待队列和补图准备均有界，不提高模型执行并发或解码图片上限。

停止本批先清除该批等待项并立即取消已注册请求，再补取消尚在启动的本批请求，只等本批已经开始的补图与保存收尾；不先等待他批补图。尚未开始的准备以提交时的停止代次校验，即使停止标记已经收起也不会迟到入队。同一范围的重复停止共用收尾过程，其他批次继续派发。某题启动失败只清除本批后续等待项，提示只显示在对应批次。批次删除和调整仍先停止本批，沿[生命周期](local-run-lifecycle.md)等待安全存储事务。准备和结果落盘共用存储锁，不承诺存储完全并行。

结果未能保存属于共享存储故障，仍阻止所有新派发、保留待保存结果，必须重试保存后手动继续，不因批次隔离放宽保护。普通追问、更正、切换模型与考试的既有限制保持不变。

## 任务总览

题目页“任务”与“我的 → 批量任务”打开同一[任务弹窗](../../apps/mobile/src/components/batch-task-center.tsx)。列表只读取历史摘要和有界内存队列快照，不加载各批原图。进行中批次优先，提供“全部”和“进行中”筛选；每张主图计一次，图内多道题不展开为多个进度单位。

[汇总](../../apps/mobile/src/batch-task-summary.ts)将答案是否已生成与任务阶段分开：有当前答案、仍在校验的题图也计入“已出答案”，每张题图至多计一次。阶段仍显示准备、等待、答题及校验；闲置题图分别显示已校验、待确认、已停止、待补充、失败和待解题。主动停止不显示为解题失败，需补充条件不自动重复重试。校验数不是正确率；旧摘要从元数据重建，不加载原图。

点击批次标题回到对应题目；更多操作按需展开单批停止、继续待解题、重试未完成和导出，不常驻大段说明。继续和重试是明确的新任务，关闭总览或保存重试不会自动触发。精细操作和取消仍使用原题页入口。

## 导出与后台边界

PDF入口只检查目标批次是否仍有等待、答题、校验或准备任务，以及目标题图是否有活动请求。其他批次工作时，可导出已经完成的批次；快速原文、已保存内容及本地图片处理不因别批答题被禁用。需要调用模型的图示重识别仍遵循原有准入，不在此次导出中新增模型调用。导出任务本身见[导出记录](export-tasks.md)。

Web队列仍依赖当前页面的运行时；切页或关闭弹窗可继续，刷新、关闭浏览器或系统终止后不自动重放付费请求。Android后台能力及原生限制见[设备运行](device-runtime.md)。本功能未新增服务端持久任务或跨浏览器同步。
