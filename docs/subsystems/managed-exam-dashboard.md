# 中心考试控制台与数据大屏

[管理端](../../apps/exam-web/src/browser/admin.tsx)保留看板、实时跟踪、待处理题、用户、场次、统计及角色入口；采用共用主题/图标，不向学生开放。边界见[中心平台](managed-exams.md)。

## 数据口径

[看板事务](../../packages/db/src/exam-dashboard.ts)在一致快照中聚合当前负责学生/管理场次，排除撤销分配；不从上限500条的管理列表推算全场总数。系统管理员、场次管理员、老师沿用既有权限，兼具学生身份不扩大范围。场次过滤只能使用可见分配中的场次；学生不得调用接口。

卡片显示去重学生/在线数、当前有效答案、AI核验、人工确认、活动任务和未解决问题。在线按有效会话近45秒活动判断，与是否入场分别统计。学生摘要携带与快照/实时跟踪相同的计时投影，已有入场时间时显示实际用时，未入场才显示“未进入”，结束后冻结；数值、状态、用时和操作列与表头居中对齐。已有答案不使用completed_once历史标志，重拍后旧答案不再计入，实时跟踪也采用相同规则。未开始分配按模板计题数，已开始按冻结题位；模块分母包含未开始学生。

状态环图按待处理、处理中、已完成、未拍及待解答划分，每题只占一类，总和等于总题数。红色问题优先于活动任务；卡片已有答案仍可包含待核验题，因此不等于环图已完成。待解答保留已拍但无当前答案/活动任务/开放问题的状态，不冒充完成。

发布趋势取最近一小时的12个五分钟桶，分别统计AI展示和人工确认的真实发布时间；同题重答属于再次发布，不是新增题数，也不是调用数或正确率。空桶为0，不插入演示趋势。统计页展示各桶明细。

## 展示与刷新

顶栏Logo靠左，右侧提供浅色、深色和跟随系统主题；偏好仅保存在当前浏览器，拒绝存储时本页仍可切换。主题脚本在样式之前以同源静态文件执行，不放宽CSP。桌面侧栏可收为图标栏并记忆选择；900像素以下使用原生弹窗抽屉，支持Esc、背景隔离与焦点恢复。导航保留名称及当前页标记，折叠不改变角色权限。

[看板组件](../../apps/exam-web/src/browser/dashboard.tsx)每五秒取快照，首页、统计与数据大屏均可手动刷新。自动轮询静默，手动刷新才显示图标转动并禁用刷新按钮，文字/宽度不变；两者复用进行中的请求，筛选切换取消旧请求。同步失败保留最后成功数据与更新时间，并显示错误，恢复不触发模型。管理导航已表达的页面标题不在正文重复，场次选择器保留无障碍名称。卡片、图表、模块和学生摘要同源同事务；学生摘要最多8条，按待处理/活动/在线优先。模块图最多8组，优先有问题的模块；摘要的“查看全部”进入带当前场次的实时跟踪；完整列表使用[服务端分页](managed-exam-lists.md)，题目列表在[待处理队列](managed-exam-attention.md)。场次选择支持分页搜索，不受快照兼容选项200条限制。

[看板首页](../../apps/exam-web/src/browser/home.tsx)先显示在线、AI核验、人工确认与活动任务四项摘要；答案数量集中在覆盖率卡片，异常数量集中在问题入口。桌面下方依次为发布趋势/题目状态、模块/学生明细；手机将学生进度提前到摘要之后，再展示问题和图表。覆盖率环与大屏共用实现及动效；待处理原因直接打开对应队列。原因和模块长列表在卡片内滚动，学生表格在小窗口改为带标签的卡片行，操作按钮始终可见；桌面表格分行保留题号及状态，避免挤占用时列。零题数与空列表保留真实空态，主题、筛选、刷新和权限不变。

发布趋势支持面积折线/堆叠柱图切换、悬停或方向键读数；状态环图、原因条图和模块进度沿用原统计口径。卡片入场、路径绘制及数据变化使用短过渡；五秒轮询不会反复播放入场动画，系统要求减少动态效果时停用动画。空桶保留零值，不生成演示曲线。

数据大屏使用同一数据与主题，采用独立三栏布局：中央突出已有答案/总题数的环形覆盖率，左侧展示模块与状态分布，右侧集中待处理原因和学生摘要，底部保留发布趋势。覆盖率不冒充正确率或完成率；零题数显示0%，不绘制完成弧。1920×1080的无浮动提醒场景可完整显示8条学生摘要；全局提醒出现时列表为末行预留空间，可在面板内滚动。长姓名/模块名截断并保留悬停全名，较小窗口按两栏或单列排列；更多模块内容在面板内滚动。只有存在活动任务时显示呼吸状态点，减少动效设置仍生效。支持场次筛选、浏览器全屏、退出全屏和返回控制台；学生详情可在原生全屏中打开。弹窗沿用原有原生dialog和焦点恢复。小屏可滚动查看；复杂数据/超长内容仍可能需要滚动，不能把一屏示例当作任意尺寸保证。学生摘要窄屏改为卡片，长内容在面板内滚动；不展示模型密钥或原始内部推理。

教师详情采用独立宽弹窗，桌面将题目/原图与答案/处理分栏，平板、手机恢复单列；普通管理表单保留紧凑尺寸。顶部统计与独立导航/操作记录弹窗减少纵向堆叠，原图查看和题目样式归[答案展示](managed-exam-answers.md)；AI原始答案按需展开，学生当前答案保持可见。红色问题位于独立的固定提醒区，不覆盖滚动中的选项和表单；原生弹窗开启时锁定背景滚动，关闭后恢复。样式见[详情布局](../../apps/exam-web/src/browser/review.css)，截图和边界检查见[布局验收](../postmortem/2026-11-03-exam-dialog-layout.md)。

进度环的数字和说明用独立HTML层，手机说明保持12px，不随SVG缩小；看板问题入口的场次传递归[问题队列](managed-exam-attention.md)。图表使用现有React和SVG，不新增依赖；取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-03-exam-console-dashboard.md)。真实模型见[原验收](../postmortem/2026-11-03-exam-console-live.md)，顶栏/主题见[验收](../postmortem/2026-11-04-console-appearance.md)，大屏分区见[验收](../postmortem/2026-11-04-wall-layout.md)，首页见[验收](../postmortem/2026-11-04-home-layout.md)，字号修复见[本轮](../postmortem/2026-11-04-managed-exam-audit-fixes.md)。
