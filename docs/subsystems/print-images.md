# PDF 题图处理

本页维护[批次 PDF](batch-pdf.md) 的图示像素处理、人工调整及失败语义。

## 像素链路

图框相对未旋转原图，以原像素留出标签边距后裁切，独立保存未加工裁片。先估计纸面、温和校正底色，存在人工四角时投影展平，再在扩大的白色画布上旋转；额外人工裁切采用旋转后坐标，最后做有界锐化。未选择四角时保持原链路。背景估计优先保留浅灰填充的部分明暗对比，可能留下阴影；相对纸面的色差采用连续权重，保护彩色标记和淡线，不承诺分离所有同色照明与图元。不重建缺失图形或细节，原照片保持不变。

首次整理的裁片参考文字基线和可确认的屏幕边缘估计倾角。孤立短标签不足以判断时借同源全图，最后回退模型角度；不把电路、斜面或函数曲线本身的斜线当作纸面倾角。检测证据弱时维持原样，检测为零不代表已证明摆正。

## 存量与人工

“图片整理”先选当前题目与图示归属，再显示本题操作；“重新整理本批”和“更新本批清晰化”集中在独立的本批操作栏。

打开仅读缓存。试卷预览、打印和下载均从原图或未加工裁片自动清晰化，已整理缓存也核对图像处理指纹；无调整时估计旋转和可靠屏幕边界，已有几何、四角及恢复原图决定保持。指纹随任务复用，多份不重复处理；普通导出不改题库/缓存，不调用模型。旧裁片可显式点击“摆正本批图示”进行本地更新，不重跑识别模型；仅处理仍在版面内、零旋转、完整裁片、无人工四角且清晰化开启的派生图。已有非零角度、四角、再裁切、恢复原图和排除决定保持原样。单图“自动整理本图”重新估计角度/可靠边界并清除四角；“自动整理本批图示”处理在用图，重估角度/裁框并保留已应用四角；手动旋转与裁切仍可单独更新。

旋转与裁框输入保留负号、小数点等编辑中状态，只在“更新图像预览”提交有效参数；范围或宽高无效时就地提示并阻断更新。方向键步进，Escape 撤销当前字段编辑而不关闭弹窗。切换图源重新同步草稿；恢复、自动整理或应用四角仅在图像提交成功后同步数值与四角草稿，相同参数也重置。普通数值预览保留未应用四角，清晰化开关保留数值和四角草稿。显示格式不回写未编辑字段的完整精度，尚未应用时导出仍使用已保存图像。

“图片整理”中的“四角校正”按原裁片的左上、右上、右下、左下保存百分比坐标，支持拖动、方向键和精确输入；范围为 -25% 至 125%，图外填白，投影输出仍限 2048 像素边长。只有显式应用才生成结果，并替换当前旋转和裁框；后续旋转、裁切作用于投影图。重选四角不即时改图，“恢复裁片／原图”清除全部加工。每次加工都从原裁片开始，不叠加压缩。

“图片整理”内的“更新本批清晰化”从未加工裁片更新底色和锐化，沿用每张图已有四角、角度、旋转后裁框及归属。仅作用于在用、已加工且清晰化开启的裁片；恢复原图和排除项跳过，不触发模型。相同像素不重复写入。

自动与人工四角、旋转、裁切、归属及文字确认按记录保存。确认改写过时原图声明，保留识别疑点；加入裁片只替换同源占位，其它未确认来源仍待核对。不改题库、答案或独立核验。

## 失败与限制

检测、加工失败或图像提交前取消保留旧图及编辑草稿。图像已提交后保存失败或取消，保留新结果、标记待保存并阻断导出；重试只补存储，不重置此后新输入的草稿，未保存关闭须确认。取消后等待原操作结算再解除忙碌，迟到加工结果不提交。解码、扫描及加工仍受各自资源边界约束；实测范围见[取消与补存验收](../postmortem/2026-10-17-pdf-image-cancellation.md)。

角度、裁切与四角范围由[共享调整契约](../../packages/contracts/src/print-image-adjustment.ts) 约束。角度支持±45度，粗扫后局部细扫；确认屏幕边缘才裁照片外框并保留纸面边距，弱证据保留全图。自动旋转不等于透视展平；人工四角也不证明物理比例已恢复。残留背景、弯曲纸面、邻图碎片、微小标签或不同方向标注仍须核对，不宣称完整修复拍摄形变。

自动导出取舍见[后续决定](../../.agents/notes/implemented/storage/2026-10-21-automatic-export-images.md)；其它选择原因与缓存兼容见[摆正决策](../../.agents/notes/implemented/storage/2026-10-15-explicit-print-deskew.md)、[清晰化决策](../../.agents/notes/implemented/storage/2026-10-15-explicit-print-enhancement.md)、[浅灰对比补充](../../.agents/notes/implemented/storage/2026-10-17-print-paper-contrast.md)和[四角决策](../../.agents/notes/implemented/storage/2026-10-15-explicit-print-perspective.md)。
