# 模型预算、传输与诊断

本文维护设备模型阶段、调用额度与响应处理。模型配置与密钥归[设备运行](device-runtime.md#模型与考试)，校验与备用接手归[解题核心](agent.md#预算和验证)，队列和保存时序归[生命周期](local-run-lifecycle.md)。设备与保留服务路径的预算不同。

## 调用额度与阶段

[RunBudget](../../packages/agent/src/policy/run-budget.ts)在设备端默认不限累计时间，保留服务端默认180 秒；模型、文件/业务/搜索工具及格式修复共享有限额度，派发前预占，失败也计数。时间和模型次数由[Agent契约](../../packages/contracts/src/agent.ts)拥有；取消与预算耗尽产生安全终态，不以换模型绕过。

设备累计时间不限不等于单次请求无限等待。[设备阶段](../../packages/agent/src/pi/mobile.ts)按以下范围执行；有限总预算若更短，以剩余时间为准：

| 阶段 | 时间窗口 |
| --- | --- |
| 自动主解题；启用备用组时的主解题 | 240 秒 |
| 手动且未启用备用组的主解题 | 300 秒 |
| 备用或校验组接手解题 | 300 秒 |
| 所有题型的核验 | 300 秒 |

无备用的自动求解届满时，近10 秒有流进展可延长最多15 秒；一次晚格式修复可取得最多20 秒，停滞不可借用。启用备用不借用；重试共用阶段截止，不重新取得完整窗口。Android防泄漏期限由派发次数乘阶段上限生成。窗口取舍见[阶段决定](../../.agents/notes/implemented/architecture/2026-10-09-batch-retry-and-phase-time.md)。

简洁主解题配置接手模型时，首个隐藏推理增量后持续60 秒没有正文或工具调用，提前中断并使用既有一次备用机会；正文/工具到达取消保护。详细学习及无接手模型不用此保护；非流式完整响应到达前没有增量，仍由阶段截止约束。

初验、纠错后复验各最多两次，共四次；重试/格式修复仍占额度，初验不挤占复验。服务父进程同样按阶段授权，见[批量派发决定](../../.agents/notes/implemented/architecture/2026-10-09-batch-dispatch-and-verification.md)。累计额度不限不取消调用次数、工具额度或并发上限。

## 格式收尾与传输重试

无工具收尾投影去掉调用协议、保留带`isError`的工具观察与原图，原SDK记录不改。未知工具被拒绝后立即关闭工具阶段，避免继续发送越权调用历史。供应商仍返回工具终态时阻止执行、停止该轮，最多使用原有一次共享格式修复；截断不进行传输重试。见[收尾修复](../../.agents/notes/implemented/agent/2026-10-07-exam-reliability-recovery.md)。

设备网络/流异常、429/5xx默认退避500 毫秒，同阶段最多重试一次；Pi续接保留工具观察、丢弃失败片段。404直接进入既有接手机会；取消、身份、额度或超限不重试。重试沿用原计时和预占，可占满本阶段两次核验额度，见[重试与降级](../../.agents/notes/implemented/agent/2026-10-08-verifier-transport-degradation.md)。这与用户从失败记录手动新建`run`的重试不同，后者见[队列准入](local-run-lifecycle.md#提交与执行)。

## 流式与非流式

备用、核验默认非流式，主解题默认流式；每组`streaming`可显式覆盖。设置预设和`.env`模型值的归属见设备运行，传输层不自行选模型。

[适配器](../../packages/agent/src/pi/non-stream-response.ts)将完整JSON交给同一Pi事件解析入口，保留工具、usage、加密签名及真实终态；Pi继续拥有模型/工具循环。未完成、失败或排队响应不能伪装为完成。供应商忽略非流式要求而返回SSE时沿既有解析器处理。设备与[本地代理](../../scripts/web-model-proxy.mjs)共享8 MiB SSE、1 MiB JSON限制；本地代理单次传输上限300 秒。

完整响应到达前没有增量，非流式不保证更快；供应商排队、模型推理与多轮请求均可能耗时。具体取舍见[非流式决定](../../.agents/notes/implemented/agent/2026-10-09-non-stream-model-transport.md)，少量实测不代表全科准确率。

## 脱敏诊断

题内“诊断详情”记录角色、模型、图片数、请求方式、实际JSON/SSE、HTTP状态、首个内容事件、工具名/耗时、排队时间、输出及隐藏推理字节数。阶段到期记录`deadline`和阶段窗口；不保存题图、工具参数、模型正文或内部推理。

区分排队、等待响应头、流传输、工具执行和阶段截止，不能把全部等待都归为模型生成长答案。工具/响应原文不可从字节统计反推；旧记录缺失的诊断不能补造。

Web代理只记录固定分类的元数据，没有逐`run`关联；连接快照和一次日志不能证明业务队列空闲。故障定位与更新步骤见[Web指南](../cookbook/local-web.md#失败处理)，真实结果留在对应复盘中。
