# 中心考试列表与分页

适用中心考试平台的用户、考试场次、分配记录、模板、实时跟踪和学生考试记录。入口见[管理端](../../apps/exam-web/src/browser/admin.tsx)与[学生工作区](../../apps/exam-web/src/browser/student-workspace.tsx)，统计口径仍归[看板](managed-exam-dashboard.md)。

## 读取语义

新界面使用[契约](../../packages/contracts/src/managed-exam.ts)定义的分页接口：默认20条，单页最多100条，支持页码跳转和20/50/100条切换；搜索、筛选和页容量变化回第一页。每页返回范围内总数、服务端规范化页码、条数及记录，空结果仍是第1页。请求超过末页时回到当前末页，界面同步规范化页码，避免停在空页。

[查询](../../packages/db/src/exam-lists.ts)在只读一致快照中计算总数、取当前页及读取选中记录。用户按创建时间和ID排序，场次/分配按开考时间和ID排序，模板按名称、版本和ID排序；同时间记录仍有稳定顺序。搜索使用参数化ILIKE，百分号、下划线和反斜线按字面转义。筛选和计数先应用可信身份范围，不从当前页推算全场总量。

分页采用偏移量，支持直接跳页；它不冻结跨请求数据快照。其他人新增、停用或修改记录时，当前页内容和总数可以更新，用户正在编辑的表单不重置。历史数组接口保留原有500/200/100条兼容上限，不再用于新版列表或选择框。没有持久化结构变更，取舍见[决策](../../.agents/notes/implemented/architecture/2026-11-04-managed-list-pagination.md)。

## 刷新与筛选

自动轮询静默更新，不切换刷新按钮、分页或输入框的可用状态，不替换已有内容。只有点击“刷新”才显示图标转动，按钮文字和宽度保持稳定；若已有后台请求则复用并等待其结果，不追加请求。首读或新查询仍显示加载状态，失败保留原页与错误。

分页主体只读取当前页面；看板不附带整批进度/分配查询，教师全局提醒另读最多3道[待处理题](managed-exam-attention.md)。列表每五秒读取当前页，同页手动与自动刷新共用进行中的请求；表单保存后的刷新会取消保存前的读请求，确保重新读取。相同查询失败保留最后成功数据并显示错误，新页或新筛选不展示旧行。查询变化或卸载取消旧请求，迟到结果不能覆盖当前列表。

页码仅在回车时提交；失焦不发起跳页，避免加载时输入框失焦又退回第一页。后台刷新不禁用正在输入的页码。搜索框按回车或搜索按钮提交，清空时立即清除查询。角色、状态、考试和场次过滤沿所属接口限定；身份不能由查询参数指定。

## 摘要与选择框

首页和大屏保持最多8条学生摘要，提供“查看全部”，进入带当前场次条件的实时跟踪。模块摘要最多8组，统计总量仍使用完整授权范围。跟踪的在线数按当前筛选范围去重统计，不由当前页累计。

学生、场次、模板和问题队列的学生筛选均支持分页搜索。单选项可由同一接口在当前搜索/页之外单独返回，仍检查原权限、角色和用途条件；失效选项清空，不自动替换成别人。初次必填单选可默认首项；学生/老师多选默认空，跨页/搜索保留选中ID与名称，分别最多100/32人，表单只提交选中项。多选列表收进搜索下拉框，批量创建和调整归[场次分配](managed-exam-allocations.md)。

学生考试记录的分页、搜索不参与自动入场判断。服务器另从完整本人范围返回最多两个可进入考试，用于判定是否只有一场；待处理考试数量也独立统计，并排除当前查看的考试。用户主动查看历史或待处理列表时，不被自动入场拉回。问题提醒在下一次确认结果到达前保留，不能因翻页而消失。

新版学生请求显式携带`entryState=1`，读取服务端按当前时间和场次/分配状态计算的入场状态，不用手机时钟判断按钮或过期。未携带参数的旧接口保持旧字段，避免已打开的旧页面被严格契约拒绝；新版读取旧快照时仅依据已有明确状态及available列表降级，不假定本机时间正确。准备开始弹窗只保存安排ID，每次成功同步重新核对；撤回或失效后关闭，恢复安排可重新提示。

待处理题仍使用每页30条的游标分页及学生/场次/模块文本搜索；空末页回退和看板场次传递归[问题队列](managed-exam-attention.md)。选择器不依赖截断的分配列表。题目导航属于固定考试题位，不使用管理列表分页；角色权限页是固定说明。

## 验收边界

[隔离回归](../../apps/exam-web/src/server/managed.integration.test.ts)使用超过旧上限的合成数据，覆盖权限、总数、搜索转义、选中项、跨页老师多选、当前考试/全局提醒、末页收缩和迟到请求。命令、失败及复测见[验收记录](../postmortem/2026-11-04-managed-list-pagination.md)。不把分页通过当作数据库百万级性能或真实用户负载保证。
