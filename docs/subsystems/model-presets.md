# 整组模型配置预设

本地Web环境设置支持具名预设，范围仅为解题、校验、备用三组模型、各自参数和服务端密钥；不包含考试或并发。载入只改变编辑草稿，另存不改变生效配置，启用直接应用已保存的整组模型并轮换令牌，不请求模型。已有预设不覆盖，移除须确认；生效配置独立保存，删除来源预设不影响当前配置。容量与字段见[契约](../../packages/contracts/src/local.ts)。

浏览器只获取预设名称、标识和模型参数，密钥留在Node侧。载入的草稿通过预设标识引用来源密钥，保存和连接测试均检查同地址、同供应商；更换服务须显式新密钥，失效预设要求刷新。所有预设变更与活动任务、配置保存、上游调用互斥；超时不自动重放。Android/iOS、普通手工Web和未提供能力标识的旧服务没有此入口。持久化操作见[Web指南](../cookbook/local-web.md)，选择原因见[预设决策](../../.agents/notes/implemented/architecture/2026-10-10-web-model-presets.md)。
