# 0.1.69 真机动画与交互验收

2026-10-03，用户连接手机后实测。设备为 iQOO Neo9 / vivo V2338A、Android 16、1260×2800。使用 Windows ADB（WSL 的 Linux ADB 无 USB 设备），保留本机资料覆盖升级；原 0.1.62，共 149 道题、6 个批次。没有提交新解题、追问、校验或付费调用。

## 发现与修复

0.1.68 同组切题的系统帧耗时较旧版下降，但录屏仍复现正文瞬时空白。前 15 秒逐解码帧扫描正文区域（630×1400 视频，x=30…599，y=390…1239，缩小至 114×170 灰度，低于 170 的像素占比不足 0.3%）在 399 帧中命中 8 帧；已查看连续画面，确认不是题文本本来为空。0.1.62 同组 416 帧未命中。抽样检查会漏掉短帧，因此最终使用全部解码帧，不能只凭截图或系统 jank 数字判断。

`apps/mobile/src/dom/answer-document.tsx` 原先在 React effect 中立即通知就绪，外层两次 React Native requestAnimationFrame 不能代表 WebView 的 Chromium 已绘制。第一步在文档内部跨两次浏览器帧后通知；卸载/载荷改变取消旧回调，仍不等待可能挂起的字体。原生首次高度测量、旧页保持及十秒失败回退继续保留。

中间包真机仍有白帧：同组 439 帧命中 5 帧，另一次快速切换 749 帧命中 8 帧。这说明 DOM 绘制时序不是完整原因，原生页面开始移动时的合成层也需要验证；未将中间包声明为修复成功。

原生纹理缓存候选包也未通过（354 个解码帧中 9 帧命中，P95 38ms），已撤回额外 GPU 纹理缓存。改用 elevation 的候选同样失败，亦已撤回。

`question-pager.tsx` 当前调整为 Android 页面 zIndex 始终为 0，非活动页保持完整布局、透明且不可交互；当前页与离场页保持不透明，并延续原生位移动画。这样切题不再改变 Fabric 子视图顺序。Web / iOS 保留原有层级方式，没有新增依赖或扩大页面缓存。安装的 RN 0.86.3 `ConcreteViewShadowNode.h` 将 zIndex 作为 orderIndex；相关背景见 [RN View Style Props](https://reactnative.dev/docs/0.86/view-style-props#zindex)。

固定层级版本两次完整录屏（320 帧和 416 帧）均未命中整块白帧，但人工查看最低墨迹帧仍发现滑入新题的一部分短暂未绘制，不能把整块检测通过宣传为所有白帧已消除。继续增加原生绘制确认：

- `plugins/solve-background/SolveDocumentModule.kt` 调用 Android [postVisualStateCallback](https://developer.android.com/reference/android/webkit/WebView#postVisualStateCallback(long,android.webkit.WebView.VisualStateCallback))，在原生首次布局及文档提交之后确认下一次绘制可展示内容。最多 8 个待确认任务，5 秒超时，取消和模块卸载释放 Promise/计时器；迟到回调忽略。
- 原生回调单独启用仍有滑入局部空白，故仅对当前/请求目标题启用短时 `offscreenPreRaster`，单页请求面积不超过 1200 万像素、同时不超过 2400 万像素；回调后 1.2 秒恢复原设置，取消、超时及卸载提前释放。大于面积限制的文档继续原生就绪确认，不作无限预绘制。
- `components/document-paint.ts` 与 `answer-panel.tsx` 使用已验证的 WebView 原生标签等待回调。读取不到标签仍由现有十秒文档期限兜底，原生错误走已有文字回退，不能伪装绘制完成。Web / iOS 保持原布局帧路径。
- `plugins/with-solve-background.cjs` 与原有原生包只增加这个文档模块，不给 DOM 开启 Expo 原生桥，不新增网络或文件能力。

`scripts/test-android-document.mjs` 冻结浏览器帧，验证提交及测量后仍未就绪，释放两帧后才就绪，字体 promise 始终不完成。旧 0.1.68 在此断言失败，0.1.69 通过。此检查验证消息时序，不替代原生合成器验收。

`scripts/test-android-pager.mjs` 兼容 Android 16 的 topResumedActivity，并为 Windows adb 的录屏拉取转换 Windows 路径。
