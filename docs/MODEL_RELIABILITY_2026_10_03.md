# 模型失败诊断与成文约束改进 — 2026-10-03

接续[历史恢复复审](RELIABILITY_REVIEW_2026_10_03.md)。本轮处理请求失败提示、设备工具阶段结束与格式修复、英文成文提示冲突。未更换模型或升级依赖，未扩大工具权限、120 秒预算或模型轮数，不添加自动重试或 fallback。

## 实现

- `packages/contracts/src/agent.ts` 增加安全目录错误码 `MODEL_REQUEST_REJECTED` 和 `MODEL_RATE_LIMITED`。设备 HTTP 400/413/422 等请求拒绝与 429 限流分别呈现可操作提示；原有鉴权、额度、404 与服务不可用路径保留。保留旧目录文案和旧错误记录的可读性，不将供应商正文或密钥作为错误消息。
- `packages/agent/src/pi/mobile.ts` 保留 Pi 自己的循环，在最终作答时同时清空工具列表并发送锁定 SDK 0.85.1 已支持的 `toolChoice:'none'`（线上请求为 `tool_choice`）。Chat Completions 与 Responses 都覆盖；已有工具调用及结果历史仍保留。一次格式修复也禁用工具，不重新开放工具阶段。不服从最终作答要求时停止，非额度原因不再误报成工具次数用尽。
- 诊断契约新增可选 `toolStopReason`，只包含固定枚举：重复调用、连续工具错误、额度、剩余时间、格式修复。设置页保留连接测试的分类错误，诊断页显示工具退出原因。
- 保留后端 `openai-phase.ts` 同步映射请求拒绝和限流，避免将这两类故障统一标成内部错误。
- `SYSTEM.md`、`VERIFIER.md` 与 TARA 受审参考明确：英文作文的 `answer` 只含完整英文文章，优先于通用中文解释和加粗结果格式；不附中文总结、译文、额外点评或模型自报词数。600–700 词是为既有 750 词上限留余量的生成建议，不是新的官方规则。未添加官方词数判定器或作文评分器。

公共记录仍为 schemaVersion 1，新错误码及可选诊断字段是兼容已有记录的扩展，无需重写已有数据。新版读取旧记录；旧版程序不能保证识别新增错误码或导入含新增诊断字段的备份。
