# Android 后台解题与失败诊断验收

2026-09-17，版本 0.1.14 / versionCode 15。授权及设计见[ADR 0014](adr/0014-android-background-solving.md)。

## 已确认的原因

此前 AppState 进入后台直接调用 `engine.cancel()`，因此息屏或切应用会主动取消任务。旧记录没有取消来源，无法单凭记录断言第一次一定由息屏触发。

第二次旧记录只有 `MODEL_OUTPUT_INVALID`。离线探针已确认 HTTP 401/503、断网、输出截断、JSON 缺字段均可能被旧路径归为同一错误；原始响应没有保存，不能事后编造具体原因。见[原始诊断](RECENT_FAILURE_REVIEW_2026-09-17.md)。

## 本轮修改

- 原生前台服务与有时限唤醒锁，Android 切后台不再主动取消，保存结果后释放资源。
- 原生任务/阶段超时，保留 120 秒总预算及 20 秒校验时限。
- 本地脱敏诊断及失败记录“诊断详情”；HTTP/网络错误保留真实业务分类。
- JSON 缺字段可使用已有的一次格式修复机会，修复后照常进行独立校验。

用户解锁后，第三题新结果显示“模型独立校验通过”，真实图文WebView正常，无加载失败兜底。诊断显示Solver连续6次请求均HTTP200，24.5秒正常stop，输出2496 Token；独立Verifier完成PASS。结合0.2～31.5秒的全部息屏采样，确认此次真实任务在息屏状态完成并保存，未靠唤醒后恢复才结束。
