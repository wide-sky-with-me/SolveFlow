# 默认考试类型与模型往返优化（0.1.38）

2026-09-21，范围与兼容见 [ADR 0017](adr/0017-exam-default-and-preload.md)。

首次进入空题页可点击“配置模型与考试类型”，或通过“我的 → 设置”选择 SAT、ACT、AP、未指定。保存后相机和相册中的新题采用该类型；旧题继续使用创建时的类型，升级前无类型的题目保持未指定。题目保存、重开、追问、按需操作与本地导出沿用该字段。

同页可选择 Chat Completions / Responses。现有配置不会自动切换；要求 Responses 工具协议的模型需手动选择 Responses，Base URL 不填写接口尾段。服务默认不强制关闭推理。设备真实调用还取决于服务自身的图片、工具和跨域支持。

## 对照数据与范围

12 题、前后各两次，共 48 次正式解题。双方均指定相同考试类型、GPT-6 Astra、同一 DMX 服务、Responses、服务默认思考、空历史、独立 UUID、简洁答案和手动校验。每次 120 秒、输出上限 16384，主机 Node 并发上限 2。按题/重复交替先后顺序；全部结果均计入耗时，失败不隐藏。

基线为修改前冻结的移动适配器与资源，资源 SHA256 `42b88e9e90db9eb1fffbf3d76010aa71ae277c3c9a948a016f7243dca7c16f71`；优化后走正式 `solveOnDevice`，预先提供通用考试和对应考试规则。模型、图像与解题输出约束保持一致。

- SAT：此前已独立核对的 8 张手机错题原图；不是完整试卷或随机抽样。
- ACT：公开 [Preparing for the ACT 2024–2025](https://www.act.org/content/dam/act/unsecured/documents/Preparing-for-the-ACT-24-25.pdf)，Form 2176CPRE 数学第 9、28 题，题页 27、29，答案页 66、67。使用 PDF 裁图，覆盖相似三角形和立体格子读图。

ACT/AP 截图不冒充手机照片，未经透视、模糊等处理。原图、原始结果与评分明细只保留在 `.runtime/exam-preload-review/`，不随源码或 APK 发布。真实手机照片、手机网络与原生 Responses 流仍待用户连接设备验收。

SAT 的首轮从请求两份考试资源改为直接答题，16 次均由两次 HTTP 减为一次。ACT 第 9 题优化后两次均另读 math 并调用 calculate，增加了往返；第 28 题总往返相同，时间仍有波动。AP 第 3 题由三次减为两次，但其中一次仍更慢；第 4 题两次均由两次减为一次。这次只消除了已知考试规则的必要读取，不限制正常数学工具调用，也没有为了计时关闭思考或省掉论证。

SAT/ACT 不只核对选项：人工检查了非根类蔬菜图例、语法句界、补角、指数单位及立体格子计数。AP 第 3、4 题的八份结果逐小问对照官方评分点，每份均满足 9/9 核对点；单位、连续性及介值条件、积分原函数、凹凸性与全区间最小值论证均保留。这是开发核对，不能替代官方阅卷或推广为整卷分数。
