# 历史资料政策

管理改造采用原路径归档：现有大写命名设计/操作/验收文档及 `docs/adr/` 保留文件名、内容和既有链接。它们记录对应日期的计划、授权、取舍和测试，不能作为当前系统的完整规范。

[docs-policy.json](../../scripts/docs-policy.json) 的 `frozen` 表保存这些文件的 SHA-256。检查器要求文件存在且内容相同，不给新文档自动登记例外；因此归档不会继续追加新规则或测试流水账。旧文档已有失效引用保留原貌，当前文档的新链接必须能解析。

新增或纠正行为写入当前文档，新的长期决策进入 `.agents/notes/`，后续事故/验收进入 `postmortem/`。真正需要修订历史资料时，先说明原因与证据并显式审查冻结清单的变化，不用脚本自动刷新哈希。

根规范迁移前的完整内容另保存在 [快照](2026-10-03-development-rules.md)，用于核对规则是否遗漏；现行入口是 [AGENTS.md](../../AGENTS.md) 和 [架构](../architecture.md)。
