# 批量解题验收记录

2026-09-21，版本0.1.39（Android versionCode 40）。用户授权实现并付费进一步测试；决策见 [ADR 0018](adr/0018-batch-solving.md)。

## 已实现

- 拍照页“批量解题”入口，连续快门不离开相机；规范化并保存后立即入队，相册可逐张加入。
- 同时最多解3张，每张自动独立核验，每批最多100张。每次执行保留120秒预算、一次修正上限。
- 拍摄序号固定，完成顺序不改变题序。原题号写入可选 `problem.sourceNumber`，在题干和历史搜索中展示；旧记录不伪造回填。
- 历史分“单独拍照”“批量记录”，批量按组打开/删除；结果复用题目导航、原图缩放、追问、更正、按需详细步骤和知识点。
- 本机最多500张，不自动驱逐旧记录。队列只保存ID，页面仅加载当前照片，导出继续受768 MiB限制。
- Android后台按runId管理截止时间与阶段计时器。单题结束/超时不终止其他任务。重启不自动重放外部调用，可手动继续待解题或重试未完成。
