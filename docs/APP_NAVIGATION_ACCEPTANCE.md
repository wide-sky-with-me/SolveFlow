# 三入口导航与紧凑解答界面（2026-09-16）

用户确认底部三个入口：题目（当前题目/历史题目）、居中拍照、我的（设置/使用说明）。0.1.5 根据后续反馈重做图标与开屏，压低底栏，简化答案层级并改善超宽公式阅读。

## 行为

- 移除顶部品牌栏；题目页保留当前/历史切换。题目卡片去掉“题目与解答”“答案与解析”，按题目、答案、详细步骤、知识点显示，多题仍按题分组。
- 模型校验通过提示降为正文下方小字；未验证警告仍显示在答案之前，失败、澄清、更正和追问保留必要语义。
- 底栏主体约52dp（另加系统安全区），拍照按钮44dp，触控区域至少44dp。中央按钮直接打开相机；取消返回原页，不丢题目或草稿。
- “我的”集中模型设置、使用说明、本机题目数量及历史入口。不引入账号、云同步或未实现功能。
- 三页保留挂载状态，切换不丢未发送追问；运行中的Agent继续执行，期间禁用模型设置和拍新题。
- 公式采用从左开始的独立横向容器；轻微超宽适度缩小，最小保留82%字号；更长公式显示左右滑动提示。字体加载、容器宽度变化后重新测量，卸载清理观察器。行内超长公式同样限制在容器宽度内。
- 删除渲染层无声的8000字符切片；输入仍受既有共享协议限制。当前协议字段上限低于该切片值，不能认定它是用户此次截断原因。
- 新图标为书页与负形勾；开屏图标72dp、轻微上移和淡出，移除光晕、标语与大字。380ms入场与初始化并行，恢复完成后220ms淡出；遵守减少动态效果。原生开屏等RN图片解码后直接交接，避免两张图标交叠。
