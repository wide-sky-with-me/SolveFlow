# 历史序号、保存时间与原图缩放（2026-09-20）

用户要求历史记录增加序号、保存时间显示小时和秒数，并让原图支持双指放大缩小。本次沿用RN组件和现有依赖，不改变模型、题图文件或本地存储结构。

## 行为与实现

- 历史按当前列表顺序显示“序号 1、2、3…”，跨页连续；收藏列表按筛选后的列表编号，增删后重新编号。序号是列表位置，不是试卷题号或永久记录ID。
- 保存时间使用原记录`createdAt`，按设备本地时区显示`YYYY-MM-DD HH:mm:ss`，24小时制。打开、收藏和重新解答不改变此时间。
- DOM历史桥接增加可选`offset`，缺省0，保留schemaVersion 1兼容旧载荷。正常列表20条/页，原生降级列表10条/页，均支持跨页编号及完整时间。
- “查看原图”和解题前“放大题图”共用原图查看器。打开时完整适应可用区域，双指以触点中心缩放，范围为相对适应尺寸的1～4倍（100%～400%），放大后单指拖动；抬起/增加手指重新建立手势基准，避免位置跳变。
- 拖动受图片边缘约束，图片小于视口的轴保持居中；缩回1倍复位。关闭后重新打开、更换图片或视口尺寸变化时重新适应。桌面支持鼠标拖动，保留可通过键盘和屏幕阅读器操作的放大、缩小、适应屏幕和关闭按钮。
- 只在Web图片手势区域禁用浏览器默认触摸缩放，避免放大整页；其他页面滚动不变。原题局部插图和模型生成图示仍保留各自现有展示方式。

实现入口：`packages/client/src/history-payload.ts`、`apps/mobile/src/components/history-panel.tsx`、`history-fallback.tsx`、`apps/mobile/src/dom/history-document.tsx`、`apps/mobile/src/components/image-viewer.tsx`、`image-zoom.ts`。
