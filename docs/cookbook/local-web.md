# 本地 Web 运行与更新

从仓库根目录执行，Node/pnpm版本及命令以[根清单](../../package.json)为准。本指南用于开发与回环服务；公网部署、浏览器兼容缺口见[发布状态](../project-status.md)。原生应用不读取根`.env`。

## 选择入口

| 用途 | 入口 | 模型配置 |
| --- | --- | --- |
| 开发界面 | `pnpm dev`，按终端提示打开Web | 应用手工设置，模型服务需允许CORS |
| 使用构建产物 | `pnpm build:web`后`pnpm start` | 未启用环境桥接时仍为手工设置 |
| 本地复用`.env` | 同上，显式启用`WEB_ENV_ENABLED=true` | 固定角色由Node代理，真实密钥不进入浏览器 |

`pnpm dev`的Expo入口不使用Node环境桥接。`pnpm start`固定监听`http://127.0.0.1:3100`，只提供`apps/mobile/dist`中的已有产物，不自动构建或请求模型；开发地址以实际输出为准。

## 构建与启动

```sh
pnpm install --frozen-lockfile
pnpm build:web
pnpm start
```

依赖未变且已经安装时可跳过安装。成功导出不是APK或iOS原生编译；启动后应能打开页面、进入设置及查看历史。页面加载成功不代表模型连接或真实答题通过。

## 环境配置

在已有根`.env`中按[安全示例](../../.env.example)填写实际服务与密钥，再显式启用桥接；不要覆盖已有服务配置。支持的角色字段、优先级和密钥边界见[设备运行](../subsystems/device-runtime.md#模型与考试)，读取规则以[加载器](../../scripts/web-env.mjs)为准。

解题、核验、备用各有独立配置；备用只有配置模型后才启用。环境模式使用`.env`显式模型值，不自动套用界面预设。非流式示例：

```dotenv
WEB_ENV_ENABLED=true
WEB_ENV_VERIFIER_STREAMING=false
WEB_ENV_BACKUP_STREAMING=false
```

以上仅展示开关，不包含可用凭据或完整模型配置。不同地址或供应商须提供角色自己的密钥；环境模式下模型字段由`.env`管理，考试与并发仍可在界面保存。普通手工模式的Web密钥仅在内存，刷新需重填；环境模式刷新取得临时角色令牌。

## 更新与重启

1. 先确认界面中的答题、校验、备用接手和加入图片任务均已结束；如需停止，明确取消并等待收尾。保存失败先处理已有结果。不能只看socket或最后一条代理日志判断空闲。
2. 修改源码后重新`pnpm build:web`；仅改`.env`无需重建。构建产物替换及服务重启会影响已打开页面，操作前核对自己的PID/路径，保留数据和旧产物以便回退。
3. 在自己的服务终端用Ctrl+C停止，再`pnpm start`加载新环境。不要停止其他项目服务或清除用户IndexedDB。
4. 刷新网页加载新脚本与配置；必要时Ctrl+F5。核对设置的模型、协议与响应方式。刷新或重启不会自动重放失败的付费请求；未确认题目需用户手动校验或重新解答。

若模型参数没有变化，本地未派发的401可按已有规则续取令牌；参数变化会要求刷新。不要把供应商401按令牌续取处理。完整行为见设备运行。

## 失败处理

| 现象 | 检查方向 |
| --- | --- |
| 页面打不开、端口占用 | 确认构建目录、服务日志与本次PID，不借用未知3100服务 |
| 模型字段不可编辑 | 检查是否启用`.env`模式；手工与环境模式的控制位置不同 |
| CAPABILITY_DENIED或401/403 | 区分本地令牌与供应商鉴权；核对配置、按提示刷新，不输出密钥 |
| MODEL_UNAVAILABLE | 查HTTP状态、网络分类及模型是否可用，不仅凭此代码断定模型名错误 |
| MODEL_TIMEOUT | 查题内诊断的角色、阶段窗口、响应和工具耗时，见[模型传输](../subsystems/model-transport.md#脱敏诊断) |
| 已有答案但未校验 | 答案已保存，校验失败不等于答案一定错误；按需手动校验或重解 |
| 历史读取或结果保存失败 | 先按[存储恢复](../subsystems/storage.md)处理，勿清库或反复派发模型 |

浏览器自动化使用自己启动的隔离服务、假模型和新浏览器数据目录，按[测试规则](../testing.md#浏览器)执行，不拿用户服务作故障注入。记录实际命令、HTTP/进程结果及未验范围，结束后清理本轮测试服务。
