## 方法

沿用 [上次模拟拍照评测](EXAM_PHOTO_EVAL_2026_09_28.md)：PDF 原始像素按题裁切，保留题干、图表和原选项；TARA 指南只截题目框，排除相邻答案及解析。每三题一题中度扰动，其余轻度，按 ID 固定随机种子。轻度透视参数 0.018、模糊 0.3 px、JPEG 88；中度 0.045、0.6 px、JPEG 78。另存 JPEG 92 清晰对照，最长边 2048 px、无 EXIF。

每题独立会话，主机 Node 运行生产 `solveOnDevice` + Pi loop，`verificationMode=automatic`、`answerMode=brief`，生产预算与权限保持。首批 3 道以 3 并发完成；剩余 638 道以 6 并发测试，与上次全量评测设置一致。不是手机相机、UI、后台生命周期或手机吞吐测试。

固定配置：`https://www.dmxapi.cn/v1`、`qwen3.8-flash`、Chat Completions、服务默认思考、context 1,000,000、max_tokens 16,384；同模型独立校验，无自动 fallback。每条结果记录代码、受审资源、模型配置、图片哈希、并发数、HTTP 状态和服务报告用量；不记录密钥或内部 thinking。

只取首次有效图片运行结果，工具上限、HTTP 错误、结构错误、超时和澄清均保留，未作答按零计。选择题通过独立官方答案文件核对 `selectedOptions`，不使用模型自评；答案文件不进入模型请求。清晰图对照不会覆盖主测成绩。TARA 写作只做内容与词数检查，不编造官方分数。

公开题可能被模型训练见过，无法排除训练数据污染。重复内容、模拟图像扰动和同模型校验均限制结果可推广性。
