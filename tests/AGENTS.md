# AGENTS.md — 测试证据

按 [测试规则](../docs/testing.md) 选择场景和实际命令。

- 默认 fake/离线；真实模型与费用必须 opt-in，继承既有授权和预算，不在 CI 偷跑付费请求。
- 使用合成、许可公开或明确获准题目；真值有来源，数学等价/容差/单位明确，不只用另一 LLM 判卷。
- 覆盖成功与失败、取消/迟到、并发、损坏、权限和释放；不删断言、不降低验收阈值。
- E2E 使用隔离存储与准确测试 URL。浏览器移动视口不等于手机，模型夹具不等于真实接通。
- 测试服务记录本次 PID/URL 并清理，不借用未知端口或擅自启动替代服务；真机测试保护已有题图、模型配置和系统设置，故障注入只用隔离数据。
- 记录命令、退出码、环境、样本数与未验证项；重复复测不累计为新场景，失败成绩保留。
